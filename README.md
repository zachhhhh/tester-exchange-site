# Tester Exchange

**Free tester exchange for Google Play's closed-testing requirement (12 testers × 14 days).**

New personal Google Play developer accounts must run a closed test with at least 12 testers for 14 days
before they can publish to production, and Google reviews whether testers really used the app.
Tester Exchange lets developers test each other's apps: earn credits by testing, spend them on testers for yours.
A companion Android app verifies daily use on each tester's phone.
