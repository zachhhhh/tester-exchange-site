Android-App mit Claude Code gebaut? Hol dir deine 12 Tester für 14 Tage

Aktualisiert im November 2026

Claude Code kann deine Android-App schreiben und bauen, aber die 12 echten Tester, die Google Play verlangt, kann es nicht liefern. Wurde dein persönliches Entwicklerkonto nach dem 13. November 2023 erstellt, musst du einen geschlossenen Test mit mindestens 12 Testern durchführen, die 14 Tage am Stück angemeldet sind, bevor du Produktion beantragen kannst. Diese Anleitung behandelt das Bauen des Bundles, den Start des geschlossenen Tests, die Beschaffung der Tester (zuerst kostenlos, dann bezahlt) und die Verbindung von Tester Exchange mit Claude Code, damit der Agent den Papierkram erledigt.

1. Das Release-Bundle (.aab) bauen

  1. Bitte den Agenten von Claude Code, das Release-Signing in der build.gradle.kts deines Moduls einzurichten (ein signingConfigs-Block mit storeFile, storePassword, keyAlias und keyPassword, gesetzt für den Build-Typ release). Halte Passwörter aus Git heraus (Android-Build-Doku: https://developer.android.com/build/building-cmdline).
  2. Führe ./gradlew bundleRelease im Terminal aus. Gradle baut und signiert das Bundle; die .aab liegt normalerweise unter app/build/outputs/bundle/release/, prüfe aber die Ausgabe deines eigenen Builds.
  3. Erstelle mit keytool einen Keystore, falls du keinen hast, und sichere ihn. Google Play App Signing wird beim Hochladen deines ersten Releases angeboten.

2. Geschlossenen Test in der Play Console starten

  1. Öffne Testen und veröffentlichen > Testen > Geschlossener Test und wähle dann Track erstellen (oder Track verwalten).
  2. Klicke auf Neuen Release erstellen, lade die .aab hoch, vergib einen Release-Namen und Hinweise, speichere als Entwurf, klicke auf Weiter und dann auf Einführung starten (Schritte von https://support.google.com/googleplay/android-developer/answer/9859348).
  3. Erledige zuerst die Aufgaben zur App-Einrichtung im Dashboard, sonst bleibt die Release-Schaltfläche deaktiviert.

3. Deine 12 Tester bekommen: erst kostenlos, dann bezahlt

  • Kostenloser Weg: Öffne https://testerexchange.com/earn auf deinem Handy und teste die Apps, die dir zugewiesen werden. Jede App, die du testest, bringt einen Tester zu deiner.
  • Bezahlter Weg: Zahle einmal, und die Tester werden automatisch zugewiesen. Die aktuellen Preise stehen unter https://testerexchange.com/llms.txt.
  • Frage 15 Tester statt 12 an, damit ein Ausfall dich nicht unter Googles Minimum drückt.

4. Tester Exchange mit Claude Code verbinden (optional)

Erstelle zuerst einen API key unter https://testerexchange.com/api. Führe dann diesen Befehl einmal in deinem Terminal aus und ersetze tx_YOUR_TOKEN durch deinen Schlüssel (der Befehl ist der unter https://testerexchange.com/agents/ aufgeführte):

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Der Server ist reines MCP über Streamable HTTP ohne OAuth; die öffentlichen Tools (about, pricing, platform_stats) funktionieren ohne Schlüssel. Halte den Schlüssel aus git und aus gemeinsam genutzten Konfigurationsdateien heraus.

5. Den Agenten fragen

  • „Nutze Tester Exchange, um 15 Tester für com.example.app zu bekommen, und sag mir, was ich in der Play Console tun muss.“
  • „Prüfe meine Tester-Exchange-Kampagne für com.example.app und sag mir, wie viele Tester gestern aktiv waren.“
  • „Hol den Kampagnenbericht und entwirf meine Antworten für den Produktionszugriff anhand der echten Zahlen.“

Das wichtigste Tool ist get_testers: Es fügt die App hinzu, öffnet ihren Test und liefert die Schritte zurück, die nur ein Mensch erledigen kann, etwa die Google-Gruppe der Tester in der Play Console hinzuzufügen. Der Agent kann nicht für dich bezahlen oder auf Produktionszugriff beantragen klicken.

Kein MCP? Nutze die HTTP-API

POST an https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call mit dem öffentlichen apikey-Header, der unter https://testerexchange.com/agents/ steht, und dem Body {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}}. Das Schema findest du unter https://testerexchange.com/openapi.json. Weitere Tools: https://testerexchange.com/guide/ai-builders/.

Häufig gestellte Fragen

Kann Claude Code den 14-Tage-Test für mich abschließen?

Nein. Die 14 Tage erfordern echte Menschen, die deine App auf ihren eigenen Android-Handys nutzen. Claude Code kann die App bauen und die Einrichtung übernehmen.

Ist Tester Exchange eine offizielle Claude Code-Integration?

Nein. Es ist ein unabhängiger Dienst, der mit jedem Client funktioniert, der Remote-MCP über HTTP unterstützt, was bei Claude Code der Fall ist.

Wohin kommt das AAB?

Lade es in einen Release des geschlossenen Tests in der Play Console hoch und füge dann die Google-Gruppe oder E-Mail-Liste deiner Tester zu diesem Track hinzu.

Gibt es einen kostenlosen Weg zu den 12 Testern?

Ja. Teste die Apps anderer Entwickler unter https://testerexchange.com/earn; jede App, die du testest, bringt einen Tester zu deiner.
