Tester Exchange Tester Exchange ਖੋਲ੍ਹੋ

Cursor ਨਾਲ ਆਪਣੀ Android ਐਪ ਬਣਾਈ? 14 ਦਿਨਾਂ ਲਈ ਆਪਣੇ 12 ਟੈਸਟਰ ਪ੍ਰਾਪਤ ਕਰੋ

ਨਵੰਬਰ 2026 ਵਿੱਚ ਅੱਪਡੇਟ ਕੀਤਾ

Cursor ਤੁਹਾਡੀ Android ਐਪ ਲਿਖ ਅਤੇ ਬਣਾ ਸਕਦਾ ਹੈ, ਪਰ Google Play ਨੂੰ ਲੋੜੀਂਦੇ 12 ਅਸਲੀ ਟੈਸਟਰ ਨਹੀਂ ਦੇ ਸਕਦਾ। ਜੇ ਤੁਹਾਡਾ ਪਰਸਨਲ ਡਿਵੈਲਪਰ ਖਾਤਾ 13 ਨਵੰਬਰ 2023 ਤੋਂ ਬਾਅਦ ਬਣਿਆ ਹੈ, ਤਾਂ ਪ੍ਰੋਡਕਸ਼ਨ ਲਈ ਅਰਜ਼ੀ ਦੇਣ ਤੋਂ ਪਹਿਲਾਂ ਤੁਹਾਨੂੰ ਘੱਟੋ-ਘੱਟ 12 ਟੈਸਟਰਾਂ ਨਾਲ ਲਗਾਤਾਰ 14 ਦਿਨ ਕਲੋਜ਼ਡ ਟੈਸਟ ਚਲਾਉਣਾ ਪਵੇਗਾ। ਇਹ ਗਾਈਡ ਬੰਡਲ ਬਣਾਉਣ, ਕਲੋਜ਼ਡ ਟੈਸਟਿੰਗ ਸ਼ੁਰੂ ਕਰਨ, ਟੈਸਟਰ ਲੈਣ (ਪਹਿਲਾਂ ਮੁਫ਼ਤ, ਫਿਰ ਭੁਗਤਾਨ ਨਾਲ) ਅਤੇ Tester Exchange ਨੂੰ Cursor ਨਾਲ ਜੋੜਨ ਨੂੰ ਕਵਰ ਕਰਦੀ ਹੈ, ਤਾਂ ਜੋ ਏਜੰਟ ਕਾਗਜ਼ੀ ਕੰਮ ਕਰ ਸਕੇ।

ਅਸਲੀ ਲੋਕ 14 ਦਿਨ ਆਪਣੇ ਫ਼ੋਨਾਂ ਉੱਤੇ ਤੁਹਾਡੀ ਐਪ ਖੋਲ੍ਹਦੇ ਹਨ। ਇੱਕ ਵਾਰ ਭੁਗਤਾਨ ਕਰੋ, ਜਾਂ ਹੋਰ ਐਪਾਂ ਟੈਸਟ ਕਰਕੇ ਮੁਫ਼ਤ ਪਾਓ।12 testers ਲਓ
ਇਸ ਪੰਨੇ ਉੱਤੇ
  • 1. ਰਿਲੀਜ਼ ਬੰਡਲ (.aab) ਬਣਾਓ
  • 2. Play Console ਵਿੱਚ ਕਲੋਜ਼ਡ ਟੈਸਟਿੰਗ ਸ਼ੁਰੂ ਕਰੋ
  • 3. ਆਪਣੇ 12 ਟੈਸਟਰ ਪ੍ਰਾਪਤ ਕਰੋ: ਪਹਿਲਾਂ ਮੁਫ਼ਤ, ਫਿਰ ਭੁਗਤਾਨ ਨਾਲ
  • 4. Tester Exchange ਨੂੰ Cursor ਨਾਲ ਜੋੜੋ (ਵਿਕਲਪਿਕ)
  • 5. ਏਜੰਟ ਨੂੰ ਪੁੱਛੋ
  • MCP ਨਹੀਂ? HTTP API ਵਰਤੋ
  • ਅਕਸਰ ਪੁੱਛੇ ਜਾਂਦੇ ਸਵਾਲ

1. ਰਿਲੀਜ਼ ਬੰਡਲ (.aab) ਬਣਾਓ

  1. Cursor ਦੇ ਏਜੰਟ ਨੂੰ ਆਪਣੇ ਮਾਡਿਊਲ ਦੀ build.gradle.kts ਵਿੱਚ ਰਿਲੀਜ਼ ਸਾਈਨਿੰਗ ਸੰਰਚਿਤ ਕਰਨ ਲਈ ਕਹੋ (storeFile, storePassword, keyAlias ਅਤੇ keyPassword ਵਾਲਾ signingConfigs ਬਲਾਕ, release build type ਉੱਤੇ ਲਾਗੂ)। ਪਾਸਵਰਡ git ਤੋਂ ਬਾਹਰ ਰੱਖੋ (Android ਦੇ build ਦਸਤਾਵੇਜ਼: https://developer.android.com/build/building-cmdline)।
  2. ਟਰਮੀਨਲ ਵਿੱਚ ./gradlew bundleRelease ਚਲਾਓ। Gradle ਬੰਡਲ ਬਣਾਉਂਦਾ ਅਤੇ ਸਾਈਨ ਕਰਦਾ ਹੈ; .aab ਆਮ ਤੌਰ ਉੱਤੇ app/build/outputs/bundle/release/ ਹੇਠ ਦਿਸਦਾ ਹੈ, ਪਰ ਆਪਣੇ build ਆਊਟਪੁੱਟ ਦੀ ਜਾਂਚ ਕਰੋ।
  3. ਜੇ ਤੁਹਾਡੇ ਕੋਲ keystore ਨਹੀਂ ਹੈ ਤਾਂ keytool ਨਾਲ ਬਣਾਓ ਅਤੇ ਉਸਦਾ ਬੈਕਅੱਪ ਰੱਖੋ। ਜਦੋਂ ਤੁਸੀਂ ਪਹਿਲੀ ਰਿਲੀਜ਼ ਅੱਪਲੋਡ ਕਰਦੇ ਹੋ ਤਾਂ Google Play App Signing ਦੀ ਪੇਸ਼ਕਸ਼ ਹੁੰਦੀ ਹੈ।

2. Play Console ਵਿੱਚ ਕਲੋਜ਼ਡ ਟੈਸਟਿੰਗ ਸ਼ੁਰੂ ਕਰੋ

  1. Test and release > Testing > Closed testing ਖੋਲ੍ਹੋ, ਫਿਰ Create track (ਜਾਂ Manage track) ਚੁਣੋ।
  2. Create new release ਉੱਤੇ ਕਲਿੱਕ ਕਰੋ, .aab ਅੱਪਲੋਡ ਕਰੋ, ਰਿਲੀਜ਼ ਦਾ ਨਾਮ ਅਤੇ ਨੋਟ ਜੋੜੋ, Save as draft, Next, ਫਿਰ Start rollout (ਕਦਮ https://support.google.com/googleplay/android-developer/answer/9859348 ਤੋਂ)।
  3. ਪਹਿਲਾਂ Dashboard ਉੱਤੇ ਐਪ ਸੈੱਟਅੱਪ ਦੇ ਕੰਮ ਪੂਰੇ ਕਰੋ, ਨਹੀਂ ਤਾਂ ਰਿਲੀਜ਼ ਬਟਨ ਅਸਮਰੱਥ ਰਹਿੰਦਾ ਹੈ।

3. ਆਪਣੇ 12 ਟੈਸਟਰ ਪ੍ਰਾਪਤ ਕਰੋ: ਪਹਿਲਾਂ ਮੁਫ਼ਤ, ਫਿਰ ਭੁਗਤਾਨ ਨਾਲ

  • ਮੁਫ਼ਤ ਰਾਹ: ਆਪਣੇ ਫ਼ੋਨ ਉੱਤੇ https://testerexchange.com/earn ਖੋਲ੍ਹੋ ਅਤੇ ਤੁਹਾਨੂੰ ਦਿੱਤੀਆਂ ਐਪਾਂ ਟੈਸਟ ਕਰੋ। ਤੁਹਾਡੀ ਟੈਸਟ ਕੀਤੀ ਹਰ ਐਪ ਤੁਹਾਡੀ ਐਪ ਲਈ ਇੱਕ ਟੈਸਟਰ ਲਿਆਉਂਦੀ ਹੈ।
  • ਭੁਗਤਾਨ ਵਾਲਾ ਰਾਹ: ਇੱਕ ਵਾਰ ਭੁਗਤਾਨ ਕਰੋ ਅਤੇ ਟੈਸਟਰ ਆਪਣੇ ਆਪ ਦਿੱਤੇ ਜਾਂਦੇ ਹਨ। ਮੌਜੂਦਾ ਕੀਮਤਾਂ https://testerexchange.com/llms.txt ਉੱਤੇ ਦਿੱਤੀਆਂ ਹਨ।
  • 12 ਦੀ ਥਾਂ 15 ਟੈਸਟਰ ਮੰਗੋ, ਤਾਂ ਜੋ ਇੱਕ ਦੇ ਛੱਡ ਜਾਣ ਨਾਲ ਤੁਸੀਂ Google ਦੀ ਘੱਟੋ-ਘੱਟ ਹੱਦ ਤੋਂ ਹੇਠਾਂ ਨਾ ਆ ਜਾਓ।

4. Tester Exchange ਨੂੰ Cursor ਨਾਲ ਜੋੜੋ (ਵਿਕਲਪਿਕ)

ਪਹਿਲਾਂ https://testerexchange.com/api ਉੱਤੇ ਇੱਕ API ਕੁੰਜੀ ਬਣਾਓ। ਫਿਰ ਇਹ ਆਪਣੇ ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ .cursor/mcp.json ਵਿੱਚ, ਜਾਂ ਹਰ ਥਾਂ ਵਰਤਣ ਲਈ ~/.cursor/mcp.json ਵਿੱਚ ਪਾਓ (ਫ਼ਾਈਲ ਟਿਕਾਣੇ Cursor ਦੇ MCP ਦਸਤਾਵੇਜ਼ਾਂ ਤੋਂ, https://cursor.com/docs/context/mcp)। ਪਹਿਲਾਂ ਆਪਣੇ shell ਵਾਤਾਵਰਣ ਵਿੱਚ TESTER_EXCHANGE_KEY ਸੈੱਟ ਕਰੋ, ਤਾਂ ਜੋ ਕੁੰਜੀ commit ਨਾ ਹੋਵੇ:

{"mcpServers":{"tester-exchange":{"url":"https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp","headers":{"Authorization":"Bearer ${env:TESTER_EXCHANGE_KEY}"}}}}

Cursor, url ਅਤੇ headers ਖੇਤਰਾਂ ਵਿੱਚ ${env:NAME} ਨੂੰ ਹੱਲ ਕਰਦਾ ਹੈ। ਜੇ ਕੋਈ ਸਰਵਰ ਲੋਡ ਨਾ ਹੋਵੇ, ਤਾਂ Output ਪੈਨਲ ਖੋਲ੍ਹੋ ਅਤੇ MCP Logs ਚੁਣੋ। ਸਰਵਰ OAuth ਤੋਂ ਬਿਨਾਂ Streamable HTTP ਉੱਤੇ ਸਾਦਾ MCP ਹੈ; ਜਨਤਕ ਟੂਲ (about, pricing, platform_stats) ਕੁੰਜੀ ਤੋਂ ਬਿਨਾਂ ਕੰਮ ਕਰਦੇ ਹਨ।

5. ਏਜੰਟ ਨੂੰ ਪੁੱਛੋ

  • "Tester Exchange ਵਰਤ ਕੇ com.example.app ਲਈ 15 ਟੈਸਟਰ ਲੈ ਅਤੇ ਦੱਸ ਕਿ ਮੈਨੂੰ Play Console ਵਿੱਚ ਕੀ ਕਰਨਾ ਹੈ।"
  • "com.example.app ਲਈ ਮੇਰੀ Tester Exchange ਮੁਹਿੰਮ ਦੇਖ ਅਤੇ ਦੱਸ ਕਿ ਕੱਲ੍ਹ ਕਿੰਨੇ ਟੈਸਟਰ ਸਰਗਰਮ ਸਨ।"
  • "ਮੁਹਿੰਮ ਦੀ ਰਿਪੋਰਟ ਕੱਢ ਅਤੇ ਅਸਲੀ ਅੰਕੜਿਆਂ ਤੋਂ ਮੇਰੇ ਪ੍ਰੋਡਕਸ਼ਨ ਐਕਸੈਸ ਦੇ ਜਵਾਬਾਂ ਦਾ ਖਰੜਾ ਬਣਾ।"

ਮੁੱਖ ਟੂਲ get_testers ਹੈ: ਇਹ ਐਪ ਜੋੜਦਾ ਹੈ, ਉਸਦਾ ਟੈਸਟ ਖੋਲ੍ਹਦਾ ਹੈ ਅਤੇ ਸਿਰਫ਼ ਇਨਸਾਨ ਵੱਲੋਂ ਹੋਣ ਵਾਲੇ ਕਦਮ ਵਾਪਸ ਦਿੰਦਾ ਹੈ, ਜਿਵੇਂ Play Console ਵਿੱਚ ਟੈਸਟਰਾਂ ਦਾ Google Group ਜੋੜਨਾ। ਏਜੰਟ ਤੁਹਾਡੇ ਲਈ ਭੁਗਤਾਨ ਨਹੀਂ ਕਰ ਸਕਦਾ ਜਾਂ Apply for production ਉੱਤੇ ਕਲਿੱਕ ਨਹੀਂ ਕਰ ਸਕਦਾ।

MCP ਨਹੀਂ? HTTP API ਵਰਤੋ

https://testerexchange.com/agents/ ਉੱਤੇ ਦਿੱਤੇ ਜਨਤਕ apikey ਹੈਡਰ ਅਤੇ {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}} ਬਾਡੀ ਨਾਲ https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call ਉੱਤੇ POST ਕਰੋ। ਸਕੀਮਾ https://testerexchange.com/openapi.json ਉੱਤੇ ਹੈ। ਹੋਰ ਟੂਲ: https://testerexchange.com/guide/ai-builders/ ।

ਅਕਸਰ ਪੁੱਛੇ ਜਾਂਦੇ ਸਵਾਲ

ਕੀ Cursor ਮੇਰੇ ਲਈ 14 ਦਿਨਾਂ ਦਾ ਟੈਸਟ ਪੂਰਾ ਕਰ ਸਕਦਾ ਹੈ?

ਨਹੀਂ। 14 ਦਿਨਾਂ ਲਈ ਅਸਲੀ ਲੋਕਾਂ ਨੂੰ ਆਪਣੇ Android ਫ਼ੋਨਾਂ ਉੱਤੇ ਤੁਹਾਡੀ ਐਪ ਵਰਤਣੀ ਪੈਂਦੀ ਹੈ। Cursor ਐਪ ਬਣਾ ਸਕਦਾ ਹੈ ਅਤੇ ਸੈੱਟਅੱਪ ਚਲਾ ਸਕਦਾ ਹੈ।

ਕੀ Tester Exchange ਅਧਿਕਾਰਤ Cursor ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਹੈ?

ਨਹੀਂ। ਇਹ ਇੱਕ ਸੁਤੰਤਰ ਸੇਵਾ ਹੈ ਜੋ HTTP ਉੱਤੇ ਰਿਮੋਟ MCP ਦਾ ਸਮਰਥਨ ਕਰਨ ਵਾਲੇ ਕਿਸੇ ਵੀ ਕਲਾਇੰਟ ਨਾਲ ਚਲਦੀ ਹੈ, ਅਤੇ Cursor ਕਰਦਾ ਹੈ।

AAB ਕਿੱਥੇ ਜਾਂਦਾ ਹੈ?

ਇਸਨੂੰ Play Console ਵਿੱਚ ਕਲੋਜ਼ਡ ਟੈਸਟਿੰਗ ਰਿਲੀਜ਼ ਵਿੱਚ ਅੱਪਲੋਡ ਕਰੋ, ਫਿਰ ਉਸ ਟ੍ਰੈਕ ਉੱਤੇ ਆਪਣੇ ਟੈਸਟਰਾਂ ਦਾ Google Group ਜਾਂ ਈਮੇਲ ਸੂਚੀ ਜੋੜੋ।

ਕੀ 12 ਟੈਸਟਰ ਲੈਣ ਦਾ ਕੋਈ ਮੁਫ਼ਤ ਤਰੀਕਾ ਹੈ?

ਹਾਂ। https://testerexchange.com/earn ਉੱਤੇ ਹੋਰ ਡਿਵੈਲਪਰਾਂ ਦੀਆਂ ਐਪਾਂ ਟੈਸਟ ਕਰੋ; ਤੁਹਾਡੀ ਟੈਸਟ ਕੀਤੀ ਹਰ ਐਪ ਤੁਹਾਡੀ ਐਪ ਲਈ ਇੱਕ ਟੈਸਟਰ ਲਿਆਉਂਦੀ ਹੈ।
