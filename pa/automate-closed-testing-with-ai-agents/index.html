AI agents ਨਾਲ Google Play closed testing ਆਟੋਮੇਟ ਕਰੋ

ਨਵੰਬਰ 2026 ਵਿੱਚ ਅੱਪਡੇਟ ਕੀਤਾ

ਜੇ ਤੁਸੀਂ ਪਹਿਲਾਂ ਹੀ AI agent ਨਾਲ ਕੋਡ ਸ਼ਿਪ ਕਰਦੇ ਹੋ, ਤਾਂ Google Play ਦੀ closed testing ਲੋੜ ਦਾ ਜ਼ਿਆਦਾਤਰ ਛੋਟਾ-ਮੋਟਾ ਕੰਮ ਵੀ ਉਸਨੂੰ ਸੌਂਪ ਸਕਦੇ ਹੋ: ਐਪ ਸੂਚੀਬੱਧ ਕਰਨਾ, testers ਲੱਭਣਾ, ਤਰੱਕੀ ਜਾਂਚਣਾ ਅਤੇ production access ਫਾਰਮ ਲਈ ਅੰਕੜੇ ਕੱਢਣਾ। ਇਸ ਲਈ Tester Exchange ਕੋਲ MCP ਸਰਵਰ, ਇੱਕ-endpoint ਵਾਲੀ HTTP API ਅਤੇ A2A agent card ਹੈ। ਇਹ ਗਾਈਡ ਦੱਸਦੀ ਹੈ ਕਿ Claude Code, Claude Desktop, Cursor ਅਤੇ ਹੋਰ clients ਨੂੰ ਕਿਵੇਂ ਜੋੜਨਾ ਹੈ, ਕੀ ਪੁੱਛਣਾ ਹੈ, ਅਤੇ ਉਹ ਕੰਮ ਕਿਹੜੇ ਹਨ ਜੋ ਕੋਈ agent ਤੁਹਾਡੇ ਲਈ ਨਹੀਂ ਕਰ ਸਕਦਾ।

ਅਸਲੀ ਲੋਕ 14 ਦਿਨ ਆਪਣੇ ਫ਼ੋਨਾਂ ਉੱਤੇ ਤੁਹਾਡੀ ਐਪ ਖੋਲ੍ਹਦੇ ਹਨ। ਇੱਕ ਵਾਰ ਭੁਗਤਾਨ ਕਰੋ, ਜਾਂ ਹੋਰ ਐਪਾਂ ਟੈਸਟ ਕਰਕੇ ਮੁਫ਼ਤ ਪਾਓ।12 testers ਲਓ

Agent ਕੀ ਕਰ ਸਕਦਾ ਹੈ ਅਤੇ ਕੀ ਨਹੀਂ

13 ਨਵੰਬਰ 2023 ਤੋਂ ਬਾਅਦ ਬਣੇ personal developer ਖਾਤਿਆਂ ਲਈ Google ਦੀ ਸ਼ਰਤ ਹੈ ਕਿ production ਲਈ ਅਰਜ਼ੀ ਦੇਣ ਤੋਂ ਪਹਿਲਾਂ ਘੱਟੋ-ਘੱਟ 12 testers ਲਗਾਤਾਰ 14 ਦਿਨ opt-in ਰਹਿਣ ਵਾਲਾ closed test ਚਲਾਇਆ ਜਾਵੇ। ਇਸ ਦੁਆਲੇ ਦਾ ਜ਼ਿਆਦਾਤਰ ਕੰਮ ਤਾਲਮੇਲ ਦਾ ਹੈ, ਜਿਸਨੂੰ agents ਚੰਗੀ ਤਰ੍ਹਾਂ ਸੰਭਾਲ ਲੈਂਦੇ ਹਨ।

  • Agent ਕਰ ਸਕਦਾ ਹੈ: ਤੁਹਾਡੀ ਐਪ ਜੋੜਨਾ, tester campaign ਖੋਲ੍ਹਣਾ, ਤੁਹਾਡੇ credits ਲਾਗੂ ਕਰਨਾ, ਕਿੰਨੇ testers ਸਰਗਰਮ ਹਨ ਇਹ ਵੇਖਣਾ, campaign ਨੂੰ ਰੋਕਣਾ ਜਾਂ ਬੰਦ ਕਰਨਾ, ਰੋਜ਼ਾਨਾ ਗਤੀਵਿਧੀ ਦੀ ਰਿਪੋਰਟ ਲਿਆਉਣਾ ਅਤੇ ਉਸ ਤੋਂ production access ਦੇ ਜਵਾਬਾਂ ਦਾ ਡਰਾਫ਼ਟ ਬਣਾਉਣ ਵਿੱਚ ਮਦਦ ਕਰਨਾ।
  • ਇਨਸਾਨ ਨੂੰ ਕਰਨਾ ਪਵੇਗਾ: Play Console ਵਿੱਚ closed track ਉੱਤੇ testers ਦਾ Google Group ਜੋੜਨਾ, release publish ਕਰਨਾ, credits ਦਾ ਭੁਗਤਾਨ ਕਰਨਾ (checkout ਹਮੇਸ਼ਾ ਕਿਸੇ ਵਿਅਕਤੀ ਦੇ ਬ੍ਰਾਊਜ਼ਰ ਵਿੱਚ ਹੁੰਦਾ ਹੈ) ਅਤੇ Apply for production ਦਬਾਉਣਾ।
  • ਜੋ ਕੋਈ ਆਟੋਮੇਟ ਨਹੀਂ ਕਰ ਸਕਦਾ: 14 ਦਿਨਾਂ ਦੀ ਅਸਲ ਵਰਤੋਂ। ਇਹ ਅਸਲੀ ਲੋਕ ਆਪਣੇ Android ਫ਼ੋਨਾਂ ਉੱਤੇ ਕਰਦੇ ਹਨ, ਅਤੇ Google ਦੇ ਨਿਯਮ ਦਾ ਪੂਰਾ ਮਕਸਦ ਇਹੀ ਹੈ।

1. Token ਬਣਾਓ

  1. https://testerexchange.com/api ਉੱਤੇ ਸਾਈਨ ਇਨ ਕਰੋ।
  2. ਇੱਕ ਨਿੱਜੀ token ਬਣਾਓ। ਇਹ tx_ ਨਾਲ ਸ਼ੁਰੂ ਹੁੰਦਾ ਹੈ। ਇਸਨੂੰ ਹੁਣੇ ਕਾਪੀ ਕਰੋ ਅਤੇ ਪਾਸਵਰਡ ਵਾਂਗ ਸੰਭਾਲੋ।
  3. Tokens ਕਿਸੇ ਵੀ ਸਮੇਂ ਰੱਦ ਕੀਤੇ ਜਾ ਸਕਦੇ ਹਨ। ਇੱਕ token campaigns ਉੱਤੇ credits ਖਰਚ ਸਕਦਾ ਹੈ, ਪਰ ਉਹ ਭੁਗਤਾਨ ਨਹੀਂ ਕਰ ਸਕਦਾ, ਪੈਸੇ ਨਹੀਂ ਕਢਵਾ ਸਕਦਾ ਅਤੇ ਤੁਹਾਡਾ ਖਾਤਾ ਨਹੀਂ ਮਿਟਾ ਸਕਦਾ।

2. MCP ਸਰਵਰ ਜੋੜੋ

MCP ਸਰਵਰ https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp ਉੱਤੇ Streamable HTTP ਵਰਤਦਾ ਹੈ। ਆਪਣਾ token header Authorization: Bearer tx_YOUR_TOKEN ਵਿੱਚ ਭੇਜੋ।

Claude Code: ਆਪਣੇ ਟਰਮੀਨਲ ਵਿੱਚ ਇਹ ਇੱਕ ਵਾਰ ਚਲਾਓ।

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code ਅਤੇ JSON config ਵਾਲੇ ਹੋਰ clients: tester-exchange ਨਾਮ ਦਾ ਸਰਵਰ ਜੋੜੋ, ਜਿਸਦੀ type http ਹੋਵੇ, ਉੱਪਰ ਦਿੱਤਾ URL ਹੋਵੇ, ਅਤੇ headers ਵਿੱਚ Authorization ਦਾ ਮੁੱਲ Bearer tx_YOUR_TOKEN ਹੋਵੇ। Config ਫ਼ਾਈਲ ਦੀ ਸਹੀ ਥਾਂ ਤੁਹਾਡੇ client ਉੱਤੇ ਨਿਰਭਰ ਹੈ; ਉਸਦੇ MCP ਦਸਤਾਵੇਜ਼ ਵੇਖੋ।

ਜੋ clients ਸਿਰਫ਼ URL ਲੈਂਦੇ ਹਨ (ਕੁਝ ChatGPT ਅਤੇ ਵੈੱਬ connectors): https://testerexchange.com/agents/ ਦੇ ਦਸਤਾਵੇਜ਼ ਉਨ੍ਹਾਂ ਲਈ URL ਵਾਲਾ ਰੂਪ ਦੱਸਦੇ ਹਨ। Token ਤੋਂ ਬਿਨਾਂ ਵੀ ਜਨਤਕ tools (Tester Exchange ਕੀ ਹੈ, ਕੀਮਤਾਂ, ਪਲੇਟਫ਼ਾਰਮ ਦੇ ਅੰਕੜੇ) ਕੰਮ ਕਰਦੇ ਹਨ।

3. ਸ਼ੁਰੂ ਕਰਨ ਲਈ ਇੱਕ tool: get_testers

ਤੁਹਾਨੂੰ ਪੂਰੀ tools ਸੂਚੀ ਸਿੱਖਣ ਦੀ ਲੋੜ ਨਹੀਂ। ਮੁੱਖ tool get_testers(package_name, name?) ਹੈ। ਇੱਕ ਕਾਲ ਤੁਹਾਡੀ ਐਪ ਜੋੜਦੀ ਹੈ, ਉਸਦਾ test ਖੋਲ੍ਹਦੀ ਹੈ, ਤੁਹਾਡੇ credits ਲਾਗੂ ਕਰਦੀ ਹੈ ਅਤੇ ਤੁਹਾਡੀ ਤਰੱਕੀ ਦੇ ਨਾਲ ਉਹ ਕਦਮ ਵੀ ਦੱਸਦੀ ਹੈ ਜੋ ਸਿਰਫ਼ ਇਨਸਾਨ ਕਰ ਸਕਦਾ ਹੈ, ਜਿਵੇਂ Play Console ਵਿੱਚ Google Group ਜੋੜਨਾ। ਤਰੱਕੀ ਵੇਖਣ ਲਈ ਇਸਨੂੰ ਕਦੇ ਵੀ ਦੁਬਾਰਾ ਕਾਲ ਕਰੋ।

ਬਾਕੀ tools ਵੇਰਵਿਆਂ ਲਈ ਹਨ: my_apps, campaign_report (testers, ਰੋਜ਼ਾਨਾ ਗਤੀਵਿਧੀ, feedback ਅਤੇ production-access ਦਾ ਡਾਟਾ), add_testers, set_campaign_status (ਰੋਕੋ, ਮੁੜ ਚਾਲੂ ਕਰੋ ਜਾਂ ਬੰਦ ਕਰੋ; ਨਾ ਵਰਤੇ credits ਤੁਹਾਡੇ ਬੈਲੈਂਸ ਵਿੱਚ ਵਾਪਸ ਆਉਂਦੇ ਹਨ), share_kit ਅਤੇ buy_credits_links, ਜੋ ਭੁਗਤਾਨ ਲਈ checkout ਲਿੰਕ ਦਿੰਦਾ ਹੈ ਤਾਂ ਜੋ ਕੋਈ ਇਨਸਾਨ ਪੈਸੇ ਦੇਵੇ।

ਕੰਮ ਕਰਨ ਵਾਲੇ prompts

  • “com.example.app ਲਈ 15 testers ਲਓ ਅਤੇ ਦੱਸੋ ਕਿ ਮੈਨੂੰ Play Console ਵਿੱਚ ਕੀ ਕਰਨਾ ਹੈ।”
  • “com.example.app ਲਈ ਮੇਰੀ Tester Exchange campaign ਵੇਖੋ। ਇਸ ਹਫ਼ਤੇ ਹਰ ਦਿਨ ਕਿੰਨੇ testers ਸਰਗਰਮ ਸਨ?”
  • “Campaign report ਕੱਢੋ ਅਤੇ ਮੇਰੇ production access ਦੇ ਜਵਾਬਾਂ ਦਾ ਡਰਾਫ਼ਟ ਬਣਾਓ। ਸਿਰਫ਼ ਅਸਲੀ ਅੰਕੜੇ ਵਰਤੋ।”
  • “ਹੁਣ ਜਦੋਂ production access ਮਨਜ਼ੂਰ ਹੋ ਗਈ ਹੈ, com.example.app ਦੀ campaign ਬੰਦ ਕਰ ਦਿਓ।”

12 ਦੀ ਥਾਂ 15 testers ਮੰਗੋ, ਤਾਂ ਜੋ ਕਿਸੇ ਦੇ ਛੱਡ ਜਾਣ ਨਾਲ ਤੁਸੀਂ Google ਦੇ ਘੱਟੋ-ਘੱਟ ਤੋਂ ਹੇਠਾਂ ਨਾ ਜਾਓ।

Scripts ਅਤੇ CI ਲਈ HTTP API

ਜੇ ਤੁਹਾਡਾ tool MCP ਨਹੀਂ ਸਮਝਦਾ, ਤਾਂ HTTP endpoint ਵਰਤੋ: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call। Body JSON ਹੈ, ਜਿਸ ਵਿੱਚ p_token (ਤੁਹਾਡਾ tx_ token), p_action (ਜਿਵੇਂ help, my_apps ਜਾਂ start_campaign) ਅਤੇ p_args (ਜਿਵੇਂ package_name ਅਤੇ testers ਦੀ ਗਿਣਤੀ) ਹੁੰਦੇ ਹਨ। ਦਸਤਾਵੇਜ਼ਾਂ ਵਿੱਚ ਦਿਖਾਇਆ ਜਨਤਕ apikey header ਭੇਜੋ।

ਪਹਿਲਾਂ help action ਕਾਲ ਕਰੋ: ਇਹ ਹਰ action ਅਤੇ ਉਸਦੇ arguments ਦੱਸਦਾ ਹੈ। ਪੂਰਾ schema https://testerexchange.com/openapi.json ਉੱਤੇ ਹੈ, ਜੋ ChatGPT custom GPT actions ਅਤੇ ਹੋਰ OpenAPI tools ਨਾਲ ਚੱਲਦਾ ਹੈ।

A2A agent card

Agent-ਤੋਂ-agent ਸੈੱਟਅੱਪਾਂ ਲਈ Tester Exchange https://testerexchange.com/.well-known/agent-card.json ਉੱਤੇ A2A agent card ਪ੍ਰਕਾਸ਼ਿਤ ਕਰਦਾ ਹੈ। A2A ਪ੍ਰੋਟੋਕੋਲ ਨੂੰ ਸਮਰਥਨ ਦੇਣ ਵਾਲੇ orchestrators ਪਤਾ ਲਗਾ ਸਕਦੇ ਹਨ ਕਿ agent ਕੀ ਪੇਸ਼ ਕਰਦਾ ਹੈ ਅਤੇ ਉਸਨੂੰ ਕਿਵੇਂ ਕਾਲ ਕਰਨਾ ਹੈ। ਤੁਹਾਡੇ ਖਾਤੇ ਨਾਲ ਜੁੜੀ ਹਰ ਚੀਜ਼ ਲਈ ਉਹੀ tx_ token ਵਰਤੋ।

ਸ਼ੁਰੂ ਤੋਂ ਅੰਤ ਤੱਕ ਪੂਰਾ ਚੱਕਰ

  1. ਤੁਸੀਂ Play Console ਵਿੱਚ closed track ਉੱਤੇ ਆਪਣੀ ਪਹਿਲੀ .aab ਅੱਪਲੋਡ ਕਰਦੇ ਹੋ।
  2. ਤੁਹਾਡਾ agent ਤੁਹਾਡੇ package name ਲਈ get_testers ਕਾਲ ਕਰਦਾ ਹੈ ਅਤੇ ਦੱਸਦਾ ਹੈ ਕਿ closed track ਉੱਤੇ Google Groups ਹੇਠ testerexchange-testers@googlegroups.com ਜੋੜੋ।
  3. ਤੁਸੀਂ group ਜੋੜਦੇ ਹੋ, ਸੇਵ ਕਰਦੇ ਹੋ, ਅਤੇ ਪੱਕਾ ਕਰਦੇ ਹੋ ਕਿ release publish ਹੈ।
  4. ਜੇ credits ਘੱਟ ਹਨ, ਤਾਂ agent ਤੁਹਾਨੂੰ checkout ਲਿੰਕ ਦਿੰਦਾ ਹੈ। ਤੁਸੀਂ ਭੁਗਤਾਨ ਕਰਦੇ ਹੋ (12 testers ਲਈ $12.99, 15 ਲਈ $14.99, 25 ਲਈ $22.99) ਜਾਂ https://testerexchange.com/earn ਉੱਤੇ ਹੋਰ ਐਪਾਂ ਟੈਸਟ ਕਰਕੇ ਮੁਫ਼ਤ credits ਕਮਾਉਂਦੇ ਹੋ।
  5. ਅਸਲੀ testers 14 ਦਿਨ ਤੁਹਾਡੀ ਐਪ install ਕਰਕੇ ਵਰਤਦੇ ਹਨ। ਤੁਹਾਡਾ agent ਹਰ ਰੋਜ਼ ਤਰੱਕੀ ਜਾਂਚਦਾ ਹੈ ਅਤੇ ਜੇ ਸਰਗਰਮ testers ਘਟਣ ਤਾਂ ਚੇਤਾਵਨੀ ਦਿੰਦਾ ਹੈ।
  6. ਦਿਨ 15 ਨੂੰ agent campaign report ਕੱਢਦਾ ਹੈ ਅਤੇ ਤੁਹਾਡੇ production access ਦੇ ਜਵਾਬਾਂ ਦਾ ਡਰਾਫ਼ਟ ਬਣਾਉਂਦਾ ਹੈ। ਤੁਸੀਂ ਉਨ੍ਹਾਂ ਨੂੰ ਪੜ੍ਹ ਕੇ Apply for production ਦਬਾਉਂਦੇ ਹੋ।

ਸੁਰੱਖਿਆ ਬਾਰੇ ਨੋਟ

  • Tokens ਨੂੰ git ਤੋਂ ਬਾਹਰ ਰੱਖੋ। ਉਨ੍ਹਾਂ ਨੂੰ ਆਪਣੇ client ਦੇ secret store ਜਾਂ environment variable ਵਿੱਚ ਰੱਖੋ।
  • ਸਾਡੇ ਪਾਸੇ tokens ਸਿਰਫ਼ hashes ਵਜੋਂ ਸੰਭਾਲੇ ਜਾਂਦੇ ਹਨ ਅਤੇ ਇੱਕ ਖਾਤੇ ਲਈ 10 ਤੱਕ ਸੀਮਤ ਹਨ। ਜੋ token ਹੁਣ ਨਹੀਂ ਵਰਤ ਰਹੇ ਉਸਨੂੰ ਰੱਦ ਕਰ ਦਿਓ।
  • ਜੋ ਕੁਝ agent ਤੁਹਾਡੇ production ਫਾਰਮ ਲਈ ਲਿਖਦਾ ਹੈ, ਜਮ੍ਹਾ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਉਹ ਪੜ੍ਹੋ। Google ਚਾਹੁੰਦਾ ਹੈ ਕਿ ਤੁਸੀਂ ਆਪਣੇ test ਦਾ ਸੱਚਾ ਵੇਰਵਾ ਦਿਓ।

ਅਕਸਰ ਪੁੱਛੇ ਜਾਂਦੇ ਸਵਾਲ

ਕੀ AI agent ਮੇਰੇ ਲਈ 14 ਦਿਨਾਂ ਦਾ test ਪੂਰਾ ਕਰ ਸਕਦਾ ਹੈ?

ਨਹੀਂ। 14 ਦਿਨਾਂ ਲਈ ਅਸਲੀ ਲੋਕ ਚਾਹੀਦੇ ਹਨ ਜੋ ਆਪਣੇ ਫ਼ੋਨਾਂ ਉੱਤੇ ਤੁਹਾਡੀ ਐਪ ਵਰਤਣ। Agents ਸੈੱਟਅੱਪ, ਨਿਗਰਾਨੀ ਅਤੇ ਰਿਪੋਰਟਿੰਗ ਸੰਭਾਲਦੇ ਹਨ।

ਕੀ agent testers ਲਈ ਭੁਗਤਾਨ ਕਰ ਸਕਦਾ ਹੈ?

ਨਹੀਂ। ਉਹ checkout ਲਿੰਕ ਦੇ ਸਕਦਾ ਹੈ, ਪਰ ਭੁਗਤਾਨ ਹਮੇਸ਼ਾ ਕਿਸੇ ਇਨਸਾਨ ਦੇ ਬ੍ਰਾਊਜ਼ਰ ਵਿੱਚ ਹੁੰਦਾ ਹੈ।

MCP ਸਰਵਰ ਨਾਲ ਕਿਹੜੇ clients ਚੱਲਦੇ ਹਨ?

ਕੋਈ ਵੀ client ਜੋ ਕਸਟਮ header ਨਾਲ Streamable HTTP ਉੱਤੇ remote MCP ਨੂੰ ਸਮਰਥਨ ਦਿੰਦਾ ਹੈ, ਜਿਵੇਂ Claude Code, Claude Desktop, Cursor ਅਤੇ VS Code। ਬਾਕੀ HTTP API ਵਰਤ ਸਕਦੇ ਹਨ।

Token ਕਿੱਥੋਂ ਮਿਲੇਗਾ?

ਸਾਈਨ ਇਨ ਕਰਨ ਤੋਂ ਬਾਅਦ https://testerexchange.com/api ਉੱਤੇ। Tokens tx_ ਨਾਲ ਸ਼ੁਰੂ ਹੁੰਦੇ ਹਨ ਅਤੇ ਕਿਸੇ ਵੀ ਸਮੇਂ ਰੱਦ ਹੋ ਸਕਦੇ ਹਨ।

ਕੀ agent ਮੇਰੇ Play Console ਵਿੱਚ ਕੁਝ ਬਦਲਦਾ ਹੈ?

ਨਹੀਂ। ਉਸ ਕੋਲ ਤੁਹਾਡੇ Play Console ਤੱਕ ਪਹੁੰਚ ਨਹੀਂ ਹੁੰਦੀ। ਉਹ ਸਿਰਫ਼ ਦੱਸਦਾ ਹੈ ਕਿ ਉੱਥੇ ਤੁਹਾਨੂੰ ਕਿਹੜੇ ਕਦਮ ਚੁੱਕਣੇ ਹਨ।
