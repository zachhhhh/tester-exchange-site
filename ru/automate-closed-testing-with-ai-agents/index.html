Автоматизация закрытого тестирования Google Play с ИИ-агентами

Обновлено в ноябре 2026 г.

Если вы уже пишете код с помощью ИИ-агента, ему можно передать и большую часть рутины, связанной с требованием Google Play о закрытом тестировании: добавление приложения, набор тестировщиков, проверку прогресса и сбор цифр для формы доступа к рабочей версии. Для этого у Tester Exchange есть MCP-сервер, HTTP API с одной конечной точкой и карточка A2A-агента. В этом руководстве показано, как подключить Claude Code, Claude Desktop, Cursor и другие клиенты, о чём просить агента и что не сможет сделать за вас ни один агент.

Что агент может и чего не может

Google требует, чтобы владельцы личных аккаунтов разработчика, созданных после 13 ноября 2023 г., провели закрытый тест как минимум с 12 тестировщиками, непрерывно участвующими 14 дней, прежде чем подавать заявку на рабочую версию. Большая часть работы вокруг этого — координация, с которой агенты хорошо справляются.

  • Агент может: добавить приложение, открыть кампанию набора тестировщиков, применить ваши кредиты, проверить, сколько тестировщиков активны, приостановить или закрыть кампанию, получить отчёт о ежедневной активности и помочь составить по нему ответы для формы доступа к рабочей версии.
  • Человек должен: добавить Google Group тестировщиков на закрытый трек в Play Console, опубликовать релиз, оплатить кредиты (оплата всегда проходит в браузере человека) и нажать Apply for production.
  • Никто не может автоматизировать: 14 дней реального использования. Это делают настоящие люди на собственных Android-телефонах — в этом и смысл правила Google.

1. Создайте токен

  1. Войдите на https://testerexchange.com/api.
  2. Создайте персональный токен. Он начинается с tx_. Скопируйте его сразу и храните как пароль.
  3. Токены можно отозвать в любой момент. Токен может тратить кредиты на кампании, но не может платить, выводить деньги или удалять ваш аккаунт.

2. Подключите MCP-сервер

MCP-сервер работает по Streamable HTTP по адресу https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp. Передавайте токен в заголовке Authorization: Bearer tx_YOUR_TOKEN.

Claude Code: выполните один раз в терминале.

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code и другие клиенты с JSON-конфигурацией: добавьте сервер с именем tester-exchange и типом http, указав URL выше и запись headers, где Authorization равно Bearer tx_YOUR_TOKEN. Точное расположение файла конфигурации зависит от клиента; смотрите его документацию по MCP.

Клиенты, принимающие только URL (некоторые коннекторы ChatGPT и веб-коннекторы): в документации на https://testerexchange.com/agents/ есть вариант с URL для них. Без токена публичные инструменты (что такое Tester Exchange, цены, статистика платформы) всё равно работают.

3. Главный инструмент для начала: get_testers

Учить весь список инструментов не нужно. Основной инструмент — get_testers(package_name, name?). Один вызов добавляет ваше приложение, открывает его тест, применяет ваши кредиты и возвращает прогресс вместе с шагами, которые может сделать только человек, например добавление Google Group в Play Console. Вызывайте его снова в любой момент, чтобы проверить прогресс.

Остальные инструменты отвечают за детали: my_apps, campaign_report (тестировщики, ежедневная активность, отзывы и данные для доступа к рабочей версии), add_testers, set_campaign_status (приостановить, возобновить или закрыть; неиспользованные кредиты возвращаются на баланс), share_kit и buy_credits_links, который возвращает ссылки на оплату для человека.

Запросы, которые работают

  • «Найди 15 тестировщиков для com.example.app и скажи, что мне нужно сделать в Play Console.»
  • «Проверь мою кампанию в Tester Exchange для com.example.app. Сколько тестировщиков были активны в каждый день этой недели?»
  • «Возьми отчёт по кампании и составь черновик моих ответов для доступа к рабочей версии. Используй только реальные цифры.»
  • «Закрой кампанию для com.example.app, теперь, когда доступ к рабочей версии одобрен.»

Просите 15 тестировщиков, а не 12, чтобы выбывший не опустил вас ниже минимума Google.

HTTP API для скриптов и CI

Если ваш инструмент не работает с MCP, используйте HTTP-эндпоинт: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call. Тело — JSON с p_token (ваш токен tx_), p_action (например, help, my_apps или start_campaign) и p_args (например, package_name и число тестировщиков). Передавайте публичный заголовок apikey, указанный в документации.

Сначала вызовите действие help: оно возвращает все действия и их аргументы. Полная схема доступна по адресу https://testerexchange.com/openapi.json, она подходит для действий custom GPT в ChatGPT и других инструментов OpenAPI.

Карточка A2A-агента

Для сценариев «агент — агент» Tester Exchange публикует карточку A2A-агента по адресу https://testerexchange.com/.well-known/agent-card.json. Оркестраторы, поддерживающие протокол A2A, могут узнать, что предлагает агент и как его вызывать. Для всего, что связано с вашим аккаунтом, используйте тот же токен tx_.

Полный цикл от начала до конца

  1. Вы загружаете первый .aab на закрытый трек в Play Console.
  2. Ваш агент вызывает get_testers для вашего имени пакета и говорит добавить testerexchange-testers@googlegroups.com в разделе Google Groups на закрытом треке.
  3. Вы добавляете группу, сохраняете и убеждаетесь, что релиз опубликован.
  4. Если кредитов не хватает, агент даёт ссылку на оплату. Вы платите (12,99 доллара за 12 тестировщиков, 14,99 за 15, 22,99 за 25) или зарабатываете кредиты бесплатно, тестируя чужие приложения на https://testerexchange.com/earn.
  5. Настоящие тестировщики устанавливают и используют ваше приложение 14 дней. Ваш агент ежедневно проверяет прогресс и предупреждает, если число активных тестировщиков падает.
  6. На 15-й день агент берёт отчёт по кампании и составляет черновик ответов для доступа к рабочей версии. Вы проверяете их и нажимаете Apply for production.

Замечания по безопасности

  • Не храните токены в git. Используйте хранилище секретов клиента или переменную окружения.
  • У нас токены хранятся только в виде хэшей, и их не больше 10 на аккаунт. Отзывайте токены, которыми больше не пользуетесь.
  • Прочитайте, что агент написал в форме доступа к рабочей версии, прежде чем отправлять её. Google просит правдиво описывать ваш тест.

Частые вопросы

Может ли ИИ-агент пройти 14-дневный тест за меня?

Нет. Для 14 дней нужны настоящие люди, использующие ваше приложение на своих телефонах. Агенты берут на себя настройку, мониторинг и отчёты.

Может ли агент оплатить тестировщиков?

Нет. Он может вернуть ссылки на оплату, но платёж всегда проходит в браузере человека.

Какие клиенты работают с MCP-сервером?

Любой клиент, поддерживающий удалённый MCP по Streamable HTTP с пользовательским заголовком, включая Claude Code, Claude Desktop, Cursor и VS Code. Остальные могут использовать HTTP API.

Где взять токен?

На https://testerexchange.com/api после входа. Токены начинаются с tx_ и могут быть отозваны в любой момент.

Меняет ли агент что-нибудь в моей Play Console?

Нет. У него нет доступа к вашей Play Console. Он подсказывает шаги, которые нужно выполнить там.
