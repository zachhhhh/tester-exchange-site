Ṣe ìdánwò àdáni Google Play láìfọwọ́ṣe pẹ̀lú AI agents

A ṣe àfikún ní November 2026

Tí o bá ti ń fi AI agent kọ kóòdù, o lè fi ọ̀pọ̀lọpọ̀ iṣẹ́ kékeré tó wà nínú ohun tí ìdánwò àdáni Google Play nílò lé e lọ́wọ́ pẹ̀lú: kíkọ áàpù rẹ sílẹ̀, gbígba olùdánwò, ṣíṣàyẹ̀wò ìlọsíwájú àti gbígba àwọn nọ́ńbà fún fọ́ọ̀mù ìráyè production. Tester Exchange ní MCP server, HTTP API oníbi-ìparí kan àti kádì A2A agent fún èyí. Ìtọ́sọ́nà yìí fi bí a ṣe ń so Claude Code, Claude Desktop, Cursor àti àwọn client mìíràn hàn, ohun tí o lè béèrè, àti àwọn apá tí agent kankan kò lè ṣe fún ọ.

Àwọn ènìyàn gidi ń ṣí áàpù rẹ lórí fóònù tiwọn fún ọjọ́ 14. Sanwó lẹ́ẹ̀kan, tàbí dán àwọn áàpù mìíràn wò lọ́fẹ̀ẹ́.Gba olùdánwò 12

Ohun tí agent lè ṣe àti ohun tí kò lè ṣe

Google ń béèrè pé kí àwọn àkọọ́lẹ̀ olùṣẹ̀dá ti ara ẹni tí a ṣẹ̀dá lẹ́yìn 13 November 2023 ṣe ìdánwò àdáni pẹ̀lú olùdánwò 12 tó kéré jù tí wọ́n opt in fún ọjọ́ 14 léraléra kí wọ́n tó béèrè fún production. Ọ̀pọ̀lọpọ̀ iṣẹ́ tó yí èyí ká jẹ́ ìṣọ̀kan àwọn nǹkan, èyí tí àwọn agent ń ṣe dáadáa.

  • Agent lè: fi áàpù rẹ kún un, ṣí ìpolongo olùdánwò, lo àwọn kírẹ́dìtì rẹ, ṣàyẹ̀wò iye olùdánwò tó ń ṣiṣẹ́, dá dúró tàbí pa ìpolongo, gba ìròyìn ìlò ojoojúmọ́, kí ó sì ràn ọ́ lọ́wọ́ láti ṣàkọsílẹ̀ àwọn ìdáhùn ìráyè production láti inú rẹ̀.
  • Ènìyàn gbọ́dọ̀: fi Google Group àwọn olùdánwò kún track ìdánwò àdáni nínú Play Console, ṣe àtẹ̀jáde release, sanwó fún kírẹ́dìtì (ìsanwó máa ń wáyé nínú browser ènìyàn nígbà gbogbo) kí ó sì tẹ Apply for production.
  • Kò sí ẹni tó lè ṣe é láìfọwọ́ṣe: ọjọ́ 14 ti ìlò gidi. Àwọn ènìyàn gidi ló ń ṣe é lórí fóònù Android tiwọn, èyí sì ni gbogbo ìdí òfin Google.

1. Ṣẹ̀dá token

  1. Wọlé ní https://testerexchange.com/api.
  2. Ṣẹ̀dá token ti ara ẹni. Ó bẹ̀rẹ̀ pẹ̀lú tx_. Ṣe àdàkọ rẹ̀ báyìí kí o sì pa á mọ́ bí ọ̀rọ̀ ìgbaniwọlé.
  3. A lè fagilé àwọn token nígbàkigbà. Token lè ná kírẹ́dìtì lórí àwọn ìpolongo, ṣùgbọ́n kò lè sanwó, yọ owó jáde tàbí pa àkọọ́lẹ̀ rẹ rẹ́.

2. So MCP server pọ̀

MCP server ń lo Streamable HTTP ní https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp. Fi token rẹ ránṣẹ́ nínú header Authorization: Bearer tx_YOUR_TOKEN.

Claude Code: ṣe àṣẹ yìí lẹ́ẹ̀kan nínú terminal rẹ.

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code àti àwọn client mìíràn tí ó ní JSON config: fi server kan tí orúkọ rẹ̀ jẹ́ tester-exchange kún un pẹ̀lú type http, URL tó wà lókè, àti ẹ̀ka headers pẹ̀lú Authorization tí a ṣètò sí Bearer tx_YOUR_TOKEN. Ibi tí fáìlì config wà dá lórí client rẹ; wo ìwé MCP rẹ̀.

Àwọn client tí wọ́n gba URL nìkan (àwọn connector ChatGPT àti ti wẹ́ẹ̀bù kan): ìwé ní https://testerexchange.com/agents/ ṣàkọsílẹ̀ àkójọpọ̀ URL fún wọn. Láìsí token, àwọn irinṣẹ́ gbogbo ènìyàn (kí ni Tester Exchange, iye owó, ìṣirò pẹpẹ) ṣì ń ṣiṣẹ́.

3. Irinṣẹ́ kan láti bẹ̀rẹ̀ pẹ̀lú: get_testers

O kò nílò láti kọ́ gbogbo àtòjọ irinṣẹ́. Irinṣẹ́ pàtàkì ni get_testers(package_name, name?). Ìpè kan fi áàpù rẹ kún un, ó ṣí ìdánwò rẹ̀, ó lo àwọn kírẹ́dìtì rẹ, ó sì dá ìlọsíwájú rẹ padà pẹ̀lú àwọn ìgbésẹ̀ tí ènìyàn nìkan lè ṣe, bíi fífi Google Group kún un nínú Play Console. Pè é lẹ́ẹ̀kan sí i nígbàkigbà láti ṣàyẹ̀wò ìlọsíwájú.

Àwọn irinṣẹ́ mìíràn bo àwọn ẹ̀kúnrẹ́rẹ́: my_apps, campaign_report (àwọn olùdánwò, ìlò ojoojúmọ́, èsì àti dátà ìráyè production), add_testers, set_campaign_status (dá dúró, tún bẹ̀rẹ̀ tàbí pa; àwọn kírẹ́dìtì tí a kò lò padà sí ìwọ̀ntúnwọ̀nsì rẹ), share_kit àti buy_credits_links, tí ó dá àwọn ìjápọ̀ ìsanwó padà fún ènìyàn láti sanwó.

Àwọn prompt tó ń ṣiṣẹ́

  • "Gba olùdánwò 15 fún com.example.app kí o sì sọ ohun tí mo gbọ́dọ̀ ṣe nínú Play Console fún mi."
  • "Ṣàyẹ̀wò ìpolongo Tester Exchange mi fún com.example.app. Olùdánwò mélòó ló ń ṣiṣẹ́ ní ọjọ́ kọ̀ọ̀kan ní ọ̀sẹ̀ yìí?"
  • "Gba ìròyìn ìpolongo náà kí o sì ṣàkọsílẹ̀ àwọn ìdáhùn ìráyè production mi. Lo àwọn nọ́ńbà gidi nìkan."
  • "Pa ìpolongo com.example.app báyìí tí a ti fọwọ́ sí ìráyè production."

Béèrè fún olùdánwò 15 dípò 12, kí olùdánwò tó kúrò má bàa mú ọ wà ní ìsàlẹ̀ ìwọ̀n tó kéré jù ti Google.

HTTP API fún àwọn script àti CI

Tí irinṣẹ́ rẹ kò bá gbọ́ MCP, lo HTTP endpoint: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call. Body jẹ́ JSON pẹ̀lú p_token (token tx_ rẹ), p_action (fún àpẹẹrẹ help, my_apps tàbí start_campaign) àti p_args (fún àpẹẹrẹ package_name àti iye olùdánwò). Fi header apikey ti gbogbo ènìyàn tí a fihàn nínú ìwé ránṣẹ́.

Pe action help ná: ó dá gbogbo action àti àwọn argument wọn padà. Schema kíkún wà ní https://testerexchange.com/openapi.json, èyí tó ń ṣiṣẹ́ pẹ̀lú ChatGPT custom GPT actions àti àwọn irinṣẹ́ OpenAPI mìíràn.

Kádì A2A agent

Fún àwọn ìṣètò agent-sí-agent, Tester Exchange ń tẹ̀ kádì A2A agent jáde ní https://testerexchange.com/.well-known/agent-card.json. Àwọn orchestrator tí wọ́n ṣe àtìlẹ́yìn fún ìlànà A2A lè wá ohun tí agent náà ń pèsè àti bí a ṣe ń pè é. Lo token tx_ kan náà fún ohunkóhun tí ó so mọ́ àkọọ́lẹ̀ rẹ.

Ìṣiṣẹ́ kíkún, láti ìbẹ̀rẹ̀ dé ìparí

  1. O gbé .aab àkọ́kọ́ rẹ sórí track ìdánwò àdáni nínú Play Console.
  2. Agent rẹ pe get_testers fún orúkọ package rẹ, ó sì sọ fún ọ láti fi testerexchange-testers@googlegroups.com kún abẹ́ Google Groups lórí track ìdánwò àdáni.
  3. O fi group náà kún un, o fi pamọ́, o sì rí i dájú pé a ti ṣe àtẹ̀jáde release náà.
  4. Tí o kò bá ní kírẹ́dìtì, agent fún ọ ní ìjápọ̀ ìsanwó. O sanwó ($12.99 fún olùdánwò 12, $14.99 fún 15, $22.99 fún 25) tàbí o jèrè kírẹ́dìtì lọ́fẹ̀ẹ́ nípa dídán àwọn áàpù mìíràn wò ní https://testerexchange.com/earn.
  5. Àwọn olùdánwò gidi fi áàpù rẹ sórí ẹ̀rọ, wọ́n sì lò ó fún ọjọ́ 14. Agent rẹ ń ṣàyẹ̀wò ìlọsíwájú lójoojúmọ́, ó sì kìlọ̀ fún ọ tí àwọn olùdánwò tó ń ṣiṣẹ́ bá dín kù.
  6. Ní ọjọ́ 15, agent gba ìròyìn ìpolongo, ó sì ṣàkọsílẹ̀ àwọn ìdáhùn ìráyè production rẹ. O ṣàyẹ̀wò wọn, o sì tẹ Apply for production.

Àwọn àkíyèsí ààbò

  • Pa àwọn token mọ́ kúrò nínú git. Fi wọ́n sínú ibi ìpamọ́ àṣírí client rẹ tàbí environment variable.
  • A kì í pa àwọn token mọ́ lẹ́gbẹ̀ẹ́ wa bí kò ṣe hash, a sì ń dín wọn kù sí 10 fún àkọọ́lẹ̀ kan. Fagilé token tí o kò lò mọ́.
  • Ka ohun tí agent kọ sínú fọ́ọ̀mù production rẹ kí o tó fi ránṣẹ́. Google ń béèrè pé kí o ṣàpèjúwe ìdánwò rẹ ní òótọ́.

Àwọn ìbéèrè tí a máa ń béèrè

Ṣé AI agent lè parí ìdánwò ọjọ́ 14 fún mi?

Rárá. Ọjọ́ 14 nílò àwọn ènìyàn gidi tí wọ́n ń lo áàpù rẹ lórí fóònù tiwọn. Àwọn agent ń ṣe ìṣètò, ìṣàkóso àti ìròyìn.

Ṣé agent lè sanwó fún àwọn olùdánwò?

Rárá. Ó lè dá àwọn ìjápọ̀ ìsanwó padà, ṣùgbọ́n ìsanwó máa ń wáyé nínú browser ènìyàn nígbà gbogbo.

Àwọn client wo ni wọ́n ń ṣiṣẹ́ pẹ̀lú MCP server?

Client èyíkéyìí tí ó ṣe àtìlẹ́yìn fún remote MCP lórí Streamable HTTP pẹ̀lú header àdáni, pẹ̀lú Claude Code, Claude Desktop, Cursor àti VS Code. Àwọn mìíràn lè lo HTTP API.

Níbo ni mo ti lè gba token?

Ní https://testerexchange.com/api lẹ́yìn tí o bá wọlé. Àwọn token bẹ̀rẹ̀ pẹ̀lú tx_, a sì lè fagilé wọn nígbàkigbà.

Ṣé agent náà yí ohunkóhun padà nínú Play Console mi?

Rárá. Kò ní ìráyè sí Play Console rẹ. Ó sọ àwọn ìgbésẹ̀ tí o gbọ́dọ̀ ṣe níbẹ̀ fún ọ.
