Ṣé o ti kọ áàpù Android rẹ pẹ̀lú Claude Code? Gba olùdánwò 12 rẹ fún ọjọ́ 14

A ṣe àfikún ní November 2026

Claude Code lè kọ àti kọ́ áàpù Android rẹ, ṣùgbọ́n kò lè pèsè olùdánwò gidi 12 tí Google Play nílò. Tí a bá dá àkọọ́lẹ̀ olùgbéjáde ti ara ẹni rẹ lẹ́yìn 13 November 2023, o gbọ́dọ̀ ṣe closed test pẹ̀lú olùdánwò tí kò dín ní 12 tí wọ́n forúkọ sílẹ̀ fún ọjọ́ 14 tẹ̀léra kí o tó béèrè fún production. Ìtọ́sọ́nà yìí bo kíkọ́ bundle, bíbẹ̀rẹ̀ closed testing, gbígba olùdánwò (ọ̀fẹ́ ná, ìsanwó lẹ́yìn) àti sísopọ̀ Tester Exchange mọ́ Claude Code kí agent lè ṣe iṣẹ́ ìwé.

Àwọn ènìyàn gidi ń ṣí áàpù rẹ lórí fóònù tiwọn fún ọjọ́ 14. Sanwó lẹ́ẹ̀kan, tàbí dán àwọn áàpù mìíràn wò lọ́fẹ̀ẹ́.Gba olùdánwò 12

1. Kọ́ release bundle (.aab)

  1. Bẹ̀ agent Claude Code láti ṣètò release signing nínú build.gradle.kts module rẹ (bulọọki signingConfigs pẹ̀lú storeFile, storePassword, keyAlias àti keyPassword, tí a lò sórí build type release). Pa àwọn ọ̀rọ̀ aṣínà mọ́ kúrò nínú git (àkọsílẹ̀ build ti Android: https://developer.android.com/build/building-cmdline ).
  2. Ṣiṣẹ́ ./gradlew bundleRelease nínú terminal. Gradle yóò kọ́ bundle náà yóò sì fọwọ́ sí i; .aab náà sábà máa ń hàn lábẹ́ app/build/outputs/bundle/release/, ṣùgbọ́n ṣàyẹ̀wò èsì build tìrẹ.
  3. Ṣẹ̀dá keystore pẹ̀lú keytool tí o kò bá ní ọ̀kan, kí o sì ṣe ẹ̀dà ìpamọ́ rẹ̀. A máa ń fi Google Play App Signing lọ̀ ọ́ nígbà tí o bá gbé release àkọ́kọ́ rẹ sókè.

2. Bẹ̀rẹ̀ closed testing nínú Play Console

  1. Ṣí Test and release > Testing > Closed testing, lẹ́yìn náà tẹ Create track (tàbí Manage track).
  2. Tẹ Create new release, gbé .aab sókè, fi orúkọ release àti àkọsílẹ̀ kún un, Save as draft, Next, lẹ́yìn náà Start rollout (àwọn ìgbésẹ̀ láti https://support.google.com/googleplay/android-developer/answer/9859348 ).
  3. Parí àwọn iṣẹ́ ìṣètò áàpù lórí Dashboard ná, bí bẹ́ẹ̀ kọ́ bọ́tìnnì release yóò wà ní àìṣiṣẹ́.

3. Gba olùdánwò 12 rẹ: ọ̀fẹ́ ná, ìsanwó lẹ́yìn

  • Ọ̀nà ọ̀fẹ́: ṣí https://testerexchange.com/earn lórí fóònù rẹ kí o sì dán àwọn áàpù tí a fún ọ wò. Áàpù kọ̀ọ̀kan tí o bá dánwò máa mú olùdánwò kan wá sí tìrẹ.
  • Ọ̀nà ìsanwó: sanwó lẹ́ẹ̀kan, a ó sì yan àwọn olùdánwò fún ọ láìfọwọ́ṣe. Àwọn owó lọ́wọ́lọ́wọ́ wà ní https://testerexchange.com/llms.txt .
  • Béèrè fún olùdánwò 15 dípò 12 kí ẹnì kan tó bá yọ kúrò má baà jẹ́ kí o wà lábẹ́ iye tó kéré jù tí Google fẹ́.

4. So Tester Exchange mọ́ Claude Code (àṣàyàn)

Kọ́kọ́ ṣẹ̀dá API key ní https://testerexchange.com/api. Lẹ́yìn náà, ṣe àṣẹ yìí lẹ́ẹ̀kan ṣoṣo nínú terminal rẹ, kí o rọ́pò tx_YOUR_TOKEN pẹ̀lú key rẹ (àṣẹ náà ni èyí tí a kọ sílẹ̀ ní https://testerexchange.com/agents/):

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Server náà jẹ́ MCP lásán lórí Streamable HTTP láìsí OAuth; àwọn irinṣẹ́ gbangba (about, pricing, platform_stats) ń ṣiṣẹ́ láìsí key. Pa key náà mọ́ kúrò nínú git àti àwọn fáìlì config tí a pín.

5. Béèrè lọ́wọ́ agent

  • “Lo Tester Exchange láti gba olùdánwò 15 fún com.example.app kí o sì sọ ohun tí mo gbọ́dọ̀ ṣe nínú Play Console fún mi.”
  • “Ṣàyẹ̀wò ìpolongo Tester Exchange mi fún com.example.app kí o sì sọ iye olùdánwò tó ṣiṣẹ́ ní àná fún mi.”
  • “Fa ròyìn ìpolongo náà jáde kí o sì ṣe àkọsílẹ̀ ìdáhùn production access mi láti inú àwọn nọ́ńbà gidi.”

Irinṣẹ́ pàtàkì ni get_testers: ó ń fi áàpù kún un, ó ń ṣí ìdánwò rẹ̀, ó sì ń dá àwọn ìgbésẹ̀ tí ènìyàn nìkan lè ṣe padà, bíi fífi Google Group àwọn olùdánwò kún Play Console. Agent kò lè sanwó tàbí tẹ Apply for production fún ọ.

Kò sí MCP? Lo HTTP API

Ṣe POST sí https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call pẹ̀lú apikey header gbangba tí a ṣe àkójọ rẹ̀ ní https://testerexchange.com/agents/ àti body {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}} . Schema wà ní https://testerexchange.com/openapi.json . Àwọn irinṣẹ́ míràn: https://testerexchange.com/guide/ai-builders/ .

Àwọn ìbéèrè tí a máa ń béèrè

Ṣé Claude Code lè parí ìdánwò ọjọ́ 14 fún mi?

Rárá. Ọjọ́ 14 náà nílò ènìyàn gidi tí wọ́n ń lo áàpù rẹ lórí fóònù Android tiwọn. Claude Code lè kọ́ áàpù náà kí ó sì darí ìṣètò.

Ṣé Tester Exchange jẹ́ ìṣọ̀kan Claude Code àṣẹ?

Rárá. Iṣẹ́ aládàáni ni, ó sì ń ṣiṣẹ́ pẹ̀lú ẹ̀rọ client èyíkéyìí tó ń ṣe àtìlẹyìn fún remote MCP lórí HTTP, èyí tí Claude Code ń ṣe.

Níbo ni AAB náà ń lọ?

Gbé e sókè sínú closed testing release nínú Play Console, lẹ́yìn náà fi Google Group tàbí àtòkọ ímeèlì àwọn olùdánwò rẹ kún track náà.

Ǹjẹ́ ọ̀nà ọ̀fẹ́ wà láti gba olùdánwò 12?

Bẹ́ẹ̀ ni. Dán àwọn áàpù àwọn olùgbéjáde míràn wò ní https://testerexchange.com/earn ; áàpù kọ̀ọ̀kan tí o bá dánwò máa mú olùdánwò kan wá sí tìrẹ.
