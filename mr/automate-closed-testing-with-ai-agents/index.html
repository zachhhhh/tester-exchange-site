AI एजंट्सने Google Play क्लोज्ड टेस्टिंग ऑटोमेट करा

नोव्हेंबर 2026 मध्ये अपडेट केले

तुम्ही आधीच AI एजंटसोबत कोड शिप करत असाल, तर Google Play च्या क्लोज्ड टेस्टिंग अटीची बहुतेक कटकटीची कामेही त्याला सोपवता येतात: ॲप लिस्ट करणे, टेस्टर्स मिळवणे, प्रगती तपासणे आणि प्रोडक्शन ॲक्सेस फॉर्मसाठी आकडे काढणे. यासाठी Tester Exchange कडे MCP सर्व्हर, एका एंडपॉइंटचा HTTP API आणि A2A एजंट कार्ड आहे. हे मार्गदर्शक Claude Code, Claude Desktop, Cursor आणि इतर क्लायंट्स कसे जोडायचे, काय विचारायचे आणि कोणताही एजंट तुमच्यासाठी करू शकत नाही असे भाग कोणते ते सांगते.

एजंट काय करू शकतो आणि काय नाही

13 नोव्हेंबर 2023 नंतर तयार झालेल्या पर्सनल डेव्हलपर अकाउंट्सनी प्रोडक्शनसाठी अर्ज करण्यापूर्वी किमान 12 टेस्टर्स सलग 14 दिवस opt-in असलेली क्लोज्ड टेस्ट चालवणे Google ला हवे आहे. याभोवतीचे बहुतेक काम समन्वयाचे आहे, आणि ते एजंट्स चांगले करतात.

  • एजंट हे करू शकतो: तुमचे ॲप जोडणे, टेस्टर कॅम्पेन सुरू करणे, तुमची क्रेडिट्स लावणे, किती टेस्टर्स सक्रिय आहेत ते तपासणे, कॅम्पेन थांबवणे किंवा बंद करणे, रोजच्या ॲक्टिव्हिटीचा रिपोर्ट आणणे आणि त्यावरून प्रोडक्शन ॲक्सेसची उत्तरे लिहायला मदत करणे.
  • माणसाने करायलाच हवे: टेस्टर्सचा Google Group Play Console मधील क्लोज्ड ट्रॅकवर जोडणे, रिलीज पब्लिश करणे, क्रेडिट्ससाठी पैसे देणे (चेकआउट नेहमी माणसाच्या ब्राउझरमध्ये होते) आणि Apply for production वर क्लिक करणे.
  • कोणीही ऑटोमेट करू शकत नाही: 14 दिवसांचा खरा वापर. तो खरे लोक त्यांच्या स्वतःच्या Android फोनवर करतात, आणि Google च्या नियमाचा तोच मूळ हेतू आहे.

1. टोकन तयार करा

  1. https://testerexchange.com/api वर साइन इन करा.
  2. पर्सनल टोकन तयार करा. ते tx_ ने सुरू होते. ते आत्ताच कॉपी करा आणि पासवर्डप्रमाणे जपून ठेवा.
  3. टोकन कधीही रद्द करता येतात. टोकन कॅम्पेन्सवर क्रेडिट्स खर्च करू शकते, पण ते पेमेंट करू शकत नाही, पैसे काढू शकत नाही किंवा तुमचे अकाउंट डिलीट करू शकत नाही.

2. MCP सर्व्हर जोडा

MCP सर्व्हर https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp येथे Streamable HTTP वापरतो. तुमचे टोकन हेडरमध्ये पाठवा: Authorization: Bearer tx_YOUR_TOKEN.

Claude Code: तुमच्या टर्मिनलमध्ये ही कमांड एकदा चालवा.

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code आणि JSON कॉन्फिग असलेले इतर क्लायंट्स: tester-exchange नावाचा सर्व्हर जोडा, type http ठेवा, वरील URL द्या आणि headers मध्ये Authorization ला Bearer tx_YOUR_TOKEN असे सेट करा. कॉन्फिग फाइल नेमकी कुठे असते ते तुमच्या क्लायंटवर अवलंबून आहे; त्याचे MCP डॉक्युमेंटेशन पाहा.

फक्त URL घेणारे क्लायंट्स (काही ChatGPT आणि वेब कनेक्टर्स): https://testerexchange.com/agents/ वरील डॉक्स त्यांच्यासाठी URL स्वरूप देतात. टोकनशिवाय पब्लिक टूल्स (Tester Exchange काय आहे, किंमत, प्लॅटफॉर्म आकडेवारी) तरीही चालतात.

3. सुरुवात करण्यासाठी एक टूल: get_testers

संपूर्ण टूल यादी शिकण्याची गरज नाही. मुख्य टूल आहे get_testers(package_name, name?). एका कॉलमध्ये तुमचे ॲप जोडले जाते, त्याची टेस्ट सुरू होते, तुमची क्रेडिट्स लागू होतात आणि तुमची प्रगती, तसेच फक्त माणसाने करायच्या पायऱ्या (उदा. Play Console मध्ये Google Group जोडणे) परत मिळतात. प्रगती तपासायला हा कॉल कधीही पुन्हा करा.

इतर टूल्स तपशील सांभाळतात: my_apps, campaign_report (टेस्टर्स, रोजची ॲक्टिव्हिटी, फीडबॅक आणि प्रोडक्शन ॲक्सेसचा डेटा), add_testers, set_campaign_status (थांबवा, पुन्हा सुरू करा किंवा बंद करा; न वापरलेली क्रेडिट्स तुमच्या बॅलन्समध्ये परत जातात), share_kit आणि buy_credits_links, जे माणसाने पैसे द्यायच्या चेकआउट लिंक्स देते.

चालणारे प्रॉम्प्ट्स

  • "com.example.app साठी 15 टेस्टर्स मिळवा आणि मला Play Console मध्ये काय करायचे ते सांग."
  • "com.example.app साठी माझे Tester Exchange कॅम्पेन तपास. या आठवड्यात दर दिवशी किती टेस्टर्स सक्रिय होते?"
  • "कॅम्पेन रिपोर्ट काढ आणि माझी प्रोडक्शन ॲक्सेसची उत्तरे लिही. फक्त खरे आकडे वापर."
  • "प्रोडक्शन ॲक्सेस मंजूर झाला आहे, त्यामुळे com.example.app चे कॅम्पेन आता बंद कर."

12 ऐवजी 15 टेस्टर्स मागा, म्हणजे एखादा गळल्यास तुम्ही Google च्या किमानच्या खाली जाणार नाही.

स्क्रिप्ट्स आणि CI साठी HTTP API

तुमचे टूल MCP बोलत नसेल, तर HTTP एंडपॉइंट वापरा: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call. बॉडी JSON असते आणि त्यात p_token (तुमचे tx_ टोकन), p_action (उदा. help, my_apps किंवा start_campaign) आणि p_args (उदा. package_name आणि टेस्टर्सची संख्या) असतात. डॉक्समध्ये दाखवलेले पब्लिक apikey हेडर पाठवा.

आधी help ॲक्शन कॉल करा: ती प्रत्येक ॲक्शन आणि तिचे आर्ग्युमेंट्स परत देते. संपूर्ण स्कीमा https://testerexchange.com/openapi.json वर आहे, जो ChatGPT custom GPT actions आणि इतर OpenAPI टूल्ससोबत चालतो.

A2A एजंट कार्ड

एजंट-टू-एजंट सेटअपसाठी Tester Exchange https://testerexchange.com/.well-known/agent-card.json येथे A2A एजंट कार्ड प्रकाशित करते. A2A प्रोटोकॉल सपोर्ट करणारे ऑर्केस्ट्रेटर्स एजंट काय देतो आणि त्याला कसे कॉल करायचे ते शोधू शकतात. तुमच्या अकाउंटशी जोडलेल्या कोणत्याही गोष्टीसाठी तेच tx_ टोकन वापरा.

सुरुवातीपासून शेवटपर्यंत पूर्ण प्रवास

  1. तुम्ही Play Console मधील क्लोज्ड ट्रॅकवर तुमचे पहिले .aab अपलोड करता.
  2. तुमचा एजंट तुमच्या पॅकेज नावासाठी get_testers कॉल करतो आणि क्लोज्ड ट्रॅकवर Google Groups खाली testerexchange-testers@googlegroups.com जोडायला सांगतो.
  3. तुम्ही ग्रुप जोडता, सेव्ह करता आणि रिलीज पब्लिश झाले आहे याची खात्री करता.
  4. क्रेडिट्स कमी असतील, तर एजंट तुम्हाला चेकआउट लिंक देतो. तुम्ही पैसे देता (12 टेस्टर्सचे $12.99, 15 चे $14.99, 25 चे $22.99) किंवा https://testerexchange.com/earn वर इतर ॲप्स टेस्ट करून क्रेडिट्स मोफत कमावता.
  5. खरे टेस्टर्स 14 दिवस तुमचे ॲप इन्स्टॉल करून वापरतात. तुमचा एजंट रोज प्रगती तपासतो आणि सक्रिय टेस्टर्स कमी झाले तर तुम्हाला सावध करतो.
  6. दिवस 15 ला एजंट कॅम्पेन रिपोर्ट काढतो आणि तुमची प्रोडक्शन ॲक्सेसची उत्तरे लिहून देतो. तुम्ही ती तपासता आणि Apply for production वर क्लिक करता.

सुरक्षेच्या सूचना

  • टोकन्स git मध्ये ठेवू नका. ती तुमच्या क्लायंटच्या सीक्रेट स्टोअरमध्ये किंवा एनव्हायर्नमेंट व्हेरिएबलमध्ये ठेवा.
  • आमच्याकडे टोकन्स फक्त हॅश स्वरूपात साठवली जातात आणि प्रत्येक अकाउंटला 10 ची मर्यादा आहे. वापरात नसलेली टोकन्स रद्द करा.
  • फॉर्म सबमिट करण्यापूर्वी एजंटने तुमच्या प्रोडक्शन फॉर्मसाठी काय लिहिले आहे ते वाचा. तुमची टेस्ट खरेपणाने सांगावी अशी Google ची अपेक्षा आहे.

वारंवार विचारले जाणारे प्रश्न

AI एजंट माझ्यासाठी 14 दिवसांची टेस्ट पूर्ण करू शकतो का?

नाही. 14 दिवसांसाठी खऱ्या लोकांनी स्वतःच्या फोनवर तुमचे ॲप वापरणे आवश्यक आहे. एजंट्स सेटअप, देखरेख आणि रिपोर्टिंग सांभाळतात.

एजंट टेस्टर्ससाठी पैसे देऊ शकतो का?

नाही. तो चेकआउट लिंक्स देऊ शकतो, पण पेमेंट नेहमी माणसाच्या ब्राउझरमध्येच होते.

कोणते क्लायंट्स MCP सर्व्हरसोबत चालतात?

कस्टम हेडरसह Streamable HTTP वरील रिमोट MCP सपोर्ट करणारा कोणताही क्लायंट, ज्यात Claude Code, Claude Desktop, Cursor आणि VS Code येतात. इतर क्लायंट्स HTTP API वापरू शकतात.

टोकन कुठून मिळते?

साइन इन केल्यानंतर https://testerexchange.com/api वर. टोकन्स tx_ ने सुरू होतात आणि कधीही रद्द करता येतात.

एजंट माझ्या Play Console मध्ये काही बदलतो का?

नाही. त्याला तुमच्या Play Console चा ॲक्सेस नसतो. तिथे कोणत्या पायऱ्या कराव्यात ते तो तुम्हाला सांगतो.
