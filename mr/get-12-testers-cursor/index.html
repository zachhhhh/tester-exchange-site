Cursor ने तुमचे Android अॅप बनवले? 14 दिवसांसाठी तुमचे 12 टेस्टर्स मिळवा

नोव्हेंबर 2026 मध्ये अपडेट केले

Cursor तुमचे Android अॅप लिहू आणि बिल्ड करू शकते, पण Google Play ला आवश्यक असलेले 12 खरे टेस्टर्स ते पुरवू शकत नाही. तुमचे पर्सनल डेव्हलपर अकाउंट 13 नोव्हेंबर 2023 नंतर तयार झाले असल्यास, प्रोडक्शनसाठी अर्ज करण्यापूर्वी तुम्हाला किमान 12 टेस्टर्ससह सलग 14 दिवस क्लोज्ड टेस्ट चालवावी लागेल. हे मार्गदर्शक बंडल बनवणे, क्लोज्ड टेस्टिंग सुरू करणे, टेस्टर्स मिळवणे (आधी मोफत, मग पैसे भरून) आणि Tester Exchange ला Cursor शी जोडणे समाविष्ट करते, जेणेकरून एजंट कागदपत्रांचे काम करू शकेल.

खरी माणसे त्यांच्या स्वतःच्या फोनवर 14 दिवस तुमचे ॲप उघडतात. एकदाच पैसे द्या, किंवा इतर ॲप्स टेस्ट करून मोफत मिळवा.12 टेस्टर्स मिळवा

1. रिलीज बंडल (.aab) तयार करा

  1. Cursor च्या एजंटला तुमच्या मॉड्यूलच्या build.gradle.kts मध्ये रिलीज साइनिंग कॉन्फिगर करायला सांगा (storeFile, storePassword, keyAlias आणि keyPassword असलेला signingConfigs ब्लॉक, release build type वर लागू). पासवर्ड्स git मध्ये जाऊ देऊ नका (Android चे build डॉक्स: https://developer.android.com/build/building-cmdline).
  2. टर्मिनलमध्ये ./gradlew bundleRelease चालवा. Gradle बंडल तयार करते आणि साइन करते; .aab सहसा app/build/outputs/bundle/release/ अंतर्गत दिसते, पण तुमचे स्वतःचे build आउटपुट तपासा.
  3. तुमच्याकडे keystore नसेल तर keytool ने तयार करा आणि त्याचा बॅकअप ठेवा. तुम्ही पहिली रिलीज अपलोड करता तेव्हा Google Play App Signing देऊ केले जाते.

2. Play Console मध्ये क्लोज्ड टेस्टिंग सुरू करा

  1. Test and release > Testing > Closed testing उघडा, मग Create track (किंवा Manage track) निवडा.
  2. Create new release क्लिक करा, .aab अपलोड करा, रिलीजचे नाव आणि नोट्स जोडा, Save as draft, Next, मग Start rollout (पायऱ्या https://support.google.com/googleplay/android-developer/answer/9859348 वरून).
  3. आधी Dashboard वरील अॅप सेटअप कामे पूर्ण करा, अन्यथा रिलीज बटण निष्क्रिय राहते.

3. तुमचे 12 टेस्टर्स मिळवा: आधी मोफत, मग पैसे भरून

  • मोफत मार्ग: तुमच्या फोनवर https://testerexchange.com/earn उघडा आणि तुम्हाला दिलेले अॅप्स टेस्ट करा. तुम्ही टेस्ट केलेले प्रत्येक अॅप तुमच्या अॅपसाठी एक टेस्टर आणते.
  • पैसे भरण्याचा मार्ग: एकदाच पैसे भरा आणि टेस्टर्स आपोआप नियुक्त होतात. सध्याच्या किमती https://testerexchange.com/llms.txt वर दिल्या आहेत.
  • 12 ऐवजी 15 टेस्टर्स मागा, म्हणजे एकाने सोडले तरी तुम्ही Google च्या किमान मर्यादेखाली जाणार नाही.

4. Tester Exchange ला Cursor शी जोडा (पर्यायी)

आधी https://testerexchange.com/api वर API की तयार करा. मग हे तुमच्या प्रोजेक्टमधील .cursor/mcp.json मध्ये, किंवा सर्वत्र वापरण्यासाठी ~/.cursor/mcp.json मध्ये ठेवा (फाइलची ठिकाणे Cursor च्या MCP डॉक्समधून, https://cursor.com/docs/context/mcp). की commit होऊ नये म्हणून आधी तुमच्या shell एन्व्हायर्नमेंटमध्ये TESTER_EXCHANGE_KEY सेट करा:

{"mcpServers":{"tester-exchange":{"url":"https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp","headers":{"Authorization":"Bearer ${env:TESTER_EXCHANGE_KEY}"}}}}

Cursor, url आणि headers फील्ड्समधील ${env:NAME} सोडवते. सर्व्हर लोड न झाल्यास, Output पॅनल उघडा आणि MCP Logs निवडा. सर्व्हर हा OAuth शिवाय Streamable HTTP वरील साधा MCP आहे; सार्वजनिक टूल्स (about, pricing, platform_stats) की शिवाय चालतात.

5. एजंटला विचारा

  • "Tester Exchange वापरून com.example.app साठी 15 टेस्टर्स मिळव आणि Play Console मध्ये मला काय करायचे आहे ते सांग."
  • "com.example.app साठी माझी Tester Exchange मोहीम तपास आणि काल किती टेस्टर्स सक्रिय होते ते सांग."
  • "मोहिमेचा रिपोर्ट काढ आणि खऱ्या आकडेवारीवरून माझी प्रोडक्शन ॲक्सेसची उत्तरे मसुदा रूपात लिही."

मुख्य टूल get_testers आहे: ते अॅप जोडते, त्याची टेस्ट उघडते आणि फक्त माणूसच करू शकेल अशा पायऱ्या परत देते, जसे की Play Console मध्ये टेस्टर्सचा Google Group जोडणे. एजंट तुमच्यासाठी पैसे भरू शकत नाही किंवा Apply for production वर क्लिक करू शकत नाही.

MCP नाही? HTTP API वापरा

https://testerexchange.com/agents/ वर दिलेल्या सार्वजनिक apikey हेडरसह आणि {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}} या बॉडीसह https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call वर POST करा. स्कीमा https://testerexchange.com/openapi.json वर आहे. आणखी टूल्स: https://testerexchange.com/guide/ai-builders/.

वारंवार विचारले जाणारे प्रश्न

Cursor माझ्यासाठी 14 दिवसांची टेस्ट पूर्ण करू शकते का?

नाही. 14 दिवसांसाठी खरे लोक तुमचे अॅप त्यांच्या स्वतःच्या Android फोनवर वापरणे आवश्यक आहे. Cursor अॅप बनवू शकते आणि सेटअप चालवू शकते.

Tester Exchange हे अधिकृत Cursor इंटिग्रेशन आहे का?

नाही. ही एक स्वतंत्र सेवा आहे जी HTTP वर रिमोट MCP सपोर्ट करणाऱ्या कोणत्याही क्लायंटसह काम करते, आणि Cursor ते करते.

AAB कुठे जाते?

ते Play Console मधील क्लोज्ड टेस्टिंग रिलीजमध्ये अपलोड करा, मग त्या ट्रॅकवर तुमच्या टेस्टर्सचा Google Group किंवा ईमेल यादी जोडा.

12 टेस्टर्स मिळवण्याचा मोफत मार्ग आहे का?

होय. https://testerexchange.com/earn वर इतर डेव्हलपर्सचे अॅप्स टेस्ट करा; तुम्ही टेस्ट केलेले प्रत्येक अॅप तुमच्या अॅपसाठी एक टेस्टर आणते.
