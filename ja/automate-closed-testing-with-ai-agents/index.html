AI エージェントで Google Play のクローズド テストを自動化する

2026 年 11 月更新

すでに AI エージェントでコードを書いているなら、Google Play のクローズド テスト要件にまつわる雑務の大半もエージェントに任せられます。アプリの登録、テスターの募集、進捗の確認、製品版へのアクセス申請フォーム用の数字の取得などです。Tester Exchange には、このための MCP サーバー、1 エンドポイントの HTTP API、A2A エージェント カードがあります。このガイドでは、Claude Code、Claude Desktop、Cursor などのクライアントの接続方法、依頼する内容、そしてエージェントには任せられない作業を紹介します。

実在の人が 14 日間、自分のスマートフォンであなたのアプリを開きます。1 回の支払い、または他のアプリを無料でテストして獲得できます。12 人のテスターを獲得

エージェントにできること、できないこと

Google は、2023 年 11 月 13 日以降に作成された個人のデベロッパー アカウントに対し、製品版を申請する前に、12 人以上のテスターが 14 日間連続でオプトインしたクローズド テストを行うことを求めています。その周辺作業の大半は調整業務で、エージェントが得意とするところです。

  • エージェントにできること：アプリの追加、テスター募集の開始、クレジットの適用、アクティブなテスター数の確認、募集の一時停止や終了、毎日の利用レポートの取得、そのレポートをもとにした製品版へのアクセス申請の回答案づくり。
  • 人間が行うこと：Play Console でテスターの Google Group をクローズド トラックに追加すること、リリースの公開、クレジットの支払い（決済は必ず人間のブラウザで行います）、［製品版を申請］のクリック。
  • 誰にも自動化できないこと：14 日間の実際の利用です。これは本物の人が自分の Android スマートフォンで行うもので、それこそが Google のルールの目的です。

1. トークンを作成する

  1. https://testerexchange.com/api にログインします。
  2. 個人用トークンを作成します。トークンは tx_ で始まります。今すぐコピーして、パスワードと同じように保管してください。
  3. トークンはいつでも無効にできます。トークンで募集にクレジットを使うことはできますが、支払い、出金、アカウントの削除はできません。

2. MCP サーバーを接続する

MCP サーバーは https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp で Streamable HTTP を使います。トークンはヘッダー Authorization: Bearer tx_YOUR_TOKEN で送信します。

Claude Code：ターミナルで次のコマンドを一度だけ実行します。

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop、Cursor、VS Code など JSON 設定を使うクライアント：tester-exchange という名前のサーバーを type を http にして追加し、上の URL と、Authorization を Bearer tx_YOUR_TOKEN に設定した headers を指定します。設定ファイルの場所はクライアントによって異なるので、各クライアントの MCP のドキュメントを確認してください。

URL だけを受け付けるクライアント（一部の ChatGPT やウェブ コネクタ）：https://testerexchange.com/agents/ のドキュメントに、そうしたクライアント向けの URL 形式が載っています。トークンがなくても、公開ツール（Tester Exchange の概要、料金、プラットフォームの統計）は使えます。

3. 最初に使うツール：get_testers

ツールの一覧をすべて覚える必要はありません。メインのツールは get_testers(package_name, name?) です。1 回呼び出すだけで、アプリの追加、テストの開始、クレジットの適用が行われ、進捗と、Play Console での Google Group の追加など人間にしかできない手順が返されます。進捗を確認したいときは、いつでもまた呼び出せます。

そのほかのツールは細かい操作に使います。my_apps、campaign_report（テスター、毎日の利用、フィードバック、製品版へのアクセス申請用のデータ）、add_testers、set_campaign_status（一時停止、再開、終了。未使用のクレジットは残高に戻ります）、share_kit、そして人間が支払うためのチェックアウト リンクを返す buy_credits_links があります。

使いやすいプロンプト

  • 「com.example.app のテスターを 15 人集めて。Play Console で私がやることを教えて。」
  • 「com.example.app の Tester Exchange の募集を確認して。今週、毎日何人のテスターがアクティブだった？」
  • 「募集レポートを取得して、製品版へのアクセス申請の回答案を作って。実際の数字だけを使って。」
  • 「製品版へのアクセスが承認されたので、com.example.app の募集を終了して。」

12 人ではなく 15 人を依頼しましょう。誰かが抜けても Google の最低人数を割らずに済みます。

スクリプトや CI 向けの HTTP API

使っているツールが MCP に対応していない場合は、HTTP エンドポイントを使います。POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call に JSON を送信します。本文には p_token（tx_ のトークン）、p_action（help、my_apps、start_campaign など）、p_args（package_name やテスター数など）を指定します。ドキュメントに載っている公開用の apikey ヘッダーも付けてください。

まず help アクションを呼び出すと、使える全アクションとその引数が返ってきます。完全なスキーマは https://testerexchange.com/openapi.json にあり、ChatGPT のカスタム GPT アクションやほかの OpenAPI ツールで使えます。

A2A エージェント カード

エージェント同士を連携させる構成のために、Tester Exchange は https://testerexchange.com/.well-known/agent-card.json で A2A エージェント カードを公開しています。A2A プロトコルに対応したオーケストレーターは、このエージェントが何を提供し、どう呼び出すかを自動で把握できます。アカウントに関わる操作には、同じ tx_ トークンを使ってください。

最初から最後までの流れ

  1. Play Console で、最初の .aab をクローズド トラックにアップロードします。
  2. エージェントがパッケージ名で get_testers を呼び出し、クローズド トラックの［Google Group］に testerexchange-testers@googlegroups.com を追加するよう案内します。
  3. グループを追加して保存し、リリースが公開されていることを確認します。
  4. クレジットが足りない場合は、エージェントがチェックアウト リンクを渡します。支払うか（12 人で $12.99、15 人で $14.99、25 人で $22.99）、https://testerexchange.com/earn でほかのアプリをテストして無料でクレジットをためます。
  5. 本物のテスターが 14 日間、アプリをインストールして使います。エージェントが毎日進捗を確認し、アクティブなテスターが減ったら知らせます。
  6. 15 日目に、エージェントが募集レポートを取得し、製品版へのアクセス申請の回答案を作ります。内容を確認して、［製品版を申請］をクリックします。

セキュリティ上の注意

  • トークンは git に入れないでください。クライアントのシークレット ストアか環境変数に保存しましょう。
  • トークンは当社側ではハッシュ値としてのみ保存され、1 アカウントにつき 10 個までです。使わなくなったトークンは無効にしてください。
  • 送信する前に、エージェントが製品版の申請フォームに書いた内容を必ず読んでください。Google は、テストの内容を正直に記入するよう求めています。

よくある質問

AI エージェントに 14 日間のテストを代わりにやってもらえますか？

いいえ。14 日間のテストには、本物の人が自分のスマートフォンでアプリを使うことが必要です。エージェントが担当するのは、設定、モニタリング、レポート作成です。

エージェントがテスターの料金を支払えますか？

いいえ。チェックアウト リンクを返すことはできますが、支払いは必ず人間のブラウザで行います。

MCP サーバーはどのクライアントで使えますか？

カスタム ヘッダー付きの Streamable HTTP によるリモート MCP に対応していれば、Claude Code、Claude Desktop、Cursor、VS Code など、どのクライアントでも使えます。それ以外は HTTP API を使ってください。

トークンはどこで取得できますか？

ログイン後に https://testerexchange.com/api で取得します。トークンは tx_ で始まり、いつでも無効にできます。

エージェントは私の Play Console を変更しますか？

いいえ。Play Console へのアクセス権はなく、そこで行う手順をあなたに案内するだけです。
