AIコーディングツールからGoogle Playの12人のテスターを獲得しよう

2026年11月更新

バイブコーディングでも、AIエディタで手書きでも、新しい個人用デベロッパーアカウントが本番公開するには、14日間オプトインしたテスター12人がGoogle Playから求められます。このハブでは、AIツールごとのTester Exchangeガイドを紹介します。Android App Bundleの作り方、クローズドテストの始め方、そしてテスターの集め方（先に他のアプリをテストして無料で、または有料でより速く）です。各ページには、AIツール自身がTester Exchangeを操作できるよう、そのままコピー＆ペーストできる設定も載せています。

ツール別ガイド

ツールは随時追加されます。現在のラインナップ：

  • Cursor： https://testerexchange.com/guide/get-12-testers-cursor/ - GradleでAABをビルドし、.cursor/mcp.json でTester ExchangeをCursorに接続します。
  • Claude Code: https://testerexchange.com/guide/get-12-testers-claude-code/ - build the AAB with Gradle, then add Tester Exchange with one claude mcp add command.

テスターを集める2つの方法

  • 無料： スマートフォンで https://testerexchange.com/earn から他のデベロッパーのアプリをテストします。テストしたアプリ1つにつき、あなたのアプリに1人のテスターが付くので、お金をかけずに12人分を埋められます。
  • 有料でより速く： テスターパックを一度だけ購入します。現在の料金は https://testerexchange.com/llms.txt にあります。有料のアプリには、他の誰よりも先にテスターが付きます。

Googleの要件

GoogleのPlay Consoleヘルプによると、2023年11月13日以降に作成された個人用デベロッパーアカウントは、本番環境へのアクセスを申請する前に、少なくとも12人のテスターが14日以上連続でオプトインしたクローズドテストを実施する必要があります（https://support.google.com/googleplay/android-developer/answer/14151465）。この14日間をAIツールが代わりに行うことはできません。実在の人が実際の端末で参加する必要があります。

セットアップはAIツールに任せよう

Tester Exchangeには、MCPサーバー、HTTP API、A2Aエージェントがあります。対応クライアントの一覧と設定スニペットは https://testerexchange.com/agents/ にあります。総合ガイドは https://testerexchange.com/guide/automate-closed-testing-with-ai-agents/ です。

よくある質問

Tester Exchangeを使うのにAIツールは必要ですか？

いいえ。ウェブサイト単体で利用できます。MCPサーバーとAPIは、すでにAIツールを使っている人向けの任意のショートカットです。

AIツールがテスターの料金を支払えますか？

いいえ。チェックアウトのリンクを返すことはできますが、支払いはブラウザで行います。無料の方法は https://testerexchange.com/earn で他のアプリをテストすることです。

Tester Exchangeはこれらのツールの公式連携ですか？

いいえ。独立したサービスです。これらのページは、各ツール標準のMCPまたはHTTPサポートをTester Exchangeに接続する方法を示しているだけです。
