Cursor দিয়ে Android অ্যাপ বানিয়েছেন? ১৪ দিনের জন্য আপনার ১২ জন টেস্টার পান

নভেম্বর ২০২৬-এ আপডেট করা হয়েছে

Cursor আপনার Android অ্যাপ লিখতে ও বিল্ড করতে পারে, কিন্তু Google Play যে ১২ জন আসল টেস্টার চায় তাদের জোগাড় করে দিতে পারে না। আপনার ব্যক্তিগত ডেভেলপার অ্যাকাউন্ট যদি ২০২৩ সালের ১৩ নভেম্বরের পরে তৈরি হয়, তাহলে প্রোডাকশনের জন্য আবেদনের আগে অন্তত ১২ জন টেস্টার একটানা ১৪ দিন অপ্ট-ইন থাকা অবস্থায় আপনাকে ক্লোজড টেস্ট চালাতে হবে। এই গাইডে আছে বান্ডল বানানো, ক্লোজড টেস্টিং শুরু করা, টেস্টার পাওয়া (আগে বিনামূল্যে, পরে পেইড) এবং Tester Exchange-কে Cursor-এর সাথে যুক্ত করা, যাতে এজেন্ট কাগজপত্রের কাজ সামলে দেয়।

আসল মানুষ 14 দিন নিজের ফোনে আপনার অ্যাপ খোলেন। একবার পেমেন্ট করুন, অথবা অন্য অ্যাপ টেস্ট করে ফ্রি-তে পান।12 জন টেস্টার পান

১. রিলিজ বান্ডল (.aab) বানান

  1. Cursor-এর এজেন্টকে বলুন আপনার মডিউলের build.gradle.kts-এ রিলিজ সাইনিং কনফিগার করতে (storeFile, storePassword, keyAlias ও keyPassword সহ একটি signingConfigs ব্লক, release বিল্ড টাইপে সেট করা)। পাসওয়ার্ড git-এর বাইরে রাখুন (Android-এর বিল্ড ডকুমেন্টেশন: https://developer.android.com/build/building-cmdline)।
  2. টার্মিনালে ./gradlew bundleRelease চালান। Gradle বান্ডল বিল্ড ও সাইন করে; .aab সাধারণত app/build/outputs/bundle/release/-এর নিচে থাকে, তবে নিজের বিল্ড আউটপুট দেখে নিন।
  3. আপনার কাছে না থাকলে keytool দিয়ে একটি keystore বানান এবং তার ব্যাকআপ রাখুন। প্রথম রিলিজ আপলোডের সময় Google Play App Signing দেওয়া হয়।

২. Play Console-এ ক্লোজড টেস্টিং শুরু করুন

  1. Test and release > Testing > Closed testing খুলুন, তারপর Create track (বা Manage track) ক্লিক করুন।
  2. Create new release ক্লিক করুন, .aab আপলোড করুন, রিলিজের নাম ও নোট যোগ করুন, Save as draft, Next, তারপর Start rollout (ধাপগুলো https://support.google.com/googleplay/android-developer/answer/9859348 থেকে)।
  3. আগে Dashboard-এ অ্যাপ সেটআপের কাজগুলো শেষ করুন, নইলে রিলিজ বোতাম নিষ্ক্রিয় থাকবে।

৩. আপনার ১২ জন টেস্টার পান: আগে বিনামূল্যে, পরে পেইড

  • বিনামূল্যের পথ: ফোনে https://testerexchange.com/earn খুলুন এবং আপনাকে দেওয়া অ্যাপগুলো টেস্ট করুন। আপনি যে অ্যাপ টেস্ট করবেন তার বিনিময়ে আপনার অ্যাপে একজন টেস্টার আসবে।
  • পেইড পথ: একবার পেমেন্ট করুন, টেস্টার স্বয়ংক্রিয়ভাবে নির্ধারিত হবে। বর্তমান দাম https://testerexchange.com/llms.txt -এ তালিকাভুক্ত আছে।
  • ১২ জনের বদলে ১৫ জন টেস্টার চান, যাতে একজন ছেড়ে গেলে আপনি Google-এর ন্যূনতম সংখ্যার নিচে না নামেন।

৪. Tester Exchange-কে Cursor-এর সাথে যুক্ত করুন (ঐচ্ছিক)

প্রথমে https://testerexchange.com/api-তে একটি API কী বানান। তারপর এটি আপনার প্রজেক্টের .cursor/mcp.json-এ রাখুন, অথবা সব জায়গায় ব্যবহার করতে ~/.cursor/mcp.json-এ রাখুন (ফাইলের অবস্থান Cursor-এর MCP ডকুমেন্টেশন অনুযায়ী, https://cursor.com/docs/context/mcp)। আগে আপনার shell এনভায়রনমেন্টে TESTER_EXCHANGE_KEY সেট করুন, যাতে কী commit না হয়:

{"mcpServers":{"tester-exchange":{"url":"https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp","headers":{"Authorization":"Bearer ${env:TESTER_EXCHANGE_KEY}"}}}}

Cursor url ও headers ফিল্ডে ${env:NAME} রিজলভ করে। কোনো সার্ভার লোড না হলে Output প্যানেল খুলে MCP Logs বেছে নিন। সার্ভারটি OAuth ছাড়া Streamable HTTP-এর ওপর সাধারণ MCP; পাবলিক টুলগুলো (about, pricing, platform_stats) কী ছাড়াই কাজ করে।

৫. এজেন্টকে বলুন

  • “com.example.app-এর জন্য Tester Exchange ব্যবহার করে ১৫ জন টেস্টার জোগাড় করো এবং Play Console-এ আমাকে কী করতে হবে বলো।”
  • “com.example.app-এর জন্য আমার Tester Exchange ক্যাম্পেইন দেখো এবং গতকাল কতজন টেস্টার সক্রিয় ছিল বলো।”
  • “ক্যাম্পেইন রিপোর্ট নাও এবং আসল সংখ্যার ভিত্তিতে আমার প্রোডাকশন অ্যাক্সেসের উত্তরের খসড়া করো।”

প্রধান টুল হলো get_testers: এটি অ্যাপ যোগ করে, তার টেস্ট চালু করে এবং শুধু মানুষই যা করতে পারে সেই ধাপগুলো ফেরত দেয়, যেমন Play Console-এ টেস্টারদের Google Group যোগ করা। এজেন্ট আপনার হয়ে পেমেন্ট করতে বা Apply for production ক্লিক করতে পারে না।

MCP নেই? HTTP API ব্যবহার করুন

https://testerexchange.com/agents/ -এ তালিকাভুক্ত পাবলিক apikey হেডার এবং {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}} বডি দিয়ে https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call -এ POST করুন। স্কিমা https://testerexchange.com/openapi.json -এ আছে। আরও টুল: https://testerexchange.com/guide/ai-builders/ ।

সচরাচর জিজ্ঞাসা

Cursor কি আমার হয়ে ১৪ দিনের টেস্ট সম্পূর্ণ করতে পারে?

না। এই ১৪ দিনে আসল মানুষকে নিজেদের Android ফোনে আপনার অ্যাপ ব্যবহার করতে হবে। Cursor অ্যাপ বিল্ড করতে এবং সেটআপ চালাতে পারে।

Tester Exchange কি Cursor-এর অফিসিয়াল ইন্টিগ্রেশন?

না। এটি একটি স্বাধীন সেবা, যা HTTP-এর ওপর রিমোট MCP সাপোর্ট করে এমন যেকোনো ক্লায়েন্টের সাথে কাজ করে, Cursor যার একটি।

AAB কোথায় যাবে?

Play Console-এ একটি ক্লোজড টেস্টিং রিলিজে এটি আপলোড করুন, তারপর সেই ট্র্যাকে আপনার টেস্টারদের Google Group বা ইমেইল তালিকা যোগ করুন।

১২ জন টেস্টার পাওয়ার কি কোনো বিনামূল্যের উপায় আছে?

হ্যাঁ। https://testerexchange.com/earn -এ অন্য ডেভেলপারদের অ্যাপ টেস্ট করুন; আপনি যে অ্যাপ টেস্ট করবেন তার বিনিময়ে আপনার অ্যাপে একজন টেস্টার আসবে।
