Tester Exchange Tester Exchange തുറക്കുക

AI agents ഉപയോഗിച്ച് Google Play closed testing ഓട്ടോമേറ്റ് ചെയ്യാം

2026 നവംബറിൽ അപ്ഡേറ്റ് ചെയ്തത്

കോഡ് എഴുതാൻ ഇതിനകം ഒരു AI agent ഉപയോഗിക്കുന്നുണ്ടെങ്കിൽ, Google Play-യുടെ closed testing നിബന്ധനയിലെ മിക്ക ചെറിയ ജോലികളും അതിനെ ഏൽപ്പിക്കാം: ആപ്പ് ലിസ്റ്റ് ചെയ്യുക, testers-നെ കണ്ടെത്തുക, പുരോഗതി പരിശോധിക്കുക, production access ഫോമിനുള്ള കണക്കുകൾ എടുക്കുക. ഇതിനായി Tester Exchange-ന് ഒരു MCP സെർവർ, ഒറ്റ എൻഡ്‌പോയിന്റുള്ള HTTP API, ഒരു A2A agent card എന്നിവയുണ്ട്. Claude Code, Claude Desktop, Cursor, മറ്റ് ക്ലയന്റുകൾ എങ്ങനെ കണക്ട് ചെയ്യാം, എന്ത് ചോദിക്കണം, ഒരു agent-നും നിങ്ങൾക്കായി ചെയ്യാൻ കഴിയാത്ത കാര്യങ്ങൾ ഏതൊക്കെ എന്നിവ ഈ ഗൈഡ് കാണിക്കുന്നു.

യഥാർത്ഥ ആളുകൾ 14 ദിവസം സ്വന്തം ഫോണുകളിൽ നിങ്ങളുടെ ആപ്പ് തുറക്കുന്നു. ഒരിക്കൽ പണമടയ്ക്കൂ, അല്ലെങ്കിൽ മറ്റ് ആപ്പുകൾ ടെസ്റ്റ് ചെയ്ത് സൗജന്യമായി നേടൂ.12 testers-നെ നേടൂ

ഒരു agent-ന് എന്ത് ചെയ്യാം, എന്ത് ചെയ്യാൻ കഴിയില്ല

2023 നവംബർ 13-ന് ശേഷം ഉണ്ടാക്കിയ personal developer അക്കൗണ്ടുകൾ production-ന് അപേക്ഷിക്കുന്നതിന് മുമ്പ് കുറഞ്ഞത് 12 testers 14 ദിവസം തുടർച്ചയായി opt-in ആയിരിക്കുന്ന closed test നടത്തണമെന്ന് Google ആവശ്യപ്പെടുന്നു. ഇതിനു ചുറ്റുമുള്ള മിക്ക ജോലിയും ഏകോപനമാണ്, അത് agents നന്നായി ചെയ്യും.

  • ഒരു agent-ന് ചെയ്യാം: നിങ്ങളുടെ ആപ്പ് ചേർക്കുക, tester campaign തുറക്കുക, ക്രെഡിറ്റുകൾ ഉപയോഗിക്കുക, എത്ര testers സജീവമാണെന്ന് പരിശോധിക്കുക, campaign താൽക്കാലികമായി നിർത്തുകയോ അടയ്ക്കുകയോ ചെയ്യുക, ദൈനംദിന പ്രവർത്തന റിപ്പോർട്ട് എടുക്കുക, അതിൽ നിന്ന് production access ഉത്തരങ്ങളുടെ ഡ്രാഫ്റ്റ് തയ്യാറാക്കാൻ സഹായിക്കുക.
  • ഒരു മനുഷ്യൻ ചെയ്യണം: Play Console-ൽ closed track-ലേക്ക് testers-ന്റെ Google Group ചേർക്കുക, റിലീസ് പബ്ലിഷ് ചെയ്യുക, ക്രെഡിറ്റുകൾക്ക് പണമടയ്ക്കുക (ചെക്കൗട്ട് എപ്പോഴും ഒരു വ്യക്തിയുടെ ബ്രൗസറിലാണ്), Apply for production ക്ലിക്ക് ചെയ്യുക.
  • ആർക്കും ഓട്ടോമേറ്റ് ചെയ്യാൻ കഴിയാത്തത്: 14 ദിവസത്തെ യഥാർത്ഥ ഉപയോഗം. യഥാർത്ഥ ആളുകൾ സ്വന്തം Android ഫോണുകളിലാണ് അത് ചെയ്യുന്നത്, അതാണ് Google-ന്റെ നിയമത്തിന്റെ ഉദ്ദേശ്യം.

1. ഒരു ടോക്കൺ ഉണ്ടാക്കൂ

  1. https://testerexchange.com/api-ൽ സൈൻ ഇൻ ചെയ്യൂ.
  2. ഒരു personal ടോക്കൺ ഉണ്ടാക്കൂ. അത് tx_ എന്ന് തുടങ്ങും. ഇപ്പോൾ തന്നെ കോപ്പി ചെയ്ത് പാസ്‌വേഡ് പോലെ സൂക്ഷിക്കൂ.
  3. ടോക്കണുകൾ എപ്പോൾ വേണമെങ്കിലും റദ്ദാക്കാം. ഒരു ടോക്കണിന് campaigns-ൽ ക്രെഡിറ്റുകൾ ചെലവഴിക്കാം, പക്ഷേ പണമടയ്ക്കാനോ പണം പിൻവലിക്കാനോ നിങ്ങളുടെ അക്കൗണ്ട് ഇല്ലാതാക്കാനോ കഴിയില്ല.

2. MCP സെർവർ കണക്ട് ചെയ്യൂ

MCP സെർവർ Streamable HTTP ഉപയോഗിക്കുന്നു, വിലാസം https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp. നിങ്ങളുടെ ടോക്കൺ Authorization: Bearer tx_YOUR_TOKEN എന്ന ഹെഡറിൽ അയക്കൂ.

Claude Code: ടെർമിനലിൽ ഒരിക്കൽ ഇത് റൺ ചെയ്യൂ.

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code, JSON കോൺഫിഗ് ഉപയോഗിക്കുന്ന മറ്റ് ക്ലയന്റുകൾ: tester-exchange എന്ന പേരിൽ ഒരു സെർവർ ചേർക്കൂ, type http, മുകളിലെ URL, Authorization എന്നത് Bearer tx_YOUR_TOKEN ആയി സജ്ജമാക്കിയ headers എൻട്രി എന്നിവ നൽകി. കോൺഫിഗ് ഫയൽ എവിടെയാണെന്നത് ക്ലയന്റിനെ ആശ്രയിച്ചിരിക്കും; അതിന്റെ MCP ഡോക്യുമെന്റേഷൻ നോക്കൂ.

URL മാത്രം സ്വീകരിക്കുന്ന ക്ലയന്റുകൾ (ചില ChatGPT, വെബ് കണക്ടറുകൾ): https://testerexchange.com/agents/-ലെ ഡോക്സിൽ അവർക്കായുള്ള URL രൂപം നൽകിയിട്ടുണ്ട്. ടോക്കൺ ഇല്ലെങ്കിലും പൊതു ടൂളുകൾ (Tester Exchange എന്താണ്, വിലകൾ, പ്ലാറ്റ്ഫോം കണക്കുകൾ) പ്രവർത്തിക്കും.

3. തുടങ്ങാനുള്ള ഒരേയൊരു ടൂൾ: get_testers

ടൂൾ ലിസ്റ്റ് മുഴുവൻ പഠിക്കേണ്ടതില്ല. പ്രധാന ടൂൾ get_testers(package_name, name?) ആണ്. ഒരൊറ്റ കോൾ നിങ്ങളുടെ ആപ്പ് ചേർക്കുകയും അതിന്റെ test തുറക്കുകയും ക്രെഡിറ്റുകൾ ഉപയോഗിക്കുകയും, പുരോഗതിയും മനുഷ്യന് മാത്രം ചെയ്യാവുന്ന ഘട്ടങ്ങളും (ഉദാഹരണത്തിന് Play Console-ൽ Google Group ചേർക്കുക) തിരികെ നൽകുകയും ചെയ്യും. പുരോഗതി അറിയാൻ എപ്പോൾ വേണമെങ്കിലും വീണ്ടും വിളിക്കാം.

വിശദാംശങ്ങൾക്ക് മറ്റ് ടൂളുകളുണ്ട്: my_apps, campaign_report (testers, ദൈനംദിന പ്രവർത്തനം, ഫീഡ്ബാക്ക്, production-access ഡാറ്റ), add_testers, set_campaign_status (താൽക്കാലികമായി നിർത്തുക, തുടരുക, അടയ്ക്കുക; ഉപയോഗിക്കാത്ത ക്രെഡിറ്റുകൾ ബാലൻസിലേക്ക് തിരിച്ചുവരും), share_kit, buy_credits_links (ഒരു മനുഷ്യന് പണമടയ്ക്കാനുള്ള ചെക്കൗട്ട് ലിങ്കുകൾ നൽകുന്നു).

നന്നായി പ്രവർത്തിക്കുന്ന പ്രോംപ്റ്റുകൾ

  • "com.example.app-ന് 15 testers-നെ നേടൂ, Play Console-ൽ ഞാൻ എന്തു ചെയ്യണമെന്ന് പറയൂ."
  • "com.example.app-ന്റെ എന്റെ Tester Exchange campaign പരിശോധിക്കൂ. ഈ ആഴ്ച ഓരോ ദിവസവും എത്ര testers സജീവമായിരുന്നു?"
  • "Campaign റിപ്പോർട്ട് എടുത്ത് എന്റെ production access ഉത്തരങ്ങൾ ഡ്രാഫ്റ്റ് ചെയ്യൂ. യഥാർത്ഥ കണക്കുകൾ മാത്രം ഉപയോഗിക്കൂ."
  • "Production access അംഗീകരിച്ചതിനാൽ com.example.app-ന്റെ campaign ഇപ്പോൾ അടയ്ക്കൂ."

12-ന് പകരം 15 testers ചോദിക്കൂ, അങ്ങനെ ഒരാൾ പോയാലും Google-ന്റെ കുറഞ്ഞ എണ്ണത്തിന് താഴെ പോകില്ല.

സ്ക്രിപ്റ്റുകൾക്കും CI-ക്കുമുള്ള HTTP API

നിങ്ങളുടെ ടൂൾ MCP സംസാരിക്കുന്നില്ലെങ്കിൽ HTTP എൻഡ്‌പോയിന്റ് ഉപയോഗിക്കൂ: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call. ബോഡി JSON ആണ്: p_token (നിങ്ങളുടെ tx_ ടോക്കൺ), p_action (ഉദാഹരണത്തിന് help, my_apps അല്ലെങ്കിൽ start_campaign), p_args (ഉദാഹരണത്തിന് package_name, tester എണ്ണം). ഡോക്സിൽ കാണിച്ചിട്ടുള്ള പൊതു apikey ഹെഡർ അയക്കൂ.

ആദ്യം help action വിളിക്കൂ: അത് എല്ലാ actions-ഉം അവയുടെ ആർഗ്യുമെന്റുകളും നൽകും. പൂർണ്ണ സ്കീമ https://testerexchange.com/openapi.json-ൽ ലഭ്യമാണ്, ഇത് ChatGPT custom GPT actions-നും മറ്റ് OpenAPI ടൂളുകൾക്കും പ്രവർത്തിക്കും.

A2A agent card

agent-to-agent സെറ്റപ്പുകൾക്കായി Tester Exchange https://testerexchange.com/.well-known/agent-card.json-ൽ ഒരു A2A agent card പ്രസിദ്ധീകരിക്കുന്നു. A2A പ്രോട്ടോക്കോൾ പിന്തുണയ്ക്കുന്ന orchestrators-ന് ഈ agent എന്താണ് നൽകുന്നതെന്നും എങ്ങനെ വിളിക്കണമെന്നും കണ്ടെത്താം. നിങ്ങളുടെ അക്കൗണ്ടുമായി ബന്ധപ്പെട്ട എന്തിനും അതേ tx_ ടോക്കൺ ഉപയോഗിക്കൂ.

തുടക്കം മുതൽ ഒടുക്കം വരെ ഒരു പൂർണ്ണ റൺ

  1. Play Console-ൽ closed track-ലേക്ക് ആദ്യത്തെ .aab നിങ്ങൾ അപ്‌ലോഡ് ചെയ്യുന്നു.
  2. നിങ്ങളുടെ agent പാക്കേജ് പേരിനായി get_testers വിളിച്ച്, closed track-ലെ Google Groups-ന് കീഴിൽ testerexchange-testers@googlegroups.com ചേർക്കാൻ നിങ്ങളോട് പറയുന്നു.
  3. നിങ്ങൾ ഗ്രൂപ്പ് ചേർത്ത് സേവ് ചെയ്യുന്നു, റിലീസ് പബ്ലിഷ് ആയെന്ന് ഉറപ്പാക്കുന്നു.
  4. ക്രെഡിറ്റുകൾ ഇല്ലെങ്കിൽ agent ഒരു ചെക്കൗട്ട് ലിങ്ക് നൽകുന്നു. നിങ്ങൾ പണമടയ്ക്കുന്നു (12 testers-ന് $12.99, 15-ന് $14.99, 25-ന് $22.99) അല്ലെങ്കിൽ https://testerexchange.com/earn-ൽ മറ്റ് ആപ്പുകൾ ടെസ്റ്റ് ചെയ്ത് സൗജന്യമായി ക്രെഡിറ്റുകൾ നേടുന്നു.
  5. യഥാർത്ഥ testers 14 ദിവസം നിങ്ങളുടെ ആപ്പ് ഇൻസ്റ്റാൾ ചെയ്ത് ഉപയോഗിക്കുന്നു. നിങ്ങളുടെ agent ദിവസവും പുരോഗതി പരിശോധിക്കുകയും സജീവ testers കുറഞ്ഞാൽ മുന്നറിയിപ്പ് നൽകുകയും ചെയ്യുന്നു.
  6. 15-ാം ദിവസം agent campaign റിപ്പോർട്ട് എടുത്ത് നിങ്ങളുടെ production access ഉത്തരങ്ങൾ ഡ്രാഫ്റ്റ് ചെയ്യുന്നു. നിങ്ങൾ അവ പരിശോധിച്ച് Apply for production ക്ലിക്ക് ചെയ്യുന്നു.

സുരക്ഷാ കുറിപ്പുകൾ

  • ടോക്കണുകൾ git-ൽ ഇടരുത്. ക്ലയന്റിന്റെ secret store-ലോ ഒരു എൻവയോൺമെന്റ് വേരിയബിളിലോ സൂക്ഷിക്കൂ.
  • ടോക്കണുകൾ ഞങ്ങളുടെ ഭാഗത്ത് ഹാഷുകളായി മാത്രമേ സൂക്ഷിക്കൂ, ഒരു അക്കൗണ്ടിന് പരമാവധി 10 ടോക്കണുകൾ. ഉപയോഗിക്കാത്ത ടോക്കണുകൾ റദ്ദാക്കൂ.
  • സമർപ്പിക്കുന്നതിന് മുമ്പ് production ഫോമിൽ agent എഴുതിയത് വായിച്ചുനോക്കൂ. നിങ്ങളുടെ test സത്യസന്ധമായി വിവരിക്കാൻ Google ആവശ്യപ്പെടുന്നു.

പതിവ് ചോദ്യങ്ങൾ

14 ദിവസത്തെ test ഒരു AI agent-ന് എനിക്കായി പൂർത്തിയാക്കാൻ കഴിയുമോ?

ഇല്ല. 14 ദിവസത്തിന് സ്വന്തം ഫോണുകളിൽ നിങ്ങളുടെ ആപ്പ് ഉപയോഗിക്കുന്ന യഥാർത്ഥ ആളുകൾ വേണം. സെറ്റപ്പ്, നിരീക്ഷണം, റിപ്പോർട്ടിംഗ് എന്നിവ agents ചെയ്യും.

Testers-ന് വേണ്ടി agent-ന് പണമടയ്ക്കാൻ കഴിയുമോ?

ഇല്ല. ചെക്കൗട്ട് ലിങ്കുകൾ തിരികെ നൽകാൻ അതിന് കഴിയും, പക്ഷേ പണമടയ്ക്കൽ എപ്പോഴും ഒരു മനുഷ്യന്റെ ബ്രൗസറിലാണ്.

ഏതൊക്കെ ക്ലയന്റുകൾ MCP സെർവറിനൊപ്പം പ്രവർത്തിക്കും?

Custom ഹെഡറോടുകൂടിയ Streamable HTTP വഴിയുള്ള remote MCP പിന്തുണയ്ക്കുന്ന ഏത് ക്ലയന്റും, Claude Code, Claude Desktop, Cursor, VS Code എന്നിവ ഉൾപ്പെടെ. മറ്റുള്ളവയ്ക്ക് HTTP API ഉപയോഗിക്കാം.

ടോക്കൺ എവിടെ നിന്ന് ലഭിക്കും?

സൈൻ ഇൻ ചെയ്ത ശേഷം https://testerexchange.com/api-ൽ. ടോക്കണുകൾ tx_ എന്ന് തുടങ്ങും, എപ്പോൾ വേണമെങ്കിലും റദ്ദാക്കാം.

Agent എന്റെ Play Console-ൽ എന്തെങ്കിലും മാറ്റുമോ?

ഇല്ല. നിങ്ങളുടെ Play Console-ലേക്ക് അതിന് ആക്സസ് ഇല്ല. അവിടെ ചെയ്യേണ്ട ഘട്ടങ്ങൾ അത് നിങ്ങളോട് പറയും.

യഥാർത്ഥ ആളുകൾ 14 ദിവസം സ്വന്തം ഫോണുകളിൽ നിങ്ങളുടെ ആപ്പ് തുറക്കുന്നു. ഒരിക്കൽ പണമടയ്ക്കൂ, അല്ലെങ്കിൽ മറ്റ് ആപ്പുകൾ ടെസ്റ്റ് ചെയ്ത് സൗജന്യമായി നേടൂ.12 testers-നെ നേടൂ
