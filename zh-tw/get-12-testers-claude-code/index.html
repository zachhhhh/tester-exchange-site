用 Claude Code 開發了 Android 應用程式？取得 14 天的 12 位測試人員

更新於 2026 年 11 月

Claude Code 可以撰寫並建置你的 Android 應用程式，但無法提供 Google Play 要求的 12 位真實測試人員。如果你的個人開發人員帳戶是在 2023 年 11 月 13 日之後建立的，就必須先進行封閉測試，且至少有 12 位測試人員連續加入 14 天，才能申請正式版。本指南涵蓋建置 bundle、開始封閉測試、取得測試人員（先免費、後付費），以及將 Tester Exchange 連接到 Claude Code，讓代理程式處理繁瑣的文書作業。

真人在自己的手機上開啟你的應用程式，持續 14 天。付一次費，或免費測試其他應用程式。取得 12 位測試人員

1. 建置 release bundle (.aab)

  1. 請 Claude Code 的代理程式在模組的 build.gradle.kts 中設定 release 簽署（在 release build type 上設定包含 storeFile、storePassword、keyAlias 和 keyPassword 的 signingConfigs 區塊）。請勿將密碼提交到 git（Android 建置文件：https://developer.android.com/build/building-cmdline ）。
  2. 在終端機執行 ./gradlew bundleRelease。Gradle 會建置並簽署 bundle；.aab 通常位於 app/build/outputs/bundle/release/，但請以你自己的建置輸出為準。
  3. 如果還沒有 keystore，請用 keytool 建立一個並妥善備份。上傳第一個版本時，系統會提供 Google Play App Signing。

2. 在 Play Console 開始封閉測試

  1. 開啟 Test and release > Testing > Closed testing，然後選擇 Create track（或 Manage track）。
  2. 點選 Create new release，上傳 .aab，填寫版本名稱和版本資訊，依序按 Save as draft、Next，最後按 Start rollout（步驟來自 https://support.google.com/googleplay/android-developer/answer/9859348 ）。
  3. 請先完成 Dashboard 上的應用程式設定工作，否則發布按鈕會維持停用狀態。

3. 取得你的 12 位測試人員：先免費，再付費

  • 免費方式：用手機開啟 https://testerexchange.com/earn ，測試系統分配給你的應用程式。你每測試一個應用程式，就會為你的應用程式帶來一位測試人員。
  • 付費方式：一次付費後，系統會自動分配測試人員。目前價格列於 https://testerexchange.com/llms.txt 。
  • 建議申請 15 位而不是 12 位測試人員，這樣即使有一人退出，也不會低於 Google 的最低要求。

4. 將 Tester Exchange 連接到 Claude Code（選用）

請先在 https://testerexchange.com/api 建立 API 金鑰。接著在終端機中執行一次以下指令，並將 tx_YOUR_TOKEN 替換為你的金鑰（指令列於 https://testerexchange.com/agents/）：

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

此伺服器是不含 OAuth 的標準 MCP over Streamable HTTP；公開工具（about、pricing、platform_stats）無需金鑰即可使用。請勿將金鑰放入 git 或共用的設定檔中。

5. 向代理程式下指令

  • 「用 Tester Exchange 為 com.example.app 取得 15 位測試人員，並告訴我在 Play Console 中需要做什麼。」
  • 「查看我為 com.example.app 建立的 Tester Exchange 活動，告訴我昨天有多少位測試人員活躍。」
  • 「取得活動報告，並根據真實數據草擬我的正式版存取權申請回覆。」

主要工具是 get_testers：它會新增應用程式、開啟測試，並回傳只有真人才能完成的步驟，例如在 Play Console 中加入測試人員的 Google Group。代理程式無法代你付款，也無法代你按下 Apply for production。

沒有 MCP？使用 HTTP API

使用 https://testerexchange.com/agents/ 列出的公開 apikey 標頭，並以 {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}} 作為內容，對 https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call 發送 POST 請求。結構描述位於 https://testerexchange.com/openapi.json 。更多工具：https://testerexchange.com/guide/ai-builders/ 。

常見問題

Claude Code 可以幫我完成 14 天的測試嗎？

不行。這 14 天需要真人在自己的 Android 手機上使用你的應用程式。Claude Code 可以建置應用程式並協助完成設定。

Tester Exchange 是 Claude Code 的官方整合嗎？

不是。它是獨立的服務，可搭配任何支援透過 HTTP 連接遠端 MCP 的用戶端使用，Claude Code 就支援。

AAB 要上傳到哪裡？

請將它上傳到 Play Console 的封閉測試版本，然後在該測試群組（track）中加入測試人員的 Google Group 或電子郵件清單。

有免費取得 12 位測試人員的方法嗎？

有。到 https://testerexchange.com/earn 測試其他開發人員的應用程式；你每測試一個應用程式，就會為你的應用程式帶來一位測試人員。
