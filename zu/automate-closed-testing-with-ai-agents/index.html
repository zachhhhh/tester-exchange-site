Yenza ukuhlola okuvaliwe kwe-Google Play ngabasizi be-AI

Kubuyekezwe ngo-Novemba 2026

Uma usunikeza umsizi we-AI ukubhala ikhodi yakho, ungamnikeza nomsebenzi omningi wesidingo sokuhlola okuvaliwe se-Google Play: ukulaha i-app yakho, ukuthola abahloli, ukuhlola inqubekela phambili nokuthola izinombolo zefomu lokufinyelela ku-production. I-Tester Exchange inesiseva se-MCP, i-HTTP API enendawo eyodwa ne-A2A agent card kulokhu. Lo mhlahlandlela ukhombisa indlela yokuxhuma i-Claude Code, i-Claude Desktop, i-Cursor namanye amaklayenti, ukuthi ubuzeni, nezingxenye okungekho msizi ongazenza ngawe.

Okungakwenza nokungakwenzi umsizi

I-Google idinga ama-akhawunti onjiniyela bomuntu siqu adalwe ngemva kuka-13 Novemba 2023 enze ukuhlola okuvaliwe okunabahloli abangu-12 okungenani abahlala benze i-opt-in izinsuku ezingu-14 ngokuqhubekayo ngaphambi kokufaka isicelo se-production. Umsebenzi omningi oyizungezile wukuhlelelana, nabasizi bawenza kahle.

  • Umsizi angakwenza: ukwengeza i-app yakho, ukuvula umkhankaso wabahloli, ukusebenzisa amakhredithi akho, ukuhlola ukuthi bangaki abahloli abasebenzayo, ukumisa noma ukuvala umkhankaso, ukuthola umbiko womsebenzi wansuku zonke nokusiza ukubhala izimpendulo zokufinyelela ku-production kuwo.
  • Umuntu kufanele enze: ukwengeza i-Google Group yabahloli ku-track yokuhlola okuvaliwe ku-Play Console, ukushicilela ukukhishwa, ukukhokhela amakhredithi (ukukhokha kwenziwa njalo ku-browser yomuntu) nokuchofoza i-Apply for production.
  • Akekho ongakwenza ngokuzenzakalelayo: izinsuku ezingu-14 zokusetshenziswa kwangempela. Lokho kwenziwa abantu bangempela emafonini abo e-Android, okuyiyona nhloso yomthetho we-Google.

1. Dala i-token

  1. Ngena ku-https://testerexchange.com/api.
  2. Dala i-token yomuntu siqu. Iqala ngo-tx_. Ikopishe manje bese uyigcina njengephasiwedi.
  3. Ama-token angahoxiswa noma inini. I-token ingasebenzisa amakhredithi kumikhankaso, kodwa ayikwazi ukukhokha, ukukhipha imali noma ukususa i-akhawunti yakho.

2. Xhuma iseva ye-MCP

Iseva ye-MCP isebenzisa i-Streamable HTTP ku-https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp. Thumela i-token yakho ku-header Authorization: Bearer tx_YOUR_TOKEN.

Claude Code: sebenzisa lokhu kanye ku-terminal yakho.

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code namanye amaklayenti anokuhlelwa kwe-JSON: engeza iseva eyaziwa ngokuthi tester-exchange ngohlobo lwe-http, i-URL engenhla, nokufakwa kwe-headers okuno-Authorization okusethelwe ku-Bearer tx_YOUR_TOKEN. Indawo eqondile yefayela lokuhlela incike eklayentini lakho; bheka imibhalo yalo ye-MCP.

Amaklayenti athatha i-URL kuphela (amanye ama-connector e-ChatGPT nawewebhu): imibhalo ku-https://testerexchange.com/agents/ ibala uhlobo lwe-URL kuwo. Ngaphandle kwe-token, amathuluzi omphakathi (ukuthi iyini i-Tester Exchange, amanani, izibalo zeplathifomu) asasebenza.

3. Ithuluzi elilodwa lokuqala: get_testers

Awudingi ukufunda uhlu lonke lwamathuluzi. Ithuluzi eliyinhloko yi-get_testers(package_name, name?). Ucingo olulodwa lwengeza i-app yakho, luvula ukuhlola kwayo, lusebenzisa amakhredithi akho futhi lubuyisa inqubekela phambili yakho namasinyathelo kuphela umuntu angawenza, njengokwengeza i-Google Group ku-Play Console. Lubize futhi noma inini ukuze uhlole inqubekela phambili.

Amanye amathuluzi ayinakekela imininingwane: my_apps, campaign_report (abahloli, umsebenzi wansuku zonke, impendulo nedatha yokufinyelela ku-production), add_testers, set_campaign_status (misa, qalisa kabusha noma vala; amakhredithi angasetshenzisiwe abuyela ebhalansini yakho), share_kit ne-buy_credits_links, ebuyisa izixhumanisi zokukhokha zomuntu ukuthi akhokhe.

Imiyalo esebenzayo

  • "Get 15 testers for com.example.app and tell me what I need to do in Play Console."
  • "Check my Tester Exchange campaign for com.example.app. How many testers were active each day this week?"
  • "Pull the campaign report and draft my production access answers. Use only the real numbers."
  • "Close the campaign for com.example.app now that production access is approved."

Cela abahloli abangu-15 kunokuba abangu-12, ukuze osholayo angakuncishisi ngaphansi kwesilinganiso esiphansi se-Google.

I-HTTP API yama-script ne-CI

Uma ithuluzi lakho lingaluzwa i-MCP, sebenzisa indawo ye-HTTP: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call. Umzimba yi-JSON ene-p_token (i-token yakho ye-tx_), p_action (isibonelo help, my_apps noma start_campaign) ne-p_args (isibonelo package_name nenani labahloli). Thumela i-header ye-apikey yomphakathi ekhonjiswe emibhalweni.

Kuqala sebenzisa isenzo se-help: sibuyisa zonke izenzo nezimpikiswano zazo. Uhlaka oluphelele luku-https://testerexchange.com/openapi.json, olusebenza nezenzo ze-custom GPT ye-ChatGPT namanye amathuluzi e-OpenAPI.

I-A2A agent card

Kumasethi omsizi-nomsizi, i-Tester Exchange ishicilela i-A2A agent card ku-https://testerexchange.com/.well-known/agent-card.json. Abalawuli abasekela umthetho we-A2A bangathola okunikezwa umsizi nokuthi ungabizwa kanjani. Sebenzisa i-token efanayo ye-tx_ kukho konke okubophelelene ne-akhawunti yakho.

Ukusebenza okuphelele, kusukela ekuqaleni kuze kube sekugcineni

  1. Ulayisha i-.aab yakho yokuqala ku-track yokuhlola okuvaliwe ku-Play Console.
  2. Umsizi wakho ubiza i-get_testers ngegama le-package lakho futhi ukutshela ukuthi wengeze testerexchange-testers@googlegroups.com ngaphansi kwe-Google Groups ku-track yokuhlola okuvaliwe.
  3. Wengeza iqembu, ugcine, futhi uqinisekise ukuthi ukukhishwa kushicilelwe.
  4. Uma ungenawo amakhredithi, umsizi ukunikeza isixhumanisi sokukhokha. Ukhokha ($12.99 ngabahloli abangu-12, $14.99 ngabangu-15, $22.99 ngabangu-25) noma uzuze amakhredithi mahhala ngokuhlola ama-app abanye ku-https://testerexchange.com/earn.
  5. Abahloli bangempela bafaka futhi basebenzise i-app yakho izinsuku ezingu-14. Umsizi wakho uhlola inqubekela phambili nsuku zonke futhi ukuxwayise uma abahloli abasebenzayo behla.
  6. Ngosuku lwe-15, umsizi uthola umbiko womkhankaso futhi abhale izimpendulo zakho zokufinyelela ku-production. Uzibuyekeza bese uchofoza i-Apply for production.

Amanothi okuphepha

  • Gcina ama-token ngaphandle kwe-git. Wafake esitolo senkomba yeklayenti lakho noma ku-environment variable.
  • Ama-token agcinwa njengama-hash kuphela ohlangothini lwethu futhi anqunyelwe ku-10 nge-akhawunti. Hoxisa noma iyiphi i-token ongasayisebenzisi.
  • Funda okubhalwa umsizi efomini lakho le-production ngaphambi kokuthumela. I-Google ikucela ukuthi uchaze ukuhlola kwakho ngeqiniso.

Imibuzo evame ukubuzwa

Ingabe umsizi we-AI angaqeda ukuhlola kwezinsuku ezingu-14 ngami?

Cha. Izinsuku ezingu-14 zidinga abantu bangempela abasebenzisa i-app yakho emafonini abo. Abasizi banakekela ukusetha, ukuqapha nokubika.

Ingabe umsizi angakhokhela abahloli?

Cha. Angabuyisa izixhumanisi zokukhokha, kodwa ukukhokha kwenziwa njalo ku-browser yomuntu.

Yimaphi amaklayenti asebenza neseva ye-MCP?

Noma yiliphi iklayenti elisekela i-MCP eyisikhawu nge-Streamable HTTP elinesihloko sangokwezifiso, kuhlanganise ne-Claude Code, i-Claude Desktop, i-Cursor ne-VS Code. Amanye angasebenzisa i-HTTP API.

Ngiyithola kuphi i-token?

Ku-https://testerexchange.com/api ngemva kokungena. Ama-token aqala ngo-tx_ futhi angahoxiswa noma inini.

Ingabe umsizi ushintsha okuthile ku-Play Console yami?

Cha. Ayinakho ukufinyelela ku-Play Console yakho. Ikutshela amasinyathelo okuwenza lapho.
