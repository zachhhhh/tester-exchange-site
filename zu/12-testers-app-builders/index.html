Umthetho uyafana kuwo wonke amathuluzi

I-Google ihlola i-akhawunti yakho yonjiniyela, hhayi ithuluzi lakho. Ama-app enziwe nge-MIT App Inventor, Kodular, Niotron, Sketchware, Thunkable, FlutterFlow, Flutter, React Native, Expo, Unity noma Godot wonke adlula ekuhlolweni okuvaliwe okufanayo.

Uma wadala i-akhawunti yonjiniyela yomuntu siqu ngemuva komhla ziyi-13 kuNovemba 2023, udinga okungenani abahloli abangu-12 abenze i-opt-in izinsuku ezingu-14 zilandelana ngaphambi kokuthi ufake isicelo sokufinyelela ku-production. Ama-akhawunti ezinhlangano awanaso lesi sidingo.

Isinyathelo 1: khipha i-release build i-builder yakho engayisayina

  1. Khipha i-Android App Bundle (.aab). I-Google Play idinga i-.aab kuma-app amasha. Ama-builder nama-engine amaningi angayikhipha; uma eyakho inikeza i-APK kuphela, bheka imibhalo yayo ukuthola inketho ye-App Bundle.
  2. Gcina i-signing key yakho iphephile. Ama-builder afana ne-App Inventor ne-Kodular akudalela i-keystore. Landa ikhophi yayo yokulondoloza. Udinga ukhiye ofanayo kuzo zonke izibuyekezo.
  3. Khetha i-package name yakho ngokucophelela. Ayisoze yashintshwa uma i-app isiku-Google Play.
  4. Hlangabezana ne-target API level. I-Google Play yamukela kuphela ama-build aqondise kunguqulo ye-Android yakamuva. Uma ukulayisha kwenqatshwa ngenxa ye-target API level, buyekeza i-builder noma i-engine yakho bese uyikhipha futhi.

Isinyathelo 2: setha ukuhlola okuvaliwe

  1. Ku-Play Console, vula Test and release → Testing → Closed testing bese udala i-track.
  2. Engeza abahloli nge-Google Group esikhundleni sohlu lwama-imeyili: abahloli bajoyina iqembu ngokwabo, futhi awusoze waphinda wanamathisela ama-imeyili.
  3. Layisha i-.aab yakho ku-track evaliwe, engeza amanothi okukhishwa bese uyithumela ukuze ibuyekezwe.
  4. Kopisha isixhumanisi se-opt-in. Abahloli bajoyina iqembu, bavule isixhumanisi se-opt-in, bathephe ku-"Become a tester", bese befaka ku-Google Play.

Isinyathelo 3: thola abahloli abangu-12 abazohlala izinsuku ezingu-14

Amagama ayishumi nambili ohlwini awanele. I-Google ibuyekeza ukuthi abahloli bayisebenzisile ngempela yini i-app yakho, futhi izinsuku ezingu-14 zibalwa kuphela uma okungenani abahloli abangu-12 bebhalisile. Thola abantu abangu-14 noma abangu-15, ukuze oyedwa noma ababili abayekayo bangalimisi iwashi.

  • Abangane nomndeni abanamafoni e-Android: mahhala, kodwa bavame ukuyeka ukuvula i-app ngemuva kwezinsuku ezimbalwa.
  • Imiphakathi nezinkundla zama-builder: abanye abasebenzisi bama-builder bayawuqonda umthetho, futhi abaningi bashintshana ngokuhlola.
  • Ukushintshana kokuhlola: ku-Tester Exchange ifoni yakho inikezwa ama-app abanye onjiniyela okuwahlola, umzuzu ngosuku, futhi ngalinye olihlolayo liletha umhloli ku-app yakho.

Isinyathelo 4: gcina abahloli besebenza futhi ukhiphe isibuyekezo

  • Nika abahloli umsebenzi omncane owodwa ngosuku, ukuze babe nesizathu sokuvula i-app.
  • Layisha i-build entsha enokulungiswa cishe ngosuku lwesi-7 bese usho ukuthi yini eshintshile. Ama-builder akwenza lokhu kushesha: khipha, layisha ku-track evaliwe efanayo, kuphelile.
  • Cela impendulo ebhaliwe futhi ulungise lokho ongakwazi. Kuphinde kukunike izimpendulo zangempela zemibuzo ye-production.

Isinyathelo 5: faka isicelo se-production

Ngemuva kwezinsuku ezingu-14, faka isicelo sokufinyelela ku-production ku-dashboard ye-Play Console. I-Google ibuza ukuthi ubathole kanjani abahloli, bayisebenzise kanjani i-app nokuthi yini oyishintshile ngokusekelwe empendulweni yabo. Phendula ngezinombolo zangempela ezivela ekuhlolweni kwakho. I-Google ngokuvamile iphendula phakathi nesonto elilodwa.

Imibuzo evame ukubuzwa

Ingabe ama-app enziwe nge-App Inventor noma i-Kodular nawo adinga abahloli abangu-12?

Yebo. Isidingo sincike ku-akhawunti yakho yonjiniyela, hhayi ethuluzini. Ama-akhawunti amasha omuntu siqu adinga abahloli abangu-12 abenze i-opt-in izinsuku ezingu-14, kungakhathaliseki ukuthi i-app yakhiwe ngani.

Ingabe abahloli bami bangafaka i-APK engibathumela yona esikhundleni salokho?

Cha. Kubalwa kuphela ukufakwa okuvela ekuhlolweni okuvaliwe ku-Google Play. Abahloli kumele benze i-opt-in ngesixhumanisi esivela ku-Play Console futhi bafake ku-Play Store.

Ngidinga i-build entsha ukuze ngiqale ukuhlola okuvaliwe?

Udinga okungenani i-build eyodwa elayishwe ku-track evaliwe. Ukulayisha i-build yesibili phakathi nokuhlola enokulungiswa okuvela empendulweni yabahloli kuwumqondo omuhle.

Ingabe ikhona indlela yamahhala yokuthola abahloli abangu-12?

Yebo. Ukushintshana kokuhlola kumahhala: uhlola ama-app abanye onjiniyela futhi nabo bahlola eyakho. I-Tester Exchange iqinisekisa ukusetshenziswa kwansuku zonke efonini yomhloli ngamunye, ngakho ukuhlola kungokwangempela.
