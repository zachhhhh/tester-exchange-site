按工具查看指南

我们会定期添加更多工具。目前有：

  • Cursor： https://testerexchange.com/guide/get-12-testers-cursor/ - 用 Gradle 构建 AAB，然后通过 .cursor/mcp.json 将 Tester Exchange 连接到 Cursor。
  • Claude Code: https://testerexchange.com/guide/get-12-testers-claude-code/ - build the AAB with Gradle, then add Tester Exchange with one claude mcp add command.

获得测试员的两种方式

  • 免费： 用手机在 https://testerexchange.com/earn 测试其他开发者的应用。你每测试一个应用，就会为你的应用带来一名测试员，因此无需付费即可凑满 12 个名额。
  • 付费且更快： 一次性购买测试员套餐；当前价格见 https://testerexchange.com/llms.txt。付费的应用会比其他所有应用更早获得测试员。

Google 的要求

根据 Google 的 Play 管理中心帮助，2023 年 11 月 13 日之后创建的个人开发者账号，必须先进行封闭测试，且至少有 12 名测试员连续加入至少 14 天，才能申请正式版访问权限（https://support.google.com/googleplay/android-developer/answer/14151465）。没有任何 AI 工具能替你完成这 14 天：必须是真实的人使用真实的手机。

让你的 AI 工具完成设置

Tester Exchange 提供 MCP 服务器、HTTP API 和 A2A 代理。完整的客户端列表和配置示例见 https://testerexchange.com/agents/。通用指南见 https://testerexchange.com/guide/automate-closed-testing-with-ai-agents/。

常见问题

使用 Tester Exchange 需要 AI 工具吗？

不需要。网站本身即可使用。MCP 服务器和 API 只是为已在使用 AI 工具的人提供的可选捷径。

AI 工具可以替我支付测试员费用吗？

不可以。它可以返回结账链接，但付款需在你的浏览器中完成。免费方式是在 https://testerexchange.com/earn 测试其他应用。

Tester Exchange 是这些工具的官方集成吗？

不是。它是独立服务。这些页面只是展示如何把工具标准的 MCP 或 HTTP 支持连接到 Tester Exchange。
