用 AI 智能体自动化 Google Play 封闭式测试

2026 年 11 月更新

如果你已经在用 AI 智能体写代码，也可以把 Google Play 封闭式测试要求中的大部分杂务交给它：登记应用、招募测试人员、查看进度，以及为正式版访问申请表整理数据。Tester Exchange 为此提供了 MCP 服务器、只有一个端点的 HTTP API 和 A2A 智能体卡片。本指南介绍如何连接 Claude Code、Claude Desktop、Cursor 等客户端、可以问些什么，以及哪些部分任何智能体都无法代劳。

智能体能做什么，不能做什么

Google 要求 2023 年 11 月 13 日之后创建的个人开发者账号，在申请正式版之前，先进行封闭式测试，至少有 12 名测试人员连续 14 天保持选择加入状态。围绕这项要求的大部分工作都是协调事务，而这正是智能体擅长的。

  • 智能体可以：添加你的应用、开启测试人员活动、使用你的积分、查看有多少测试人员处于活跃状态、暂停或关闭活动、获取每日活动报告，并据此协助起草正式版访问申请的回答。
  • 必须由人来做：在 Play Console 中把测试人员的 Google Group 添加到封闭式测试轨道、发布版本、为积分付款（结账始终在真人的浏览器中完成），以及点击“申请正式版访问权限”。
  • 谁也无法自动化：14 天的真实使用。这要由真人在自己的 Android 手机上完成，这正是 Google 这条规则的意义所在。

1. 创建令牌

  1. 在 https://testerexchange.com/api 登录。
  2. 创建个人令牌。它以 tx_ 开头。请立即复制，并像保管密码一样妥善保存。
  3. 令牌可以随时撤销。令牌可以用积分开展活动，但无法付款、提现或删除你的账号。

2. 连接 MCP 服务器

MCP 服务器使用 Streamable HTTP，地址为 https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp。请在请求头 Authorization: Bearer tx_YOUR_TOKEN 中发送你的令牌。

Claude Code：在终端中运行一次下面的命令。

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop、Cursor、VS Code 以及其他使用 JSON 配置的客户端：添加一个名为 tester-exchange 的服务器，类型为 http，填入上面的 URL，并添加 headers 项，将 Authorization 设为 Bearer tx_YOUR_TOKEN。具体的配置文件位置因客户端而异，请查阅其 MCP 文档。

只接受 URL 的客户端（部分 ChatGPT 和网页连接器）：https://testerexchange.com/agents/ 上的文档列出了适用于它们的 URL 形式。没有令牌时，公开工具（Tester Exchange 是什么、定价、平台统计数据）仍然可用。

3. 先从一个工具开始：get_testers

你不需要学会整个工具列表。主要的工具是 get_testers(package_name, name?)。一次调用就能添加你的应用、开启测试、使用你的积分，并返回你的进度，以及只有人才能完成的步骤，例如在 Play Console 中添加 Google Group。随时可以再次调用它来查看进度。

其他工具负责处理细节：my_apps、campaign_report（测试人员、每日活动、反馈和正式版访问数据）、add_testers、set_campaign_status（暂停、恢复或关闭；未用完的积分会退回你的余额）、share_kit，以及 buy_credits_links（返回结账链接，由真人付款）。

好用的提示词

  • “为 com.example.app 获取 15 名测试人员，并告诉我在 Play Console 中需要做什么。”
  • “查看我在 Tester Exchange 上 com.example.app 的活动。这周每天有多少测试人员处于活跃状态？”
  • “拉取活动报告并起草我的正式版访问申请回答。只使用真实数据。”
  • “正式版访问权限已获批准，现在关闭 com.example.app 的活动。”

请要 15 名测试人员而不是 12 名，这样有人退出也不会让你低于 Google 的最低要求。

适用于脚本和 CI 的 HTTP API

如果你的工具不支持 MCP，请使用 HTTP 端点：POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call。请求体为 JSON，包含 p_token（你的 tx_ 令牌）、p_action（例如 help、my_apps 或 start_campaign）和 p_args（例如 package_name 和测试人员数量）。请发送文档中列出的公开 apikey 请求头。

请先调用 help 操作：它会返回所有操作及其参数。完整的 schema 位于 https://testerexchange.com/openapi.json，可用于 ChatGPT 自定义 GPT 操作和其他 OpenAPI 工具。

A2A 智能体卡片

对于智能体之间协作的场景，Tester Exchange 在 https://testerexchange.com/.well-known/agent-card.json 发布了 A2A 智能体卡片。支持 A2A 协议的编排器可以据此发现该智能体提供的能力以及调用方式。涉及你账号的操作，请使用同一个 tx_ 令牌。

完整流程，从头到尾

  1. 你在 Play Console 中把第一个 .aab 上传到封闭式测试轨道。
  2. 你的智能体针对你的包名调用 get_testers，并提示你在封闭式测试轨道的“Google Groups”下添加 testerexchange-testers@googlegroups.com。
  3. 你添加该群组并保存，确保版本已发布。
  4. 如果积分不足，智能体会给你一个结账链接。你可以付款（12 名测试人员 $12.99，15 名 $14.99，25 名 $22.99），或者在 https://testerexchange.com/earn 测试其他应用来免费赚取积分。
  5. 真人测试人员安装并使用你的应用 14 天。你的智能体每天检查进度，并在活跃测试人员减少时提醒你。
  6. 第 15 天，智能体拉取活动报告并起草你的正式版访问申请回答。你审核后，点击“申请正式版访问权限”。

安全提示

  • 不要把令牌提交到 git。请放在客户端的密钥存储或环境变量中。
  • 我们这边只以哈希形式保存令牌，且每个账号最多 10 个。请撤销不再使用的令牌。
  • 提交前，请检查智能体在你的正式版申请表中写了什么。Google 要求你如实描述你的测试。

常见问题

AI 智能体能替我完成 14 天的测试吗？

不能。这 14 天需要真人在自己的手机上使用你的应用。智能体负责设置、监控和报告。

智能体可以为测试人员付款吗？

不可以。它可以返回结账链接，但付款始终在真人的浏览器中完成。

哪些客户端可以使用 MCP 服务器？

任何支持基于 Streamable HTTP 的远程 MCP 并允许自定义请求头的客户端，包括 Claude Code、Claude Desktop、Cursor 和 VS Code。其他客户端可以使用 HTTP API。

在哪里获取令牌？

登录后在 https://testerexchange.com/api 获取。令牌以 tx_ 开头，可随时撤销。

智能体会更改我 Play Console 里的任何内容吗？

不会。它无法访问你的 Play Console，只会告诉你需要在那里执行的步骤。
