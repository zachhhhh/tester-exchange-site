AI ایجنٹس کے ذریعے Google Play کلوزڈ ٹیسٹنگ آٹومیٹ کریں

نومبر 2026 میں اپ ڈیٹ کیا گیا

اگر آپ پہلے ہی AI ایجنٹ کے ساتھ کوڈ شپ کرتے ہیں تو Google Play کی کلوزڈ ٹیسٹنگ شرط کا زیادہ تر بھاگ دوڑ والا کام بھی اسی کو سونپ سکتے ہیں: ایپ لسٹ کرنا، ٹیسٹر بھرتی کرنا، پراگریس چیک کرنا اور پروڈکشن ایکسیس فارم کے لیے اعداد و شمار نکالنا۔ اس کے لیے Tester Exchange کا MCP سرور، ایک اینڈ پوائنٹ والا HTTP API اور A2A ایجنٹ کارڈ موجود ہے۔ یہ گائیڈ بتاتی ہے کہ Claude Code، Claude Desktop، Cursor اور دوسرے کلائنٹس کیسے جوڑیں، کیا پوچھیں، اور وہ کام کون سے ہیں جو کوئی ایجنٹ آپ کی جگہ نہیں کر سکتا۔

اصلی لوگ 14 دن تک اپنے فون پر آپ کی ایپ کھولتے ہیں۔ ایک بار ادائیگی کریں، یا دوسری ایپس ٹیسٹ کر کے مفت پائیں۔12 ٹیسٹرز حاصل کریں

ایجنٹ کیا کر سکتا ہے اور کیا نہیں

Google کی شرط ہے کہ 13 نومبر 2023 کے بعد بنے ذاتی ڈویلپر اکاؤنٹس پروڈکشن کے لیے اپلائی کرنے سے پہلے کم از کم 12 ٹیسٹرز کے ساتھ لگاتار 14 دن کا کلوزڈ ٹیسٹ چلائیں۔ اس کے گرد زیادہ تر کام کوآرڈینیشن کا ہے، جو ایجنٹس اچھی طرح سنبھال لیتے ہیں۔

  • ایجنٹ کر سکتا ہے: آپ کی ایپ شامل کرنا، ٹیسٹر مہم کھولنا، آپ کے کریڈٹ لگانا، دیکھنا کہ کتنے ٹیسٹر ایکٹو ہیں، مہم روکنا یا بند کرنا، روزانہ ایکٹیویٹی رپورٹ نکالنا، اور اسی کی بنیاد پر پروڈکشن ایکسیس کے جوابات کا ڈرافٹ بنانے میں مدد دینا۔
  • انسان کو کرنا ہوگا: Play Console میں کلوزڈ ٹریک پر ٹیسٹرز کا Google Group شامل کرنا، ریلیز پبلش کرنا، کریڈٹ کی ادائیگی کرنا (چیک آؤٹ ہمیشہ انسان کے براؤزر میں ہوتا ہے) اور Apply for production پر کلک کرنا۔
  • کوئی آٹومیٹ نہیں کر سکتا: 14 دن کا اصلی استعمال۔ یہ اصلی لوگ اپنے Android فونز پر کرتے ہیں، اور Google کے اصول کا مقصد ہی یہی ہے۔

1. ٹوکن بنائیں

  1. https://testerexchange.com/api پر سائن اِن کریں۔
  2. ذاتی ٹوکن بنائیں۔ یہ tx_ سے شروع ہوتا ہے۔ اسی وقت کاپی کر لیں اور پاس ورڈ کی طرح محفوظ رکھیں۔
  3. ٹوکن کسی بھی وقت منسوخ کیا جا سکتا ہے۔ ٹوکن مہمات پر کریڈٹ خرچ کر سکتا ہے، مگر ادائیگی، رقم نکالنے یا آپ کا اکاؤنٹ ڈیلیٹ کرنے کا اختیار نہیں رکھتا۔

2. MCP سرور جوڑیں

MCP سرور Streamable HTTP استعمال کرتا ہے اور اس کا پتہ https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp ہے۔ اپنا ٹوکن ہیڈر Authorization: Bearer tx_YOUR_TOKEN میں بھیجیں۔

Claude Code: اپنے ٹرمینل میں ایک بار یہ چلائیں۔

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop، Cursor، VS Code اور JSON کنفیگ والے دوسرے کلائنٹس: tester-exchange نام کا سرور شامل کریں، type http رکھیں، اوپر والا URL دیں، اور headers میں Authorization کی ویلیو Bearer tx_YOUR_TOKEN رکھیں۔ کنفیگ فائل کی ٹھیک جگہ آپ کے کلائنٹ پر منحصر ہے؛ اس کی MCP دستاویزات دیکھیں۔

جو کلائنٹس صرف URL لیتے ہیں (کچھ ChatGPT اور ویب کنیکٹرز): https://testerexchange.com/agents/ کی دستاویزات میں ان کے لیے URL والا طریقہ درج ہے۔ ٹوکن کے بغیر بھی عوامی ٹولز (Tester Exchange کیا ہے، قیمتیں، پلیٹ فارم کے اعداد و شمار) کام کرتے ہیں۔

3. شروع کرنے کا ایک ٹول: get_testers

آپ کو پورے ٹول لسٹ کو سیکھنے کی ضرورت نہیں۔ بنیادی ٹول get_testers(package_name, name?) ہے۔ ایک کال آپ کی ایپ شامل کرتی ہے، اس کا ٹیسٹ کھولتی ہے، آپ کے کریڈٹ لگاتی ہے، اور آپ کی پراگریس کے ساتھ وہ قدم واپس دیتی ہے جو صرف انسان کر سکتا ہے، جیسے Play Console میں Google Group شامل کرنا۔ پراگریس دیکھنے کے لیے اسے کسی بھی وقت دوبارہ کال کریں۔

باقی ٹولز تفصیلات سنبھالتے ہیں: my_apps، campaign_report (ٹیسٹرز، روزانہ ایکٹیویٹی، فیڈ بیک اور پروڈکشن ایکسیس کا ڈیٹا)، add_testers، set_campaign_status (روکنا، دوبارہ شروع کرنا یا بند کرنا؛ بچے ہوئے کریڈٹ آپ کے بیلنس میں واپس آ جاتے ہیں)، share_kit اور buy_credits_links، جو انسان کے ادائیگی کرنے کے لیے چیک آؤٹ لنکس دیتا ہے۔

کام کرنے والے پرامپٹس

  • “com.example.app کے لیے 15 ٹیسٹر حاصل کرو اور بتاؤ کہ مجھے Play Console میں کیا کرنا ہے۔”
  • “com.example.app کے لیے میری Tester Exchange مہم چیک کرو۔ اس ہفتے ہر دن کتنے ٹیسٹر ایکٹو تھے؟”
  • “مہم کی رپورٹ نکالو اور میرے پروڈکشن ایکسیس کے جوابات کا ڈرافٹ بناؤ۔ صرف اصلی اعداد استعمال کرو۔”
  • “اب جب پروڈکشن ایکسیس منظور ہو گیا ہے تو com.example.app کی مہم بند کر دو۔”

12 کے بجائے 15 ٹیسٹر مانگیں، تاکہ کوئی ٹیسٹر چھوڑ جائے تو آپ Google کی کم از کم حد سے نیچے نہ جائیں۔

اسکرپٹس اور CI کے لیے HTTP API

اگر آپ کا ٹول MCP نہیں سمجھتا تو HTTP اینڈ پوائنٹ استعمال کریں: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call۔ باڈی JSON ہوتی ہے جس میں p_token (آپ کا tx_ ٹوکن)، p_action (مثلاً help، my_apps یا start_campaign) اور p_args (مثلاً package_name اور ٹیسٹرز کی تعداد) ہوتے ہیں۔ دستاویزات میں دکھایا گیا عوامی apikey ہیڈر بھی بھیجیں۔

پہلے help ایکشن کال کریں: یہ تمام ایکشنز اور ان کے آرگومنٹس لوٹاتا ہے۔ مکمل اسکیما https://testerexchange.com/openapi.json پر ہے، جو ChatGPT کے custom GPT ایکشنز اور دوسرے OpenAPI ٹولز کے ساتھ کام کرتا ہے۔

A2A ایجنٹ کارڈ

ایجنٹ سے ایجنٹ والے سیٹ اپ کے لیے Tester Exchange https://testerexchange.com/.well-known/agent-card.json پر A2A ایجنٹ کارڈ شائع کرتا ہے۔ A2A پروٹوکول سپورٹ کرنے والے آرکسٹریٹرز اس سے جان سکتے ہیں کہ ایجنٹ کیا پیش کرتا ہے اور اسے کیسے کال کرنا ہے۔ آپ کے اکاؤنٹ سے جڑی ہر چیز کے لیے وہی tx_ ٹوکن استعمال کریں۔

شروع سے آخر تک پورا عمل

  1. آپ Play Console میں کلوزڈ ٹریک پر اپنی پہلی .aab اپ لوڈ کرتے ہیں۔
  2. آپ کا ایجنٹ آپ کے پیکیج نام کے ساتھ get_testers کال کرتا ہے اور آپ کو بتاتا ہے کہ کلوزڈ ٹریک پر Google Groups کے تحت testerexchange-testers@googlegroups.com شامل کریں۔
  3. آپ گروپ شامل کر کے محفوظ کرتے ہیں اور یقینی بناتے ہیں کہ ریلیز پبلش ہو چکی ہے۔
  4. اگر کریڈٹ کم ہوں تو ایجنٹ آپ کو چیک آؤٹ لنک دیتا ہے۔ آپ ادائیگی کرتے ہیں (12 ٹیسٹرز کے $12.99، 15 کے $14.99، 25 کے $22.99) یا https://testerexchange.com/earn پر دوسری ایپس ٹیسٹ کر کے مفت کریڈٹ کماتے ہیں۔
  5. اصلی ٹیسٹر 14 دن تک آپ کی ایپ انسٹال کر کے استعمال کرتے ہیں۔ آپ کا ایجنٹ روزانہ پراگریس چیک کرتا ہے اور ایکٹو ٹیسٹرز کم ہوں تو خبردار کرتا ہے۔
  6. پندرہویں دن ایجنٹ مہم کی رپورٹ نکال کر آپ کے پروڈکشن ایکسیس کے جوابات کا ڈرافٹ بناتا ہے۔ آپ انہیں پڑھ کر Apply for production پر کلک کرتے ہیں۔

حفاظتی نکات

  • ٹوکنز کو git سے باہر رکھیں۔ انہیں اپنے کلائنٹ کے سیکرٹ اسٹور یا environment variable میں رکھیں۔
  • ہماری طرف ٹوکن صرف hash کی شکل میں محفوظ ہوتے ہیں اور فی اکاؤنٹ 10 تک محدود ہیں۔ جو ٹوکن استعمال نہ کر رہے ہوں انہیں منسوخ کر دیں۔
  • فارم جمع کرانے سے پہلے پڑھ لیں کہ ایجنٹ نے آپ کے پروڈکشن فارم میں کیا لکھا ہے۔ Google چاہتا ہے کہ آپ اپنے ٹیسٹ کو سچائی سے بیان کریں۔

اکثر پوچھے جانے والے سوالات

کیا AI ایجنٹ میری جگہ 14 دن کا ٹیسٹ مکمل کر سکتا ہے؟

نہیں۔ 14 دن کے لیے اصلی لوگ چاہییں جو اپنے فونز پر آپ کی ایپ استعمال کریں۔ ایجنٹس سیٹ اپ، نگرانی اور رپورٹنگ سنبھالتے ہیں۔

کیا ایجنٹ ٹیسٹرز کی ادائیگی کر سکتا ہے؟

نہیں۔ وہ چیک آؤٹ لنکس دے سکتا ہے، مگر ادائیگی ہمیشہ انسان کے براؤزر میں ہوتی ہے۔

کون سے کلائنٹس MCP سرور کے ساتھ کام کرتے ہیں؟

کوئی بھی کلائنٹ جو کسٹم ہیڈر کے ساتھ Streamable HTTP پر ریموٹ MCP سپورٹ کرتا ہو، جن میں Claude Code، Claude Desktop، Cursor اور VS Code شامل ہیں۔ باقی HTTP API استعمال کر سکتے ہیں۔

ٹوکن کہاں سے ملے گا؟

سائن اِن کرنے کے بعد https://testerexchange.com/api پر۔ ٹوکن tx_ سے شروع ہوتے ہیں اور کسی بھی وقت منسوخ ہو سکتے ہیں۔

کیا ایجنٹ میرے Play Console میں کچھ بدلتا ہے؟

نہیں۔ اسے آپ کے Play Console تک رسائی ہی نہیں ہوتی۔ وہ آپ کو بتاتا ہے کہ وہاں کیا کرنا ہے۔
