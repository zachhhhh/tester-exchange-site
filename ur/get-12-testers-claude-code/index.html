Claude Code سے اپنی Android ایپ بنائی؟ 14 دن کے لیے اپنے 12 ٹیسٹرز حاصل کریں

نومبر 2026 میں اپ ڈیٹ کیا گیا

Claude Code آپ کی Android ایپ لکھ اور بنا سکتا ہے، لیکن Google Play کو درکار 12 اصلی ٹیسٹرز فراہم نہیں کر سکتا۔ اگر آپ کا پرسنل ڈیولپر اکاؤنٹ 13 نومبر 2023 کے بعد بنا ہے، تو پروڈکشن کے لیے درخواست دینے سے پہلے آپ کو کم از کم 12 ٹیسٹرز کے ساتھ مسلسل 14 دن کا کلوزڈ ٹیسٹ چلانا ہوگا۔ یہ گائیڈ بنڈل بنانے، کلوزڈ ٹیسٹنگ شروع کرنے، ٹیسٹرز حاصل کرنے (پہلے مفت، پھر ادائیگی سے) اور Tester Exchange کو Claude Code سے جوڑنے کا احاطہ کرتی ہے تاکہ ایجنٹ کاغذی کارروائی کر سکے۔

اصلی لوگ 14 دن تک اپنے فون پر آپ کی ایپ کھولتے ہیں۔ ایک بار ادائیگی کریں، یا دوسری ایپس ٹیسٹ کر کے مفت پائیں۔12 ٹیسٹرز حاصل کریں
اس صفحے پر
  • 1. ریلیز بنڈل (.aab) بنائیں
  • 2. Play Console میں کلوزڈ ٹیسٹنگ شروع کریں
  • 3. اپنے 12 ٹیسٹرز حاصل کریں: پہلے مفت، پھر ادائیگی سے
  • 4. Tester Exchange کو Claude Code سے جوڑیں (اختیاری)
  • 5. ایجنٹ سے پوچھیں
  • MCP نہیں ہے؟ HTTP API استعمال کریں
  • اکثر پوچھے جانے والے سوالات

1. ریلیز بنڈل (.aab) بنائیں

  1. Claude Code کے ایجنٹ سے کہیں کہ آپ کے ماڈیول کی build.gradle.kts میں ریلیز سائننگ ترتیب دے (storeFile، storePassword، keyAlias اور keyPassword والا signingConfigs بلاک، release build type پر لاگو)۔ پاس ورڈز کو git سے باہر رکھیں (Android کی build دستاویزات: https://developer.android.com/build/building-cmdline)۔
  2. ٹرمینل میں ./gradlew bundleRelease چلائیں۔ Gradle بنڈل بناتا اور سائن کرتا ہے؛ .aab عموماً app/build/outputs/bundle/release/ کے تحت ظاہر ہوتا ہے، لیکن اپنے build آؤٹ پٹ کی جانچ کریں۔
  3. اگر آپ کے پاس keystore نہیں ہے تو keytool سے بنائیں اور اس کا بیک اپ رکھیں۔ Google Play App Signing پہلی ریلیز اپ لوڈ کرتے وقت پیش کی جاتی ہے۔

2. Play Console میں کلوزڈ ٹیسٹنگ شروع کریں

  1. Test and release > Testing > Closed testing کھولیں، پھر Create track (یا Manage track) منتخب کریں۔
  2. Create new release پر کلک کریں، .aab اپ لوڈ کریں، ریلیز کا نام اور نوٹس شامل کریں، Save as draft، Next، پھر Start rollout (اقدامات https://support.google.com/googleplay/android-developer/answer/9859348 سے)۔
  3. پہلے Dashboard پر ایپ سیٹ اپ کے کام مکمل کریں، ورنہ ریلیز بٹن غیر فعال رہتا ہے۔

3. اپنے 12 ٹیسٹرز حاصل کریں: پہلے مفت، پھر ادائیگی سے

  • مفت راستہ: اپنے فون پر https://testerexchange.com/earn کھولیں اور جو ایپس آپ کو دی جائیں انہیں ٹیسٹ کریں۔ آپ جو بھی ایپ ٹیسٹ کرتے ہیں وہ آپ کی ایپ کے لیے ایک ٹیسٹر لاتی ہے۔
  • ادائیگی کا راستہ: ایک بار ادائیگی کریں اور ٹیسٹرز خود بخود تفویض ہو جاتے ہیں۔ موجودہ قیمتیں https://testerexchange.com/llms.txt پر درج ہیں۔
  • 12 کے بجائے 15 ٹیسٹرز مانگیں تاکہ ایک کے چھوڑ دینے سے آپ Google کی کم از کم حد سے نیچے نہ آ جائیں۔

4. Tester Exchange کو Claude Code سے جوڑیں (اختیاری)

سب سے پہلے https://testerexchange.com/api پر API key بنائیں۔ پھر اپنے ٹرمینل میں یہ کمانڈ ایک بار چلائیں اور tx_YOUR_TOKEN کی جگہ اپنی کلید لکھیں (کمانڈ وہی ہے جو https://testerexchange.com/agents/ پر درج ہے):

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

سرور OAuth کے بغیر Streamable HTTP پر سادہ MCP ہے؛ عوامی ٹولز (about, pricing, platform_stats) کلید کے بغیر کام کرتے ہیں۔ کلید کو git اور مشترکہ کنفیگ فائلوں سے دور رکھیں۔

5. ایجنٹ سے پوچھیں

  • "Tester Exchange استعمال کر کے com.example.app کے لیے 15 ٹیسٹرز حاصل کرو اور بتاؤ کہ مجھے Play Console میں کیا کرنا ہے۔"
  • "com.example.app کے لیے میری Tester Exchange مہم چیک کرو اور بتاؤ کہ کل کتنے ٹیسٹرز فعال تھے۔"
  • "مہم کی رپورٹ نکالو اور اصل اعداد و شمار کی بنیاد پر میرے پروڈکشن ایکسیس کے جوابات کا مسودہ بناؤ۔"

بنیادی ٹول get_testers ہے: یہ ایپ شامل کرتا ہے، اس کا ٹیسٹ کھولتا ہے اور وہ اقدامات واپس کرتا ہے جو صرف انسان کر سکتا ہے، جیسے Play Console میں ٹیسٹرز کا Google Group شامل کرنا۔ ایجنٹ آپ کی جگہ ادائیگی نہیں کر سکتا اور نہ Apply for production پر کلک کر سکتا ہے۔

MCP نہیں ہے؟ HTTP API استعمال کریں

https://testerexchange.com/agents/ پر درج عوامی apikey ہیڈر اور {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}} باڈی کے ساتھ https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call پر POST کریں۔ اسکیما https://testerexchange.com/openapi.json پر ہے۔ مزید ٹولز: https://testerexchange.com/guide/ai-builders/ ۔

اکثر پوچھے جانے والے سوالات

کیا Claude Code میرے لیے 14 دن کا ٹیسٹ مکمل کر سکتا ہے؟

نہیں۔ 14 دن کے لیے اصلی لوگوں کو اپنے Android فونز پر آپ کی ایپ استعمال کرنی ہوتی ہے۔ Claude Code ایپ بنا سکتا ہے اور سیٹ اپ چلا سکتا ہے۔

کیا Tester Exchange سرکاری Claude Code انٹیگریشن ہے؟

نہیں۔ یہ ایک آزاد سروس ہے جو HTTP پر ریموٹ MCP کو سپورٹ کرنے والے ہر کلائنٹ کے ساتھ کام کرتی ہے، اور Claude Code ایسا ہی ایک کلائنٹ ہے۔

AAB کہاں جاتا ہے؟

اسے Play Console میں کلوزڈ ٹیسٹنگ ریلیز میں اپ لوڈ کریں، پھر اس ٹریک پر اپنے ٹیسٹرز کا Google Group یا ای میل فہرست شامل کریں۔

کیا 12 ٹیسٹرز حاصل کرنے کا کوئی مفت طریقہ ہے؟

جی ہاں۔ https://testerexchange.com/earn پر دوسرے ڈیولپرز کی ایپس ٹیسٹ کریں؛ آپ جو بھی ایپ ٹیسٹ کرتے ہیں وہ آپ کی ایپ کے لیے ایک ٹیسٹر لاتی ہے۔
