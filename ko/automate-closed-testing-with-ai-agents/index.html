AI 에이전트로 Google Play 비공개 테스트 자동화하기

2026년 11월 업데이트

이미 AI 에이전트와 함께 코드를 배포하고 있다면, Google Play 비공개 테스트 요건의 잡무도 대부분 맡길 수 있어요. 앱 등록, 테스터 모집, 진행 상황 확인, 프로덕션 액세스 신청서에 쓸 수치 가져오기까지요. Tester Exchange에는 이를 위한 MCP 서버, 엔드포인트 하나짜리 HTTP API, A2A 에이전트 카드가 있어요. 이 가이드에서는 Claude Code, Claude Desktop, Cursor 같은 클라이언트를 연결하는 방법, 무엇을 요청하면 되는지, 어떤 에이전트도 대신할 수 없는 부분을 알려 드려요.

실제 사람이 14일 동안 자기 휴대폰에서 앱을 열어요. 한 번 결제하거나, 다른 앱을 테스트해서 무료로 받으세요.테스터 12명 받기

에이전트가 할 수 있는 일과 없는 일

Google은 2023년 11월 13일 이후에 만든 개인 개발자 계정에 대해, 프로덕션을 신청하기 전에 테스터 12명 이상이 14일 연속으로 옵트인한 비공개 테스트를 하도록 요구해요. 이 과정의 대부분은 조율 작업이고, 에이전트가 잘하는 영역이에요.

  • 에이전트가 할 수 있는 일: 앱 추가, 테스터 캠페인 시작, 크레딧 적용, 활동 중인 테스터 수 확인, 캠페인 일시중지 또는 종료, 일별 활동 리포트 가져오기, 그 리포트로 프로덕션 액세스 답변 초안 작성 돕기.
  • 사람이 직접 해야 하는 일: Play Console에서 테스터의 Google Group을 비공개 트랙에 추가하기, 릴리스 게시, 크레딧 결제(결제는 항상 사람의 브라우저에서 이뤄져요), 프로덕션 신청 버튼 누르기.
  • 누구도 자동화할 수 없는 일: 14일 동안의 실제 사용. 이건 실제 사람이 자기 Android 휴대전화로 하는 일이고, 그게 바로 Google 규칙의 핵심이에요.

1. 토큰 만들기

  1. https://testerexchange.com/api에 로그인하세요.
  2. 개인 토큰을 만드세요. 토큰은 tx_로 시작해요. 지금 복사해서 비밀번호처럼 보관하세요.
  3. 토큰은 언제든 폐기할 수 있어요. 토큰으로 캠페인에 크레딧을 쓸 수는 있지만, 결제, 출금, 계정 삭제는 할 수 없어요.

2. MCP 서버 연결하기

MCP 서버는 https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp 에서 Streamable HTTP를 사용해요. 토큰은 Authorization: Bearer tx_YOUR_TOKEN 헤더로 보내세요.

Claude Code: 터미널에서 한 번만 실행하세요.

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code 등 JSON 설정을 쓰는 클라이언트: 이름이 tester-exchange이고 type이 http인 서버를 추가하고, 위 URL과 Authorization을 Bearer tx_YOUR_TOKEN으로 지정한 headers 항목을 넣으세요. 설정 파일의 정확한 위치는 클라이언트마다 다르니 해당 클라이언트의 MCP 문서를 확인하세요.

URL만 받는 클라이언트(일부 ChatGPT 및 웹 커넥터): https://testerexchange.com/agents/ 의 문서에 해당 클라이언트용 URL 형식이 있어요. 토큰이 없어도 공개 도구(Tester Exchange 소개, 가격, 플랫폼 통계)는 쓸 수 있어요.

3. 가장 먼저 쓸 도구: get_testers

도구 목록을 전부 익힐 필요는 없어요. 핵심 도구는 get_testers(package_name, name?)예요. 한 번 호출하면 앱을 추가하고, 테스트를 열고, 크레딧을 적용한 뒤, 진행 상황과 사람이 직접 해야 하는 단계(예: Play Console에서 Google Group 추가)를 알려 줘요. 진행 상황을 확인하고 싶을 때마다 다시 호출하면 돼요.

나머지 도구는 세부 작업을 맡아요. my_apps, campaign_report(테스터, 일별 활동, 피드백, 프로덕션 액세스용 데이터), add_testers, set_campaign_status(일시중지, 재개, 종료. 쓰지 않은 크레딧은 잔액으로 돌아와요), share_kit, 그리고 사람이 결제할 수 있도록 결제 링크를 돌려주는 buy_credits_links가 있어요.

잘 통하는 프롬프트

  • "com.example.app 테스터 15명을 구해 주고, Play Console에서 내가 해야 할 일을 알려 줘."
  • "com.example.app의 Tester Exchange 캠페인을 확인해 줘. 이번 주에 하루별로 활동한 테스터가 몇 명이었어?"
  • "캠페인 리포트를 가져와서 프로덕션 액세스 답변 초안을 써 줘. 실제 수치만 사용해."
  • "프로덕션 액세스가 승인됐으니 com.example.app 캠페인을 종료해 줘."

12명이 아니라 15명을 요청하세요. 몇 명이 빠져도 Google의 최소 인원 아래로 내려가지 않아요.

스크립트와 CI용 HTTP API

사용하는 도구가 MCP를 지원하지 않는다면 HTTP 엔드포인트를 쓰세요. POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call 로 요청해요. 본문은 JSON이고, p_token(tx_ 토큰), p_action(예: help, my_apps, start_campaign), p_args(예: package_name과 테스터 수)를 담아요. 문서에 나온 공개 apikey 헤더도 함께 보내세요.

먼저 help 액션을 호출하세요. 사용 가능한 모든 액션과 인자를 알려 줘요. 전체 스키마는 https://testerexchange.com/openapi.json 에 있고, ChatGPT 커스텀 GPT 액션 등 OpenAPI 도구에서 쓸 수 있어요.

A2A 에이전트 카드

에이전트끼리 연결하는 구성을 위해 Tester Exchange는 https://testerexchange.com/.well-known/agent-card.json 에 A2A 에이전트 카드를 공개하고 있어요. A2A 프로토콜을 지원하는 오케스트레이터는 이 에이전트가 무엇을 제공하는지, 어떻게 호출하는지 스스로 찾아낼 수 있어요. 계정과 관련된 작업에는 같은 tx_ 토큰을 사용하세요.

처음부터 끝까지 한 번에 보기

  1. Play Console의 비공개 트랙에 첫 .aab를 업로드해요.
  2. 에이전트가 내 패키지 이름으로 get_testers를 호출하고, 비공개 트랙의 Google Groups에 testerexchange-testers@googlegroups.com을 추가하라고 알려 줘요.
  3. 그룹을 추가하고 저장한 뒤, 릴리스가 게시됐는지 확인해요.
  4. 크레딧이 부족하면 에이전트가 결제 링크를 줘요. 직접 결제하거나(테스터 12명 $12.99, 15명 $14.99, 25명 $22.99), https://testerexchange.com/earn 에서 다른 앱을 테스트해 크레딧을 무료로 모으세요.
  5. 실제 테스터가 14일 동안 앱을 설치하고 사용해요. 에이전트가 매일 진행 상황을 확인하고, 활동 중인 테스터가 줄면 알려 줘요.
  6. 15일째에 에이전트가 캠페인 리포트를 가져와 프로덕션 액세스 답변 초안을 써 줘요. 내용을 검토한 뒤 프로덕션 신청 버튼을 누르세요.

보안 안내

  • 토큰은 git에 올리지 마세요. 클라이언트의 비밀 저장소나 환경 변수에 보관하세요.
  • 토큰은 저희 쪽에 해시로만 저장되고, 계정당 최대 10개까지 만들 수 있어요. 더 이상 쓰지 않는 토큰은 폐기하세요.
  • 에이전트가 프로덕션 신청서에 쓴 내용은 제출 전에 직접 읽어 보세요. Google은 테스트를 사실대로 설명하라고 요구해요.

자주 묻는 질문

AI 에이전트가 대신 14일 테스트를 해 줄 수 있나요?

아니요. 14일 동안은 실제 사람이 자기 휴대전화로 내 앱을 사용해야 해요. 에이전트는 설정, 모니터링, 리포트를 맡아요.

에이전트가 테스터 비용을 결제할 수 있나요?

아니요. 결제 링크를 돌려줄 수는 있지만, 결제는 항상 사람의 브라우저에서 이뤄져요.

어떤 클라이언트가 MCP 서버와 호환되나요?

커스텀 헤더를 쓰는 Streamable HTTP 원격 MCP를 지원하는 클라이언트라면 모두 돼요. Claude Code, Claude Desktop, Cursor, VS Code가 해당돼요. 그 외에는 HTTP API를 쓰면 돼요.

토큰은 어디서 받나요?

로그인한 뒤 https://testerexchange.com/api 에서 받을 수 있어요. 토큰은 tx_로 시작하고 언제든 폐기할 수 있어요.

에이전트가 내 Play Console을 바꾸나요?

아니요. Play Console에는 접근할 수 없어요. 거기서 해야 할 단계를 알려 줄 뿐이에요.
