Tester Exchange Tester Exchange ખોલો

Cursor થી તમારી Android એપ બનાવી? 14 દિવસ માટે તમારા 12 ટેસ્ટર્સ મેળવો

નવેમ્બર 2026માં અપડેટ કરેલ

Cursor તમારી Android એપ લખી અને બનાવી શકે છે, પણ Google Play ને જરૂરી 12 અસલી ટેસ્ટર્સ તે આપી શકતું નથી. જો તમારું પર્સનલ ડેવલપર એકાઉન્ટ 13 નવેમ્બર 2023 પછી બન્યું હોય, તો પ્રોડક્શન માટે અરજી કરતા પહેલાં તમારે ઓછામાં ઓછા 12 ટેસ્ટર્સ સાથે સતત 14 દિવસ સુધી ક્લોઝ્ડ ટેસ્ટ ચલાવવો પડશે. આ માર્ગદર્શિકા બંડલ બનાવવું, ક્લોઝ્ડ ટેસ્ટિંગ શરૂ કરવું, ટેસ્ટર્સ મેળવવા (પહેલા મફત, પછી ચૂકવણી સાથે) અને Tester Exchange ને Cursor સાથે જોડવું આવરી લે છે, જેથી એજન્ટ કાગળિયાંનું કામ કરી શકે.

સાચા લોકો 14 દિવસ સુધી પોતાના ફોન પર તમારી ઍપ ખોલે છે. એક વાર ચૂકવો, અથવા બીજી ઍપ્સ ટેસ્ટ કરીને મફત મેળવો.12 testers મેળવો
આ પેજ પર
  • 1. રિલીઝ બંડલ (.aab) બનાવો
  • 2. Play Console માં ક્લોઝ્ડ ટેસ્ટિંગ શરૂ કરો
  • 3. તમારા 12 ટેસ્ટર્સ મેળવો: પહેલા મફત, પછી ચૂકવણી સાથે
  • 4. Tester Exchange ને Cursor સાથે જોડો (વૈકલ્પિક)
  • 5. એજન્ટને પૂછો
  • MCP નથી? HTTP API વાપરો
  • વારંવાર પૂછાતા પ્રશ્નો

1. રિલીઝ બંડલ (.aab) બનાવો

  1. Cursor ના એજન્ટને તમારા મોડ્યુલની build.gradle.kts માં રિલીઝ સાઇનિંગ ગોઠવવા કહો (storeFile, storePassword, keyAlias અને keyPassword સાથેનો signingConfigs બ્લોક, release build type પર લાગુ). પાસવર્ડ્સ git થી બહાર રાખો (Android ના build ડૉક્સ: https://developer.android.com/build/building-cmdline).
  2. ટર્મિનલમાં ./gradlew bundleRelease ચલાવો. Gradle બંડલ બનાવે છે અને સાઇન કરે છે; .aab સામાન્ય રીતે app/build/outputs/bundle/release/ હેઠળ દેખાય છે, પણ તમારા પોતાના build આઉટપુટને તપાસો.
  3. જો તમારી પાસે keystore ન હોય તો keytool વડે બનાવો અને તેનો બેકઅપ રાખો. તમે પહેલી રિલીઝ અપલોડ કરો ત્યારે Google Play App Signing ઓફર થાય છે.

2. Play Console માં ક્લોઝ્ડ ટેસ્ટિંગ શરૂ કરો

  1. Test and release > Testing > Closed testing ખોલો, પછી Create track (અથવા Manage track) પસંદ કરો.
  2. Create new release પર ક્લિક કરો, .aab અપલોડ કરો, રિલીઝનું નામ અને નોંધો ઉમેરો, Save as draft, Next, પછી Start rollout (પગલાં https://support.google.com/googleplay/android-developer/answer/9859348 પરથી).
  3. પહેલા Dashboard પરના એપ સેટઅપ કાર્યો પૂરાં કરો, નહિતર રિલીઝ બટન નિષ્ક્રિય રહે છે.

3. તમારા 12 ટેસ્ટર્સ મેળવો: પહેલા મફત, પછી ચૂકવણી સાથે

  • મફત રસ્તો: તમારા ફોન પર https://testerexchange.com/earn ખોલો અને તમને અપાયેલી એપ્સ ટેસ્ટ કરો. તમે ટેસ્ટ કરેલી દરેક એપ તમારી એપ માટે એક ટેસ્ટર લાવે છે.
  • ચૂકવણીનો રસ્તો: એકવાર ચૂકવણી કરો અને ટેસ્ટર્સ આપમેળે સોંપાય છે. હાલની કિંમતો https://testerexchange.com/llms.txt પર આપેલી છે.
  • 12 ને બદલે 15 ટેસ્ટર્સ માંગો, જેથી એક જણ છોડી દે તો પણ તમે Google ના લઘુત્તમથી નીચે ન રહો.

4. Tester Exchange ને Cursor સાથે જોડો (વૈકલ્પિક)

પહેલા https://testerexchange.com/api પર API કી બનાવો. પછી આ તમારા પ્રોજેક્ટની .cursor/mcp.json માં મૂકો, અથવા બધે વાપરવા માટે ~/.cursor/mcp.json માં (ફાઇલના સ્થાન Cursor ના MCP ડૉક્સ પરથી, https://cursor.com/docs/context/mcp). કી commit ન થાય તે માટે પહેલા તમારા shell એન્વાયરમેન્ટમાં TESTER_EXCHANGE_KEY સેટ કરો:

{"mcpServers":{"tester-exchange":{"url":"https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp","headers":{"Authorization":"Bearer ${env:TESTER_EXCHANGE_KEY}"}}}}

Cursor, url અને headers ફીલ્ડ્સમાં ${env:NAME} ને ઉકેલે છે. જો સર્વર લોડ ન થાય, તો Output પેનલ ખોલો અને MCP Logs પસંદ કરો. સર્વર OAuth વગરનું, Streamable HTTP પર સાદું MCP છે; જાહેર ટૂલ્સ (about, pricing, platform_stats) કી વગર કામ કરે છે.

5. એજન્ટને પૂછો

  • "com.example.app માટે 15 ટેસ્ટર્સ મેળવવા Tester Exchange વાપર અને Play Console માં મારે શું કરવું પડશે તે કહે."
  • "com.example.app માટે મારું Tester Exchange કેમ્પેઇન તપાસ અને ગઈકાલે કેટલા ટેસ્ટર્સ સક્રિય હતા તે કહે."
  • "કેમ્પેઇન રિપોર્ટ કાઢ અને અસલી આંકડાઓના આધારે મારા પ્રોડક્શન એક્સેસના જવાબોનો ડ્રાફ્ટ બનાવ."

મુખ્ય ટૂલ get_testers છે: તે એપ ઉમેરે છે, તેનો ટેસ્ટ ખોલે છે અને ફક્ત માણસ જ કરી શકે તેવાં પગલાં પરત આપે છે, જેમ કે Play Console માં ટેસ્ટર્સનું Google Group ઉમેરવું. એજન્ટ તમારા વતી ચૂકવણી કરી શકતો નથી કે Apply for production પર ક્લિક કરી શકતો નથી.

MCP નથી? HTTP API વાપરો

https://testerexchange.com/agents/ પર આપેલ જાહેર apikey હેડર સાથે અને {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}} બોડી સાથે https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call પર POST કરો. સ્કીમા https://testerexchange.com/openapi.json પર છે. વધુ ટૂલ્સ: https://testerexchange.com/guide/ai-builders/.

વારંવાર પૂછાતા પ્રશ્નો

શું Cursor મારા માટે 14 દિવસનો ટેસ્ટ પૂરો કરી શકે?

ના. 14 દિવસ માટે અસલી લોકો પોતાના Android ફોન પર તમારી એપ વાપરે તે જરૂરી છે. Cursor એપ બનાવી શકે અને સેટઅપ ચલાવી શકે.

શું Tester Exchange એ અધિકૃત Cursor ઇન્ટિગ્રેશન છે?

ના. તે એક સ્વતંત્ર સેવા છે જે HTTP પર રિમોટ MCP સપોર્ટ કરતા કોઈપણ ક્લાયન્ટ સાથે કામ કરે છે, અને Cursor તે કરે છે.

AAB ક્યાં જાય છે?

તેને Play Console માં ક્લોઝ્ડ ટેસ્ટિંગ રિલીઝમાં અપલોડ કરો, પછી તે ટ્રેક પર તમારા ટેસ્ટર્સનું Google Group અથવા ઇમેઇલ લિસ્ટ ઉમેરો.

12 ટેસ્ટર્સ મેળવવાનો કોઈ મફત રસ્તો છે?

હા. https://testerexchange.com/earn પર બીજા ડેવલપર્સની એપ્સ ટેસ્ટ કરો; તમે ટેસ્ટ કરેલી દરેક એપ તમારી એપ માટે એક ટેસ્ટર લાવે છે.
