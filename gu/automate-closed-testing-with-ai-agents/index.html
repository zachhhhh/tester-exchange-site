AI agents થી Google Play closed testing ઓટોમેટ કરો

નવેમ્બર 2026 માં અપડેટ

તમે પહેલેથી AI agent સાથે કોડ મોકલતા હો, તો Google Play ની closed testing જરૂરિયાતનું મોટા ભાગનું રૂટિન કામ પણ તેને સોંપી શકો: ઍપ લિસ્ટ કરવી, testers લાવવા, પ્રગતિ તપાસવી અને production access ફોર્મ માટે આંકડા કાઢવા. આ માટે Tester Exchange પાસે MCP server, એક-endpoint HTTP API અને A2A agent card છે. આ ગાઇડ બતાવે છે કે Claude Code, Claude Desktop, Cursor અને બીજા clients કેવી રીતે જોડવા, શું માગવું, અને કયા ભાગો કોઈ agent તમારા વતી કરી શકતો નથી.

સાચા લોકો 14 દિવસ સુધી પોતાના ફોન પર તમારી ઍપ ખોલે છે. એક વાર ચૂકવો, અથવા બીજી ઍપ્સ ટેસ્ટ કરીને મફત મેળવો.12 testers મેળવો

Agent શું કરી શકે અને શું નહીં

Google 13 નવેમ્બર 2023 પછી બનેલા personal developer એકાઉન્ટ પાસે production માટે અરજી કરતાં પહેલાં 14 સતત દિવસ opt-in રહેલા ઓછામાં ઓછા 12 testers સાથે closed test ચલાવવાની માગણી કરે છે. એની આસપાસનું મોટા ભાગનું કામ સંકલનનું છે, જે agents સારી રીતે કરે છે.

  • Agent કરી શકે: તમારી ઍપ ઉમેરવી, tester campaign ખોલવી, તમારી ક્રેડિટ લાગુ કરવી, કેટલા testers સક્રિય છે તે તપાસવું, campaign થોભાવવી કે બંધ કરવી, રોજની પ્રવૃત્તિનો રિપોર્ટ કાઢવો અને તેના આધારે production access જવાબોનો ડ્રાફ્ટ બનાવવામાં મદદ કરવી.
  • માણસે કરવું પડે: Play Console માં closed track પર testers નું Google Group ઉમેરવું, release publish કરવી, ક્રેડિટ માટે ચૂકવણી કરવી (checkout હંમેશાં માણસના બ્રાઉઝરમાં થાય છે) અને Apply for production ક્લિક કરવું.
  • કોઈ ઓટોમેટ ન કરી શકે: 14 દિવસનો સાચો ઉપયોગ. એ સાચા લોકો પોતાના Android ફોન પર કરે છે, અને Google ના નિયમનો આખો હેતુ એ જ છે.

1. Token બનાવો

  1. https://testerexchange.com/api પર સાઇન ઇન કરો.
  2. Personal token બનાવો. તે tx_ થી શરૂ થાય છે. તેને હમણાં જ કૉપિ કરો અને પાસવર્ડની જેમ સાચવો.
  3. Tokens ગમે ત્યારે રદ કરી શકાય છે. Token campaigns પર ક્રેડિટ ખર્ચી શકે છે, પણ ચૂકવણી, પૈસા ઉપાડવા કે તમારું એકાઉન્ટ કાઢી નાખવું કરી શકતો નથી.

2. MCP server જોડો

MCP server https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp પર Streamable HTTP વાપરે છે. તમારો token Authorization: Bearer tx_YOUR_TOKEN હેડરમાં મોકલો.

Claude Code: તમારા ટર્મિનલમાં આ એક વાર ચલાવો.

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code અને JSON config વાળા બીજા clients: tester-exchange નામનું server ઉમેરો, type http, ઉપરનું URL, અને Authorization ને Bearer tx_YOUR_TOKEN પર સેટ કરતી headers એન્ટ્રી સાથે. Config ફાઇલ ક્યાં છે તે તમારા client પર આધારિત છે; તેના MCP દસ્તાવેજો જુઓ.

ફક્ત URL લેતા clients (કેટલાક ChatGPT અને વેબ connectors): https://testerexchange.com/agents/ પરના દસ્તાવેજોમાં તેમના માટેનું URL સ્વરૂપ છે. Token વગર પણ જાહેર tools (Tester Exchange શું છે, કિંમતો, platform આંકડા) કામ કરે છે.

3. શરૂ કરવા માટેનું એક tool: get_testers

આખી tool યાદી શીખવાની જરૂર નથી. મુખ્ય tool get_testers(package_name, name?) છે. એક કૉલ તમારી ઍપ ઉમેરે છે, તેનો test ખોલે છે, તમારી ક્રેડિટ લાગુ કરે છે અને તમારી પ્રગતિ તથા ફક્ત માણસ કરી શકે એવાં પગલાં (જેમ કે Play Console માં Google Group ઉમેરવું) પાછાં આપે છે. પ્રગતિ તપાસવા ગમે ત્યારે ફરી કૉલ કરો.

વિગતો માટે બીજા tools છે: my_apps, campaign_report (testers, રોજની પ્રવૃત્તિ, feedback અને production-access ડેટા), add_testers, set_campaign_status (થોભાવો, ફરી ચાલુ કરો કે બંધ કરો; વપરાયા વગરની ક્રેડિટ તમારા બૅલેન્સમાં પાછી જાય છે), share_kit અને buy_credits_links, જે માણસને ચૂકવણી કરવા માટે checkout લિંક આપે છે.

અસરકારક prompts

  • "com.example.app માટે 15 testers મેળવ અને Play Console માં મારે શું કરવાનું છે તે કહે."
  • "com.example.app માટે મારી Tester Exchange campaign તપાસ. આ અઠવાડિયે દરરોજ કેટલા testers સક્રિય હતા?"
  • "Campaign રિપોર્ટ કાઢ અને મારા production access જવાબોનો ડ્રાફ્ટ બનાવ. ફક્ત સાચા આંકડા વાપર."
  • "Production access મંજૂર થઈ ગયું છે, હવે com.example.app ની campaign બંધ કર."

12 ને બદલે 15 testers માગો, જેથી કોઈ છોડી જાય તો પણ તમે Google ના લઘુતમથી નીચે ન જાઓ.

Scripts અને CI માટે HTTP API

તમારું tool MCP સમજતું ન હોય તો HTTP endpoint વાપરો: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call. Body JSON છે જેમાં p_token (તમારો tx_ token), p_action (દા.ત. help, my_apps કે start_campaign) અને p_args (દા.ત. package_name અને testers ની સંખ્યા) હોય છે. દસ્તાવેજોમાં બતાવેલો જાહેર apikey હેડર મોકલો.

પહેલાં help action કૉલ કરો: તે દરેક action અને તેના arguments પાછા આપે છે. સંપૂર્ણ schema https://testerexchange.com/openapi.json પર છે, જે ChatGPT custom GPT actions અને બીજાં OpenAPI tools સાથે ચાલે છે.

A2A agent card

Agent-થી-agent સેટઅપ માટે Tester Exchange https://testerexchange.com/.well-known/agent-card.json પર A2A agent card પ્રકાશિત કરે છે. A2A protocol સપોર્ટ કરતા orchestrators જાણી શકે છે કે agent શું આપે છે અને તેને કેવી રીતે કૉલ કરવો. તમારા એકાઉન્ટ સાથે જોડાયેલા કોઈપણ કામ માટે એ જ tx_ token વાપરો.

શરૂઆતથી અંત સુધીની આખી પ્રક્રિયા

  1. તમે Play Console માં closed track પર તમારી પહેલી .aab અપલોડ કરો છો.
  2. તમારો agent તમારા package name માટે get_testers કૉલ કરે છે અને કહે છે કે closed track પર Google Groups હેઠળ testerexchange-testers@googlegroups.com ઉમેરો.
  3. તમે group ઉમેરો છો, save કરો છો, અને release publish થઈ છે તેની ખાતરી કરો છો.
  4. ક્રેડિટ ઓછી હોય તો agent તમને checkout લિંક આપે છે. તમે ચૂકવો છો (12 testers માટે $12.99, 15 માટે $14.99, 25 માટે $22.99) અથવા https://testerexchange.com/earn પર બીજી ઍપ્સ ટેસ્ટ કરીને મફતમાં ક્રેડિટ કમાઓ છો.
  5. સાચા testers 14 દિવસ સુધી તમારી ઍપ ઇન્સ્ટોલ કરીને વાપરે છે. તમારો agent રોજ પ્રગતિ તપાસે છે અને સક્રિય testers ઘટે તો ચેતવણી આપે છે.
  6. દિવસ 15 એ agent campaign રિપોર્ટ કાઢે છે અને તમારા production access જવાબોનો ડ્રાફ્ટ બનાવે છે. તમે તે ચકાસો છો અને Apply for production ક્લિક કરો છો.

સલામતી નોંધો

  • Tokens ને git માં ન મૂકો. તેમને તમારા client ના secret store કે environment variable માં રાખો.
  • અમારી બાજુ tokens ફક્ત hashes તરીકે સંગ્રહાય છે અને દરેક એકાઉન્ટ દીઠ 10 સુધી મર્યાદિત છે. ન વપરાતો કોઈપણ token રદ કરો.
  • Production ફોર્મમાં agent જે લખે તે સબમિટ કરતાં પહેલાં વાંચો. Google તમારા test નું સાચું વર્ણન કરવાનું કહે છે.

વારંવાર પૂછાતા પ્રશ્નો

શું AI agent મારા માટે 14 દિવસનો test પૂરો કરી શકે?

ના. 14 દિવસ માટે સાચા લોકોએ પોતાના ફોન પર તમારી ઍપ વાપરવી પડે છે. Agents સેટઅપ, દેખરેખ અને રિપોર્ટિંગ સંભાળે છે.

શું agent testers માટે ચૂકવણી કરી શકે?

ના. તે checkout લિંક આપી શકે, પણ ચૂકવણી હંમેશાં માણસના બ્રાઉઝરમાં થાય છે.

MCP server સાથે કયા clients ચાલે છે?

Custom હેડર સાથે Streamable HTTP પર remote MCP સપોર્ટ કરતો કોઈપણ client, જેમાં Claude Code, Claude Desktop, Cursor અને VS Code આવે છે. બીજા HTTP API વાપરી શકે.

Token ક્યાંથી મળે?

સાઇન ઇન કર્યા પછી https://testerexchange.com/api પર. Tokens tx_ થી શરૂ થાય છે અને ગમે ત્યારે રદ કરી શકાય છે.

શું agent મારા Play Console માં કંઈ બદલે છે?

ના. તેની પાસે તમારા Play Console ની એક્સેસ નથી. ત્યાં કયાં પગલાં લેવાં તે તે તમને કહે છે.
