Vytvoril si aplikáciu pre Android v Claude Codee? Získaj 12 testerov na 14 dní

Aktualizované v novembri 2026

Claude Code dokáže napísať a zostaviť tvoju aplikáciu pre Android, ale nezaobstará 12 skutočných testerov, ktorých Google Play vyžaduje. Ak bol tvoj osobný vývojársky účet vytvorený po 13. novembri 2023, musíš pred žiadosťou o produkciu uskutočniť uzavretý test s aspoň 12 testermi prihlásenými 14 dní v kuse. Tento návod pokrýva vytvorenie balíka, spustenie uzavretého testovania, získanie testerov (najprv zadarmo, potom platene) a pripojenie Tester Exchange ku Claude Codeu, aby agent vybavil administratívu.

1. Vytvor vydávací balík (.aab)

  1. Požiadaj agenta Claude Codeu, aby nastavil podpisovanie vydania v build.gradle.kts tvojho modulu (blok signingConfigs so storeFile, storePassword, keyAlias a keyPassword, nastavený pre typ zostavenia release). Heslá nedávaj do gitu (dokumentácia zostavovania Androidu: https://developer.android.com/build/building-cmdline).
  2. Spusti ./gradlew bundleRelease v termináli. Gradle zostaví a podpíše balík; súbor .aab sa zvyčajne objaví v app/build/outputs/bundle/release/, no skontroluj výstup vlastného zostavenia.
  3. Ak keystore nemáš, vytvor ho pomocou keytool a zálohuj ho. Google Play App Signing sa ponúka pri nahraní prvého vydania.

2. Spusti uzavreté testovanie v Play Console

  1. Otvor Test and release > Testing > Closed testing a potom Create track (alebo Manage track).
  2. Klikni na Create new release, nahraj .aab, pridaj názov a poznámky k vydaniu, Save as draft, Next a potom Start rollout (kroky z https://support.google.com/googleplay/android-developer/answer/9859348).
  3. Najprv dokonči úlohy nastavenia aplikácie na Dashboard, inak zostane tlačidlo vydania neaktívne.

3. Získaj 12 testerov: najprv zadarmo, potom platene

  • Bezplatná cesta: otvor https://testerexchange.com/earn vo svojom telefóne a testuj pridelené aplikácie. Každá aplikácia, ktorú otestuješ, privedie testera do tvojej.
  • Platená cesta: zaplať raz a testeri sa pridelia automaticky. Aktuálne ceny sú uvedené na https://testerexchange.com/llms.txt.
  • Pýtaj 15 testerov namiesto 12, aby ťa jeden odídenec nepripravil o minimum, ktoré Google vyžaduje.

4. Pripoj Tester Exchange ku Claude Codeu (voliteľné)

Najprv si vytvorte API key na https://testerexchange.com/api. Potom raz spustite v termináli tento príkaz a nahraďte tx_YOUR_TOKEN svojím kľúčom (príkaz je uvedený na https://testerexchange.com/agents/):

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Server je čistý MCP cez Streamable HTTP bez OAuth; verejné nástroje (about, pricing, platform_stats) fungujú aj bez kľúča. Kľúč nedávajte do git ani do zdieľaných konfiguračných súborov.

5. Opýtaj sa agenta

  • „Použi Tester Exchange na získanie 15 testerov pre com.example.app a povedz mi, čo musím urobiť v Play Console.“
  • „Skontroluj moju kampaň v Tester Exchange pre com.example.app a povedz mi, koľko testerov bolo včera aktívnych.“
  • „Stiahni správu kampane a priprav moje odpovede k žiadosti o prístup do produkcie zo skutočných čísel.“

Hlavný nástroj je get_testers: pridá aplikáciu, otvorí jej test a vráti kroky, ktoré zvládne len človek, napríklad pridanie Google skupiny testerov v Play Console. Agent nemôže zaplatiť ani kliknúť na Apply for production za teba.

Bez MCP? Použi HTTP API

Pošli POST na https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call s verejnou hlavičkou apikey uvedenou na https://testerexchange.com/agents/ a telom {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}}. Schéma je na https://testerexchange.com/openapi.json. Ďalšie nástroje: https://testerexchange.com/guide/ai-builders/.

Často kladené otázky

Môže Claude Code absolvovať 14-dňový test za mňa?

Nie. Tých 14 dní vyžaduje skutočných ľudí, ktorí používajú tvoju aplikáciu na vlastných telefónoch s Androidom. Claude Code môže vytvoriť aplikáciu a viesť nastavenie.

Je Tester Exchange oficiálna integrácia Claude Codeu?

Nie. Je to nezávislá služba, ktorá funguje s každým klientom podporujúcim vzdialený MCP cez HTTP, čo Claude Code spĺňa.

Kam sa nahrá AAB?

Nahraj ho do vydania uzavretého testovania v Play Console a potom pridaj Google skupinu alebo zoznam e-mailov svojich testerov k tomuto track.

Existuje bezplatný spôsob, ako získať 12 testerov?

Áno. Testuj aplikácie iných vývojárov na https://testerexchange.com/earn; každá aplikácia, ktorú otestuješ, privedie testera do tvojej.
