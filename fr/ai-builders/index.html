Obtenez vos 12 testeurs Google Play depuis votre outil de code IA

Mis à jour en novembre 2026

Que vous ayez créé votre application Android en « vibe coding » ou à la main avec un éditeur IA, Google Play exige toujours 12 testeurs inscrits pendant 14 jours avant qu'un nouveau compte développeur personnel puisse publier en production. Ce hub propose un guide Tester Exchange pour chaque outil d'IA : comment produire l'Android App Bundle, lancer le test fermé et obtenir les testeurs, gratuitement en testant d'abord d'autres applications, ou en payant pour aller plus vite. Chaque page montre aussi la configuration exacte à copier-coller pour que votre outil d'IA pilote lui-même Tester Exchange.

Guides par outil

D'autres outils sont ajoutés régulièrement. Aujourd'hui :

  • Cursor : https://testerexchange.com/guide/get-12-testers-cursor/ - générez l'AAB avec Gradle, puis connectez Tester Exchange à Cursor avec .cursor/mcp.json.

Les deux voies pour obtenir des testeurs

  • Gratuit : testez les applications d'autres développeurs sur https://testerexchange.com/earn depuis votre téléphone. Chaque application que vous testez apporte un testeur à la vôtre, ce qui vous permet de remplir vos 12 places sans payer.
  • Payant et plus rapide : payez une fois pour un pack de testeurs ; les prix actuels sont sur https://testerexchange.com/llms.txt. Les applications payantes reçoivent leurs testeurs avant toutes les autres.

Ce que Google exige

L'aide de la Play Console indique que les comptes développeur personnels créés après le 13 novembre 2023 doivent mener un test fermé avec au moins 12 testeurs inscrits en continu pendant au moins 14 jours avant de pouvoir demander l'accès à la production (https://support.google.com/googleplay/android-developer/answer/14151465). Aucun outil d'IA ne peut faire ces 14 jours à votre place : il faut de vraies personnes sur de vrais téléphones.

Laissez votre outil d'IA faire la configuration

Tester Exchange propose un serveur MCP, une API HTTP et un agent A2A. La liste complète des clients et des extraits de configuration se trouve sur https://testerexchange.com/agents/. Le guide général est https://testerexchange.com/guide/automate-closed-testing-with-ai-agents/.

Questions fréquentes

Ai-je besoin d'un outil d'IA pour utiliser Tester Exchange ?

Non. Le site fonctionne seul. Le serveur MCP et l'API sont des raccourcis facultatifs pour ceux qui travaillent déjà avec un outil d'IA.

L'outil d'IA peut-il payer les testeurs ?

Non. Il peut renvoyer un lien de paiement, mais le paiement se fait dans votre navigateur. La voie gratuite consiste à tester d'autres applications sur https://testerexchange.com/earn.

Tester Exchange est-il une intégration officielle de ces outils ?

Non. C'est un service indépendant. Ces pages montrent seulement comment relier la prise en charge standard de MCP ou HTTP d'un outil à Tester Exchange.
