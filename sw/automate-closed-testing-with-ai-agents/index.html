Otomatisha jaribio la faragha la Google Play kwa AI agents

Imesasishwa Novemba 2026

Ikiwa tayari unatoa msimbo kwa msaada wa AI agent, unaweza pia kumkabidhi kazi nyingi ndogo za sharti la jaribio la faragha la Google Play: kuorodhesha programu yako, kutafuta wajaribu, kukagua maendeleo na kuvuta namba za fomu ya ufikiaji wa production. Tester Exchange ina seva ya MCP, HTTP API yenye endpoint moja na kadi ya A2A agent kwa ajili hiyo. Mwongozo huu unaonyesha jinsi ya kuunganisha Claude Code, Claude Desktop, Cursor na clients nyingine, nini cha kuomba, na sehemu ambazo hakuna agent anayeweza kukufanyia.

Agent anachoweza na asichoweza kufanya

Google inazitaka akaunti za kibinafsi za wasanidi zilizoundwa baada ya tarehe 13 Novemba 2023 kuendesha jaribio la faragha lenye angalau wajaribu 12 waliojiunga kwa siku 14 mfululizo kabla ya kuomba production. Kazi nyingi kuhusu hilo ni uratibu, ambao agents huushughulikia vizuri.

  • Agent anaweza: kuongeza programu yako, kufungua kampeni ya wajaribu, kutumia krediti zako, kukagua wajaribu wangapi wako hai, kusimamisha au kufunga kampeni, kuvuta ripoti ya shughuli za kila siku na kusaidia kuandaa majibu ya ufikiaji wa production kutoka kwayo.
  • Binadamu lazima: aongeze Google Group ya wajaribu kwenye njia ya jaribio la faragha kwenye Play Console, achapishe toleo, alipie krediti (malipo hufanyika kila mara kwenye kivinjari cha mtu) na abonyeze Apply for production.
  • Hakuna anayeweza kuotomatisha: siku 14 za matumizi halisi. Hizo hufanywa na watu halisi kwenye simu zao za Android, na hiyo ndiyo maana nzima ya kanuni ya Google.

1. Tengeneza token

  1. Ingia kwenye https://testerexchange.com/api.
  2. Tengeneza token ya kibinafsi. Inaanza na tx_. Inakili sasa na iweke kama nenosiri.
  3. Token zinaweza kufutwa wakati wowote. Token inaweza kutumia krediti kwenye kampeni, lakini haiwezi kulipa, kutoa pesa wala kufuta akaunti yako.

2. Unganisha seva ya MCP

Seva ya MCP inatumia Streamable HTTP kwenye https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp. Tuma token yako kwenye header Authorization: Bearer tx_YOUR_TOKEN.

Claude Code: endesha hii mara moja kwenye terminal yako.

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code na clients nyingine zenye config ya JSON: ongeza seva iitwayo tester-exchange yenye type http, URL iliyo juu, na ingizo la headers lenye Authorization lililowekwa kuwa Bearer tx_YOUR_TOKEN. Mahali halisi pa faili ya config hutegemea client yako; angalia nyaraka zake za MCP.

Clients zinazokubali URL pekee (baadhi ya viunganishi vya ChatGPT na vya wavuti): nyaraka zilizo https://testerexchange.com/agents/ zinaorodhesha muundo wa URL kwa ajili yake. Bila token, zana za umma (Tester Exchange ni nini, bei, takwimu za jukwaa) bado zinafanya kazi.

3. Zana moja ya kuanzia: get_testers

Huhitaji kujifunza orodha nzima ya zana. Zana kuu ni get_testers(package_name, name?). Wito mmoja huongeza programu yako, hufungua jaribio lake, hutumia krediti zako na hurudisha maendeleo yako pamoja na hatua ambazo binadamu pekee anaweza kuzifanya, kama kuongeza Google Group kwenye Play Console. Iite tena wakati wowote kukagua maendeleo.

Zana nyingine zinashughulikia maelezo: my_apps, campaign_report (wajaribu, shughuli za kila siku, maoni na data ya ufikiaji wa production), add_testers, set_campaign_status (simamisha, endelea au funga; krediti ambazo hazijatumika hurudi kwenye salio lako), share_kit na buy_credits_links, inayorudisha viungo vya malipo ili binadamu alipe.

Maagizo yanayofanya kazi

  • "Get 15 testers for com.example.app and tell me what I need to do in Play Console."
  • "Check my Tester Exchange campaign for com.example.app. How many testers were active each day this week?"
  • "Pull the campaign report and draft my production access answers. Use only the real numbers."
  • "Close the campaign for com.example.app now that production access is approved."

Omba wajaribu 15 badala ya 12, ili mjaribu mmoja akiacha usishuke chini ya kiwango cha chini cha Google.

HTTP API kwa scripts na CI

Ikiwa zana yako haitumii MCP, tumia endpoint ya HTTP: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call. Mwili (body) ni JSON wenye p_token (token yako ya tx_), p_action (kwa mfano help, my_apps au start_campaign) na p_args (kwa mfano package_name na idadi ya wajaribu). Tuma header ya umma ya apikey inayoonyeshwa kwenye nyaraka.

Anza kwa kuita action ya help: inarudisha kila action na hoja zake. Schema kamili iko https://testerexchange.com/openapi.json, inayofanya kazi na ChatGPT custom GPT actions na zana nyingine za OpenAPI.

Kadi ya A2A agent

Kwa mifumo ya agent-kwa-agent, Tester Exchange inachapisha kadi ya A2A agent kwenye https://testerexchange.com/.well-known/agent-card.json. Orchestrators zinazounga mkono itifaki ya A2A zinaweza kugundua agent anachotoa na jinsi ya kumwita. Tumia token ile ile ya tx_ kwa chochote kinachohusiana na akaunti yako.

Mzunguko mzima, tangu mwanzo hadi mwisho

  1. Unapakia .aab yako ya kwanza kwenye njia ya jaribio la faragha kwenye Play Console.
  2. Agent wako anaita get_testers kwa package name yako na anakuambia uongeze testerexchange-testers@googlegroups.com chini ya Google Groups kwenye njia ya jaribio la faragha.
  3. Unaongeza group, unahifadhi, na unahakikisha toleo limechapishwa.
  4. Ikiwa huna krediti, agent anakupa kiungo cha malipo. Unalipa ($12.99 kwa wajaribu 12, $14.99 kwa 15, $22.99 kwa 25) au unapata krediti bure kwa kujaribu programu nyingine kwenye https://testerexchange.com/earn.
  5. Wajaribu halisi wanasakinisha na kutumia programu yako kwa siku 14. Agent wako anakagua maendeleo kila siku na anakuonya wajaribu walio hai wakipungua.
  6. Siku ya 15, agent anavuta ripoti ya kampeni na kuandaa rasimu ya majibu yako ya ufikiaji wa production. Unayapitia na kubonyeza Apply for production.

Tahadhari za usalama

  • Usiweke token kwenye git. Ziweke kwenye hifadhi ya siri ya client yako au kwenye environment variable.
  • Token huhifadhiwa upande wetu kama hashes pekee na zimewekewa kikomo cha 10 kwa kila akaunti. Futa token yoyote usiyoitumia tena.
  • Soma agent anachoandika kwenye fomu yako ya production kabla ya kuwasilisha. Google inakuomba ueleze jaribio lako kwa ukweli.

Maswali yanayoulizwa mara kwa mara

Je, AI agent anaweza kukamilisha jaribio la siku 14 kwa niaba yangu?

Hapana. Siku 14 zinahitaji watu halisi wanaotumia programu yako kwenye simu zao wenyewe. Agents hushughulikia usanidi, ufuatiliaji na kuripoti.

Je, agent anaweza kulipia wajaribu?

Hapana. Anaweza kurudisha viungo vya malipo, lakini malipo hufanyika kila mara kwenye kivinjari cha binadamu.

Ni clients zipi zinafanya kazi na seva ya MCP?

Client yoyote inayounga mkono MCP ya mbali kupitia Streamable HTTP yenye header maalum, ikiwemo Claude Code, Claude Desktop, Cursor na VS Code. Nyingine zinaweza kutumia HTTP API.

Naweza kupata token wapi?

Kwenye https://testerexchange.com/api baada ya kuingia. Token zinaanza na tx_ na zinaweza kufutwa wakati wowote.

Je, agent hubadilisha chochote kwenye Play Console yangu?

Hapana. Hana ufikiaji wa Play Console yako. Anakuambia hatua za kufanya huko.
