1. Wuo ngwugwu mwepụta (.aab)

  1. Gwa onye ọrụ Claude Code ka o hazie nbinye aka mwepụta na build.gradle.kts nke module gị (mgbochi signingConfigs nwere storeFile, storePassword, keyAlias na keyPassword, tọrọ na ụdị build release). Debe paswọọdụ ahụ na git na-adịghị (akwụkwọ ntụziaka build Android: https://developer.android.com/build/building-cmdline).
  2. Mee ./gradlew bundleRelease na terminal. Gradle na-ewu ma na-abanye aka na bundle; .aab na-apụta n'ozuzu n'okpuru app/build/outputs/bundle/release/, mana lelee nsonaazụ build nke gị.
  3. Mepụta keystore site na keytool ma ọ bụrụ na ị nweghị otu, ma mee nkwado ya. A na-enye Google Play App Signing mgbe ị bugoro mwepụta mbụ gị.

2. Malite nnwale emechiri emechi na Play Console

  1. Meghee Test and release > Testing > Closed testing, wee pịa Create track (ma ọ bụ Manage track).
  2. Pịa Create new release, bugo .aab, tinye aha mwepụta na ndetu, Save as draft, Next, wee Start rollout (nzọụkwụ site na https://support.google.com/googleplay/android-developer/answer/9859348).
  3. Buru ụzọ mezue ọrụ nhazi app dị na Dashboard, ma ọ bụghị ya bọtịnụ mwepụta ga-anọgide na-adịghị arụ ọrụ.

3. Nweta ndị nnwale 12 gị: n'efu buru ụzọ, ịkwụ ụgwọ n'ikpeazụ

  • Ụzọ n'efu: meghee https://testerexchange.com/earn na ekwentị gị wee nwalee app ndị a nyere gị. App ọ bụla ị nwalere na-eweta onye nnwale n'app gị.
  • Ụzọ akwụ ụgwọ: kwụọ ụgwọ otu ugboro a ga-ekenye ndị nnwale n'onwe ha. A depụtara ọnụahịa dị ugbu a na https://testerexchange.com/llms.txt.
  • Rịọ ndị nnwale 15 kama 12, ka otu onye si na ya pụọ ghara ime ka ị daa n'okpuru ọnụọgụ kacha nta Google.

4. Jikọọ Tester Exchange na Claude Code (nhọrọ)

Buru ụzọ mepụta API key na https://testerexchange.com/api. Mgbe ahụ, mee iwu a otu ugboro n'ime terminal gị, were key gị dochie tx_YOUR_TOKEN (iwu ahụ bụ nke edepụtara na https://testerexchange.com/agents/):

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Sava ahụ bụ MCP dị mfe site na Streamable HTTP na-enweghị OAuth; ngwaọrụ ọha (about, pricing, platform_stats) na-arụ ọrụ na-enweghị key. Debe key ahụ n'èzí git na faịlụ config ekekọrịtara.

5. Jụọ onye ọrụ AI

  • „Jiri Tester Exchange nweta ndị nnwale 15 maka com.example.app ma gwa m ihe m aghaghị ime na Play Console.”
  • „Lelee mkpọsa Tester Exchange m maka com.example.app ma gwa m ọnụọgụ ndị nnwale rụrụ ọrụ ụnyaahụ.”
  • „Weta akụkọ mkpọsa ahụ ma dee akwụkwọ nzaghachi m maka ohere production site na ọnụọgụ n'ezie.”

Ngwa bụ isi bụ get_testers: ọ na-agbakwunye app ahụ, na-emeghe nnwale ya ma na-eweghachi nzọụkwụ naanị mmadụ nwere ike ime, dị ka itinye Google Group nke ndị nnwale na Play Console. Onye ọrụ AI enweghị ike ịkwụ ụgwọ ma ọ bụ pịa Apply for production maka gị.

Enweghị MCP? Jiri API HTTP

Zipu POST na https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call yana isi apikey ọha edepụtara na https://testerexchange.com/agents/ na ahụ {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}}. Schema dị na https://testerexchange.com/openapi.json. Ngwa ndị ọzọ: https://testerexchange.com/guide/ai-builders/ .

Tester Exchange ọ bụ njikọta gọọmentị nke Claude Code?

Mba. Ọ bụ ọrụ nwere onwe ya nke na-arụ ọrụ na client ọ bụla na-akwado remote MCP site na HTTP, nke Claude Code na-eme.
