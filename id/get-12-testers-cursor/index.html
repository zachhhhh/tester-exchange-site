Membuat aplikasi Android dengan Cursor? Dapatkan 12 tester selama 14 hari

Diperbarui November 2026

Cursor dapat menulis dan membangun aplikasi Android Anda, tetapi tidak dapat menyediakan 12 tester sungguhan yang diwajibkan Google Play. Jika akun pengembang pribadi Anda dibuat setelah 13 November 2023, Anda harus menjalankan pengujian tertutup dengan setidaknya 12 tester yang ikut serta selama 14 hari berturut-turut sebelum mengajukan produksi. Panduan ini mencakup cara membuat bundle, memulai pengujian tertutup, mendapatkan tester (gratis dulu, berbayar kemudian), dan menghubungkan Tester Exchange ke Cursor agar agen dapat mengurus administrasinya.

1. Buat bundle rilis (.aab)

  1. Minta agen Cursor untuk mengonfigurasi penandatanganan rilis di build.gradle.kts modul Anda (blok signingConfigs berisi storeFile, storePassword, keyAlias, dan keyPassword, diterapkan pada build type release). Jangan simpan kata sandi di git (dokumentasi build Android: https://developer.android.com/build/building-cmdline).
  2. Jalankan ./gradlew bundleRelease di terminal. Gradle membangun dan menandatangani bundle; file .aab biasanya muncul di app/build/outputs/bundle/release/, tetapi periksa output build Anda sendiri.
  3. Buat keystore dengan keytool jika belum punya, dan cadangkan. Google Play App Signing ditawarkan saat Anda mengunggah rilis pertama.

2. Mulai pengujian tertutup di Play Console

  1. Buka Test and release > Testing > Closed testing, lalu Create track (atau Manage track).
  2. Klik Create new release, unggah .aab, tambahkan nama dan catatan rilis, Save as draft, Next, lalu Start rollout (langkah dari https://support.google.com/googleplay/android-developer/answer/9859348).
  3. Selesaikan dulu tugas penyiapan aplikasi di Dashboard, atau tombol rilis akan tetap nonaktif.

3. Dapatkan 12 tester: gratis dulu, berbayar kemudian

  • Jalur gratis: buka https://testerexchange.com/earn di ponsel Anda dan uji aplikasi yang diberikan. Setiap aplikasi yang Anda uji mendatangkan satu tester ke aplikasi Anda.
  • Jalur berbayar: bayar sekali dan tester ditugaskan otomatis. Harga terkini tercantum di https://testerexchange.com/llms.txt.
  • Minta 15 tester, bukan 12, agar satu orang yang keluar tidak membuat Anda berada di bawah batas minimum Google.

4. Hubungkan Tester Exchange ke Cursor (opsional)

Pertama, buat kunci API di https://testerexchange.com/api. Lalu letakkan ini di .cursor/mcp.json dalam proyek Anda, atau di ~/.cursor/mcp.json agar berlaku di mana saja (lokasi file dari dokumentasi MCP Cursor, https://cursor.com/docs/context/mcp). Atur TESTER_EXCHANGE_KEY di environment shell Anda terlebih dahulu agar kunci tidak ikut di-commit:

{"mcpServers":{"tester-exchange":{"url":"https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp","headers":{"Authorization":"Bearer ${env:TESTER_EXCHANGE_KEY}"}}}}

Cursor menerjemahkan ${env:NAME} pada kolom url dan headers. Jika server gagal dimuat, buka panel Output dan pilih MCP Logs. Servernya adalah MCP biasa lewat Streamable HTTP tanpa OAuth; alat publik (about, pricing, platform_stats) bekerja tanpa kunci.

5. Tanyakan pada agen

  • “Gunakan Tester Exchange untuk mendapatkan 15 tester bagi com.example.app dan beri tahu saya apa yang harus saya lakukan di Play Console.”
  • “Periksa kampanye Tester Exchange saya untuk com.example.app dan beri tahu berapa tester yang aktif kemarin.”
  • “Ambil laporan kampanye dan susun jawaban akses produksi saya dari angka yang sebenarnya.”

Alat utamanya adalah get_testers: alat ini menambahkan aplikasi, membuka pengujiannya, dan mengembalikan langkah yang hanya bisa dilakukan manusia, seperti menambahkan Google Group tester di Play Console. Agen tidak dapat membayar atau mengklik Apply for production untuk Anda.

Tanpa MCP? Gunakan API HTTP

POST ke https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call dengan header apikey publik yang tercantum di https://testerexchange.com/agents/ dan body {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}}. Skemanya ada di https://testerexchange.com/openapi.json. Alat lainnya: https://testerexchange.com/guide/ai-builders/.

Pertanyaan yang sering diajukan

Bisakah Cursor menyelesaikan pengujian 14 hari untuk saya?

Tidak. 14 hari itu membutuhkan orang sungguhan yang memakai aplikasi Anda di ponsel Android mereka sendiri. Cursor dapat membuat aplikasi dan menjalankan penyiapannya.

Apakah Tester Exchange integrasi resmi Cursor?

Bukan. Ini layanan independen yang bekerja dengan klien mana pun yang mendukung MCP jarak jauh lewat HTTP, dan Cursor mendukungnya.

Ke mana AAB diunggah?

Unggah ke rilis pengujian tertutup di Play Console, lalu tambahkan Google Group atau daftar email tester Anda pada track tersebut.

Adakah cara gratis untuk mendapatkan 12 tester?

Ada. Uji aplikasi developer lain di https://testerexchange.com/earn; setiap aplikasi yang Anda uji mendatangkan satu tester ke aplikasi Anda.
