Tester Exchange Tester Exchange-ті ашу

Google Play жабық тестін AI агенттермен автоматтандыру

2026 жылғы қарашада жаңартылды

Егер код жазуда AI агентті пайдалансаңыз, Google Play-дің жабық тест талабының көп техникалық жұмысын да соған тапсыра аласыз: қолданбаны тізімге қосу, тестерлерді тарту, барысты тексеру және production қолжетімділігі формасы үшін сандарды алу. Tester Exchange-те осыған арналған MCP сервері, бір эндпоинтті HTTP API және A2A agent card бар. Бұл нұсқаулық Claude Code, Claude Desktop, Cursor және басқа клиенттерді қалай қосуды, нені сұрауды және ешбір агент сіздің орныңызға істей алмайтын нәрселерді көрсетеді.

Нақты адамдар қолданбаңызды 14 күн бойы өз телефондарында ашады. Бір рет төлеңіз немесе басқа қолданбаларды тегін тестілеңіз.12 тестер алу

Агент нені істей алады және нені істей алмайды

Google 2023 жылғы 13 қарашадан кейін ашылған жеке әзірлеуші аккаунттарынан production-ға өтінім бермес бұрын кемінде 12 тестер қатарынан 14 күн қосылған күйде болатын жабық тест өткізуді талап етеді. Оның айналасындағы жұмыстың көбі үйлестіру, ал оны агенттер жақсы атқарады.

  • Агент істей алады: қолданбаңызды қосады, тестер кампаниясын ашады, кредиттеріңізді қолданады, қанша тестер белсенді екенін тексереді, кампанияны тоқтатады немесе жабады, күнделікті белсенділік есебін алады және соның негізінде production қолжетімділігі жауаптарының жобасын жазуға көмектеседі.
  • Адам істеуі керек: Play Console-да тестерлердің Google Group-ын жабық трекке қосу, релизді жариялау, кредиттерге төлеу (төлем әрқашан адамның браузерінде жасалады) және Apply for production түймесін басу.
  • Ешкім автоматтандыра алмайды: 14 күндік нақты пайдалануды. Оны нақты адамдар өз Android телефондарында орындайды, Google ережесінің мәні де осында.

1. Токен жасаңыз

  1. https://testerexchange.com/api бетінде жүйеге кіріңіз.
  2. Жеке токен жасаңыз. Ол tx_ деп басталады. Қазір көшіріп алып, құпия сөз сияқты сақтаңыз.
  3. Токендерді кез келген уақытта қайтарып алуға болады. Токен кампанияларға кредит жұмсай алады, бірақ төлей алмайды, ақша шығара алмайды және аккаунтыңызды жоя алмайды.

2. MCP серверін қосыңыз

MCP сервері Streamable HTTP арқылы https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp мекенжайында жұмыс істейді. Токенді Authorization: Bearer tx_YOUR_TOKEN тақырыбында жіберіңіз.

Claude Code: терминалда мынаны бір рет орындаңыз.

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code және JSON конфигурациясы бар басқа клиенттер: tester-exchange деп аталатын, түрі http болатын сервер қосыңыз, жоғарыдағы URL-ді және Authorization мәні Bearer tx_YOUR_TOKEN болатын headers жазбасын көрсетіңіз. Конфигурация файлының орны клиентке байланысты; оның MCP құжаттамасын қараңыз.

Тек URL қабылдайтын клиенттер (кейбір ChatGPT және веб-коннекторлар): https://testerexchange.com/agents/ құжаттамасында олар үшін URL нұсқасы бар. Токенсіз де ашық құралдар (Tester Exchange деген не, бағалар, платформа статистикасы) жұмыс істейді.

3. Бастайтын жалғыз құрал: get_testers

Құралдардың бүкіл тізімін үйренудің қажеті жоқ. Басты құрал — get_testers(package_name, name?). Бір шақыру қолданбаңызды қосады, тестін ашады, кредиттеріңізді қолданады және барысыңызды, сондай-ақ тек адам істей алатын қадамдарды (мысалы, Play Console-да Google Group қосу) қайтарады. Барысты тексеру үшін оны кез келген уақытта қайта шақырыңыз.

Басқа құралдар егжей-тегжейді қамтиды: my_apps, campaign_report (тестерлер, күнделікті белсенділік, пікірлер және production қолжетімділігі деректері), add_testers, set_campaign_status (тоқтату, жалғастыру немесе жабу; пайдаланылмаған кредиттер балансқа қайтады), share_kit және адамның төлеуі үшін төлем сілтемелерін беретін buy_credits_links.

Жақсы жұмыс істейтін сұраныстар

  • "com.example.app үшін 15 тестер алып бер және Play Console-да не істеу керегін айт."
  • "com.example.app үшін Tester Exchange кампаниямды тексер. Осы аптада күн сайын қанша тестер белсенді болды?"
  • "Кампания есебін алып, production қолжетімділігі жауаптарымның жобасын жаз. Тек нақты сандарды пайдалан."
  • "Production қолжетімділігі мақұлданды, com.example.app кампаниясын жап."

12 емес, 15 тестер сұраңыз, сонда біреудің шығып кетуі Google-дың ең аз шегінен төмен түсірмейді.

Скрипттер мен CI үшін HTTP API

Құралыңыз MCP-мен жұмыс істемесе, HTTP эндпоинтін пайдаланыңыз: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call. Дене — p_token (сіздің tx_ токеніңіз), p_action (мысалы, help, my_apps немесе start_campaign) және p_args (мысалы, package_name мен тестер саны) бар JSON. Құжаттамада көрсетілген ашық apikey тақырыбын жіберіңіз.

Алдымен help әрекетін шақырыңыз: ол барлық әрекеттер мен олардың аргументтерін қайтарады. Толық схема https://testerexchange.com/openapi.json мекенжайында, ол ChatGPT custom GPT actions және басқа OpenAPI құралдарымен жұмыс істейді.

A2A agent card

Агенттен агентке жүйелері үшін Tester Exchange https://testerexchange.com/.well-known/agent-card.json мекенжайында A2A agent card жариялайды. A2A протоколын қолдайтын оркестраторлар агенттің не ұсынатынын және оны қалай шақыру керегін біле алады. Аккаунтыңызға қатысты кез келген әрекет үшін сол tx_ токенін пайдаланыңыз.

Басынан аяғына дейін толық жүріс

  1. Play Console-да жабық трекке алғашқы .aab файлыңызды жүктейсіз.
  2. Агентіңіз пакет атауыңыз үшін get_testers шақырады және жабық тректегі Google Groups астына testerexchange-testers@googlegroups.com қосуды айтады.
  3. Топты қосып, сақтайсыз және релиздің жарияланғанына көз жеткізесіз.
  4. Кредит жетпесе, агент төлем сілтемесін береді. Сіз төлейсіз (12 тестер US$12.99, 15 тестер US$14.99, 25 тестер US$22.99) немесе https://testerexchange.com/earn бетінде басқа қолданбаларды тегін тестілеп, кредит жинайсыз.
  5. Нақты тестерлер қолданбаңызды 14 күн орнатып, пайдаланады. Агентіңіз барысты күн сайын тексеріп, белсенді тестерлер азайса, ескертеді.
  6. 15-күні агент кампания есебін алып, production қолжетімділігі жауаптарының жобасын жазады. Сіз оларды қарап шығып, Apply for production түймесін басасыз.

Қауіпсіздік туралы ескертпелер

  • Токендерді git-ке салмаңыз. Оларды клиентіңіздің құпия сақтау орнында немесе орта айнымалысында ұстаңыз.
  • Біздің жақта токендер тек хэш түрінде сақталады және бір аккаунтқа 10-мен шектеледі. Пайдаланбайтын токенді қайтарып алыңыз.
  • Жібермес бұрын агент production формасына жазғанды оқып шығыңыз. Google тестіңізді шынайы сипаттауды сұрайды.

Жиі қойылатын сұрақтар

AI агент менің орныма 14 күндік тестті өткізе ала ма?

Жоқ. 14 күн бойы нақты адамдар қолданбаңызды өз телефондарында пайдалануы керек. Агенттер баптауды, мониторингті және есепті атқарады.

Агент тестерлерге төлей ала ма?

Жоқ. Ол төлем сілтемелерін қайтара алады, бірақ төлем әрқашан адамның браузерінде жасалады.

MCP серверімен қандай клиенттер жұмыс істейді?

Streamable HTTP арқылы қашықтағы MCP-ді және арнайы тақырыпты қолдайтын кез келген клиент, соның ішінде Claude Code, Claude Desktop, Cursor және VS Code. Басқалары HTTP API-ді пайдалана алады.

Токенді қайдан алам?

Жүйеге кіргеннен кейін https://testerexchange.com/api бетінде. Токендер tx_ деп басталады және кез келген уақытта қайтарып алынуы мүмкін.

Агент менің Play Console-дағы бір нәрсені өзгерте ме?

Жоқ. Оның Play Console-ға қолжетімділігі жоқ. Ол сізге сонда істейтін қадамдарды айтады.
