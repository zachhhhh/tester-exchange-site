Android қолданбасын Cursor-мен жасадыңыз ба? 12 тестерді 14 күнге алыңыз

2026 жылғы қарашада жаңартылды

Cursor Android қолданбаңызды жаза және жинай алады, бірақ Google Play талап ететін 12 нақты тестерді бере алмайды. Жеке әзірлеуші аккаунтыңыз 2023 жылғы 13 қарашадан кейін ашылған болса, өндіріске өтініш бермес бұрын кемінде 12 тестермен 14 күн қатарынан қосылған жабық тест жүргізуіңіз керек. Бұл нұсқаулықта бандлды жинау, жабық тестілеуді бастау, тестерлерді алу (алдымен тегін, сосын ақылы) және агент құжат жұмысын орындауы үшін Tester Exchange-ті Cursor-ға қосу қарастырылған.

Нақты адамдар қолданбаңызды 14 күн бойы өз телефондарында ашады. Бір рет төлеңіз немесе басқа қолданбаларды тегін тестілеңіз.12 тестер алу

1. Release бандлын (.aab) жинаңыз

  1. Cursor агентінен модуліңіздің build.gradle.kts файлында release қол қоюын баптауды сұраңыз (storeFile, storePassword, keyAlias және keyPassword бар signingConfigs блогы, release build type-қа қолданылады). Құпиясөздерді git-тен тыс сақтаңыз (Android build құжаттамасы: https://developer.android.com/build/building-cmdline).
  2. Терминалда ./gradlew bundleRelease командасын іске қосыңыз. Gradle бандлды жинап, қол қояды; .aab әдетте app/build/outputs/bundle/release/ ішінде пайда болады, бірақ өз build нәтижеңізді тексеріңіз.
  3. Keystore жоқ болса, keytool арқылы жасаңыз және көшірмесін сақтаңыз. Google Play App Signing бірінші релизді жүктегенде ұсынылады.

2. Play Console-да жабық тестілеуді бастаңыз

  1. Test and release > Testing > Closed testing бөлімін ашып, Create track (немесе Manage track) таңдаңыз.
  2. Create new release түймесін басыңыз, .aab жүктеңіз, релиз атауы мен жазбаларды қосыңыз, Save as draft, Next, сосын Start rollout (қадамдар https://support.google.com/googleplay/android-developer/answer/9859348 бетінен).
  3. Алдымен Dashboard-тағы қолданбаны баптау тапсырмаларын аяқтаңыз, әйтпесе релиз түймесі өшірулі болып қалады.

3. 12 тестерді алыңыз: алдымен тегін, сосын ақылы

  • Тегін жол: телефоныңызда https://testerexchange.com/earn ашып, берілген қолданбаларды тестілеңіз. Тестілеген әр қолданба сіздікіне бір тестер әкеледі.
  • Ақылы жол: бір рет төлеңіз, тестерлер автоматты түрде тағайындалады. Ағымдағы бағалар https://testerexchange.com/llms.txt бетінде көрсетілген.
  • 12 орнына 15 тестер сұраңыз, сонда біреуі шығып кетсе де, Google белгілеген минимумнан төмен түспейсіз.

4. Tester Exchange-ті Cursor-ға қосыңыз (міндетті емес)

Алдымен https://testerexchange.com/api бетінде API кілтін жасаңыз. Сосын мұны жобаңыздағы .cursor/mcp.json файлына, не барлық жерде қолдану үшін ~/.cursor/mcp.json файлына жазыңыз (файл орындары Cursor-дың MCP құжаттамасынан, https://cursor.com/docs/context/mcp). Кілт commit-қа түспеуі үшін алдымен shell ортасында TESTER_EXCHANGE_KEY мәнін орнатыңыз:

{"mcpServers":{"tester-exchange":{"url":"https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp","headers":{"Authorization":"Bearer ${env:TESTER_EXCHANGE_KEY}"}}}}

Cursor url және headers өрістеріндегі ${env:NAME} мәнін шешеді. Сервер жүктелмесе, Output панелін ашып, MCP Logs таңдаңыз. Сервер - OAuth-сыз Streamable HTTP үстіндегі қарапайым MCP; ашық құралдар (about, pricing, platform_stats) кілтсіз жұмыс істейді.

5. Агенттен сұраңыз

  • "Tester Exchange арқылы com.example.app үшін 15 тестер алып, Play Console-да не істеуім керегін айт."
  • "com.example.app үшін Tester Exchange науқанымды тексеріп, кеше қанша тестер белсенді болғанын айт."
  • "Науқан есебін алып, өндіріске қол жеткізу жауаптарымның жобасын нақты сандар негізінде жаз."

Негізгі құрал - get_testers: ол қолданбаны қосады, тестін ашады және тек адам орындай алатын қадамдарды қайтарады, мысалы Play Console-ға тестерлердің Google Group-ын қосу. Агент сіздің орныңызға төлей алмайды немесе Apply for production түймесін баса алмайды.

MCP жоқ па? HTTP API қолданыңыз

https://testerexchange.com/agents/ бетінде көрсетілген ашық apikey тақырыбымен және {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}} денесімен https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call мекенжайына POST жіберіңіз. Схема https://testerexchange.com/openapi.json бетінде. Басқа құралдар: https://testerexchange.com/guide/ai-builders/.

Жиі қойылатын сұрақтар

Cursor 14 күндік тестті менің орныма аяқтай ала ма?

Жоқ. 14 күн ішінде нақты адамдар қолданбаңызды өз Android телефондарында пайдалануы керек. Cursor қолданбаны жасап, баптауды басқара алады.

Tester Exchange - Cursor-дың ресми интеграциясы ма?

Жоқ. Бұл HTTP арқылы қашықтағы MCP-ні қолдайтын кез келген клиентпен жұмыс істейтін тәуелсіз қызмет, Cursor да солардың бірі.

AAB қайда жүктеледі?

Оны Play Console-дағы жабық тестілеу релизіне жүктеңіз, сосын сол трекке тестерлеріңіздің Google Group-ын немесе электрондық пошта тізімін қосыңыз.

12 тестерді алудың тегін жолы бар ма?

Иә. https://testerexchange.com/earn бетінде басқа әзірлеушілердің қолданбаларын тестілеңіз; тестілеген әр қолданба сіздікіне бір тестер әкеледі.
