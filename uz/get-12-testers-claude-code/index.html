Android ilovangizni Claude Code bilan yaratdingizmi? 12 ta testerni 14 kunga oling

2026-yil noyabrda yangilangan

Claude Code Android ilovangizni yoza va qura oladi, lekin Google Play talab qiladigan 12 ta haqiqiy testerni topib bera olmaydi. Agar shaxsiy dasturchi akkauntingiz 2023-yil 13-noyabrdan keyin yaratilgan bo‘lsa, production’ga ariza berishdan oldin kamida 12 ta tester 14 kun ketma-ket ro‘yxatdan o‘tgan holda yopiq test o‘tkazishingiz kerak. Bu qo‘llanmada paketni qurish, yopiq testni boshlash, testerlarni olish (avval bepul, keyin pullik) va agent qog‘ozbozlikni bajarishi uchun Tester Exchange’ni Claude Code’ga ulash yoritilgan.

1. Release paketini (.aab) yarating

  1. Claude Code agentidan modulingizning build.gradle.kts faylida release imzolashni sozlashni so‘rang (release build type’ga o‘rnatilgan, storeFile, storePassword, keyAlias va keyPassword bilan signingConfigs bloki). Parollarni git’da saqlamang (Android build hujjatlari: https://developer.android.com/build/building-cmdline).
  2. Terminalda ./gradlew bundleRelease ni ishga tushiring. Gradle paketni quradi va imzolaydi; .aab odatda app/build/outputs/bundle/release/ ostida paydo bo‘ladi, ammo o‘z build natijangizni tekshiring.
  3. Agar keystore bo‘lmasa, keytool bilan yarating va zaxira nusxasini oling. Google Play App Signing birinchi release’ni yuklaganingizda taklif qilinadi.

2. Play Console’da yopiq testni boshlang

  1. Test and release > Testing > Closed testing ni oching, so‘ng Create track (yoki Manage track) ni bosing.
  2. Create new release ni bosing, .aab ni yuklang, release nomi va izohlarini qo‘shing, Save as draft, Next, so‘ng Start rollout (qadamlar https://support.google.com/googleplay/android-developer/answer/9859348 dan).
  3. Avval Dashboard’dagi ilovani sozlash vazifalarini bajaring, aks holda release tugmasi o‘chiq qoladi.

3. 12 ta testerni oling: avval bepul, keyin pullik

  • Bepul yo‘l: telefoningizda https://testerexchange.com/earn ni oching va berilgan ilovalarni sinang. Siz sinagan har bir ilova sizning ilovangizga tester olib keladi.
  • Pullik yo‘l: bir marta to‘lang, testerlar avtomatik tayinlanadi. Joriy narxlar https://testerexchange.com/llms.txt da keltirilgan.
  • 12 emas, 15 ta tester so‘rang, shunda bittasi chiqib ketsa ham Google minimumidan past bo‘lib qolmaysiz.

4. Tester Exchange’ni Claude Code’ga ulang (ixtiyoriy)

Avval https://testerexchange.com/api manzilida API key yarating. Keyin terminalda buni bir marta ishga tushiring va tx_YOUR_TOKEN o‘rniga o‘z key’ingizni qo‘ying (buyruq https://testerexchange.com/agents/ sahifasida keltirilgan):

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Server OAuth’siz Streamable HTTP orqali oddiy MCP hisoblanadi; ochiq vositalar (about, pricing, platform_stats) key’siz ham ishlaydi. Key’ni git’dan va umumiy config fayllaridan tashqarida saqlang.

5. Agentdan so‘rang

  • “Tester Exchange yordamida com.example.app uchun 15 ta tester oling va Play Console’da nima qilishim kerakligini ayting.”
  • “com.example.app uchun Tester Exchange kampaniyamni tekshiring va kecha nechta tester faol bo‘lganini ayting.”
  • “Kampaniya hisobotini oling va production’ga kirish javoblarimni haqiqiy raqamlar asosida tayyorlang.”

Asosiy vosita get_testers: u ilovani qo‘shadi, uning testini ochadi va faqat inson bajara oladigan qadamlarni qaytaradi, masalan Play Console’ga testerlarning Google Group’ini qo‘shish. Agent sizning o‘rningizga to‘lay olmaydi yoki Apply for production ni bosa olmaydi.

MCP yo‘qmi? HTTP API’dan foydalaning

https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call manziliga https://testerexchange.com/agents/ da keltirilgan ommaviy apikey sarlavhasi va {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}} tanasi bilan POST yuboring. Sxema https://testerexchange.com/openapi.json da. Boshqa vositalar: https://testerexchange.com/guide/ai-builders/.

Ko‘p so‘raladigan savollar

Claude Code 14 kunlik testni men uchun bajara oladimi?

Yo‘q. 14 kun davomida ilovangizdan o‘z Android telefonlarida haqiqiy odamlar foydalanishi kerak. Claude Code ilovani yaratishi va sozlashni boshqarishi mumkin.

Tester Exchange Claude Code’ning rasmiy integratsiyasimi?

Yo‘q. Bu mustaqil xizmat bo‘lib, HTTP orqali remote MCP’ni qo‘llab-quvvatlaydigan har qanday client bilan ishlaydi, Claude Code ham shunday.

AAB qayerga yuklanadi?

Uni Play Console’dagi yopiq test release’iga yuklang, so‘ng o‘sha track’ga testerlaringizning Google Group’i yoki email ro‘yxatini qo‘shing.

12 ta testerni olishning bepul usuli bormi?

Ha. https://testerexchange.com/earn orqali boshqa dasturchilarning ilovalarini sinang; siz sinagan har bir ilova sizning ilovangizga tester olib keladi.
