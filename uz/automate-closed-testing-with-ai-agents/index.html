Agent nima qila oladi va nima qila olmaydi

Google 2023-yil 13-noyabrdan keyin ochilgan shaxsiy dasturchi hisoblaridan production’ga ariza berishdan oldin kamida 12 tester ketma-ket 14 kun opt-in holatida turgan yopiq test oʻtkazishni talab qiladi. Bunga oid ishlarning koʻpi muvofiqlashtirish boʻlib, agentlar buni yaxshi uddalaydi.

  • Agent qila oladi: ilovangizni qoʻshish, tester kampaniyasini ochish, kreditlaringizni qoʻllash, nechta tester faol ekanini tekshirish, kampaniyani toʻxtatish yoki yopish, kunlik faollik hisobotini olish va undan production ruxsati javoblarining qoralamasini yozishga yordam berish.
  • Inson qilishi kerak: Play Console’da testerlar Google Group’ini yopiq trekka qoʻshish, relizni nashr etish, kreditlar uchun toʻlash (toʻlov har doim odamning brauzerida amalga oshadi) va Apply for production tugmasini bosish.
  • Hech kim avtomatlashtira olmaydi: 14 kunlik haqiqiy foydalanish. Buni haqiqiy odamlar oʻz Android telefonlarida bajaradi, Google qoidasining butun mohiyati ham shu.

1. Token yarating

  1. https://testerexchange.com/api sahifasida tizimga kiring.
  2. Shaxsiy token yarating. U tx_ bilan boshlanadi. Uni hoziroq nusxalab, parol kabi saqlang.
  3. Tokenlarni istalgan vaqtda bekor qilish mumkin. Token kampaniyalar uchun kreditlarni sarflay oladi, lekin pul toʻlay, pul yechib ola yoki hisobingizni oʻchira olmaydi.

2. MCP serverni ulang

MCP server https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp manzilida Streamable HTTP’dan foydalanadi. Tokeningizni Authorization: Bearer tx_YOUR_TOKEN sarlavhasida yuboring.

Claude Code: buni terminalda bir marta ishga tushiring.

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code va JSON konfiguratsiyali boshqa klientlar: tester-exchange nomli server qoʻshing, turi http, yuqoridagi URL va Authorization qiymati Bearer tx_YOUR_TOKEN boʻlgan headers yozuvi bilan. Konfiguratsiya faylining aniq joylashuvi klientingizga bogʻliq; uning MCP hujjatlarini tekshiring.

Faqat URL qabul qiladigan klientlar (baʼzi ChatGPT va veb-konnektorlar): https://testerexchange.com/agents/ hujjatlarida ular uchun URL shakli keltirilgan. Token boʻlmasa ham ommaviy vositalar (Tester Exchange nima, narxlar, platforma statistikasi) ishlaydi.

3. Boshlash uchun yagona vosita: get_testers

Butun vositalar roʻyxatini oʻrganish shart emas. Asosiy vosita — get_testers(package_name, name?). Bitta chaqiruv ilovangizni qoʻshadi, testini ochadi, kreditlaringizni qoʻllaydi va jarayoningiz hamda faqat inson bajara oladigan qadamlarni qaytaradi, masalan, Play Console’da Google Group’ni qoʻshish. Jarayonni tekshirish uchun uni istalgan vaqtda yana chaqiring.

Qolgan vositalar tafsilotlarni qamrab oladi: my_apps, campaign_report (testerlar, kunlik faollik, fikr-mulohazalar va production ruxsati maʼlumotlari), add_testers, set_campaign_status (toʻxtatish, davom ettirish yoki yopish; ishlatilmagan kreditlar balansingizga qaytadi), share_kit va buy_credits_links, u inson toʻlashi uchun checkout havolalarini qaytaradi.

Ishlaydigan promptlar

  • "com.example.app uchun 15 ta tester ol va Play Console’da nima qilishim kerakligini ayt."
  • "Tester Exchange’dagi com.example.app kampaniyamni tekshir. Bu hafta har kuni nechta tester faol boʻldi?"
  • "Kampaniya hisobotini ol va production ruxsati javoblarimning qoralamasini yoz. Faqat haqiqiy raqamlardan foydalan."
  • "Production ruxsati tasdiqlangani uchun com.example.app kampaniyasini hozir yop."

12 emas, 15 ta tester soʻrang, shunda bitta chiqib ketgan tester sizni Google minimumidan pastga tushirib yubormaydi.

Skriptlar va CI uchun HTTP API

Vositangiz MCP bilan ishlamasa, HTTP endpointdan foydalaning: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call. Soʻrov tanasi JSON boʻlib, unda p_token (tx_ tokeningiz), p_action (masalan, help, my_apps yoki start_campaign) va p_args (masalan, package_name va testerlar soni) bor. Hujjatlarda koʻrsatilgan ommaviy apikey sarlavhasini yuboring.

Avval help amalini chaqiring: u barcha amallar va ularning argumentlarini qaytaradi. Toʻliq sxema https://testerexchange.com/openapi.json manzilida, u ChatGPT custom GPT actions va boshqa OpenAPI vositalari bilan ishlaydi.

A2A agent kartasi

Agentdan agentga ulanadigan tizimlar uchun Tester Exchange https://testerexchange.com/.well-known/agent-card.json manzilida A2A agent kartasini eʼlon qiladi. A2A protokolini qoʻllab-quvvatlaydigan orkestratorlar agent nimalarni taklif qilishini va uni qanday chaqirishni bilib oladi. Hisobingizga bogʻliq har qanday ish uchun xuddi shu tx_ tokenidan foydalaning.

Boshidan oxirigacha toʻliq jarayon

  1. Siz birinchi .aab faylingizni Play Console’dagi yopiq trekka yuklaysiz.
  2. Agentingiz paket nomingiz uchun get_testers’ni chaqiradi va yopiq trekda Google Groups ostiga testerexchange-testers@googlegroups.com’ni qoʻshishni aytadi.
  3. Siz guruhni qoʻshasiz, saqlaysiz va reliz nashr etilganiga ishonch hosil qilasiz.
  4. Kreditlaringiz yetmasa, agent sizga checkout havolasini beradi. Siz toʻlaysiz (12 tester uchun $12.99, 15 uchun $14.99, 25 uchun $22.99) yoki https://testerexchange.com/earn sahifasida boshqa ilovalarni test qilib, bepul kredit ishlaysiz.
  5. Haqiqiy testerlar ilovangizni 14 kun davomida oʻrnatib, ishlatadi. Agentingiz jarayonni har kuni tekshiradi va faol testerlar kamaysa, sizni ogohlantiradi.
  6. 15-kuni agent kampaniya hisobotini oladi va production ruxsati javoblarining qoralamasini yozadi. Siz ularni koʻrib chiqib, Apply for production tugmasini bosasiz.

Xavfsizlik boʻyicha eslatmalar

  • Tokenlarni git’dan tashqarida saqlang. Ularni klientingizning maxfiy maʼlumotlar ombori yoki muhit oʻzgaruvchisiga joylang.
  • Tokenlar bizda faqat xesh koʻrinishida saqlanadi va har bir hisob uchun 10 tadan oshmaydi. Endi ishlatmaydigan har qanday tokenni bekor qiling.
  • Yuborishdan oldin agent production shakliga yozganlarini oʻqib chiqing. Google testingizni rostgoʻylik bilan tasvirlashingizni soʻraydi.
