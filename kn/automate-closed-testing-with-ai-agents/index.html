ನವೆಂಬರ್ 2026 ರಲ್ಲಿ ಅಪ್‌ಡೇಟ್ ಮಾಡಲಾಗಿದೆ

ನೀವು ಈಗಾಗಲೇ AI agent ಜೊತೆ ಕೋಡ್ ಶಿಪ್ ಮಾಡುತ್ತಿದ್ದರೆ, Google Play ಯ closed testing ಅಗತ್ಯದ ಬಹುತೇಕ ಒತ್ತಡದ ಕೆಲಸವನ್ನೂ ಅದಕ್ಕೆ ವಹಿಸಬಹುದು: ಆ್ಯಪ್ ಪಟ್ಟಿ ಮಾಡುವುದು, testers ಹುಡುಕುವುದು, ಪ್ರಗತಿ ಪರಿಶೀಲಿಸುವುದು ಮತ್ತು production access ಫಾರ್ಮ್‌ಗೆ ಸಂಖ್ಯೆಗಳನ್ನು ಎಳೆಯುವುದು. ಇದಕ್ಕಾಗಿ Tester Exchange ನಲ್ಲಿ MCP ಸರ್ವರ್, ಒಂದೇ endpoint ನ HTTP API ಮತ್ತು A2A agent card ಇವೆ. Claude Code, Claude Desktop, Cursor ಮತ್ತು ಇತರ clients ಅನ್ನು ಹೇಗೆ ಸಂಪರ್ಕಿಸಬೇಕು, ಏನು ಕೇಳಬೇಕು, ಮತ್ತು ಯಾವ ಯಾವ ಕೆಲಸವನ್ನು ಯಾವ agent ಕೂಡ ನಿಮಗಾಗಿ ಮಾಡಲಾಗದು ಎಂದು ಈ ಗೈಡ್ ತೋರಿಸುತ್ತದೆ.

Agent ಏನು ಮಾಡಬಹುದು, ಏನು ಮಾಡಲಾಗದು

13 ನವೆಂಬರ್ 2023 ರ ನಂತರ ರಚಿಸಿದ personal developer ಖಾತೆಗಳು production ಗೆ ಅರ್ಜಿ ಹಾಕುವ ಮೊದಲು, ಕನಿಷ್ಠ 12 testers 14 ದಿನ ನಿರಂತರವಾಗಿ opt-in ಆಗಿರುವ closed test ನಡೆಸಬೇಕು ಎಂದು Google ಅಗತ್ಯಪಡಿಸುತ್ತದೆ. ಇದರ ಸುತ್ತಲಿನ ಹೆಚ್ಚಿನ ಕೆಲಸ ಸಮನ್ವಯ, ಅದನ್ನು agents ಚೆನ್ನಾಗಿ ನಿಭಾಯಿಸುತ್ತವೆ.

  • Agent ಮಾಡಬಲ್ಲದು: ನಿಮ್ಮ ಆ್ಯಪ್ ಸೇರಿಸುವುದು, tester campaign ತೆರೆಯುವುದು, ಕ್ರೆಡಿಟ್‌ಗಳನ್ನು ಅನ್ವಯಿಸುವುದು, ಎಷ್ಟು testers ಸಕ್ರಿಯರಾಗಿದ್ದಾರೆ ಎಂದು ಪರಿಶೀಲಿಸುವುದು, campaign ಅನ್ನು ವಿರಾಮಗೊಳಿಸುವುದು ಅಥವಾ ಮುಚ್ಚುವುದು, ದಿನನಿತ್ಯದ ಚಟುವಟಿಕೆ ವರದಿ ತರುವುದು ಮತ್ತು ಅದರ ಆಧಾರದ ಮೇಲೆ production access ಉತ್ತರಗಳ ಡ್ರಾಫ್ಟ್ ಮಾಡಲು ಸಹಾಯ ಮಾಡುವುದು.
  • ಮನುಷ್ಯರೇ ಮಾಡಬೇಕು: Play Console ನಲ್ಲಿ testers ರ Google Group ಅನ್ನು closed track ಗೆ ಸೇರಿಸುವುದು, release ಪಬ್ಲಿಷ್ ಮಾಡುವುದು, ಕ್ರೆಡಿಟ್‌ಗಳಿಗೆ ಹಣ ಪಾವತಿಸುವುದು (checkout ಯಾವಾಗಲೂ ವ್ಯಕ್ತಿಯ ಬ್ರೌಸರ್‌ನಲ್ಲೇ ನಡೆಯುತ್ತದೆ) ಮತ್ತು Apply for production ಕ್ಲಿಕ್ ಮಾಡುವುದು.
  • ಯಾರೂ ಸ್ವಯಂಚಾಲಿತಗೊಳಿಸಲಾಗದ್ದು: 14 ದಿನಗಳ ನಿಜವಾದ ಬಳಕೆ. ಅದನ್ನು ನಿಜವಾದ ಜನರು ತಮ್ಮದೇ Android ಫೋನ್‌ಗಳಲ್ಲಿ ಮಾಡುತ್ತಾರೆ; Google ನಿಯಮದ ಉದ್ದೇಶವೇ ಅದು.

1. Token ರಚಿಸಿ

  1. https://testerexchange.com/api ನಲ್ಲಿ ಸೈನ್ ಇನ್ ಮಾಡಿ.
  2. ವೈಯಕ್ತಿಕ token ರಚಿಸಿ. ಅದು tx_ ನಿಂದ ಆರಂಭವಾಗುತ್ತದೆ. ಈಗಲೇ ಕಾಪಿ ಮಾಡಿ, ಪಾಸ್‌ವರ್ಡ್‌ನಂತೆ ಸುರಕ್ಷಿತವಾಗಿ ಇಡಿ.
  3. Tokens ಅನ್ನು ಯಾವಾಗ ಬೇಕಾದರೂ ರದ್ದುಪಡಿಸಬಹುದು. Token campaigns ಮೇಲೆ ಕ್ರೆಡಿಟ್ ಖರ್ಚು ಮಾಡಬಹುದು, ಆದರೆ ಹಣ ಪಾವತಿಸಲು, ಹಣ ಹಿಂಪಡೆಯಲು ಅಥವಾ ನಿಮ್ಮ ಖಾತೆ ಅಳಿಸಲು ಸಾಧ್ಯವಿಲ್ಲ.

2. MCP ಸರ್ವರ್ ಸಂಪರ್ಕಿಸಿ

MCP ಸರ್ವರ್ https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp ನಲ್ಲಿ Streamable HTTP ಬಳಸುತ್ತದೆ. ನಿಮ್ಮ token ಅನ್ನು Authorization: Bearer tx_YOUR_TOKEN ಹೆಡರ್‌ನಲ್ಲಿ ಕಳುಹಿಸಿ.

Claude Code: ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ ಇದನ್ನು ಒಮ್ಮೆ ಚಲಾಯಿಸಿ.

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code ಮತ್ತು JSON config ಇರುವ ಇತರ clients: tester-exchange ಎಂಬ ಹೆಸರಿನ ಸರ್ವರ್ ಸೇರಿಸಿ, type http, ಮೇಲಿನ URL, ಮತ್ತು Authorization ಅನ್ನು Bearer tx_YOUR_TOKEN ಎಂದು ಹೊಂದಿಸಿದ headers ನಮೂದನ್ನು ಸೇರಿಸಿ. Config ಫೈಲ್‌ನ ನಿಖರ ಸ್ಥಳ ನಿಮ್ಮ client ಮೇಲೆ ಅವಲಂಬಿತ; ಅದರ MCP ದಸ್ತಾವೇಜು ನೋಡಿ.

URL ಮಾತ್ರ ಸ್ವೀಕರಿಸುವ clients (ಕೆಲವು ChatGPT ಮತ್ತು ವೆಬ್ connectors): ಅವುಗಳಿಗಾಗಿ URL ರೂಪವನ್ನು https://testerexchange.com/agents/ ನ ದಸ್ತಾವೇಜು ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ. Token ಇಲ್ಲದೆಯೂ ಸಾರ್ವಜನಿಕ tools (Tester Exchange ಎಂದರೇನು, ಬೆಲೆ, ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಅಂಕಿಅಂಶ) ಕೆಲಸ ಮಾಡುತ್ತವೆ.

3. ಆರಂಭಿಸಲು ಒಂದೇ tool: get_testers

ಪೂರ್ತಿ tool ಪಟ್ಟಿಯನ್ನು ಕಲಿಯುವ ಅಗತ್ಯವಿಲ್ಲ. ಮುಖ್ಯ tool get_testers(package_name, name?). ಒಂದೇ ಕರೆ ನಿಮ್ಮ ಆ್ಯಪ್ ಸೇರಿಸುತ್ತದೆ, ಅದರ ಟೆಸ್ಟ್ ತೆರೆಯುತ್ತದೆ, ನಿಮ್ಮ ಕ್ರೆಡಿಟ್‌ಗಳನ್ನು ಅನ್ವಯಿಸುತ್ತದೆ, ಮತ್ತು ನಿಮ್ಮ ಪ್ರಗತಿಯ ಜೊತೆಗೆ Play Console ನಲ್ಲಿ Google Group ಸೇರಿಸುವಂತಹ, ಮನುಷ್ಯರೇ ಮಾಡಬೇಕಾದ ಹಂತಗಳನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ. ಪ್ರಗತಿ ನೋಡಲು ಯಾವಾಗ ಬೇಕಾದರೂ ಮತ್ತೆ ಕರೆಯಿರಿ.

ಉಳಿದ tools ವಿವರಗಳನ್ನು ನಿಭಾಯಿಸುತ್ತವೆ: my_apps, campaign_report (testers, ದಿನನಿತ್ಯದ ಚಟುವಟಿಕೆ, feedback ಮತ್ತು production-access ಡೇಟಾ), add_testers, set_campaign_status (ವಿರಾಮ, ಪುನರಾರಂಭ ಅಥವಾ ಮುಚ್ಚುವುದು; ಬಳಸದ ಕ್ರೆಡಿಟ್‌ಗಳು ನಿಮ್ಮ ಬ್ಯಾಲೆನ್ಸ್‌ಗೆ ಮರಳುತ್ತವೆ), share_kit ಮತ್ತು buy_credits_links, ಇದು ವ್ಯಕ್ತಿ ಪಾವತಿಸಲು checkout ಲಿಂಕ್‌ಗಳನ್ನು ಕೊಡುತ್ತದೆ.

ಚೆನ್ನಾಗಿ ಕೆಲಸ ಮಾಡುವ prompts

  • "com.example.app ಗಾಗಿ ನನ್ನ Tester Exchange campaign ಪರಿಶೀಲಿಸು. ಈ ವಾರ ಪ್ರತಿದಿನ ಎಷ್ಟು testers ಸಕ್ರಿಯರಾಗಿದ್ದರು?"
  • "Campaign report ತೆಗೆದು ನನ್ನ production access ಉತ್ತರಗಳ ಡ್ರಾಫ್ಟ್ ಮಾಡು. ನಿಜವಾದ ಸಂಖ್ಯೆಗಳನ್ನು ಮಾತ್ರ ಬಳಸು."
  • "Production access ಅನುಮೋದನೆಯಾಗಿದೆ, ಈಗ com.example.app ನ campaign ಮುಚ್ಚು."

12 ಬದಲು 15 testers ಕೇಳಿ, ಹೀಗೆ ಒಬ್ಬರು ಬಿಟ್ಟರೂ Google ನ ಕನಿಷ್ಠಕ್ಕಿಂತ ಕೆಳಗೆ ಹೋಗುವುದಿಲ್ಲ.

Scripts ಮತ್ತು CI ಗಾಗಿ HTTP API

ನಿಮ್ಮ tool MCP ಮಾತನಾಡದಿದ್ದರೆ, HTTP endpoint ಬಳಸಿ: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call. Body JSON ಆಗಿರುತ್ತದೆ ಮತ್ತು ಅದರಲ್ಲಿ p_token (ನಿಮ್ಮ tx_ token), p_action (ಉದಾಹರಣೆಗೆ help, my_apps ಅಥವಾ start_campaign) ಮತ್ತು p_args (ಉದಾಹರಣೆಗೆ package_name ಮತ್ತು tester ಸಂಖ್ಯೆ) ಇರುತ್ತವೆ. ದಸ್ತಾವೇಜಿನಲ್ಲಿ ತೋರಿಸಿದ ಸಾರ್ವಜನಿಕ apikey ಹೆಡರ್ ಕಳುಹಿಸಿ.

ಮೊದಲು help action ಕರೆಯಿರಿ: ಅದು ಎಲ್ಲ actions ಮತ್ತು ಅವುಗಳ arguments ಅನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ. ಪೂರ್ಣ schema https://testerexchange.com/openapi.json ನಲ್ಲಿದೆ; ಇದು ChatGPT custom GPT actions ಮತ್ತು ಇತರ OpenAPI tools ಗಳೊಂದಿಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ.

A2A agent card

Agent-to-agent ಸೆಟಪ್‌ಗಳಿಗಾಗಿ, Tester Exchange https://testerexchange.com/.well-known/agent-card.json ನಲ್ಲಿ A2A agent card ಪ್ರಕಟಿಸುತ್ತದೆ. A2A ಪ್ರೋಟೋಕಾಲ್ ಬೆಂಬಲಿಸುವ orchestrators ಈ agent ಏನು ಒದಗಿಸುತ್ತದೆ ಮತ್ತು ಅದನ್ನು ಹೇಗೆ ಕರೆಯಬೇಕು ಎಂದು ಕಂಡುಕೊಳ್ಳಬಹುದು. ನಿಮ್ಮ ಖಾತೆಗೆ ಸಂಬಂಧಿಸಿದ ಯಾವುದಕ್ಕೂ ಅದೇ tx_ token ಬಳಸಿ.

ಆರಂಭದಿಂದ ಕೊನೆಯವರೆಗೆ ಪೂರ್ತಿ ಓಟ

  1. Play Console ನಲ್ಲಿ closed track ಗೆ ನಿಮ್ಮ ಮೊದಲ .aab ಅಪ್‌ಲೋಡ್ ಮಾಡುತ್ತೀರಿ.
  2. ನಿಮ್ಮ agent ನಿಮ್ಮ package name ಗಾಗಿ get_testers ಕರೆಯುತ್ತದೆ, ಮತ್ತು closed track ನ Google Groups ಅಡಿಯಲ್ಲಿ testerexchange-testers@googlegroups.com ಸೇರಿಸಲು ಹೇಳುತ್ತದೆ.
  3. ನೀವು group ಸೇರಿಸಿ, ಸೇವ್ ಮಾಡಿ, ಮತ್ತು release ಪಬ್ಲಿಷ್ ಆಗಿದೆ ಎಂದು ಖಚಿತಪಡಿಸುತ್ತೀರಿ.
  4. ಕ್ರೆಡಿಟ್‌ಗಳಿಲ್ಲದಿದ್ದರೆ, agent ನಿಮಗೆ checkout ಲಿಂಕ್ ಕೊಡುತ್ತದೆ. ನೀವು ಪಾವತಿಸುತ್ತೀರಿ (12 testers ಗೆ $12.99, 15 ಕ್ಕೆ $14.99, 25 ಕ್ಕೆ $22.99), ಅಥವಾ https://testerexchange.com/earn ನಲ್ಲಿ ಇತರ ಆ್ಯಪ್‌ಗಳನ್ನು ಟೆಸ್ಟ್ ಮಾಡಿ ಉಚಿತವಾಗಿ ಕ್ರೆಡಿಟ್ ಗಳಿಸುತ್ತೀರಿ.
  5. ನಿಜವಾದ testers 14 ದಿನ ನಿಮ್ಮ ಆ್ಯಪ್ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ ಬಳಸುತ್ತಾರೆ. ನಿಮ್ಮ agent ಪ್ರತಿದಿನ ಪ್ರಗತಿ ಪರಿಶೀಲಿಸುತ್ತದೆ, ಸಕ್ರಿಯ testers ಕಡಿಮೆಯಾದರೆ ಎಚ್ಚರಿಸುತ್ತದೆ.
  6. 15 ನೇ ದಿನ, agent campaign report ತೆಗೆದು ನಿಮ್ಮ production access ಉತ್ತರಗಳ ಡ್ರಾಫ್ಟ್ ಮಾಡುತ್ತದೆ. ನೀವು ಅವನ್ನು ಪರಿಶೀಲಿಸಿ Apply for production ಕ್ಲಿಕ್ ಮಾಡುತ್ತೀರಿ.

ಸುರಕ್ಷತಾ ಟಿಪ್ಪಣಿಗಳು

  • Tokens ಅನ್ನು git ನಿಂದ ಹೊರಗಿಡಿ. ನಿಮ್ಮ client ನ secret store ನಲ್ಲಿ ಅಥವಾ environment variable ನಲ್ಲಿ ಇಡಿ.
  • ನಮ್ಮ ಕಡೆ tokens hash ರೂಪದಲ್ಲಿ ಮಾತ್ರ ಸಂಗ್ರಹವಾಗುತ್ತವೆ, ಮತ್ತು ಪ್ರತಿ ಖಾತೆಗೆ 10 ಕ್ಕೆ ಸೀಮಿತ. ಬಳಸದ token ಅನ್ನು ರದ್ದುಪಡಿಸಿ.
  • ಸಲ್ಲಿಸುವ ಮೊದಲು, agent ನಿಮ್ಮ production ಫಾರ್ಮ್‌ನಲ್ಲಿ ಬರೆದದ್ದನ್ನು ಓದಿ. ನಿಮ್ಮ ಟೆಸ್ಟ್ ಅನ್ನು ಸತ್ಯವಾಗಿ ವಿವರಿಸಬೇಕೆಂದು Google ಕೇಳುತ್ತದೆ.
