Tester Exchange Tester Exchange ತೆರೆಯಿರಿ

App Inventor, Kodular, Flutter, Unity ಮತ್ತು ಇತರ builders ನಿಂದ ಮಾಡಿದ ಆ್ಯಪ್‌ಗಳಿಗೆ Google Play 12 testers

ಅಕ್ಟೋಬರ್ 2026 ರಲ್ಲಿ ಅಪ್‌ಡೇಟ್ ಮಾಡಲಾಗಿದೆ

ನಿಮ್ಮ ಆ್ಯಪ್ ಮಾಡಲು ಯಾವ tool ಬಳಸಿದಿರಿ ಎಂಬುದು ಮುಖ್ಯವಲ್ಲ. ನಿಮ್ಮ Google Play developer ಖಾತೆ ಹೊಸ personal ಖಾತೆಯಾಗಿದ್ದರೆ, production ಗೆ ಪಬ್ಲಿಷ್ ಮಾಡುವ ಮೊದಲು ಕನಿಷ್ಠ 12 testers ಜೊತೆ 14 ದಿನದ closed test ಬೇಕು. builder ಮತ್ತು game-engine ಬಳಕೆದಾರರು ಸಿಕ್ಕಿಹಾಕಿಕೊಳ್ಳುವ ಭಾಗಗಳನ್ನು, ಮತ್ತು testers ಹುಡುಕುವ ಉಚಿತ ಮಾರ್ಗವನ್ನು ಈ ಗೈಡ್ ವಿವರಿಸುತ್ತದೆ.

ನಿಜವಾದ ಜನರು 14 ದಿನ ತಮ್ಮದೇ ಫೋನ್‌ಗಳಲ್ಲಿ ನಿಮ್ಮ ಆ್ಯಪ್ ತೆರೆಯುತ್ತಾರೆ. ಒಮ್ಮೆ ಪಾವತಿಸಿ, ಅಥವಾ ಇತರ ಆ್ಯಪ್‌ಗಳನ್ನು ಟೆಸ್ಟ್ ಮಾಡಿ ಉಚಿತವಾಗಿ ಪಡೆಯಿರಿ.12 testers ಪಡೆಯಿರಿ

ಪ್ರತಿ tool ಗೂ ನಿಯಮ ಒಂದೇ

Google ನಿಮ್ಮ developer ಖಾತೆಯನ್ನು ಪರಿಶೀಲಿಸುತ್ತದೆ, ನಿಮ್ಮ tool ಅನ್ನಲ್ಲ. MIT App Inventor, Kodular, Niotron, Sketchware, Thunkable, FlutterFlow, Flutter, React Native, Expo, Unity ಅಥವಾ Godot ನಿಂದ ಮಾಡಿದ ಎಲ್ಲಾ ಆ್ಯಪ್‌ಗಳೂ ಅದೇ closed test ಮೂಲಕ ಹೋಗುತ್ತವೆ.

ನೀವು 13 ನವೆಂಬರ್ 2023 ರ ನಂತರ personal developer ಖಾತೆ ರಚಿಸಿದ್ದರೆ, production access ಗೆ ಅರ್ಜಿ ಹಾಕುವ ಮೊದಲು ಕನಿಷ್ಠ 12 testers ಸತತ 14 ದಿನ opt-in ಆಗಿರಬೇಕು. Organization ಖಾತೆಗಳಿಗೆ ಈ ಷರತ್ತು ಇಲ್ಲ.

ಹಂತ 1: ನಿಮ್ಮ builder sign ಮಾಡಬಲ್ಲ release build export ಮಾಡಿ

  1. Android App Bundle (.aab) export ಮಾಡಿ. ಹೊಸ ಆ್ಯಪ್‌ಗಳಿಗೆ Google Play ಗೆ .aab ಬೇಕು. ಹೆಚ್ಚಿನ builders ಮತ್ತು engines ಅದನ್ನು export ಮಾಡಬಲ್ಲವು; ನಿಮ್ಮದು APK ಮಾತ್ರ ನೀಡಿದರೆ, App Bundle ಆಯ್ಕೆಗಾಗಿ ಅದರ docs ನೋಡಿ.
  2. ನಿಮ್ಮ signing key ಸುರಕ್ಷಿತವಾಗಿಡಿ. App Inventor ಮತ್ತು Kodular ನಂತಹ builders ನಿಮಗಾಗಿ keystore ರಚಿಸುತ್ತವೆ. ಅದರ ಬ್ಯಾಕಪ್ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ. ಪ್ರತಿ ಅಪ್‌ಡೇಟ್‌ಗೂ ಅದೇ key ಬೇಕು.
  3. Package name ಅನ್ನು ಎಚ್ಚರಿಕೆಯಿಂದ ಆಯ್ಕೆಮಾಡಿ. ಆ್ಯಪ್ Google Play ಗೆ ಬಂದ ನಂತರ ಅದನ್ನು ಎಂದಿಗೂ ಬದಲಾಯಿಸಲು ಆಗುವುದಿಲ್ಲ.
  4. Target API level ಪೂರೈಸಿ. ಇತ್ತೀಚಿನ Android ಆವೃತ್ತಿಯನ್ನು target ಮಾಡುವ builds ಅನ್ನು ಮಾತ್ರ Google Play ಸ್ವೀಕರಿಸುತ್ತದೆ. Target API level ಕಾರಣ ಅಪ್‌ಲೋಡ್ ರಿಜೆಕ್ಟ್ ಆದರೆ, builder ಅಥವಾ engine ಅಪ್‌ಡೇಟ್ ಮಾಡಿ ಮತ್ತೆ export ಮಾಡಿ.

ಹಂತ 2: closed test ಸೆಟಪ್ ಮಾಡಿ

  1. Play Console ನಲ್ಲಿ Test and release → Testing → Closed testing ತೆರೆದು track ರಚಿಸಿ.
  2. ಇಮೇಲ್ ಲಿಸ್ಟ್ ಬದಲು Google Group ಮೂಲಕ testers ಸೇರಿಸಿ: testers ತಾವೇ group ಗೆ ಸೇರುತ್ತಾರೆ, ಮತ್ತು ನೀವು ಮತ್ತೆ ಇಮೇಲ್ ಪೇಸ್ಟ್ ಮಾಡಬೇಕಿಲ್ಲ.
  3. ನಿಮ್ಮ .aab ಅನ್ನು closed track ಗೆ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ, release notes ಸೇರಿಸಿ, ರಿವ್ಯೂಗೆ ಕಳುಹಿಸಿ.
  4. opt-in ಲಿಂಕ್ ಕಾಪಿ ಮಾಡಿ. Testers group ಗೆ ಸೇರಿ, opt-in ಲಿಂಕ್ ತೆರೆದು, "Become a tester" ಟ್ಯಾಪ್ ಮಾಡಿ, ನಂತರ Google Play ನಿಂದ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡುತ್ತಾರೆ.

ಹಂತ 3: 14 ದಿನ ಉಳಿಯುವ 12 testers ಹುಡುಕಿ

ಲಿಸ್ಟ್‌ನಲ್ಲಿ ಹನ್ನೆರಡು ಹೆಸರುಗಳು ಸಾಕಾಗುವುದಿಲ್ಲ. Testers ನಿಜವಾಗಿ ಆ್ಯಪ್ ಬಳಸಿದರೆ ಎಂದು Google ಪರಿಶೀಲಿಸುತ್ತದೆ, ಮತ್ತು ಕನಿಷ್ಠ 12 testers opt-in ಆಗಿರುವಾಗ ಮಾತ್ರ 14 ದಿನಗಳು ಎಣಿಕೆಯಾಗುತ್ತವೆ. 14 ಅಥವಾ 15 ಜನರನ್ನು ಸೇರಿಸಿ, ಒಂದಿಬ್ಬರು ಬಿಟ್ಟರೂ ಗಡಿಯಾರ ನಿಲ್ಲದಂತೆ.

  • Android ಫೋನ್ ಇರುವ ಸ್ನೇಹಿತರು ಮತ್ತು ಕುಟುಂಬ: ಉಚಿತ, ಆದರೆ ಕೆಲವು ದಿನಗಳ ನಂತರ ಅವರು ಹೆಚ್ಚಾಗಿ ಆ್ಯಪ್ ತೆರೆಯುವುದನ್ನು ನಿಲ್ಲಿಸುತ್ತಾರೆ.
  • Builder ಸಮುದಾಯಗಳು ಮತ್ತು ಫೋರಮ್‌ಗಳು: ಸಹ builders ಗೆ ನಿಯಮ ಅರ್ಥವಾಗುತ್ತದೆ, ಮತ್ತು ಹಲವರು test swap ಮಾಡುತ್ತಾರೆ.
  • Test ಎಕ್ಸ್‌ಚೇಂಜ್: Tester Exchange ನಲ್ಲಿ ನಿಮ್ಮ ಫೋನ್‌ಗೆ ಇತರ developers ಆ್ಯಪ್‌ಗಳು ಟೆಸ್ಟ್ ಮಾಡಲು ಸಿಗುತ್ತವೆ, ದಿನಕ್ಕೆ ಒಂದು ನಿಮಿಷ, ಮತ್ತು ನೀವು ಟೆಸ್ಟ್ ಮಾಡುವ ಪ್ರತಿಯೊಂದೂ ನಿಮ್ಮ ಆ್ಯಪ್‌ಗೆ ಒಬ್ಬ tester ತರುತ್ತದೆ.

ಹಂತ 4: testers ಅನ್ನು ಸಕ್ರಿಯವಾಗಿಡಿ ಮತ್ತು ಅಪ್‌ಡೇಟ್ ಕಳುಹಿಸಿ

  • Testers ಗೆ ದಿನಕ್ಕೆ ಒಂದು ಚಿಕ್ಕ ಕೆಲಸ ಕೊಡಿ, ಹೀಗೆ ಆ್ಯಪ್ ತೆರೆಯಲು ಕಾರಣ ಇರುತ್ತದೆ.
  • ದಿನ 7 ರ ಸುಮಾರಿಗೆ ಸರಿಪಡಿಕೆಗಳೊಂದಿಗೆ ಹೊಸ build ಅಪ್‌ಲೋಡ್ ಮಾಡಿ ಮತ್ತು ಏನು ಬದಲಾಗಿದೆ ಎಂದು ಹೇಳಿ. Builders ಇದನ್ನು ವೇಗವಾಗಿಸುತ್ತವೆ: export ಮಾಡಿ, ಅದೇ closed track ಗೆ ಅಪ್‌ಲೋಡ್ ಮಾಡಿ, ಮುಗಿಯಿತು.
  • ಬರವಣಿಗೆಯ feedback ಕೇಳಿ ಮತ್ತು ಸಾಧ್ಯವಾದದ್ದನ್ನು ಸರಿಪಡಿಸಿ. ಇದು production ಪ್ರಶ್ನೆಗಳಿಗೆ ನಿಜವಾದ ಉತ್ತರಗಳನ್ನೂ ಕೊಡುತ್ತದೆ.

ಹಂತ 5: production ಗೆ ಅರ್ಜಿ ಹಾಕಿ

14 ದಿನಗಳ ನಂತರ Play Console dashboard ನಲ್ಲಿ production access ಗೆ ಅರ್ಜಿ ಹಾಕಿ. ನೀವು testers ಅನ್ನು ಹೇಗೆ ಸೇರಿಸಿದಿರಿ, ಅವರು ಆ್ಯಪ್ ಹೇಗೆ ಬಳಸಿದರು ಮತ್ತು ಅವರ feedback ಆಧಾರದ ಮೇಲೆ ನೀವು ಏನು ಬದಲಾಯಿಸಿದಿರಿ ಎಂದು Google ಕೇಳುತ್ತದೆ. ನಿಮ್ಮ ಟೆಸ್ಟ್‌ನ ನಿಜವಾದ ಸಂಖ್ಯೆಗಳೊಂದಿಗೆ ಉತ್ತರಿಸಿ. Google ಸಾಮಾನ್ಯವಾಗಿ ಸುಮಾರು ಒಂದು ವಾರದಲ್ಲಿ ಉತ್ತರಿಸುತ್ತದೆ.

ಪದೇ ಪದೇ ಕೇಳುವ ಪ್ರಶ್ನೆಗಳು

App Inventor ಅಥವಾ Kodular ನಿಂದ ಮಾಡಿದ ಆ್ಯಪ್‌ಗಳಿಗೂ 12 testers ಬೇಕೇ?

ಹೌದು. ಈ ಷರತ್ತು ನಿಮ್ಮ developer ಖಾತೆಯನ್ನು ಅವಲಂಬಿಸಿದೆ, tool ಅನ್ನಲ್ಲ. ಆ್ಯಪ್ ಯಾವುದರಿಂದ ಮಾಡಿದ್ದರೂ, ಹೊಸ personal ಖಾತೆಗಳಿಗೆ 14 ದಿನ opt-in ಆಗಿರುವ 12 testers ಬೇಕು.

ನಾನು ಕಳುಹಿಸುವ APK ಅನ್ನು testers ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಬಹುದೇ?

ಇಲ್ಲ. Google Play ನ closed test ನಿಂದಾದ ಇನ್‌ಸ್ಟಾಲ್‌ಗಳು ಮಾತ್ರ ಎಣಿಕೆಯಾಗುತ್ತವೆ. Testers Play Console ಲಿಂಕ್ ಮೂಲಕ opt-in ಆಗಿ Play Store ನಿಂದ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಬೇಕು.

closed test ಶುರುಮಾಡಲು ಹೊಸ build ಬೇಕೇ?

Closed track ಗೆ ಕನಿಷ್ಠ ಒಂದು build ಅಪ್‌ಲೋಡ್ ಆಗಿರಬೇಕು. ಟೆಸ್ಟ್ ಸಮಯದಲ್ಲಿ testers feedback ಆಧಾರಿತ ಸರಿಪಡಿಕೆಗಳೊಂದಿಗೆ ಎರಡನೇ build ಅಪ್‌ಲೋಡ್ ಮಾಡುವುದು ಒಳ್ಳೆಯದು.

12 testers ಪಡೆಯಲು ಉಚಿತ ಮಾರ್ಗ ಇದೆಯೇ?

ಹೌದು. Test swaps ಉಚಿತ: ನೀವು ಇತರ developers ಆ್ಯಪ್‌ಗಳನ್ನು ಟೆಸ್ಟ್ ಮಾಡುತ್ತೀರಿ, ಅವರು ನಿಮ್ಮದನ್ನು. Tester Exchange ಪ್ರತಿ tester ಫೋನ್‌ನಲ್ಲಿ ದಿನನಿತ್ಯದ ಬಳಕೆ ಪರಿಶೀಲಿಸುತ್ತದೆ, ಹಾಗಾಗಿ ಟೆಸ್ಟಿಂಗ್ ನಿಜವಾದದ್ದು.

ನಿಜವಾದ ಜನರು 14 ದಿನ ತಮ್ಮದೇ ಫೋನ್‌ಗಳಲ್ಲಿ ನಿಮ್ಮ ಆ್ಯಪ್ ತೆರೆಯುತ್ತಾರೆ. ಒಮ್ಮೆ ಪಾವತಿಸಿ, ಅಥವಾ ಇತರ ಆ್ಯಪ್‌ಗಳನ್ನು ಟೆಸ್ಟ್ ಮಾಡಿ ಉಚಿತವಾಗಿ ಪಡೆಯಿರಿ.12 testers ಪಡೆಯಿರಿ
