Tester Exchange Tester Exchangeን ክፈት

የAndroid መተግበሪያዎን በClaude Code ሠርተዋል? ለ14 ቀናት 12 ሞካሪዎችዎን ያግኙ

ኅዳር 2026 የተዘመነ

Claude Code የAndroid መተግበሪያዎን መጻፍና መገንባት ይችላል፣ ነገር ግን Google Play የሚጠይቃቸውን 12 እውነተኛ ሞካሪዎች ማቅረብ አይችልም። የግል ገንቢ መለያዎ ከኅዳር 13 2023 በኋላ የተፈጠረ ከሆነ፣ ለproduction ከማመልከትዎ በፊት ቢያንስ 12 ሞካሪዎች ለ14 ተከታታይ ቀናት የተመዘገቡበት closed test ማካሄድ አለብዎት። ይህ መመሪያ ጥቅሉን መገንባትን፣ closed testing መጀመርን፣ ሞካሪዎችን ማግኘትን (መጀመሪያ ነጻ፣ ሁለተኛ የሚከፈልበት) እና ወኪሉ የወረቀት ሥራውን እንዲሠራ Tester Exchangeን ከClaude Code ጋር ማገናኘትን ይሸፍናል።

እውነተኛ ሰዎች መተግበሪያዎን በራሳቸው ስልኮች ለ14 ቀናት ይከፍታሉ። አንድ ጊዜ ይክፈሉ፣ ወይም ሌሎች መተግበሪያዎችን በነፃ ይሞክሩ።12 ሞካሪዎችን ያግኙ
በዚህ ገጽ ላይ

  • 3. 12 ሞካሪዎችዎን ያግኙ፦ መጀመሪያ ነጻ፣ ሁለተኛ የሚከፈልበት
  • 4. Tester Exchangeን ከClaude Code ጋር ያገናኙ (አማራጭ)

  • በተደጋጋሚ የሚጠየቁ ጥያቄዎች

1. የrelease ጥቅሉን (.aab) ይገንቡ

  1. የClaude Code ወኪልን በሞዱልዎ build.gradle.kts ውስጥ የrelease ፊርማን እንዲያዋቅር ይጠይቁት (storeFile፣ storePassword፣ keyAlias እና keyPassword ያለው signingConfigs ብሎክ፣ በrelease build type ላይ የተዘረጋ)። የይለፍ ቃሎችን ከgit ውጭ ያድርጉ (የAndroid build ሰነድ፦ https://developer.android.com/build/building-cmdline )።
  2. በterminal ውስጥ ./gradlew bundleRelease ያሂዱ። Gradle ጥቅሉን ይገነባል እና ይፈርማል፤ .aab ብዙውን ጊዜ በapp/build/outputs/bundle/release/ ስር ይታያል፣ ነገር ግን የራስዎን build ውጤት ያረጋግጡ።
  3. keystore ከሌለዎት በkeytool ይፍጠሩና ምትኬ ያስቀምጡ። Google Play App Signing የመጀመሪያ release ሲጭኑ ይቀርባል።

2. በPlay Console ውስጥ closed testing ይጀምሩ

  1. Test and release > Testing > Closed testing ይክፈቱ፣ ከዚያ Create track (ወይም Manage track) ይጫኑ።
  2. Create new release ይጫኑ፣ .aabን ይጫኑ፣ የrelease ስም እና ማስታወሻ ይጨምሩ፣ Save as draft፣ Next፣ ከዚያ Start rollout (ደረጃዎቹ ከhttps://support.google.com/googleplay/android-developer/answer/9859348 የተወሰዱ ናቸው)።
  3. መጀመሪያ በDashboard ላይ ያሉትን የመተግበሪያ ማዋቀሪያ ሥራዎች ያጠናቅቁ፣ አለበለዚያ የrelease አዝራሩ ተሰናክሎ ይቆያል።

3. 12 ሞካሪዎችዎን ያግኙ፦ መጀመሪያ ነጻ፣ ሁለተኛ የሚከፈልበት

  • ነጻ መንገድ፦ በስልክዎ https://testerexchange.com/earn ይክፈቱና የተሰጡዎትን መተግበሪያዎች ይሞክሩ። የሞከሩት እያንዳንዱ መተግበሪያ ለእርስዎ መተግበሪያ አንድ ሞካሪ ያመጣል።
  • የሚከፈልበት መንገድ፦ አንድ ጊዜ ይክፈሉ እና ሞካሪዎች በራስ-ሰር ይመደባሉ። የአሁኑ ዋጋዎች በhttps://testerexchange.com/llms.txt ላይ ተዘርዝረዋል።
  • አንድ ሰው ቢወጣ ከGoogle ዝቅተኛ ቁጥር በታች እንዳይሆኑ ከ12 ይልቅ 15 ሞካሪዎችን ይጠይቁ።

4. Tester Exchangeን ከClaude Code ጋር ያገናኙ (አማራጭ)

በመጀመሪያ በhttps://testerexchange.com/api ላይ API key ይፍጠሩ። ከዚያ በተርሚናልዎ ውስጥ ይህን አንድ ጊዜ ያስኬዱ፤ tx_YOUR_TOKENን በእርስዎ key ይተኩ (ትዕዛዙ በhttps://testerexchange.com/agents/ ላይ የተዘረዘረው ነው)፦

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

ሰርቨሩ ያለ OAuth በStreamable HTTP ላይ ቀላል MCP ነው፤ የሕዝብ መሣሪያዎቹ (about, pricing, platform_stats) ያለ key ይሰራሉ። keyውን ከgit እና ከተጋሩ የconfig ፋይሎች ውጭ ያድርጉ።

5. ወኪሉን ይጠይቁ

  • “Tester Exchangeን ተጠቅመህ ለcom.example.app 15 ሞካሪዎችን አግኝና በPlay Console ውስጥ ምን ማድረግ እንዳለብኝ ንገረኝ።”
  • “ለcom.example.app የTester Exchange ዘመቻዬን ፈትሸህ ትላንት ስንት ሞካሪዎች ንቁ እንደነበሩ ንገረኝ።”
  • “የዘመቻውን ሪፖርት አውጥተህ ከእውነተኛ ቁጥሮች የproduction access መልሶቼን ረቂቅ አዘጋጅ።”

ዋናው መሣሪያ get_testers ነው፦ መተግበሪያውን ይጨምራል፣ ፈተናውን ይከፍታል እና ሰው ብቻ ሊያደርጋቸው የሚችሉ ደረጃዎችን ይመልሳል፣ ለምሳሌ የሞካሪዎቹን Google Group በPlay Console ውስጥ መጨመር። ወኪሉ ስለእርስዎ መክፈልም ሆነ Apply for production መጫን አይችልም።

MCP የለዎትም? HTTP APIን ይጠቀሙ

በhttps://testerexchange.com/agents/ ላይ በተዘረዘረው ይፋዊ apikey header እና በ{"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}} አካል ወደ https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call POST ያድርጉ። ስኬማው በhttps://testerexchange.com/openapi.json ላይ አለ። ተጨማሪ መሣሪያዎች፦ https://testerexchange.com/guide/ai-builders/ ።

በተደጋጋሚ የሚጠየቁ ጥያቄዎች

Claude Code የ14 ቀኑን ፈተና ሊያጠናቅቅልኝ ይችላል?

አይችልም። 14 ቀናቱ መተግበሪያዎን በራሳቸው የAndroid ስልኮች የሚጠቀሙ እውነተኛ ሰዎችን ይፈልጋል። Claude Code መተግበሪያውን መገንባትና ዝግጅቱን መምራት ይችላል።

Tester Exchange የClaude Code ይፋዊ ውህደት ነው?

አይደለም። ይህ በHTTP የremote MCP ን የሚደግፍ ማንኛውም client ጋር የሚሰራ ራሱን የቻለ አገልግሎት ነው፤ Claude Code ደግሞ ይደግፈዋል።

AABው የት ይሄዳል?

በPlay Console ውስጥ ባለ የclosed testing release ውስጥ ይጫኑት፣ ከዚያ በዚያ track ላይ የሞካሪዎችዎን Google Group ወይም የኢሜይል ዝርዝር ይጨምሩ።

12 ሞካሪዎችን ለማግኘት ነጻ መንገድ አለ?

አዎ። በhttps://testerexchange.com/earn ላይ የሌሎች ገንቢዎችን መተግበሪያዎች ይሞክሩ፤ የሞከሩት እያንዳንዱ መተግበሪያ ለእርስዎ መተግበሪያ አንድ ሞካሪ ያመጣል።

እውነተኛ ሰዎች መተግበሪያዎን በራሳቸው ስልኮች ለ14 ቀናት ይከፍታሉ። አንድ ጊዜ ይክፈሉ፣ ወይም ሌሎች መተግበሪያዎችን በነፃ ይሞክሩ።12 ሞካሪዎችን ያግኙ
