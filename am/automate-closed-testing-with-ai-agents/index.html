2. MCP serverን ያገናኙ

MCP serverው Streamable HTTP በ https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp ይጠቀማል። tokenዎን በheader Authorization: Bearer tx_YOUR_TOKEN ውስጥ ይላኩ።

Claude Code፦ ይህንን አንድ ጊዜ በterminalዎ ውስጥ ያሂዱ።

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop፣ Cursor፣ VS Code እና JSON config ያላቸው ሌሎች clients፦ tester-exchange የሚባል server ከtype http፣ ከላይ ያለው URL፣ እና Authorization ወደ Bearer tx_YOUR_TOKEN የተዋቀረበት headers ግቤት ጋር ይጨምሩ። የconfig ፋይሉ ትክክለኛ ቦታ በclientዎ ይወሰናል፤ የMCP ሰነዱን ይመልከቱ።

URL ብቻ የሚቀበሉ clients (አንዳንድ የChatGPT እና የድር connectors)፦ https://testerexchange.com/agents/ ላይ ያሉት ሰነዶች ለእነሱ የሚሆን የURL ቅጽ ይዘረዝራሉ። token ሳይኖርም የሕዝብ መሣሪያዎች (Tester Exchange ምን እንደሆነ፣ ዋጋዎች፣ የመድረኩ ስታቲስቲክስ) ይሠራሉ።

3. ለመጀመር አንዱ መሣሪያ፦ get_testers

ሙሉውን የመሣሪያ ዝርዝር መማር አያስፈልግዎትም። ዋናው መሣሪያ get_testers(package_name, name?) ነው። አንድ ጥሪ መተግበሪያዎን ይጨምራል፣ ሙከራውን ይከፍታል፣ ክሬዲቶችዎን ይተገብራል፣ እድገትዎን እና ሰው ብቻ ሊያደርጋቸው የሚችሉ ርምጃዎችን (ለምሳሌ Google Groupን በPlay Console ውስጥ መጨመር) ይመልሳል። እድገትን ለመመልከት በማንኛውም ጊዜ እንደገና ይጥሩት።

ሌሎች መሣሪያዎች ዝርዝሮችን ይሸፍናሉ፦ my_apps፣ campaign_report (ሞካሪዎች፣ የዕለት እንቅስቃሴ፣ አስተያየት እና የproduction-access ውሂብ)፣ add_testers፣ set_campaign_status (ማቆም፣ መቀጠል ወይም መዝጋት፤ ያልተጠቀሙ ክሬዲቶች ወደ ሒሳብዎ ይመለሳሉ)፣ share_kit እና buy_credits_links፣ ይህም ሰው የሚከፍልባቸውን የክፍያ አገናኞች ይመልሳል።

ለscripts እና CI የሚሆን HTTP API

መሣሪያዎ MCP የማይናገር ከሆነ የHTTP endpointን ይጠቀሙ፦ POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call። bodyው JSON ሲሆን p_token (የtx_ tokenዎ)፣ p_action (ለምሳሌ help፣ my_apps ወይም start_campaign) እና p_args (ለምሳሌ package_name እና የሞካሪ ብዛት) ይይዛል። በሰነዶቹ ውስጥ የሚታየውን የሕዝብ apikey header ይላኩ።

መጀመሪያ የhelp actionን ይጥሩ፦ ሁሉንም actions እና ግብአቶቻቸውን ይመልሳል። ሙሉው schema በ https://testerexchange.com/openapi.json ላይ ይገኛል፣ ከChatGPT custom GPT actions እና ከሌሎች OpenAPI መሣሪያዎች ጋር ይሠራል።

A2A agent card

ለagent-ለ-agent ዝግጅቶች Tester Exchange የA2A agent cardን በ https://testerexchange.com/.well-known/agent-card.json ላይ ያትማል። የA2A protocolን የሚደግፉ orchestrators agentው ምን እንደሚያቀርብና እንዴት እንደሚጠራ ማወቅ ይችላሉ። ከመለያዎ ጋር ለተያያዘ ለማንኛውም ነገር ያንኑ tx_ token ይጠቀሙ።

አይችልም። 14ቱ ቀናት መተግበሪያዎን በራሳቸው ስልኮች የሚጠቀሙ እውነተኛ ሰዎችን ይጠይቃሉ። agents ማዋቀርን፣ ክትትልንና ሪፖርትን ይይዛሉ።

agentው ለሞካሪዎች መክፈል ይችላል?

አይችልም። የክፍያ አገናኞችን ሊመልስ ይችላል፣ ነገር ግን ክፍያው ሁልጊዜ በሰው browser ውስጥ ይከናወናል።

ከMCP serverው ጋር የሚሠሩት የትኞቹ clients ናቸው?

በStreamable HTTP የርቀት MCP እና custom headerን የሚደግፍ ማንኛውም client፣ Claude Code፣ Claude Desktop፣ Cursor እና VS Codeን ጨምሮ። ሌሎች HTTP APIን መጠቀም ይችላሉ።

token ከየት አገኛለሁ?

ከገቡ በኋላ በ https://testerexchange.com/api ላይ። tokens በtx_ ይጀምራሉ፣ በማንኛውም ጊዜም ሊሰረዙ ይችላሉ።

agentው በPlay Consoleዬ ውስጥ አንድ ነገር ይቀይራል?

አይቀይርም። ወደ Play Consoleዎ መዳረሻ የለውም። እዚያ የሚያደርጓቸውን ርምጃዎች ይነግርዎታል።

እውነተኛ ሰዎች መተግበሪያዎን በራሳቸው ስልኮች ለ14 ቀናት ይከፍታሉ። አንድ ጊዜ ይክፈሉ፣ ወይም ሌሎች መተግበሪያዎችን በነፃ ይሞክሩ።12 ሞካሪዎችን ያግኙ
