Направили сте Android апликацију у Claude Code-у? Обезбедите 12 тестера на 14 дана

Ажурирано у новембру 2026.

Claude Code може да напише и изгради вашу Android апликацију, али не може да обезбеди 12 стварних тестера које Google Play тражи. Ако је ваш лични програмерски налог направљен после 13. новембра 2023, морате да покренете затворени тест са најмање 12 тестера који су укључени 14 узастопних дана пре пријаве за продукцију. Овај водич покрива прављење бундла, покретање затвореног тестирања, обезбеђивање тестера (прво бесплатно, затим плаћено) и повезивање Tester Exchange-а са Claude Code-ом како би агент обавио административни део.

Прави људи отварају вашу апликацију на својим телефонима 14 дана. Платите једном или бесплатно тестирајте друге апликације.Набави 12 тестера

1. Направите release бундл (.aab)

  1. Затражите од Claude Code агента да подеси потписивање release верзије у build.gradle.kts вашег модула (signingConfigs блок са storeFile, storePassword, keyAlias и keyPassword, примењен на release build type). Лозинке држите ван git-а (Android документација о билдовању: https://developer.android.com/build/building-cmdline).
  2. Покрените ./gradlew bundleRelease у терминалу. Gradle гради и потписује бундл; .aab се обично појављује у app/build/outputs/bundle/release/, али проверите излаз свог билда.
  3. Направите keystore помоћу keytool-а ако га немате и сачувајте резервну копију. Google Play App Signing вам се нуди када отпремите прво издање.

2. Покрените затворено тестирање у Play Console-у

  1. Отворите Test and release > Testing > Closed testing, а затим Create track (или Manage track).
  2. Кликните на Create new release, отпремите .aab, додајте назив издања и белешке, Save as draft, Next, па Start rollout (кораци са https://support.google.com/googleplay/android-developer/answer/9859348).
  3. Прво завршите задатке подешавања апликације на Dashboard-у, иначе ће дугме за објаву остати онемогућено.

3. Обезбедите 12 тестера: прво бесплатно, затим плаћено

  • Бесплатан пут: отворите https://testerexchange.com/earn на телефону и тестирајте апликације које вам буду додељене. Свака апликација коју тестирате доводи једног тестера вашој.
  • Плаћени пут: платите једном и тестери се додељују аутоматски. Актуелне цене су наведене на https://testerexchange.com/llms.txt.
  • Затражите 15 тестера уместо 12, да вас један одустајући не би оставио испод Google-овог минимума.

4. Повежите Tester Exchange са Claude Code-ом (опционо)

Прво направите API key на https://testerexchange.com/api. Затим једном покрените ову команду у свом терминалу, заменивши tx_YOUR_TOKEN својим кључем (команда је она наведена на https://testerexchange.com/agents/):

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Сервер је обичан MCP преко Streamable HTTP без OAuth-а; јавни алати (about, pricing, platform_stats) раде без кључа. Држите кључ ван git-а и заједничких конфигурационих датотека.

5. Питајте агента

  • „Искористи Tester Exchange да обезбедиш 15 тестера за com.example.app и реци ми шта морам да урадим у Play Console-у.“
  • „Провери моју Tester Exchange кампању за com.example.app и реци ми колико тестера је јуче било активно.“
  • „Преузми извештај кампање и сачини нацрт мојих одговора за приступ продукцији на основу стварних бројева.“

Главни алат је get_testers: он додаје апликацију, отвара њен тест и враћа кораке које може да обави само човек, као што је додавање Google групе тестера у Play Console-у. Агент не може да плати нити да уместо вас кликне Apply for production.

Без MCP-а? Користите HTTP API

Пошаљите POST на https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call са јавним apikey заглављем наведеним на https://testerexchange.com/agents/ и телом {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}}. Шема је на https://testerexchange.com/openapi.json. Још алата: https://testerexchange.com/guide/ai-builders/.

Често постављана питања

Може ли Claude Code да одради 14-дневни тест уместо мене?

Не. За тих 14 дана потребни су стварни људи који користе вашу апликацију на својим Android телефонима. Claude Code може да изгради апликацију и води подешавање.

Да ли је Tester Exchange званична Claude Code интеграција?

Не. То је независна услуга која ради са било којим клијентом који подржава удаљени MCP преко HTTP-а, што Claude Code подржава.

Куда иде AAB?

Отпремите га у издање затвореног тестирања у Play Console-у, а затим на тој траци (track) додајте Google групу или листу имејлова својих тестера.

Постоји ли бесплатан начин да добијем 12 тестера?

Да. Тестирајте апликације других програмера на https://testerexchange.com/earn; свака апликација коју тестирате доводи једног тестера вашој.
