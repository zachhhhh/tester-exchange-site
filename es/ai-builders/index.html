Tanto si programaste tu app Android con vibe coding como si la escribiste a mano con un editor con IA, Google Play sigue exigiendo 12 testers inscritos durante 14 días antes de que una cuenta de desarrollador personal nueva pueda publicar en producción. Este centro reúne una guía de Tester Exchange para cada herramienta de IA: cómo generar el Android App Bundle, cómo iniciar las pruebas cerradas y cómo conseguir los testers, gratis probando antes otras apps, o de pago y más rápido. Cada página muestra además la configuración exacta para copiar y pegar, de modo que tu herramienta de IA pueda manejar Tester Exchange por sí misma.

Guías por herramienta

Añadimos más herramientas con regularidad. Por ahora:

  • Cursor: https://testerexchange.com/guide/get-12-testers-cursor/ - genera el AAB con Gradle y luego conecta Tester Exchange a Cursor con .cursor/mcp.json.
  • Claude Code: https://testerexchange.com/guide/get-12-testers-claude-code/ - build the AAB with Gradle, then add Tester Exchange with one claude mcp add command.
  • Windsurf: https://testerexchange.com/guide/get-12-testers-windsurf/ - build the AAB with Gradle, then add Tester Exchange to ~/.codeium/windsurf/mcp_config.json.

Las dos vías para conseguir testers

  • Gratis: prueba las apps de otros desarrolladores en https://testerexchange.com/earn desde tu teléfono. Cada app que pruebas aporta un tester a la tuya, así que puedes completar tus 12 plazas sin pagar.
  • De pago y más rápido: paga una vez por un paquete de testers; los precios actuales están en https://testerexchange.com/llms.txt. Las apps de pago reciben testers antes que nadie.

Qué exige Google

La ayuda de Play Console de Google indica que las cuentas de desarrollador personales creadas después del 13 de noviembre de 2023 deben realizar una prueba cerrada con al menos 12 testers inscritos de forma continua durante al menos 14 días antes de poder solicitar acceso a producción (https://support.google.com/googleplay/android-developer/answer/14151465). Ninguna herramienta de IA puede cumplir esos 14 días por ti: tienen que ser personas reales con teléfonos reales.

Deja que tu herramienta de IA haga la configuración

Tester Exchange tiene un servidor MCP, una API HTTP y un agente A2A. La lista completa de clientes y fragmentos de configuración está en https://testerexchange.com/agents/. La guía general es https://testerexchange.com/guide/automate-closed-testing-with-ai-agents/.

Preguntas frecuentes

¿Necesito una herramienta de IA para usar Tester Exchange?

No. El sitio web funciona por sí solo. El servidor MCP y la API son atajos opcionales para quienes ya trabajan con una herramienta de IA.

¿Puede la herramienta de IA pagar los testers?

No. Puede devolver un enlace de pago, pero el pago se hace en tu navegador. La vía gratuita es probar otras apps en https://testerexchange.com/earn.

¿Es Tester Exchange una integración oficial de estas herramientas?

No. Es un servicio independiente. Estas páginas solo muestran cómo conectar la compatibilidad estándar de MCP o HTTP de una herramienta con Tester Exchange.
