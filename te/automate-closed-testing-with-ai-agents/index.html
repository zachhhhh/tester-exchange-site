AI agents‌తో Google Play closed testing ఆటోమేట్ చేయండి

నవంబర్ 2026లో అప్‌డేట్ చేయబడింది

మీరు ఇప్పటికే AI agent సహాయంతో కోడ్ పంపుతున్నట్లయితే, Google Play closed testing requirement లోని చాలా పనులను కూడా దానికి అప్పగించవచ్చు: యాప్‌ను జాబితా చేయడం, testers‌ను రిక్రూట్ చేయడం, ప్రోగ్రెస్ చెక్ చేయడం, production access ఫారమ్ కోసం గణాంకాలు తీసుకోవడం. దీని కోసం Tester Exchange‌కు MCP server, ఒకే endpoint ఉన్న HTTP API, A2A agent card ఉన్నాయి. ఈ గైడ్ Claude Code, Claude Desktop, Cursor, ఇతర clients‌ను ఎలా కనెక్ట్ చేయాలో, ఏమి అడగాలో, ఏ agent చేయలేని భాగాలేమిటో చూపిస్తుంది.

Agent ఏం చేయగలదు, ఏం చేయలేదు

13 నవంబర్ 2023 తర్వాత సృష్టించిన personal developer ఖాతాలు production‌కు దరఖాస్తు చేసే ముందు 14 నిరంతర రోజులు opt-in అయిన కనీసం 12 testers‌తో closed test నడపాలని Google కోరుతుంది. దాని చుట్టూ ఉన్న పనిలో ఎక్కువ భాగం సమన్వయమే, దాన్ని agents బాగా చేస్తాయి.

  • Agent చేయగలది: మీ యాప్‌ను చేర్చడం, tester campaign తెరవడం, మీ credits వర్తింపజేయడం, ఎంతమంది testers యాక్టివ్‌గా ఉన్నారో చెక్ చేయడం, campaign‌ను pause లేదా close చేయడం, daily-activity report తీసుకోవడం, దాని ఆధారంగా production access సమాధానాలు రాయడంలో సహాయపడటం.
  • మనిషి చేయాల్సింది: Play Console‌లో closed track‌కు testers Google Group‌ను చేర్చడం, release పబ్లిష్ చేయడం, credits కోసం చెల్లించడం (checkout ఎల్లప్పుడూ వ్యక్తి browser‌లోనే జరుగుతుంది), Apply for production నొక్కడం.
  • ఎవరూ ఆటోమేట్ చేయలేనిది: 14 రోజుల నిజమైన వాడకం. అది నిజమైన వ్యక్తులు తమ సొంత Android ఫోన్లలో చేస్తారు; Google నియమం ఉద్దేశ్యమే అది.

1. Token సృష్టించండి

  1. https://testerexchange.com/api లో సైన్ ఇన్ అవ్వండి.
  2. వ్యక్తిగత token సృష్టించండి. అది tx_ తో మొదలవుతుంది. ఇప్పుడే కాపీ చేసి, పాస్‌వర్డ్‌లా భద్రంగా ఉంచండి.
  3. Tokens‌ను ఎప్పుడైనా రద్దు చేయవచ్చు. Token campaigns‌పై credits ఖర్చు చేయగలదు, కానీ చెల్లింపు చేయలేదు, డబ్బు విత్‌డ్రా చేయలేదు, మీ ఖాతాను తొలగించలేదు.

2. MCP server‌ను కనెక్ట్ చేయండి

MCP server https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp వద్ద Streamable HTTP వాడుతుంది. మీ token‌ను Authorization: Bearer tx_YOUR_TOKEN హెడర్‌లో పంపండి.

Claude Code: మీ terminal‌లో ఒకసారి ఇది నడపండి.

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code, JSON config ఉన్న ఇతర clients: tester-exchange అనే server‌ను type http, పై URL, Authorization ను Bearer tx_YOUR_TOKEN గా సెట్ చేసిన headers ఎంట్రీతో చేర్చండి. Config ఫైల్ ఖచ్చితమైన స్థానం మీ client‌పై ఆధారపడి ఉంటుంది; దాని MCP డాక్యుమెంటేషన్ చూడండి.

URL మాత్రమే తీసుకునే clients (కొన్ని ChatGPT, web connectors): వాటి కోసం URL రూపం https://testerexchange.com/agents/ లోని docs‌లో ఉంది. Token లేకుండా కూడా పబ్లిక్ tools (Tester Exchange అంటే ఏమిటి, ధరలు, platform గణాంకాలు) పనిచేస్తాయి.

3. మొదలుపెట్టడానికి ఒకే tool: get_testers

మొత్తం tool జాబితాను నేర్చుకోవాల్సిన అవసరం లేదు. ప్రధాన tool get_testers(package_name, name?). ఒక్క కాల్ మీ యాప్‌ను చేర్చి, దాని test తెరిచి, మీ credits వర్తింపజేసి, మీ ప్రోగ్రెస్‌తో పాటు Play Console‌లో Google Group చేర్చడం లాంటి మనిషి మాత్రమే చేయగల స్టెప్‌లను తిరిగి ఇస్తుంది. ప్రోగ్రెస్ చూడటానికి ఎప్పుడైనా మళ్లీ కాల్ చేయండి.

మిగతా tools వివరాలను చూసుకుంటాయి: my_apps, campaign_report (testers, daily activity, feedback, production-access డేటా), add_testers, set_campaign_status (pause, resume లేదా close; వాడని credits మీ బ్యాలెన్స్‌కు తిరిగి వస్తాయి), share_kit, మనిషి చెల్లించడానికి checkout లింక్‌లను ఇచ్చే buy_credits_links.

బాగా పనిచేసే prompts

  • “com.example.app కోసం 15 testers‌ను తీసుకో, Play Console‌లో నేను ఏం చేయాలో చెప్పు.”
  • “com.example.app కోసం నా Tester Exchange campaign‌ను చెక్ చేయి. ఈ వారం రోజూ ఎంతమంది testers యాక్టివ్‌గా ఉన్నారు?”
  • “Campaign report తీసుకుని నా production access సమాధానాలు రాయి. నిజమైన సంఖ్యలే వాడు.”
  • “Production access ఆమోదం అయింది కాబట్టి com.example.app campaign‌ను close చేయి.”

12కు బదులు 15 testers‌ను అడగండి, తద్వారా ఒకరు వదిలేసినా Google కనీస సంఖ్య కంటే తగ్గరు.

Scripts, CI కోసం HTTP API

మీ tool MCP మాట్లాడకపోతే, HTTP endpoint వాడండి: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call. Body JSON, అందులో p_token (మీ tx_ token), p_action (ఉదాహరణకు help, my_apps లేదా start_campaign), p_args (ఉదాహరణకు package_name, tester సంఖ్య) ఉంటాయి. Docs‌లో చూపిన పబ్లిక్ apikey హెడర్‌ను పంపండి.

ముందు help action‌ను కాల్ చేయండి: అది ప్రతి action‌ను, దాని arguments‌ను తిరిగి ఇస్తుంది. పూర్తి schema https://testerexchange.com/openapi.json వద్ద ఉంది; ఇది ChatGPT custom GPT actions, ఇతర OpenAPI tools‌తో పనిచేస్తుంది.

A2A agent card

Agent-to-agent సెటప్‌ల కోసం Tester Exchange https://testerexchange.com/.well-known/agent-card.json వద్ద A2A agent card‌ను ప్రచురిస్తుంది. A2A protocol‌కు మద్దతు ఇచ్చే orchestrators ఈ agent ఏమి అందిస్తుందో, దాన్ని ఎలా కాల్ చేయాలో తెలుసుకోగలవు. మీ ఖాతాకు సంబంధించిన దేనికైనా అదే tx_ token వాడండి.

మొదటి నుంచి చివరి వరకు పూర్తి ప్రక్రియ

  1. Play Console‌లో closed track‌కు మీ మొదటి .aab అప్‌లోడ్ చేస్తారు.
  2. మీ agent మీ package name కోసం get_testers కాల్ చేసి, closed track‌లో Google Groups కింద testerexchange-testers@googlegroups.com చేర్చమని చెబుతుంది.
  3. మీరు group చేర్చి, సేవ్ చేసి, release పబ్లిష్ అయి ఉందో చూసుకుంటారు.
  4. Credits లేకపోతే, agent checkout లింక్ ఇస్తుంది. మీరు చెల్లిస్తారు (12 testers‌కు $12.99, 15కు $14.99, 25కు $22.99), లేదా https://testerexchange.com/earn లో ఇతర యాప్‌లను టెస్ట్ చేసి credits ఉచితంగా సంపాదిస్తారు.
  5. నిజమైన testers 14 రోజులు మీ యాప్‌ను ఇన్‌స్టాల్ చేసి వాడతారు. మీ agent రోజూ ప్రోగ్రెస్ చెక్ చేసి, యాక్టివ్ testers తగ్గితే హెచ్చరిస్తుంది.
  6. 15వ రోజున agent campaign report తీసుకుని మీ production access సమాధానాలు రాస్తుంది. మీరు వాటిని సమీక్షించి Apply for production నొక్కుతారు.

భద్రతా సూచనలు

  • Tokens‌ను git‌లో ఉంచకండి. వాటిని మీ client secret store‌లో లేదా environment variable‌లో పెట్టండి.
  • మా వైపు tokens hashes రూపంలో మాత్రమే నిల్వ అవుతాయి, ఒక్కో ఖాతాకు 10కి పరిమితం. వాడని tokens‌ను రద్దు చేయండి.
  • సబ్మిట్ చేసే ముందు production ఫారమ్‌లో agent రాసినది చదవండి. మీ test గురించి నిజాయితీగా వివరించమని Google కోరుతుంది.

తరచుగా అడిగే ప్రశ్నలు

AI agent నా కోసం 14 రోజుల test పూర్తి చేయగలదా?

లేదు. 14 రోజులకు నిజమైన వ్యక్తులు తమ సొంత ఫోన్లలో మీ యాప్‌ను వాడాలి. Agents సెటప్, పర్యవేక్షణ, రిపోర్టింగ్ చూసుకుంటాయి.

Agent testers కోసం చెల్లించగలదా?

లేదు. అది checkout లింక్‌లను ఇవ్వగలదు, కానీ చెల్లింపు ఎల్లప్పుడూ మనిషి browser‌లోనే జరుగుతుంది.

MCP server‌తో ఏ clients పనిచేస్తాయి?

Custom హెడర్‌తో Streamable HTTP ద్వారా remote MCPకి మద్దతు ఇచ్చే ఏ client అయినా, Claude Code, Claude Desktop, Cursor, VS Code సహా. ఇతరులు HTTP API వాడవచ్చు.

Token ఎక్కడ దొరుకుతుంది?

సైన్ ఇన్ అయిన తర్వాత https://testerexchange.com/api వద్ద. Tokens tx_ తో మొదలవుతాయి, ఎప్పుడైనా రద్దు చేయవచ్చు.

Agent నా Play Consoleలో ఏమైనా మారుస్తుందా?

లేదు. దానికి మీ Play Console యాక్సెస్ లేదు. అక్కడ మీరు చేయాల్సిన స్టెప్‌లను అది చెబుతుంది.
