Tester Exchange Tester Exchange తెరవండి

Claude Codeతో మీ Android యాప్ తయారు చేశారా? 14 రోజులకు మీ 12 టెస్టర్లను పొందండి

నవంబర్ 2026లో నవీకరించబడింది

Claude Code మీ Android యాప్‌ను రాయగలదు మరియు బిల్డ్ చేయగలదు, కానీ Google Play కోరే 12 నిజమైన టెస్టర్లను అందించలేదు. మీ వ్యక్తిగత డెవలపర్ ఖాతా 13 నవంబర్ 2023 తర్వాత సృష్టించబడి ఉంటే, ప్రొడక్షన్‌కు దరఖాస్తు చేసే ముందు వరుసగా 14 రోజులు ఆప్ట్ ఇన్ అయిన కనీసం 12 టెస్టర్లతో క్లోజ్డ్ టెస్ట్ నడపాలి. ఈ గైడ్ బండిల్ బిల్డ్ చేయడం, క్లోజ్డ్ టెస్టింగ్ ప్రారంభించడం, టెస్టర్లను పొందడం (ముందు ఉచితం, తర్వాత చెల్లింపు) మరియు ఏజెంట్ పేపర్‌వర్క్ చేయడానికి Tester Exchangeను Claude Codeకు కనెక్ట్ చేయడం గురించి వివరిస్తుంది.

నిజమైన వ్యక్తులు 14 రోజులు తమ సొంత ఫోన్‌లలో మీ యాప్ తెరుస్తారు. ఒక్కసారి చెల్లించండి, లేదా ఇతర యాప్‌లు టెస్ట్ చేసి ఉచితంగా పొందండి.12 testers పొందండి
ఈ పేజీలో
  • 1. రిలీజ్ బండిల్ (.aab) బిల్డ్ చేయండి
  • 2. Play Consoleలో క్లోజ్డ్ టెస్టింగ్ ప్రారంభించండి
  • 3. మీ 12 టెస్టర్లను పొందండి: ముందు ఉచితం, తర్వాత చెల్లింపు
  • 4. Tester Exchangeను Claude Codeకు కనెక్ట్ చేయండి (ఐచ్ఛికం)
  • 5. ఏజెంట్‌ను అడగండి

  • తరచుగా అడిగే ప్రశ్నలు

1. రిలీజ్ బండిల్ (.aab) బిల్డ్ చేయండి

  1. మీ మాడ్యూల్ build.gradle.ktsలో రిలీజ్ సైనింగ్‌ను కాన్ఫిగర్ చేయమని Claude Code ఏజెంట్‌ను అడగండి (storeFile, storePassword, keyAlias మరియు keyPasswordతో signingConfigs బ్లాక్, release build typeకు సెట్ చేయబడినది). పాస్‌వర్డ్‌లను git లో ఉంచకండి (Android బిల్డ్ డాక్స్: https://developer.android.com/build/building-cmdline).
  2. టెర్మినల్‌లో ./gradlew bundleRelease రన్ చేయండి. Gradle బండిల్‌ను బిల్డ్ చేసి సైన్ చేస్తుంది; .aab సాధారణంగా app/build/outputs/bundle/release/ కింద కనిపిస్తుంది, అయితే మీ స్వంత బిల్డ్ అవుట్‌పుట్‌ను తనిఖీ చేయండి.
  3. మీకు keystore లేకపోతే keytoolతో సృష్టించండి, మరియు బ్యాకప్ తీసుకోండి. మీ మొదటి రిలీజ్ అప్‌లోడ్ చేసినప్పుడు Google Play App Signing అందించబడుతుంది.

2. Play Consoleలో క్లోజ్డ్ టెస్టింగ్ ప్రారంభించండి

  1. Test and release > Testing > Closed testing తెరవండి, ఆపై Create track (లేదా Manage track).
  2. Create new release క్లిక్ చేసి, .aab అప్‌లోడ్ చేయండి, రిలీజ్ పేరు మరియు నోట్స్ జోడించండి, Save as draft, Next, ఆపై Start rollout (దశలు https://support.google.com/googleplay/android-developer/answer/9859348 నుండి).
  3. ముందుగా Dashboardలోని యాప్ సెటప్ పనులను పూర్తి చేయండి, లేకపోతే రిలీజ్ బటన్ డిసేబుల్ అయి ఉంటుంది.

3. మీ 12 టెస్టర్లను పొందండి: ముందు ఉచితం, తర్వాత చెల్లింపు

  • ఉచిత మార్గం: మీ ఫోన్‌లో https://testerexchange.com/earn తెరిచి మీకు ఇచ్చిన యాప్‌లను టెస్ట్ చేయండి. మీరు టెస్ట్ చేసే ప్రతి యాప్ మీ యాప్‌కు ఒక టెస్టర్‌ను తెస్తుంది.
  • చెల్లింపు మార్గం: ఒక్కసారి చెల్లించండి, టెస్టర్లు స్వయంచాలకంగా కేటాయించబడతారు. ప్రస్తుత ధరలు https://testerexchange.com/llms.txt లో జాబితా చేయబడ్డాయి.
  • ఒక్కరు తప్పుకున్నా Google కనీస సంఖ్య కంటే తక్కువ కాకుండా ఉండటానికి 12 కాకుండా 15 టెస్టర్లను అడగండి.

4. Tester Exchangeను Claude Codeకు కనెక్ట్ చేయండి (ఐచ్ఛికం)

ముందుగా https://testerexchange.com/api వద్ద API కీని సృష్టించండి. తర్వాత మీ టెర్మినల్‌లో దీన్ని ఒకసారి అమలు చేయండి, tx_YOUR_TOKEN స్థానంలో మీ కీని ఉంచండి (ఆదేశం https://testerexchange.com/agents/ వద్ద ఉంది):

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

సర్వర్ OAuth లేకుండా Streamable HTTP పై సాధారణ MCP; పబ్లిక్ టూల్స్ (about, pricing, platform_stats) కీ లేకుండానే పనిచేస్తాయి. కీని git లోనూ, షేర్ చేసిన కాన్ఫిగ్ ఫైళ్లలోనూ ఉంచకండి.

5. ఏజెంట్‌ను అడగండి

  • “Tester Exchange ఉపయోగించి com.example.app కోసం 15 టెస్టర్లను పొందండి మరియు Play Consoleలో నేను ఏమి చేయాలో చెప్పండి.”
  • “com.example.app కోసం నా Tester Exchange క్యాంపెయిన్‌ను తనిఖీ చేసి నిన్న ఎంతమంది టెస్టర్లు యాక్టివ్‌గా ఉన్నారో చెప్పండి.”
  • “క్యాంపెయిన్ రిపోర్ట్ తీసుకుని నిజమైన సంఖ్యల నుండి నా ప్రొడక్షన్ యాక్సెస్ సమాధానాలను డ్రాఫ్ట్ చేయండి.”

ప్రధాన టూల్ get_testers: ఇది యాప్‌ను జోడిస్తుంది, దాని టెస్ట్‌ను తెరుస్తుంది మరియు Play Consoleలో టెస్టర్ల Google Group జోడించడం వంటి మనిషి మాత్రమే చేయగల దశలను తిరిగి ఇస్తుంది. ఏజెంట్ మీ కోసం చెల్లించలేదు లేదా Apply for production క్లిక్ చేయలేదు.

MCP లేదా? HTTP API ఉపయోగించండి

https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call కు https://testerexchange.com/agents/ లో జాబితా చేసిన పబ్లిక్ apikey హెడర్‌తో మరియు {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}} బాడీతో POST చేయండి. స్కీమా https://testerexchange.com/openapi.json లో ఉంది. మరిన్ని టూల్స్: https://testerexchange.com/guide/ai-builders/.

తరచుగా అడిగే ప్రశ్నలు

14 రోజుల టెస్ట్‌ను Claude Code నా కోసం పూర్తి చేయగలదా?

లేదు. ఆ 14 రోజులకు నిజమైన వ్యక్తులు తమ సొంత Android ఫోన్లలో మీ యాప్‌ను ఉపయోగించాలి. Claude Code యాప్‌ను తయారు చేసి సెటప్‌ను నడిపించగలదు.

Tester Exchange అధికారిక Claude Code ఇంటిగ్రేషనా?

కాదు. ఇది స్వతంత్ర సేవ; HTTP ద్వారా రిమోట్ MCP కు మద్దతిచ్చే ఏ క్లయింట్‌తోనైనా పనిచేస్తుంది, Claude Code అలా మద్దతిస్తుంది.

AAB ఎక్కడ అప్‌లోడ్ చేయాలి?

దాన్ని Play Consoleలో క్లోజ్డ్ టెస్టింగ్ రిలీజ్‌కు అప్‌లోడ్ చేసి, ఆ ట్రాక్‌లో మీ టెస్టర్ల Google Group లేదా ఇమెయిల్ జాబితాను జోడించండి.

12 టెస్టర్లను పొందడానికి ఉచిత మార్గం ఉందా?

ఉంది. https://testerexchange.com/earn లో ఇతర డెవలపర్‌ల యాప్‌లను టెస్ట్ చేయండి; మీరు టెస్ట్ చేసే ప్రతి యాప్ మీ యాప్‌కు ఒక టెస్టర్‌ను తెస్తుంది.

నిజమైన వ్యక్తులు 14 రోజులు తమ సొంత ఫోన్‌లలో మీ యాప్ తెరుస్తారు. ఒక్కసారి చెల్లించండి, లేదా ఇతర యాప్‌లు టెస్ట్ చేసి ఉచితంగా పొందండి.12 testers పొందండి
