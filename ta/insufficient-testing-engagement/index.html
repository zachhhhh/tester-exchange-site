Closed testing-க்குப் பிறகு நிராகரிக்கப்பட்டதா? “more testing required”-ஐச் சரிசெய்வது எப்படி

அக்டோபர் 2026-ல் புதுப்பிக்கப்பட்டது

12 tester-களுடன் 14 நாட்கள் closed test நடத்தி, production-க்கு விண்ணப்பித்தீர்கள், உங்கள் ஆப்புக்கு இன்னும் testing தேவை என்று Google சொன்னது. புதிய personal கணக்குகளுக்கு இதுவே மிகப் பொதுவான முடிவு. டெஸ்ட்டின்போது உங்கள் ஆப்பின் போதுமான உண்மையான பயன்பாட்டை Google பார்க்கவில்லை என்பதே பொதுவாக இதன் அர்த்தம். Google எதைப் பார்க்கிறது, வெற்றிபெறும் இரண்டாவது டெஸ்ட்டை எப்படி நடத்துவது என்பதை இங்கே பாருங்கள்.

உண்மையான மனிதர்கள் தங்கள் சொந்த போன்களில் 14 நாட்கள் உங்கள் ஆப்பைத் திறக்கிறார்கள். ஒருமுறை பணம் செலுத்துங்கள், அல்லது மற்ற ஆப்களை டெஸ்ட் செய்து இலவசமாகப் பெறுங்கள்.12 tester-களைப் பெறு

உங்கள் ஆப்புக்கு இன்னும் testing தேவை என்று Google ஏன் சொல்கிறது

Opt-in செய்வதும் டெஸ்ட் செய்வதும் ஒன்றல்ல. எத்தனை tester-கள் ஆப்பை install செய்தார்கள், எத்தனை முறை திறந்தார்கள், டெஸ்ட்டின்போது நீங்கள் update-களை வெளியிட்டீர்களா என்பதை Google பார்க்க முடியும். ஒருமுறை install செய்துவிட்டுத் திரும்பி வராத டெஸ்ட், உண்மையான டெஸ்ட் அல்ல, ஒரு சடங்காகத்தான் தெரியும்.

  • குறைந்த engagement: tester-கள் ஆப்பை install செய்தார்கள், ஆனால் அரிதாகவோ ஒருபோதுமோ திறக்கவில்லை.
  • மிகக் குறைவான active tester-கள்: சிலர் டெஸ்ட்டிலிருந்து விலகினார்கள், opt-in tester-கள் 12-க்குக் கீழே போனார்கள்.
  • மேம்பாடு இல்லை: 14 நாட்களில் புதிய build-களும் இல்லை, feedback-க்கு வெளிப்படையான பதிலும் இல்லை.
  • பலவீனமான பதில்கள்: production கேள்வித்தாளில் எண்களோ feedback உதாரணங்களோ இல்லாத தெளிவற்ற பதில்கள்.

இரண்டாவது முயற்சியில் வெற்றிபெறும் திட்டம்

  1. Closed test-ஐத் தொடர்ந்து இயக்குங்கள். Track-ஐ delete செய்யவோ, இன்னும் active-ஆக இருக்கும் tester-களை நீக்கவோ வேண்டாம்.
  2. தினமும் ஆப்பைத் திறக்கும் 14–15 உண்மையான tester-களைச் சேருங்கள், சிலர் விலகினாலும் 12-க்குக் கீழே போகமாட்டீர்கள்.
  3. Tester-களுக்கு வாரத்துக்கு ஒன்றிரண்டு தெளிவான task-கள் கொடுங்கள் (“கணக்கு உருவாக்குங்கள், ஒரு item சேருங்கள், ஒரு setting-ஐ மாற்றுங்கள்”).
  4. எழுத்துப்பூர்வ feedback கேளுங்கள், தெரிவிக்கப்பட்ட சில பிரச்சினைகளையாவது சரிசெய்யுங்கள், டெஸ்ட்டின்போது closed track-ல் புதிய build-களை upload செய்யுங்கள்.
  5. ஒரு log வையுங்கள்: தினசரி active tester-கள், மொத்த tester-days, பெற்ற feedback, நீங்கள் மாற்றியவை.
  6. இன்னும் 14 நாட்கள் உண்மையான பயன்பாட்டுக்குப் பிறகு, மீண்டும் விண்ணப்பித்து ஒவ்வொரு கேள்விக்கும் அந்த எண்களுடன் பதில் அளியுங்கள்.

Engagement-க்கான ஆதாரத்தைக் காட்டுங்கள்

உங்கள் பதில்கள் ஒரு சிறிய test report போல இருக்க வேண்டும்: எத்தனை tester-கள், எத்தனை நாட்கள் ஆப்பைப் பயன்படுத்தினார்கள், என்ன தெரிவித்தார்கள், எந்த build-கள் அதைச் சரிசெய்தன. Tester Exchange ஒவ்வொரு tester-க்கும் சரிபார்க்கப்பட்ட தினசரி பயன்பாட்டைப் பதிவுசெய்து, உங்கள் உண்மையான தரவிலிருந்து இந்தப் பதில்களை draft செய்கிறது, அதனால் நினைவிலிருந்து அவற்றை மீண்டும் உருவாக்க வேண்டியதில்லை.

செய்யக்கூடாதவை

  • உங்கள் கூடுதல் போன்களையோ கணக்குகளையோ tester-களாகப் பயன்படுத்த வேண்டாம். ஒரே device-ல் பல கணக்குகள் உண்மையான testing-ஆகக் கணக்கிடப்படாது.
  • Install மட்டும் செய்து ஆப்பைத் திறக்காத “tester-களுக்கு” பணம் செலுத்த வேண்டாம். நிராகரிக்கப்படுவது சரியாக அதுதான்.
  • இணையத்திலிருந்து பொதுவான பதில்களை copy செய்ய வேண்டாம். உங்கள் சொந்த எண்களையும் சொந்த feedback-ஐயும் பயன்படுத்துங்கள்.

அடிக்கடி கேட்கப்படும் கேள்விகள்

14 நாட்களை மீண்டும் தொடங்க வேண்டுமா?

உங்கள் closed test அப்படியே இருக்கும், ஆனால் மீண்டும் விண்ணப்பிக்கும் முன் இன்னும் உண்மையான testing-ஐ Google பார்க்க விரும்புகிறது. குறைந்தது இன்னும் 14 நாட்கள் active பயன்பாட்டுக்குத் திட்டமிடுங்கள்.

Tester-கள் எத்தனை முறை ஆப்பைத் திறக்க வேண்டும்?

Google ஒரு எண்ணை வெளியிடவில்லை. பெரும்பாலான tester-களின் தினசரி பயன்பாடே பாதுகாப்பான pattern, Tester Exchange சரிபார்ப்பதும் அதைத்தான்.

Feedback முக்கியமா?

ஆம். Tester-கள் என்ன சொன்னார்கள், நீங்கள் என்ன மாற்றினீர்கள் என்று கேள்வித்தாள் கேட்கிறது. உண்மையான feedback-உம் உண்மையான fix-களும் உங்கள் பதில்களை நம்பகமானதாக்கும்.
