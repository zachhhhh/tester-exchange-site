AI agent-களுடன் Google Play closed testing-ஐத் தானியக்கமாக்குவது

நவம்பர் 2026-ல் புதுப்பிக்கப்பட்டது

ஏற்கனவே AI agent மூலம் code வெளியிடுகிறீர்கள் என்றால், Google Play closed testing தேவையின் பெரும்பாலான சலிப்பான வேலைகளையும் அதனிடம் ஒப்படைக்கலாம்: உங்கள் ஆப்பைப் பட்டியலிடுதல், tester-களைச் சேர்த்தல், முன்னேற்றத்தைச் சரிபார்த்தல், production access படிவத்துக்கான எண்களை எடுத்தல். இதற்காக Tester Exchange-ல் ஒரு MCP server, ஒரே endpoint கொண்ட HTTP API மற்றும் ஒரு A2A agent card உள்ளன. Claude Code, Claude Desktop, Cursor மற்றும் பிற client-களை எப்படி இணைப்பது, என்ன கேட்பது, எந்த agent-ஆலும் செய்ய முடியாத பகுதிகள் எவை என்பதை இந்த வழிகாட்டி காட்டுகிறது.

உண்மையான மனிதர்கள் தங்கள் சொந்த போன்களில் 14 நாட்கள் உங்கள் ஆப்பைத் திறக்கிறார்கள். ஒருமுறை பணம் செலுத்துங்கள், அல்லது மற்ற ஆப்களை டெஸ்ட் செய்து இலவசமாகப் பெறுங்கள்.12 tester-களைப் பெறு

Agent என்ன செய்யும், என்ன செய்யாது

2023 நவம்பர் 13-க்குப் பிறகு உருவாக்கப்பட்ட personal developer கணக்குகள், production-க்கு விண்ணப்பிக்கும் முன் குறைந்தது 12 tester-கள் 14 தொடர்ச்சியான நாட்கள் opt-in செய்த closed test ஒன்றை நடத்த வேண்டும் என்று Google கேட்கிறது. இதைச் சுற்றியுள்ள பெரும்பாலான வேலை ஒருங்கிணைப்புதான், அதை agent-கள் நன்றாகக் கையாளும்.

  • Agent செய்யக்கூடியவை: உங்கள் ஆப்பைச் சேர்ப்பது, tester campaign தொடங்குவது, உங்கள் credit-களைப் பயன்படுத்துவது, எத்தனை tester-கள் செயலில் உள்ளனர் என்று பார்ப்பது, campaign-ஐ pause செய்வது அல்லது மூடுவது, தினசரி-செயல்பாட்டு அறிக்கையைப் பெறுவது, அதிலிருந்து production access பதில்களை வரைய உதவுவது.
  • மனிதர் செய்ய வேண்டியவை: Play Console-ல் closed track-ல் tester-களின் Google Group-ஐச் சேர்ப்பது, release-ஐ publish செய்வது, credit-களுக்குப் பணம் செலுத்துவது (checkout எப்போதும் ஒருவரின் browser-ல் நடக்கும்), Apply for production என்பதைக் கிளிக் செய்வது.
  • யாராலும் தானியக்கமாக்க முடியாதது: 14 நாட்கள் உண்மையான பயன்பாடு. அதை உண்மையான மனிதர்கள் தங்கள் சொந்த Android போன்களில் செய்கிறார்கள்; Google-ன் விதியின் நோக்கமே அதுதான்.

1. Token உருவாக்குங்கள்

  1. https://testerexchange.com/api-ல் உள்நுழையுங்கள்.
  2. ஒரு தனிப்பட்ட token உருவாக்குங்கள். அது tx_ என்று தொடங்கும். இப்போதே நகலெடுத்து, கடவுச்சொல்லைப் போலப் பாதுகாப்பாக வைத்துக்கொள்ளுங்கள்.
  3. Token-களை எப்போது வேண்டுமானாலும் ரத்து செய்யலாம். ஒரு token campaign-களில் credit-களைச் செலவிட முடியும், ஆனால் பணம் செலுத்தவோ, பணத்தை எடுக்கவோ, உங்கள் கணக்கை நீக்கவோ முடியாது.

2. MCP server-ஐ இணையுங்கள்

MCP server https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp என்ற முகவரியில் Streamable HTTP பயன்படுத்துகிறது. உங்கள் token-ஐ Authorization: Bearer tx_YOUR_TOKEN என்ற header-ல் அனுப்புங்கள்.

Claude Code: உங்கள் terminal-ல் இதை ஒருமுறை இயக்குங்கள்.

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code மற்றும் JSON config கொண்ட பிற client-கள்: tester-exchange என்ற பெயரில் ஒரு server-ஐச் சேர்த்து, type http, மேலே உள்ள URL, மற்றும் Authorization-ஐ Bearer tx_YOUR_TOKEN என அமைத்த headers உள்ளீடு கொடுங்கள். Config கோப்பின் இடம் உங்கள் client-ஐப் பொறுத்தது; அதன் MCP ஆவணத்தைப் பாருங்கள்.

URL மட்டும் ஏற்கும் client-கள் (சில ChatGPT மற்றும் web connector-கள்): அவற்றுக்கான URL வடிவத்தை https://testerexchange.com/agents/ ஆவணங்கள் பட்டியலிடுகின்றன. Token இல்லாமலும் பொதுக் கருவிகள் (Tester Exchange என்றால் என்ன, விலை, தளப் புள்ளிவிவரங்கள்) செயல்படும்.

3. தொடங்க ஒரே கருவி: get_testers

முழுக் கருவிப் பட்டியலையும் கற்க வேண்டியதில்லை. முக்கியக் கருவி get_testers(package_name, name?). ஒரே அழைப்பில் அது உங்கள் ஆப்பைச் சேர்க்கும், அதன் test-ஐத் தொடங்கும், உங்கள் credit-களைப் பயன்படுத்தும், உங்கள் முன்னேற்றத்தையும், Play Console-ல் Google Group-ஐச் சேர்ப்பது போன்ற மனிதர் மட்டுமே செய்யக்கூடிய படிகளையும் திருப்பித் தரும். முன்னேற்றம் அறிய எப்போது வேண்டுமானாலும் மீண்டும் அழைக்கலாம்.

மற்ற கருவிகள் விவரங்களைக் கையாளும்: my_apps, campaign_report (tester-கள், தினசரி செயல்பாடு, கருத்துகள், production-access தரவு), add_testers, set_campaign_status (pause, resume அல்லது close; பயன்படுத்தப்படாத credit-கள் உங்கள் இருப்புக்குத் திரும்பும்), share_kit, மற்றும் மனிதர் பணம் செலுத்துவதற்கான checkout link-களைத் தரும் buy_credits_links.

நன்றாக வேலை செய்யும் prompt-கள்

  • “com.example.app-க்கு 15 tester-களைப் பெறு, Play Console-ல் நான் என்ன செய்ய வேண்டும் என்றும் சொல்.”
  • “com.example.app-க்கான என் Tester Exchange campaign-ஐச் சரிபார். இந்த வாரம் ஒவ்வொரு நாளும் எத்தனை tester-கள் செயலில் இருந்தனர்?”
  • “Campaign அறிக்கையை எடுத்து என் production access பதில்களை வரை. உண்மையான எண்களை மட்டும் பயன்படுத்து.”
  • “Production access அங்கீகரிக்கப்பட்டுவிட்டதால் com.example.app-க்கான campaign-ஐ இப்போது மூடு.”

12-க்குப் பதிலாக 15 tester-களைக் கேளுங்கள்; ஒருவர் விலகினாலும் Google-ன் குறைந்தபட்சத்துக்குக் கீழே போகாமல் இருக்கும்.

Script-கள் மற்றும் CI-க்கான HTTP API

உங்கள் கருவி MCP-ஐப் புரிந்துகொள்ளவில்லை என்றால், HTTP endpoint-ஐப் பயன்படுத்துங்கள்: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call. Body என்பது p_token (உங்கள் tx_ token), p_action (எ.கா. help, my_apps அல்லது start_campaign), p_args (எ.கா. package_name மற்றும் tester எண்ணிக்கை) கொண்ட JSON. ஆவணங்களில் காட்டப்பட்டுள்ள பொது apikey header-ஐயும் அனுப்புங்கள்.

முதலில் help action-ஐ அழைக்கவும்: அது ஒவ்வொரு action-ஐயும் அதன் arguments-ஐயும் தரும். முழு schema https://testerexchange.com/openapi.json-ல் உள்ளது; இது ChatGPT custom GPT action-கள் மற்றும் பிற OpenAPI கருவிகளுடன் வேலை செய்யும்.

A2A agent card

Agent-க்கும் agent-க்கும் இடையிலான அமைப்புகளுக்காக, Tester Exchange https://testerexchange.com/.well-known/agent-card.json என்ற முகவரியில் ஒரு A2A agent card-ஐ வெளியிடுகிறது. A2A protocol-ஐ ஆதரிக்கும் orchestrator-கள், அந்த agent என்ன வழங்குகிறது, அதை எப்படி அழைப்பது என்பதைக் கண்டறியலாம். உங்கள் கணக்குடன் தொடர்புடைய எதற்கும் அதே tx_ token-ஐப் பயன்படுத்துங்கள்.

தொடக்கம் முதல் முடிவு வரை முழுச் செயல்முறை

  1. Play Console-ல் closed track-க்கு உங்கள் முதல் .aab-ஐப் பதிவேற்றுகிறீர்கள்.
  2. உங்கள் agent உங்கள் package name-க்கு get_testers-ஐ அழைத்து, closed track-ல் Google Groups கீழ் testerexchange-testers@googlegroups.com-ஐச் சேர்க்கச் சொல்கிறது.
  3. நீங்கள் அந்த group-ஐச் சேர்த்து, சேமித்து, release publish ஆகிவிட்டதா என்று உறுதிசெய்கிறீர்கள்.
  4. Credit-கள் இல்லையென்றால், agent உங்களுக்கு ஒரு checkout link தரும். நீங்கள் பணம் செலுத்தலாம் (12 tester-களுக்கு $12.99, 15-க்கு $14.99, 25-க்கு $22.99), அல்லது https://testerexchange.com/earn-ல் மற்ற ஆப்களை டெஸ்ட் செய்து credit-களை இலவசமாகச் சம்பாதிக்கலாம்.
  5. உண்மையான tester-கள் 14 நாட்கள் உங்கள் ஆப்பை install செய்து பயன்படுத்துகிறார்கள். உங்கள் agent தினமும் முன்னேற்றத்தைச் சரிபார்த்து, செயலில் உள்ள tester-கள் குறைந்தால் எச்சரிக்கிறது.
  6. 15-ஆம் நாளில், agent campaign அறிக்கையை எடுத்து உங்கள் production access பதில்களை வரைகிறது. நீங்கள் அவற்றைச் சரிபார்த்து Apply for production-ஐக் கிளிக் செய்கிறீர்கள்.

பாதுகாப்புக் குறிப்புகள்

  • Token-களை git-ல் சேர்க்காதீர்கள். உங்கள் client-ன் secret store-ல் அல்லது ஒரு environment variable-ல் வையுங்கள்.
  • எங்கள் பக்கத்தில் token-கள் hash வடிவில் மட்டுமே சேமிக்கப்படுகின்றன; ஒரு கணக்குக்கு 10 வரை மட்டுமே அனுமதி. இனி பயன்படுத்தாத token-களை ரத்து செய்யுங்கள்.
  • Agent உங்கள் production படிவத்தில் எழுதுவதைச் சமர்ப்பிக்கும் முன் படியுங்கள். உங்கள் test-ஐ உண்மையாக விவரிக்க வேண்டும் என்று Google கேட்கிறது.

அடிக்கடி கேட்கப்படும் கேள்விகள்

எனக்காக 14 நாள் test-ஐ ஒரு AI agent முடிக்க முடியுமா?

முடியாது. அந்த 14 நாட்களுக்கு, உங்கள் ஆப்பைத் தங்கள் சொந்த போன்களில் பயன்படுத்தும் உண்மையான மனிதர்கள் தேவை. அமைப்பு, கண்காணிப்பு, அறிக்கையிடல் ஆகியவற்றை agent-கள் கையாளும்.

Agent tester-களுக்குப் பணம் செலுத்த முடியுமா?

முடியாது. அது checkout link-களைத் தரலாம், ஆனால் பணம் செலுத்துதல் எப்போதும் மனிதரின் browser-ல்தான் நடக்கும்.

MCP server-உடன் எந்த client-கள் வேலை செய்யும்?

தனிப்பயன் header உடன் Streamable HTTP மூலம் remote MCP-ஐ ஆதரிக்கும் எந்த client-உம்: Claude Code, Claude Desktop, Cursor, VS Code உட்பட. மற்றவை HTTP API-ஐப் பயன்படுத்தலாம்.

Token எங்கே கிடைக்கும்?

உள்நுழைந்த பிறகு https://testerexchange.com/api-ல். Token-கள் tx_ என்று தொடங்கும்; எப்போது வேண்டுமானாலும் ரத்து செய்யலாம்.

Agent என் Play Console-ல் ஏதாவது மாற்றுமா?

மாற்றாது. உங்கள் Play Console-க்கு அதற்கு அணுகலே இல்லை. அங்கே நீங்கள் செய்ய வேண்டிய படிகளை மட்டும் அது சொல்லும்.

உண்மையான மனிதர்கள் தங்கள் சொந்த போன்களில் 14 நாட்கள் உங்கள் ஆப்பைத் திறக்கிறார்கள். ஒருமுறை பணம் செலுத்துங்கள், அல்லது மற்ற ஆப்களை டெஸ்ட் செய்து இலவசமாகப் பெறுங்கள்.12 tester-களைப் பெறு
