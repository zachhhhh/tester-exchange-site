Tester Exchange Tester Exchange ஐத் திறக்கவும்

Cursor மூலம் உங்கள் Android ஆப்பை உருவாக்கினீர்களா? 14 நாட்களுக்கு உங்கள் 12 டெஸ்டர்களைப் பெறுங்கள்

நவம்பர் 2026 இல் புதுப்பிக்கப்பட்டது

Cursor உங்கள் Android ஆப்பை எழுதி build செய்ய முடியும், ஆனால் Google Play கோரும் 12 உண்மையான டெஸ்டர்களை அதனால் தர முடியாது. உங்கள் தனிநபர் டெவலப்பர் கணக்கு 13 நவம்பர் 2023 க்குப் பிறகு உருவாக்கப்பட்டிருந்தால், production க்கு விண்ணப்பிக்கும் முன் குறைந்தது 12 டெஸ்டர்கள் 14 தொடர்ச்சியான நாட்கள் இணைந்திருக்கும் க்ளோஸ்டு டெஸ்ட் நடத்த வேண்டும். இந்த வழிகாட்டி bundle ஐ உருவாக்குதல், க்ளோஸ்டு டெஸ்டிங்கைத் தொடங்குதல், டெஸ்டர்களைப் பெறுதல் (முதலில் இலவசம், பிறகு கட்டணம்), மற்றும் ஏஜென்ட் காகிதவேலைகளைச் செய்யும்படி Tester Exchange ஐ Cursor உடன் இணைத்தல் ஆகியவற்றை விளக்குகிறது.

உண்மையான மனிதர்கள் தங்கள் சொந்த போன்களில் 14 நாட்கள் உங்கள் ஆப்பைத் திறக்கிறார்கள். ஒருமுறை பணம் செலுத்துங்கள், அல்லது மற்ற ஆப்களை டெஸ்ட் செய்து இலவசமாகப் பெறுங்கள்.12 tester-களைப் பெறு
இந்தப் பக்கத்தில்
  • 1. Release bundle (.aab) ஐ உருவாக்குங்கள்
  • 2. Play Console இல் க்ளோஸ்டு டெஸ்டிங்கைத் தொடங்குங்கள்
  • 3. உங்கள் 12 டெஸ்டர்களைப் பெறுங்கள்: முதலில் இலவசம், பிறகு கட்டணம்
  • 4. Tester Exchange ஐ Cursor உடன் இணையுங்கள் (விருப்பத்தேர்வு)
  • 5. ஏஜென்ட்டிடம் கேளுங்கள்
  • MCP இல்லையா? HTTP API ஐப் பயன்படுத்துங்கள்
  • அடிக்கடி கேட்கப்படும் கேள்விகள்

1. Release bundle (.aab) ஐ உருவாக்குங்கள்

  1. உங்கள் module இன் build.gradle.kts இல் release கையொப்பமிடலை அமைக்குமாறு Cursor இன் ஏஜென்ட்டிடம் கேளுங்கள் (storeFile, storePassword, keyAlias மற்றும் keyPassword கொண்ட signingConfigs தொகுதி, release build type இல் அமைக்கப்படும்). கடவுச்சொற்களை git இல் சேர்க்காதீர்கள் (Android build ஆவணங்கள்: https://developer.android.com/build/building-cmdline).
  2. டெர்மினலில் ./gradlew bundleRelease ஐ இயக்குங்கள். Gradle bundle ஐ உருவாக்கி கையொப்பமிடும்; .aab பொதுவாக app/build/outputs/bundle/release/ இல் தோன்றும், ஆனால் உங்கள் சொந்த build வெளியீட்டைச் சரிபாருங்கள்.
  3. உங்களிடம் keystore இல்லையெனில் keytool மூலம் உருவாக்கி அதன் காப்புப்பிரதியை வைத்திருங்கள். முதல் release ஐப் பதிவேற்றும்போது Google Play App Signing வழங்கப்படும்.

2. Play Console இல் க்ளோஸ்டு டெஸ்டிங்கைத் தொடங்குங்கள்

  1. Test and release > Testing > Closed testing ஐத் திறந்து, பிறகு Create track (அல்லது Manage track) ஐத் தேர்ந்தெடுங்கள்.
  2. Create new release ஐக் கிளிக் செய்யுங்கள், .aab ஐப் பதிவேற்றுங்கள், release பெயரையும் குறிப்புகளையும் சேர்த்து, Save as draft, Next, பிறகு Start rollout (படிகள் https://support.google.com/googleplay/android-developer/answer/9859348 இலிருந்து).
  3. முதலில் Dashboard இல் உள்ள ஆப் அமைப்புப் பணிகளை முடியுங்கள்; இல்லையெனில் release பொத்தான் முடக்கப்பட்டே இருக்கும்.

3. உங்கள் 12 டெஸ்டர்களைப் பெறுங்கள்: முதலில் இலவசம், பிறகு கட்டணம்

  • இலவச வழி: உங்கள் போனில் https://testerexchange.com/earn ஐத் திறந்து, உங்களுக்குத் தரப்படும் ஆப்களைச் சோதியுங்கள். நீங்கள் சோதிக்கும் ஒவ்வொரு ஆப்பும் உங்கள் ஆப்புக்கு ஒரு டெஸ்டரைக் கொண்டுவருகிறது.
  • கட்டண வழி: ஒருமுறை கட்டணம் செலுத்துங்கள், டெஸ்டர்கள் தானாக ஒதுக்கப்படுவார்கள். தற்போதைய விலைகள் https://testerexchange.com/llms.txt இல் பட்டியலிடப்பட்டுள்ளன.
  • 12 க்குப் பதிலாக 15 டெஸ்டர்களைக் கேளுங்கள்; ஒருவர் விலகினாலும் Google இன் குறைந்தபட்சத்துக்குக் கீழே நீங்கள் செல்லாதிருக்க.

4. Tester Exchange ஐ Cursor உடன் இணையுங்கள் (விருப்பத்தேர்வு)

முதலில் https://testerexchange.com/api இல் ஒரு API key ஐ உருவாக்குங்கள். பிறகு இதை உங்கள் திட்டத்தில் உள்ள .cursor/mcp.json இல், அல்லது எல்லா இடங்களிலும் பயன்படுத்த ~/.cursor/mcp.json இல் வையுங்கள் (கோப்பு இடங்கள் Cursor இன் MCP ஆவணங்களிலிருந்து, https://cursor.com/docs/context/mcp). key commit ஆகாமல் இருக்க, முதலில் உங்கள் shell சூழலில் TESTER_EXCHANGE_KEY ஐ அமையுங்கள்:

{"mcpServers":{"tester-exchange":{"url":"https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp","headers":{"Authorization":"Bearer ${env:TESTER_EXCHANGE_KEY}"}}}}

Cursor, url மற்றும் headers புலங்களில் உள்ள ${env:NAME} ஐ மாற்றித் தீர்க்கிறது. சர்வர் ஏற்றப்படாவிட்டால், Output பேனலைத் திறந்து MCP Logs ஐத் தேர்ந்தெடுங்கள். சர்வர் OAuth இல்லாத Streamable HTTP மீதான சாதாரண MCP; பொதுக் கருவிகள் (about, pricing, platform_stats) key இல்லாமல் வேலை செய்யும்.

  • "பிரச்சார அறிக்கையை எடுத்து, உண்மையான எண்களை வைத்து என் production அணுகல் பதில்களை வரைவாக எழுது."

முக்கியக் கருவி get_testers: இது ஆப்பைச் சேர்க்கிறது, அதன் டெஸ்டைத் திறக்கிறது, மனிதர் மட்டுமே செய்யக்கூடிய படிகளைத் திருப்பித் தருகிறது, எ.கா. Play Console இல் டெஸ்டர்களின் Google Group ஐச் சேர்த்தல். ஏஜென்ட் உங்களுக்காகப் பணம் செலுத்தவோ Apply for production ஐக் கிளிக் செய்யவோ முடியாது.

MCP இல்லையா? HTTP API ஐப் பயன்படுத்துங்கள்

https://testerexchange.com/agents/ இல் பட்டியலிடப்பட்ட பொது apikey header உடனும் {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}} body உடனும் https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call க்கு POST செய்யுங்கள். ஸ்கீமா https://testerexchange.com/openapi.json இல் உள்ளது. மேலும் கருவிகள்: https://testerexchange.com/guide/ai-builders/.

அடிக்கடி கேட்கப்படும் கேள்விகள்

14 நாள் டெஸ்ட்டை Cursor எனக்காக முடிக்க முடியுமா?

இல்லை. அந்த 14 நாட்களுக்கு உண்மையான மனிதர்கள் தங்கள் சொந்த Android போன்களில் உங்கள் ஆப்பைப் பயன்படுத்த வேண்டும். Cursor ஆப்பை உருவாக்கி அமைப்பை நடத்த முடியும்.

Tester Exchange அதிகாரப்பூர்வ Cursor ஒருங்கிணைப்பா?

இல்லை. இது HTTP வழியே ரிமோட் MCP ஐ ஆதரிக்கும் எந்த கிளையன்ட்டுடனும் வேலை செய்யும் சுயாதீன சேவை; Cursor அதை ஆதரிக்கிறது.

AAB எங்கே செல்கிறது?

அதை Play Console இல் க்ளோஸ்டு டெஸ்டிங் release இல் பதிவேற்றுங்கள், பிறகு அந்த track இல் உங்கள் டெஸ்டர்களின் Google Group அல்லது மின்னஞ்சல் பட்டியலைச் சேர்க்கவும்.
