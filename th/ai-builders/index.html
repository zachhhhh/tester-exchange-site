Tester Exchange เปิด Tester Exchange

รับเทสเตอร์ Google Play 12 คนจากเครื่องมือเขียนโค้ด AI ของคุณ

อัปเดตเมื่อพฤศจิกายน 2026

ไม่ว่าคุณจะ vibe-code แอป Android หรือเขียนเองด้วยตัวแก้ไขที่มี AI ช่วย Google Play ก็ยังกำหนดให้มีเทสเตอร์ 12 คนที่เข้าร่วมต่อเนื่อง 14 วัน ก่อนที่บัญชีนักพัฒนาส่วนบุคคลใหม่จะเผยแพร่ขึ้น production ได้ หน้ารวมนี้แสดงคู่มือ Tester Exchange สำหรับเครื่องมือ AI แต่ละตัว: วิธีสร้าง Android App Bundle วิธีเริ่ม closed testing และวิธีหาเทสเตอร์ ทั้งแบบฟรีด้วยการทดสอบแอปอื่นก่อน หรือแบบจ่ายเงินที่เร็วกว่า แต่ละหน้ายังมีการตั้งค่าแบบคัดลอกไปวางได้ทันที เพื่อให้เครื่องมือ AI ของคุณควบคุม Tester Exchange ได้เอง

คนจริงเปิดแอปของคุณบนโทรศัพท์ของตัวเองนาน 14 วัน จ่ายครั้งเดียว หรือทดสอบแอปอื่นฟรีรับผู้ทดสอบ 12 คน

คู่มือแยกตามเครื่องมือ

เราเพิ่มเครื่องมืออื่น ๆ อย่างสม่ำเสมอ ตอนนี้มี:

  • Cursor: https://testerexchange.com/guide/get-12-testers-cursor/ - สร้าง AAB ด้วย Gradle แล้วเชื่อมต่อ Tester Exchange กับ Cursor ผ่าน .cursor/mcp.json
  • Claude Code: https://testerexchange.com/guide/get-12-testers-claude-code/ - build the AAB with Gradle, then add Tester Exchange with one claude mcp add command.
  • Windsurf: https://testerexchange.com/guide/get-12-testers-windsurf/ - build the AAB with Gradle, then add Tester Exchange to ~/.codeium/windsurf/mcp_config.json.

สองวิธีในการหาเทสเตอร์

  • ฟรี: ทดสอบแอปของนักพัฒนาคนอื่นที่ https://testerexchange.com/earn บนโทรศัพท์ของคุณ ทุกแอปที่คุณทดสอบจะนำเทสเตอร์หนึ่งคนมาให้แอปของคุณ จึงเติมครบ 12 ที่นั่งได้โดยไม่ต้องจ่ายเงิน
  • จ่ายเงินและเร็วกว่า: จ่ายครั้งเดียวเพื่อรับแพ็กเกจเทสเตอร์ ราคาปัจจุบันอยู่ที่ https://testerexchange.com/llms.txt แอปที่จ่ายเงินจะได้เทสเตอร์ก่อนใคร

สิ่งที่ Google กำหนด

ศูนย์ช่วยเหลือ Play Console ของ Google ระบุว่าบัญชีนักพัฒนาส่วนบุคคลที่สร้างหลังวันที่ 13 พฤศจิกายน 2023 ต้องทำ closed test โดยมีเทสเตอร์อย่างน้อย 12 คนเข้าร่วมต่อเนื่องอย่างน้อย 14 วัน จึงจะสมัครขอสิทธิ์เข้าถึง production ได้ (https://support.google.com/googleplay/android-developer/answer/14151465) ไม่มีเครื่องมือ AI ใดทำ 14 วันนี้แทนคุณได้ ต้องเป็นคนจริงบนโทรศัพท์จริงเท่านั้น

ให้เครื่องมือ AI ของคุณตั้งค่าให้

Tester Exchange มีเซิร์ฟเวอร์ MCP, HTTP API และเอเจนต์ A2A รายการไคลเอนต์และตัวอย่างการตั้งค่าทั้งหมดอยู่ที่ https://testerexchange.com/agents/ ส่วนคู่มือทั่วไปอยู่ที่ https://testerexchange.com/guide/automate-closed-testing-with-ai-agents/

คำถามที่พบบ่อย

ฉันต้องใช้เครื่องมือ AI เพื่อใช้ Tester Exchange หรือไม่?

ไม่จำเป็น เว็บไซต์ใช้งานได้ด้วยตัวเอง เซิร์ฟเวอร์ MCP และ API เป็นทางลัดเสริมสำหรับคนที่ทำงานกับเครื่องมือ AI อยู่แล้ว

เครื่องมือ AI จ่ายเงินซื้อเทสเตอร์ให้ได้ไหม?

ไม่ได้ มันส่งลิงก์ชำระเงินกลับมาได้ แต่การชำระเงินทำในเบราว์เซอร์ของคุณ ทางฟรีคือการทดสอบแอปอื่นที่ https://testerexchange.com/earn

Tester Exchange เป็นการเชื่อมต่ออย่างเป็นทางการของเครื่องมือเหล่านี้หรือไม่?

ไม่ใช่ เป็นบริการอิสระ หน้าเหล่านี้เพียงแสดงวิธีเชื่อมต่อการรองรับ MCP หรือ HTTP มาตรฐานของเครื่องมือเข้ากับ Tester Exchange
