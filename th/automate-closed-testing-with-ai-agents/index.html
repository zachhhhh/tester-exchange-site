Tester Exchange เปิด Tester Exchange

ทำการทดสอบแบบปิดบน Google Play อัตโนมัติด้วย AI Agent

อัปเดตพฤศจิกายน 2026

ถ้าคุณเขียนโค้ดร่วมกับ AI agent อยู่แล้ว คุณก็โยนงานจุกจิกส่วนใหญ่ของข้อกำหนดการทดสอบแบบปิดของ Google Play ให้มันทำได้เช่นกัน ทั้งการเพิ่มแอป การหาผู้ทดสอบ การตรวจความคืบหน้า และการดึงตัวเลขมาใส่แบบฟอร์มขอสิทธิ์ Production Tester Exchange มี MCP server, HTTP API ที่มี endpoint เดียว และ A2A agent card ไว้ใช้งานนี้ คู่มือนี้แสดงวิธีเชื่อมต่อ Claude Code, Claude Desktop, Cursor และไคลเอนต์อื่น ๆ สิ่งที่ควรสั่ง และส่วนที่ไม่มี agent ตัวไหนทำแทนคุณได้

คนจริงเปิดแอปของคุณบนโทรศัพท์ของตัวเองนาน 14 วัน จ่ายครั้งเดียว หรือทดสอบแอปอื่นฟรีรับผู้ทดสอบ 12 คน

สิ่งที่ agent ทำได้และทำไม่ได้

Google กำหนดให้บัญชีนักพัฒนาส่วนตัวที่สร้างหลังวันที่ 13 พฤศจิกายน 2023 ต้องทำการทดสอบแบบปิดโดยมีผู้ทดสอบอย่างน้อย 12 คนเข้าร่วมต่อเนื่อง 14 วันก่อนขอ Production งานรอบ ๆ เรื่องนี้ส่วนใหญ่เป็นงานประสานงาน ซึ่ง agent ทำได้ดี

  • agent ทำได้: เพิ่มแอปของคุณ เปิดแคมเปญหาผู้ทดสอบ ใช้เครดิตของคุณ ตรวจว่ามีผู้ทดสอบที่ใช้งานอยู่กี่คน หยุดหรือปิดแคมเปญ ดึงรายงานการใช้งานรายวัน และช่วยร่างคำตอบสำหรับขอสิทธิ์ Production จากรายงานนั้น
  • คนต้องทำเอง: เพิ่ม Google Group ของผู้ทดสอบเข้าแทร็กการทดสอบแบบปิดใน Play Console, เผยแพร่รุ่น, จ่ายเงินซื้อเครดิต (การชำระเงินเกิดในเบราว์เซอร์ของคนเสมอ) และกดขอสิทธิ์ Production
  • ไม่มีใครทำอัตโนมัติได้: การใช้งานจริง 14 วัน ซึ่งทำโดยคนจริงบนโทรศัพท์ Android ของตัวเอง และนั่นคือเจตนารมณ์ของกฎของ Google

1. สร้างโทเค็น

  1. ลงชื่อเข้าใช้ที่ https://testerexchange.com/api
  2. สร้างโทเค็นส่วนตัว โทเค็นจะขึ้นต้นด้วย tx_ คัดลอกไว้ทันทีและเก็บเหมือนรหัสผ่าน
  3. เพิกถอนโทเค็นได้ทุกเมื่อ โทเค็นใช้เครดิตกับแคมเปญได้ แต่ชำระเงิน ถอนเงิน หรือลบบัญชีของคุณไม่ได้

2. เชื่อมต่อ MCP server

MCP server ใช้ Streamable HTTP ที่ https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp ส่งโทเค็นของคุณใน header Authorization: Bearer tx_YOUR_TOKEN

Claude Code: รันคำสั่งนี้ครั้งเดียวในเทอร์มินัล

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code และไคลเอนต์อื่นที่ใช้ไฟล์ตั้งค่า JSON: เพิ่มเซิร์ฟเวอร์ชื่อ tester-exchange โดยกำหนด type เป็น http ใส่ URL ข้างต้น และเพิ่ม headers โดยตั้ง Authorization เป็น Bearer tx_YOUR_TOKEN ตำแหน่งไฟล์ตั้งค่าขึ้นอยู่กับไคลเอนต์ของคุณ ดูได้จากเอกสาร MCP ของไคลเอนต์นั้น

ไคลเอนต์ที่รับแค่ URL (ตัวเชื่อมต่อของ ChatGPT และเว็บบางตัว): เอกสารที่ https://testerexchange.com/agents/ มี URL รูปแบบสำหรับกรณีนี้ แม้ไม่มีโทเค็น เครื่องมือสาธารณะ (Tester Exchange คืออะไร ราคา สถิติแพลตฟอร์ม) ก็ยังใช้ได้

3. เครื่องมือเดียวที่ควรเริ่มด้วย: get_testers

คุณไม่ต้องเรียนรู้รายการเครื่องมือทั้งหมด เครื่องมือหลักคือ get_testers(package_name, name?) เรียกครั้งเดียวก็เพิ่มแอปของคุณ เปิดการทดสอบ ใช้เครดิตของคุณ และส่งคืนความคืบหน้าพร้อมขั้นตอนที่มีแต่คนทำได้ เช่น การเพิ่ม Google Group ใน Play Console เรียกซ้ำเมื่อไรก็ได้เพื่อตรวจความคืบหน้า

เครื่องมืออื่นครอบคลุมรายละเอียด ได้แก่ my_apps, campaign_report (ผู้ทดสอบ การใช้งานรายวัน ฟีดแบ็ก และข้อมูลสำหรับขอสิทธิ์ Production), add_testers, set_campaign_status (หยุด ทำต่อ หรือปิด เครดิตที่ไม่ได้ใช้จะกลับเข้ายอดคงเหลือ), share_kit และ buy_credits_links ซึ่งส่งลิงก์ชำระเงินให้คนเป็นผู้จ่าย

พรอมต์ที่ได้ผล

  • "Get 15 testers for com.example.app and tell me what I need to do in Play Console."
  • "Check my Tester Exchange campaign for com.example.app. How many testers were active each day this week?"
  • "Pull the campaign report and draft my production access answers. Use only the real numbers."
  • "Close the campaign for com.example.app now that production access is approved."

ขอผู้ทดสอบ 15 คนแทนที่จะเป็น 12 คน เพื่อไม่ให้คนที่ออกไปทำให้คุณต่ำกว่าขั้นต่ำของ Google

HTTP API สำหรับสคริปต์และ CI

ถ้าเครื่องมือของคุณไม่รองรับ MCP ให้ใช้ HTTP endpoint: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call เนื้อหาเป็น JSON ที่มี p_token (โทเค็น tx_ ของคุณ), p_action (เช่น help, my_apps หรือ start_campaign) และ p_args (เช่น package_name และจำนวนผู้ทดสอบ) ส่ง header apikey สาธารณะตามที่แสดงในเอกสาร

เรียก action ชื่อ help ก่อน มันจะส่งคืน action ทั้งหมดพร้อมอาร์กิวเมนต์ สคีมาฉบับเต็มอยู่ที่ https://testerexchange.com/openapi.json ใช้ได้กับ action ของ custom GPT บน ChatGPT และเครื่องมือ OpenAPI อื่น ๆ

A2A agent card

สำหรับการตั้งค่าแบบ agent ต่อ agent Tester Exchange เผยแพร่ A2A agent card ที่ https://testerexchange.com/.well-known/agent-card.json ตัวจัดการที่รองรับโปรโตคอล A2A ค้นพบได้ว่า agent นี้ให้บริการอะไรและเรียกใช้อย่างไร ใช้โทเค็น tx_ ตัวเดียวกันสำหรับทุกอย่างที่ผูกกับบัญชีของคุณ

ตัวอย่างการทำงานครบวงจร ตั้งแต่ต้นจนจบ

  1. คุณอัปโหลดไฟล์ .aab แรกไปยังแทร็กการทดสอบแบบปิดใน Play Console
  2. agent ของคุณเรียก get_testers ด้วย package name ของคุณ แล้วบอกให้คุณเพิ่ม testerexchange-testers@googlegroups.com ในส่วน Google Groups ของแทร็กการทดสอบแบบปิด
  3. คุณเพิ่มกลุ่ม บันทึก และตรวจว่าเผยแพร่รุ่นแล้ว
  4. ถ้าเครดิตไม่พอ agent จะส่งลิงก์ชำระเงินให้ คุณจ่าย ($12.99 สำหรับ 12 คน, $14.99 สำหรับ 15 คน, $22.99 สำหรับ 25 คน) หรือหาเครดิตฟรีด้วยการทดสอบแอปอื่นที่ https://testerexchange.com/earn
  5. ผู้ทดสอบตัวจริงติดตั้งและใช้แอปของคุณเป็นเวลา 14 วัน agent ของคุณตรวจความคืบหน้าทุกวันและเตือนคุณถ้าผู้ทดสอบที่ใช้งานอยู่ลดลง
  6. วันที่ 15 agent ดึงรายงานแคมเปญและร่างคำตอบสำหรับขอสิทธิ์ Production คุณตรวจทาน แล้วกดขอสิทธิ์ Production

ข้อควรระวังด้านความปลอดภัย

  • อย่าเก็บโทเค็นใน git ให้เก็บไว้ในที่เก็บความลับของไคลเอนต์หรือในตัวแปรสภาพแวดล้อม
  • ฝั่งเราเก็บโทเค็นเป็นค่าแฮชเท่านั้น และจำกัดไว้ที่ 10 โทเค็นต่อบัญชี เพิกถอนโทเค็นที่ไม่ได้ใช้แล้ว
  • อ่านสิ่งที่ agent เขียนในแบบฟอร์ม Production ของคุณก่อนส่ง Google ให้คุณอธิบายการทดสอบตามความจริง

คำถามที่พบบ่อย

AI agent ทำการทดสอบ 14 วันแทนฉันได้ไหม?

ไม่ได้ การทดสอบ 14 วันต้องใช้คนจริงที่ใช้แอปของคุณบนโทรศัพท์ของตัวเอง agent จัดการการตั้งค่า การติดตามผล และการรายงาน

agent จ่ายเงินซื้อผู้ทดสอบได้ไหม?

ไม่ได้ agent ส่งลิงก์ชำระเงินให้ได้ แต่การชำระเงินเกิดในเบราว์เซอร์ของคนเสมอ

ไคลเอนต์ไหนใช้กับ MCP server ได้บ้าง?

ไคลเอนต์ใดก็ตามที่รองรับ remote MCP ผ่าน Streamable HTTP พร้อม header กำหนดเอง รวมถึง Claude Code, Claude Desktop, Cursor และ VS Code ไคลเอนต์อื่นใช้ HTTP API ได้

ขอโทเค็นได้ที่ไหน?

ที่ https://testerexchange.com/api หลังลงชื่อเข้าใช้ โทเค็นขึ้นต้นด้วย tx_ และเพิกถอนได้ทุกเมื่อ

agent เปลี่ยนแปลงอะไรใน Play Console ของฉันไหม?

ไม่ agent เข้าถึง Play Console ของคุณไม่ได้ มันแค่บอกขั้นตอนที่คุณต้องทำเอง
