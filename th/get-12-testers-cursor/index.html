Tester Exchange เปิด Tester Exchange

สร้างแอป Android ด้วย Cursor แล้วใช่ไหม? รับเทสเตอร์ 12 คนเป็นเวลา 14 วัน

อัปเดตเมื่อพฤศจิกายน 2026

Cursor เขียนและสร้างแอป Android ของคุณได้ แต่หาเทสเตอร์ตัวจริง 12 คนที่ Google Play กำหนดไม่ได้ หากบัญชีนักพัฒนาส่วนบุคคลของคุณสร้างหลังวันที่ 13 พฤศจิกายน 2023 คุณต้องทำ closed test โดยมีเทสเตอร์อย่างน้อย 12 คนเข้าร่วมต่อเนื่อง 14 วัน ก่อนสมัครขึ้น production คู่มือนี้ครอบคลุมการสร้างบันเดิล การเริ่ม closed testing การหาเทสเตอร์ (ฟรีก่อน จ่ายเงินทีหลัง) และการเชื่อมต่อ Tester Exchange กับ Cursor เพื่อให้เอเจนต์จัดการงานเอกสารให้

คนจริงเปิดแอปของคุณบนโทรศัพท์ของตัวเองนาน 14 วัน จ่ายครั้งเดียว หรือทดสอบแอปอื่นฟรีรับผู้ทดสอบ 12 คน

1. สร้างบันเดิลรุ่นเผยแพร่ (.aab)

  1. ให้เอเจนต์ของ Cursor ตั้งค่าการเซ็นชื่อรุ่น release ใน build.gradle.kts ของโมดูล (บล็อก signingConfigs ที่มี storeFile, storePassword, keyAlias และ keyPassword กำหนดให้กับ build type แบบ release) อย่าเก็บรหัสผ่านไว้ใน git (เอกสารการ build ของ Android: https://developer.android.com/build/building-cmdline)
  2. รัน ./gradlew bundleRelease ในเทอร์มินัล Gradle จะ build และเซ็นบันเดิลให้ ไฟล์ .aab มักอยู่ใต้ app/build/outputs/bundle/release/ แต่ควรตรวจผลลัพธ์การ build ของคุณเอง
  3. สร้าง keystore ด้วย keytool หากยังไม่มี และสำรองข้อมูลไว้ Google Play App Signing จะถูกเสนอให้เมื่อคุณอัปโหลดรุ่นแรก

2. เริ่ม closed testing ใน Play Console

  1. เปิด Test and release > Testing > Closed testing แล้วเลือก Create track (หรือ Manage track)
  2. คลิก Create new release อัปโหลดไฟล์ .aab ใส่ชื่อรุ่นและบันทึกประจำรุ่น แล้ว Save as draft, Next และ Start rollout (ขั้นตอนจาก https://support.google.com/googleplay/android-developer/answer/9859348)
  3. ทำงานตั้งค่าแอปบน Dashboard ให้เสร็จก่อน ไม่เช่นนั้นปุ่มเผยแพร่รุ่นจะยังกดไม่ได้

3. รับเทสเตอร์ 12 คน: ฟรีก่อน จ่ายเงินทีหลัง

  • ทางฟรี: เปิด https://testerexchange.com/earn บนโทรศัพท์แล้วทดสอบแอปที่ได้รับมอบหมาย ทุกแอปที่คุณทดสอบจะนำเทสเตอร์หนึ่งคนมาให้แอปของคุณ
  • ทางจ่ายเงิน: จ่ายครั้งเดียวแล้วระบบจะกำหนดเทสเตอร์ให้อัตโนมัติ ราคาปัจจุบันอยู่ที่ https://testerexchange.com/llms.txt
  • ขอเทสเตอร์ 15 คนแทนที่จะเป็น 12 คน เพื่อไม่ให้มีคนหลุดแล้วทำให้คุณต่ำกว่าขั้นต่ำของ Google

4. เชื่อมต่อ Tester Exchange กับ Cursor (ไม่บังคับ)

ก่อนอื่นให้สร้างคีย์ API ที่ https://testerexchange.com/api จากนั้นใส่ข้อความนี้ใน .cursor/mcp.json ในโปรเจกต์ของคุณ หรือใน ~/.cursor/mcp.json เพื่อใช้ทุกโปรเจกต์ (ตำแหน่งไฟล์ตามเอกสาร MCP ของ Cursor, https://cursor.com/docs/context/mcp) ตั้งค่า TESTER_EXCHANGE_KEY ในตัวแปรสภาพแวดล้อมของ shell ก่อน เพื่อไม่ให้คีย์ถูก commit:

{"mcpServers":{"tester-exchange":{"url":"https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp","headers":{"Authorization":"Bearer ${env:TESTER_EXCHANGE_KEY}"}}}}

Cursor จะแทนค่า ${env:NAME} ในฟิลด์ url และ headers หากเซิร์ฟเวอร์โหลดไม่ขึ้น ให้เปิดแผง Output แล้วเลือก MCP Logs เซิร์ฟเวอร์เป็น MCP ธรรมดาผ่าน Streamable HTTP โดยไม่ใช้ OAuth เครื่องมือสาธารณะ (about, pricing, platform_stats) ใช้ได้โดยไม่ต้องมีคีย์

5. สั่งงานเอเจนต์

  • “ใช้ Tester Exchange รับเทสเตอร์ 15 คนให้ com.example.app และบอกฉันว่าต้องทำอะไรใน Play Console”
  • “ตรวจแคมเปญ Tester Exchange ของฉันสำหรับ com.example.app และบอกว่าเมื่อวานมีเทสเตอร์ที่ใช้งานอยู่กี่คน”
  • “ดึงรายงานแคมเปญ แล้วร่างคำตอบสำหรับการขอสิทธิ์เข้าถึง production จากตัวเลขจริง”

เครื่องมือหลักคือ get_testers: มันเพิ่มแอป เปิดการทดสอบ และส่งคืนขั้นตอนที่มีแต่คนเท่านั้นที่ทำได้ เช่น การเพิ่ม Google Group ของเทสเตอร์ใน Play Console เอเจนต์ไม่สามารถจ่ายเงินหรือกด Apply for production แทนคุณได้

ไม่ใช้ MCP? ใช้ HTTP API

ส่ง POST ไปที่ https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call พร้อมส่วนหัว apikey สาธารณะที่ระบุไว้ที่ https://testerexchange.com/agents/ และเนื้อหา {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}} สคีมาอยู่ที่ https://testerexchange.com/openapi.json เครื่องมืออื่น ๆ: https://testerexchange.com/guide/ai-builders/

คำถามที่พบบ่อย

Cursor ทำการทดสอบ 14 วันแทนฉันได้ไหม?

ไม่ได้ 14 วันนั้นต้องมีคนจริงใช้แอปของคุณบนโทรศัพท์ Android ของตัวเอง Cursor ช่วยสร้างแอปและควบคุมการตั้งค่าได้

Tester Exchange เป็นการเชื่อมต่ออย่างเป็นทางการของ Cursor หรือไม่?

ไม่ใช่ เป็นบริการอิสระที่ใช้ได้กับไคลเอนต์ใดก็ตามที่รองรับ MCP ระยะไกลผ่าน HTTP ซึ่ง Cursor รองรับ

AAB อัปโหลดที่ไหน?

อัปโหลดไปยังรุ่น closed testing ใน Play Console จากนั้นเพิ่ม Google Group หรือรายชื่ออีเมลของเทสเตอร์ในแทร็กนั้น

มีวิธีรับเทสเตอร์ 12 คนแบบฟรีไหม?
