1. បង្កើត release bundle (.aab)

  1. ស្នើឱ្យភ្នាក់ងាររបស់ Claude Code កំណត់រចនាសម្ព័ន្ធការចុះហត្ថលេខា release នៅក្នុង build.gradle.kts របស់ម៉ូឌុលអ្នក (ប្លុក signingConfigs ដែលមាន storeFile, storePassword, keyAlias និង keyPassword កំណត់លើ release build type)។ កុំទុកពាក្យសម្ងាត់ក្នុង git (ឯកសារ build របស់ Android៖ https://developer.android.com/build/building-cmdline)។
  2. ដំណើរការ ./gradlew bundleRelease ក្នុង terminal។ Gradle បង្កើត និងចុះហត្ថលេខា bundle ហើយ .aab ជាធម្មតាលេចឡើងក្រោម app/build/outputs/bundle/release/ ប៉ុន្តែសូមពិនិត្យលទ្ធផល build របស់អ្នកផ្ទាល់។
  3. បង្កើត keystore ដោយ keytool ប្រសិនបើអ្នកមិនទាន់មាន ហើយបម្រុងទុក។ Google Play App Signing ត្រូវបានផ្តល់ជូនពេលអ្នកបង្ហោះ release ដំបូងរបស់អ្នក។

2. ចាប់ផ្តើមការសាកល្បងបិទក្នុង Play Console

  1. បើក Test and release > Testing > Closed testing បន្ទាប់មក Create track (ឬ Manage track)។
  2. ចុច Create new release បង្ហោះ .aab បន្ថែមឈ្មោះ release និងកំណត់ចំណាំ Save as draft, Next បន្ទាប់មក Start rollout (ជំហានពី https://support.google.com/googleplay/android-developer/answer/9859348)។
  3. បំពេញការងារដំឡើងកម្មវិធីនៅលើ Dashboard ជាមុន បើមិនដូច្នោះទេ ប៊ូតុង release នៅតែបិទ។

3. ទទួលបានអ្នកសាកល្បង 12 នាក់របស់អ្នក៖ ឥតគិតថ្លៃមុន បង់ប្រាក់ក្រោយ

  • ផ្លូវឥតគិតថ្លៃ៖ បើក https://testerexchange.com/earn លើទូរស័ព្ទរបស់អ្នក ហើយសាកល្បងកម្មវិធីដែលបានផ្តល់ឱ្យ។ កម្មវិធីនីមួយៗដែលអ្នកសាកល្បងនាំអ្នកសាកល្បងម្នាក់មកកម្មវិធីរបស់អ្នក។
  • ផ្លូវបង់ប្រាក់៖ បង់ម្តង ហើយអ្នកសាកល្បងត្រូវបានចាត់តាំងដោយស្វ័យប្រវត្តិ។ តម្លៃបច្ចុប្បន្នមានបញ្ជីនៅ https://testerexchange.com/llms.txt។
  • ស្នើអ្នកសាកល្បង 15 នាក់ជំនួស 12 ដើម្បីកុំឱ្យអ្នកដែលចាកចេញម្នាក់ធ្វើឱ្យអ្នកនៅក្រោមអប្បបរមារបស់ Google។

4. ភ្ជាប់ Tester Exchange ទៅ Claude Code (ស្រេចចិត្ត)

ដំបូង សូមបង្កើត API key នៅ https://testerexchange.com/api។ បន្ទាប់មក រត់ពាក្យបញ្ជានេះម្តងក្នុង terminal របស់អ្នក ដោយជំនួស tx_YOUR_TOKEN ដោយ key របស់អ្នក (ពាក្យបញ្ជាគឺជាពាក្យបញ្ជាដែលបានចុះបញ្ជីនៅ https://testerexchange.com/agents/)៖

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

ម៉ាស៊ីនមេគឺជា MCP ធម្មតាតាម Streamable HTTP ដោយគ្មាន OAuth; ឧបករណ៍សាធារណៈ (about, pricing, platform_stats) ដំណើរការដោយមិនត្រូវការ key។ សូមកុំដាក់ key ក្នុង git ឬក្នុងឯកសារ config ដែលចែករំលែក។
