  • រយៈពេល session៖ មនុស្សនឹងមិនលេង level 20 នាទីរាល់ថ្ងៃរយៈពេលពីរសប្តាហ៍ទេ។
  • ខ្វះមាតិកា៖ vertical slice ដែលមាន level តែមួយអស់អ្វីធ្វើនៅថ្ងៃទីបី។

ការកំណត់ build ដែលត្រូវពិនិត្យមុនគេ

  • Unity៖ បង្កើត Android App Bundle (.aab) ប្រើ IL2CPP ជាមួយ ARM64 បើក (Google Play តម្រូវឱ្យគាំទ្រ 64-bit) ហើយកំណត់ API level អប្បបរមាដែលមិនដកទូរសព្ទច្រើនជាងចាំបាច់។ ប្រសិនបើ build របស់អ្នកធំ សូមប្រើ Play Asset Delivery ជាជាងការទាញយកដ៏ធំតែមួយ។
  • Unreal Engine៖ package សម្រាប់ Android ជា App Bundle ជាមួយ arm64 ពិនិត្យកម្រិត SDK គោលដៅ និងអប្បបរមានៅក្នុង Project Settings ហើយរក្សាការទាញយកដំបូងឱ្យតូចដោយផ្លាស់ប្តូរមាតិកាស្រេចចិត្តទៅក្នុង asset pack។
  • Godot៖ ប្រើ Android export template ជាមួយ Gradle build បើក ហើយ export ជា AAB។ ត្រូវប្រាកដថា arm64-v8a រួមបញ្ចូល ហើយសាកល្បង renderer នៅលើទូរសព្ទកម្រិតទាប ព្រោះឧបករណ៍មួយចំនួនដោះស្រាយ Compatibility renderer បានល្អជាង Forward+ ឬ Mobile។
  • គ្រប់ engine ទាំងអស់៖ កំណត់គោលដៅ API level ដែល Google Play តម្រូវសម្រាប់កម្មវិធីថ្មីបច្ចុប្បន្ន ហើយចុះហត្ថលេខាជាមួយ Play App Signing។

  • ថ្ងៃទី 8 ដល់ 11៖ សាកល្បង build ថ្មីដែលមានការជួសជុល លេង level ម្តងទៀតដើម្បីមើលថាវាមានអារម្មណ៍ល្អជាងឬអត់។
