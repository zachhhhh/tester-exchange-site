ជំហានទី 1៖ export release build ដែល builder របស់អ្នកអាចចុះហត្ថលេខាបាន

  1. Export Android App Bundle (.aab)។ Google Play ត្រូវការ .aab សម្រាប់កម្មវិធីថ្មី។ Builder និង engine ភាគច្រើនអាច export វាបាន ប្រសិនបើរបស់អ្នកផ្តល់តែ APK សូមពិនិត្យឯកសាររបស់វាសម្រាប់ជម្រើស App Bundle។
  2. រក្សា signing key របស់អ្នកឱ្យមានសុវត្ថិភាព។ Builder ដូចជា App Inventor និង Kodular បង្កើត keystore ឱ្យអ្នក។ ទាញយកច្បាប់ចម្លងបម្រុងទុករបស់វា។ អ្នកត្រូវការ key ដូចគ្នាសម្រាប់រាល់ update។
  3. ជ្រើសរើស package name ដោយប្រុងប្រយ័ត្ន។ វាមិនអាចផ្លាស់ប្តូរបានទេនៅពេលកម្មវិធីនៅលើ Google Play។
  4. បំពេញតាម target API level។ Google Play ទទួលយកតែ build ដែល target Android version ថ្មីៗប៉ុណ្ណោះ។ ប្រសិនបើការ upload ត្រូវបានបដិសេធដោយសារ target API level សូម update builder ឬ engine របស់អ្នក ហើយ export ម្តងទៀត។

ជំហានទី 2៖ រៀបចំ closed test

  1. នៅក្នុង Play Console បើក Test and release → Testing → Closed testing ហើយបង្កើត track។
  2. បន្ថែម tester ដោយប្រើ Google Group ជាជាងបញ្ជីអ៊ីមែល៖ tester ចូលរួមក្រុមដោយខ្លួនឯង ហើយអ្នកមិនចាំបាច់បិទភ្ជាប់អ៊ីមែលម្តងទៀតទេ។
  3. Upload .aab របស់អ្នកទៅ closed track បន្ថែម release notes ហើយផ្ញើវាទៅពិនិត្យ។
  4. ចម្លង តំណ opt-in។ Tester ចូលរួមក្រុម បើកតំណ opt-in ចុច "Become a tester" បន្ទាប់មកដំឡើងពី Google Play។
