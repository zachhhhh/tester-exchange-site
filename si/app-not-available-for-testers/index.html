Google කියන්නේ internal testing වලට opt-in වූ පරිශීලකයන්ට open සහ closed testing සඳහා සුදුසුකම් නැති බවයි. Tester කලින් ඔබේ internal test එකට එක්වී සිටියේ නම්, ඔහු මුලින් එයින් ඉවත් විය යුතුයි (internal opt-in link එක විවෘත කර වැඩසටහනෙන් ඉවත් වන්න), පසුව closed test එකට opt-in වන්න.

8. Play Store පෙන්වන්නේ පැරණි තත්ත්වයක්

ඉහත සියල්ල නිවැරදි නම්, tester ට Play Store වසා, Android Settings හි එහි cache එක හිස් කර, නැවත උත්සාහ කරන්න කියන්න. වෙනත් ඇප් එකක built-in browser එක තුළ නොව, දුරකථනයේ Chrome තුළ opt-in link එක විවෘත කිරීමත් උපකාරී වේ.

ඔබ මෙය විසඳන අතරතුර ඔබේ දින 14 ආරක්ෂා කරගන්න

අවශ්‍යතාවය ගණන් කරන්නේ දින 14ක් අඛණ්ඩව opt-in වී සිටින testers 12ක් නිසා, ඇතුළු විය නොහැකි testers ගෙන් ප්‍රයෝජනයක් නැත. එක් tester කෙනෙක් හිරවුණත් මුළු test එකම ප්‍රමාද නොවීමට අමතර දෙතුන් දෙනෙක් බඳවාගන්න (15ක් හොඳ ඉලක්කයකි). Tester Exchange නතර වන testers ආදේශ කරයි, අපගේ testers ට ඔබේ ඇප් එක install කළ නොහැකි නම් Play Console හි ගත යුතු නිවැරදි පියවර එහි setup තිරය ඔබට කියයි.

Publish කර කොපමණ කලකට පසු testers ට install කළ හැකිද?

Google කියන්නේ පළමු test link එක ක්‍රියාත්මක වීමට පැය කිහිපයක් ගත විය හැකි බවයි.

Install කළ නොහැකි testers 12 ට ගණන් වෙනවාද?

ගණන් වන්නේ opt-in වූ testers පමණි. කිසිදා opt-in වීමට නොහැකි වූ කෙනෙක් ඔබේ දින 14 ට උදව් නොකරයි.

Testers ට Google Play සෙවීමෙන් මගේ ඇප් එක සොයාගත හැකිද?

නැහැ. Closed tests සෙවුමේ නොපෙනේ. Opt-in link එක හෝ Play Store link එක බෙදාගන්න.

Testers එක් කළ පසු නැවත publish කළ යුතුද?
