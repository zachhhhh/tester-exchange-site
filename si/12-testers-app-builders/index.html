ඔබ ඇප් එක හැදුවේ කුමන tool එකෙන්ද යන්න වැදගත් නැහැ. ඔබේ Google Play developer ගිණුම නව පුද්ගලික ගිණුමක් නම්, production වෙත publish කිරීමට පෙර අවම වශයෙන් testers 12ක් සමඟ දින 14ක closed test එකක් අවශ්‍යයි. Builder සහ game engine භාවිත කරන්නන් පැටලෙන කොටස් සහ testers නොමිලේ සොයාගන්නා ක්‍රමයක් මෙම මාර්ගෝපදේශයේ ඇත.

සැබෑ මිනිසුන් දින 14ක් තමන්ගේම දුරකථනවල ඔබේ ඇප් එක විවෘත කරයි. එක් වරක් ගෙවන්න, නැත්නම් වෙනත් ඇප් නොමිලේ ටෙස්ට් කරන්න.Testers 12ක් ලබාගන්න

සෑම tool එකකටම නීතිය එකමයි

Google පරීක්ෂා කරන්නේ ඔබේ developer ගිණුමයි, ඔබේ tool එක නොවේ. MIT App Inventor, Kodular, Niotron, Sketchware, Thunkable, FlutterFlow, Flutter, React Native, Expo, Unity හෝ Godot වලින් සෑදූ සියලු ඇප් එකම closed test එක හරහා යයි.

ඔබ 2023 නොවැම්බර් 13ට පසු පුද්ගලික developer ගිණුමක් සෑදුවා නම්, production access සඳහා අයදුම් කිරීමට පෙර අවම වශයෙන් testers 12ක් අඛණ්ඩව දින 14ක් opt-in වී සිටිය යුතුයි. සංවිධාන ගිණුම්වලට මෙම අවශ්‍යතාව නැහැ.

පියවර 1: ඔබේ builder එකට sign කළ හැකි release build එකක් export කරන්න

  1. Android App Bundle (.aab) එකක් export කරන්න. නව ඇප් සඳහා Google Play ට .aab එකක් අවශ්‍යයි. බොහෝ builders සහ engines වලට එය export කළ හැකියි; ඔබේ එක APK පමණක් දෙනවා නම්, App Bundle විකල්පය සඳහා එහි documentation බලන්න.
  2. ඔබේ signing key එක ආරක්ෂිතව තබාගන්න. App Inventor සහ Kodular වැනි builders ඔබ වෙනුවෙන් keystore එකක් සාදයි. එහි backup එකක් බාගන්න. සෑම update එකකටම ඔබට එකම key එක අවශ්‍යයි.
  3. Package name එක පරිස්සමෙන් තෝරන්න. ඇප් එක Google Play වෙත ගිය පසු එය කිසිදා වෙනස් කළ නොහැකියි.
  4. Target API level එකට ගැළපෙන්න. Google Play පිළිගන්නේ මෑත Android version එකක් target කරන builds පමණයි. Target API level නිසා upload එක ප්‍රතික්ෂේප වුණොත්, ඔබේ builder හෝ engine එක update කර නැවත export කරන්න.

පියවර 2: closed test එක සකසන්න

  1. Play Console හි Test and release → Testing → Closed testing විවෘත කර track එකක් සාදන්න.
  2. Email list එකක් වෙනුවට Google Group එකකින් testers එකතු කරන්න: testers තනිවම group එකට එක්වන අතර, ඔබට නැවත emails paste කිරීමට සිදු නොවේ.
  3. ඔබේ .aab එක closed track එකට upload කර, release notes එකතු කර, සමාලෝචනයට යවන්න.
  4. Opt-in link එක copy කරන්න. Testers group එකට එක්වී, opt-in link එක විවෘත කර, "Become a tester" තට්ටු කර, ඉන්පසු Google Play වෙතින් install කරයි.

පියවර 3: දින 14ක් රැඳී සිටින testers 12ක් සොයාගන්න

ලැයිස්තුවක නම් දොළහක් ප්‍රමාණවත් නැහැ. Testers ඇත්තටම ඔබේ ඇප් එක භාවිත කළාද කියා Google සමාලෝචනය කරන අතර, දින 14 ගණන් වන්නේ අවම වශයෙන් testers 12ක් opt-in වී සිටින තාක් පමණයි. කෙනෙක් දෙන්නෙක් ඉවත් වුවත් ගණන් කිරීම නතර නොවීමට 14 හෝ 15 දෙනෙක් බඳවාගන්න.

  • Android දුරකථන ඇති මිතුරන් සහ පවුලේ අය: නොමිලේ, නමුත් ඔවුන් බොහෝ විට දින කිහිපයකට පසු ඇප් එක විවෘත කිරීම නවත්වනවා.
  • Builder ප්‍රජාවන් සහ forums: අනෙක් builders නීතිය තේරුම් ගන්නා අතර, බොහෝ දෙනා tests swap කරනවා.
  • Test exchange එකක්: Tester Exchange හි ඔබේ දුරකථනයට ටෙස්ට් කිරීමට වෙනත් developersලාගේ ඇප් ලැබේ, දිනකට විනාඩියක්, ඔබ ටෙස්ට් කරන සෑම එකක්ම ඔබේ ඇප් එකට tester කෙනෙක් ගෙනේ.

පියවර 4: testers සක්‍රීයව තබාගෙන update එකක් නිකුත් කරන්න

  • ඇප් එක විවෘත කිරීමට හේතුවක් ලැබෙන ලෙස testersලාට දිනකට එක් කුඩා කාර්යයක් දෙන්න.
  • දින 7 පමණ වන විට නිවැරදි කිරීම් සහිත නව build එකක් upload කර වෙනස් වූ දේ කියන්න. Builders මෙය ඉක්මන් කරයි: export කරන්න, එකම closed track එකට upload කරන්න, හරි.
  • ලිඛිත feedback ඉල්ලා, හැකි දේ නිවැරදි කරන්න. එය production ප්‍රශ්නවලට සැබෑ පිළිතුරුද ලබාදෙයි.

පියවර 5: production සඳහා අයදුම් කරන්න

දින 14කට පසු, Play Console dashboard එකේ production access සඳහා අයදුම් කරන්න. ඔබ testers බඳවාගත් ආකාරය, ඔවුන් ඇප් එක භාවිත කළ ආකාරය සහ ඔවුන්ගේ feedback අනුව ඔබ වෙනස් කළ දේ Google අහනවා. ඔබේ ටෙස්ට් එකේ සැබෑ සංඛ්‍යා සමඟ පිළිතුරු දෙන්න. Google සාමාන්‍යයෙන් සතියක් පමණ ඇතුළත පිළිතුරු දෙයි.

නිතර අසන ප්‍රශ්න

App Inventor හෝ Kodular වලින් සෑදූ ඇප්වලටත් testers 12ක් අවශ්‍යද?

ඔව්. අවශ්‍යතාව රඳා පවතින්නේ ඔබේ developer ගිණුම මතයි, tool එක මත නොවේ. ඇප් එක කුමකින් හැදුවත්, නව පුද්ගලික ගිණුම්වලට දින 14ක් opt-in වී සිටින testers 12ක් අවශ්‍යයි.

මගේ testersලාට ඒ වෙනුවට මා එවන APK එකක් install කළ හැකිද?
