Automatizace uzavřeného testování na Google Play pomocí AI agentů

Aktualizováno v listopadu 2026

Pokud už kód vydáváte s pomocí AI agenta, můžete mu předat i většinu starostí kolem požadavku Google Play na uzavřené testování: zadání aplikace, nábor testerů, kontrolu průběhu a získání čísel pro formulář o přístupu do produkce. Tester Exchange k tomu nabízí MCP server, HTTP API s jediným koncovým bodem a kartu A2A agenta. Tento návod ukazuje, jak připojit Claude Code, Claude Desktop, Cursor a další klienty, co se ptát a které části za vás žádný agent neudělá.

Co agent umí a neumí

Google vyžaduje, aby osobní vývojářské účty založené po 13. listopadu 2023 před žádostí o produkci provedly uzavřený test s alespoň 12 testery přihlášenými 14 dní v kuse. Většina práce kolem toho je koordinace, kterou agenti zvládají dobře.

  • Agent umí: přidat vaši aplikaci, otevřít kampaň s testery, uplatnit vaše kredity, zjistit, kolik testerů je aktivních, kampaň pozastavit nebo ukončit, stáhnout denní report aktivity a pomoci z něj sestavit odpovědi do formuláře o přístupu do produkce.
  • Člověk musí: přidat Google Group testerů k uzavřené stopě v Play Console, publikovat vydání, zaplatit kredity (platba vždy probíhá v prohlížeči člověka) a kliknout na Požádat o produkci.
  • Nikdo nemůže zautomatizovat: 14 dní skutečného používání. To dělají skuteční lidé na vlastních telefonech s Androidem, což je celý smysl pravidla Googlu.

1. Vytvořte token

  1. Přihlaste se na https://testerexchange.com/api.
  2. Vytvořte osobní token. Začíná na tx_. Hned ho zkopírujte a uložte jako heslo.
  3. Tokeny lze kdykoli zrušit. Token může utrácet kredity na kampaně, ale nemůže platit, vybírat peníze ani smazat váš účet.

2. Připojte MCP server

MCP server používá Streamable HTTP na adrese https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp. Token posílejte v hlavičce Authorization: Bearer tx_YOUR_TOKEN.

Claude Code: spusťte jednou v terminálu.

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code a další klienty s JSON konfigurací: přidejte server s názvem tester-exchange, typem http, výše uvedenou adresou URL a položkou headers s hodnotou Authorization nastavenou na Bearer tx_YOUR_TOKEN. Přesné umístění konfiguračního souboru závisí na klientovi; najdete ho v jeho dokumentaci k MCP.

Klienti, které přijímají jen URL (některé konektory ChatGPT a webové konektory): dokumentace na https://testerexchange.com/agents/ pro ně uvádí variantu s URL. Bez tokenu fungují veřejné nástroje (co je Tester Exchange, ceník, statistiky platformy).

3. Jeden nástroj, od kterého začít: get_testers

Nemusíte se učit celý seznam nástrojů. Hlavní nástroj je get_testers(package_name, name?). Jedno volání přidá vaši aplikaci, otevře její test, uplatní vaše kredity a vrátí průběh i kroky, které může udělat jen člověk, například přidání Google Group v Play Console. Kdykoli ho zavolejte znovu a zkontrolujte průběh.

Podrobnosti pokrývají další nástroje: my_apps, campaign_report (testeři, denní aktivita, zpětná vazba a data pro přístup do produkce), add_testers, set_campaign_status (pozastavení, obnovení nebo ukončení; nevyužité kredity se vrátí na zůstatek), share_kit a buy_credits_links, který vrací odkazy k platbě pro člověka.

Zadání, která fungují

  • „Zajisti 15 testerů pro com.example.app a řekni mi, co musím udělat v Play Console.“
  • „Zkontroluj moji kampaň na Tester Exchange pro com.example.app. Kolik testerů bylo tento týden každý den aktivních?“
  • „Stáhni report kampaně a navrhni moje odpovědi pro přístup do produkce. Použij jen skutečná čísla.“
  • „Ukonči kampaň pro com.example.app, teď když je přístup do produkce schválen.“

Žádejte 15 testerů místo 12, aby vás jeden odpadlý nedostal pod minimum Googlu.

HTTP API pro skripty a CI

Pokud váš nástroj MCP nepodporuje, použijte HTTP koncový bod: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call. Tělo je JSON s p_token (váš token tx_), p_action (například help, my_apps nebo start_campaign) a p_args (například package_name a počet testerů). Pošlete veřejnou hlavičku apikey uvedenou v dokumentaci.

Nejdřív zavolejte akci help: vrátí všechny akce a jejich argumenty. Úplné schéma je na https://testerexchange.com/openapi.json a funguje s akcemi vlastních GPT v ChatGPT i dalšími nástroji OpenAPI.

Karta A2A agenta

Pro nastavení typu agent s agentem Tester Exchange zveřejňuje kartu A2A agenta na https://testerexchange.com/.well-known/agent-card.json. Orchestrátory podporující protokol A2A tak zjistí, co agent nabízí a jak ho volat. Pro vše spojené s vaším účtem použijte stejný token tx_.

Celý průběh od začátku do konce

  1. Nahrajete první .aab na uzavřenou stopu v Play Console.
  2. Váš agent zavolá get_testers pro název balíčku a řekne vám, ať u uzavřené stopy v části Google Groups přidáte testerexchange-testers@googlegroups.com.
  3. Přidáte skupinu, uložíte a ověříte, že je vydání publikováno.
  4. Pokud nemáte kredity, agent vám dá odkaz k platbě. Zaplatíte (12,99 $ za 12 testerů, 14,99 $ za 15, 22,99 $ za 25) nebo získáte kredity zdarma testováním cizích aplikací na https://testerexchange.com/earn.
  5. Skuteční testeři aplikaci 14 dní instalují a používají. Váš agent denně kontroluje průběh a upozorní vás, když aktivních testerů ubývá.
  6. Patnáctý den agent stáhne report kampaně a navrhne odpovědi pro přístup do produkce. Zkontrolujete je a kliknete na Požádat o produkci.

Bezpečnostní poznámky

  • Tokeny nedávejte do gitu. Uložte je do úložiště tajných údajů svého klienta nebo do proměnné prostředí.
  • U nás se tokeny ukládají pouze jako hashe a na účet jich může být nejvýše 10. Token, který nepoužíváte, zrušte.
  • Než formulář pro produkci odešlete, přečtěte si, co do něj agent napsal. Google po vás chce, abyste test popsali pravdivě.

Časté dotazy

Může za mě AI agent absolvovat 14denní test?

Ne. 14 dní vyžaduje skutečné lidi, kteří vaši aplikaci používají na vlastních telefonech. Agenti zvládají nastavení, sledování a reporty.

Může agent zaplatit testery?

Ne. Může vrátit odkazy k platbě, ale platba vždy probíhá v prohlížeči člověka.

Se kterými klienty MCP server funguje?

S každým klientem, který podporuje vzdálené MCP přes Streamable HTTP s vlastní hlavičkou, včetně Claude Code, Claude Desktop, Cursoru a VS Code. Ostatní mohou použít HTTP API.

Kde získám token?

Na https://testerexchange.com/api po přihlášení. Tokeny začínají na tx_ a lze je kdykoli zrušit.

Mění agent něco v mé Play Console?

Ne. K vaší Play Console nemá přístup. Řekne vám kroky, které tam máte udělat.
