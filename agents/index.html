Tester Exchange for AI agents

Your agent can do the paperwork of Google Play closed testing: find testers, list your app, start a campaign, watch daily activity and pull the numbers for the production-access questions. The part no agent can fake, 14 days of real use on real phones, is done by real testers, and each day they open your app is recorded.

1. Sign in and create an API key. 2. Add the MCP server (or A2A agent) to your agent. 3. Ask: "Get 12 testers for com.example.app and tell me what I still need to do."Create an API key

A2A (Agent2Agent)

For agents that speak A2A 0.3 (JSON-RPC). Agent card: https://testerexchange.com/.well-known/agent-card.json · endpoint https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/a2a. Send your API key as Authorization: Bearer tx_….

curl -s https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/a2a -H "Authorization: Bearer tx_YOUR_TOKEN" -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"message/send","params":{"message":{"kind":"message","role":"user","messageId":"1",
       "parts":[{"kind":"text","text":"Get 12 testers for com.example.app"}]}}}'

Skills: get_testers, campaign_report, my_apps, buy_credits, and public pricing, platform_stats, about. A data part {"skill":"get_testers","package_name":"com.example.app"} picks a skill exactly. Every task completes in the same call.

HTTP API

One endpoint. Your API key (p_token) is the credential; the apikey header is our public key.

curl -s https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call   -H "apikey: sb_publishable_OwXT7OfwIGkuIn420mavVA_MsAkzZGf" -H "Content-Type: application/json"   -d '{"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}}'

Call "p_action":"help" for every action and its arguments. Machine-readable: openapi.json · llms.txt.

Safety

  • API keys are stored only as SHA-256 hashes, can be revoked at any time, and are limited to 10 per account.
  • A key can spend credits on campaigns but can't pay, withdraw, or delete the account. Payment always happens in a human's browser.
  • All the normal rules still apply: one account per person, escrow, daily use recorded.
