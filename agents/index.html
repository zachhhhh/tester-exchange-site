HTTP API

One endpoint. The token is the credential; the apikey header is our public key.

curl -s https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call   -H "apikey: sb_publishable_OwXT7OfwIGkuIn420mavVA_MsAkzZGf" -H "Content-Type: application/json"   -d '{"p_token":"tx_YOUR_TOKEN","p_action":"start_campaign","p_args":{"package_name":"com.example.app","testers":15}}'

Call "p_action":"help" for every action and its arguments. Machine-readable: openapi.json · llms.txt.

Safety

  • Tokens are stored only as SHA-256 hashes, can be revoked at any time, and are limited to 10 per account.
  • A token can spend credits on campaigns but can't pay, withdraw, or delete the account. Payment always happens in a human's browser.
  • All the normal rules still apply: one account per phone, escrow, verified daily use.
