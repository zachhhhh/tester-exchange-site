Google Play qapalı testini AI agentlərlə avtomatlaşdırın

Noyabr 2026-da yenilənib

Kodu artıq AI agentlə yazırsınızsa, Google Play-in qapalı test tələbinin əksər texniki işini də ona verə bilərsiniz: tətbiqin əlavə edilməsi, testerlərin cəlb olunması, irəliləyişin yoxlanması və production giriş formu üçün rəqəmlərin çıxarılması. Bunun üçün Tester Exchange-də MCP server, tək endpointli HTTP API və A2A agent kartı var. Bu bələdçi Claude Code, Claude Desktop, Cursor və digər klientləri necə qoşmağı, nə istəməyi və heç bir agentin sizin əvəzinizə edə bilməyəcəyi işləri göstərir.

Agent nə edə bilər, nə edə bilməz

Google 13 noyabr 2023-dən sonra yaradılmış fərdi developer hesablarından production-a müraciətdən əvvəl 14 ardıcıl gün ərzində ən azı 12 testerin opt-in etdiyi qapalı test keçirməyi tələb edir. Bunun ətrafındakı işlərin çoxu koordinasiyadır və agentlər bunu yaxşı bacarır.

  • Agent bacarır: tətbiqinizi əlavə etmək, tester kampaniyası açmaq, kreditlərinizi tətbiq etmək, neçə testerin aktiv olduğunu yoxlamaq, kampaniyanı dayandırmaq və ya bağlamaq, gündəlik aktivlik hesabatını çəkmək və ona əsasən production giriş cavablarının qaralamasını yazmağa kömək etmək.
  • İnsan etməlidir: Play Console-da testerlərin Google Group-unu qapalı trekə əlavə etmək, buraxılışı dərc etmək, kreditlər üçün ödəniş etmək (ödəniş həmişə insanın brauzerində olur) və Apply for production düyməsini basmaq.
  • Heç kim avtomatlaşdıra bilməz: 14 günlük real istifadə. Bunu real insanlar öz Android telefonlarında edir və Google-un qaydasının bütün mənası budur.

1. Token yaradın

  1. https://testerexchange.com/api ünvanında daxil olun.
  2. Şəxsi token yaradın. O tx_ ilə başlayır. İndi kopyalayın və parol kimi saxlayın.
  3. Tokenləri istənilən vaxt ləğv etmək olar. Token kampaniyalarda kredit xərcləyə bilər, amma ödəniş edə, pul çıxara və ya hesabınızı silə bilməz.

2. MCP serverini qoşun

MCP server Streamable HTTP-dən https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp ünvanında istifadə edir. Tokeninizi Authorization: Bearer tx_YOUR_TOKEN başlığında göndərin.

Claude Code: bunu terminalda bir dəfə işə salın.

claude mcp add --transport http tester-exchange https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp --header "Authorization: Bearer tx_YOUR_TOKEN"

Claude Desktop, Cursor, VS Code və JSON konfiqurasiyalı digər klientlər: tester-exchange adlı, http tipli server əlavə edin, yuxarıdakı URL-i yazın və Authorization dəyəri Bearer tx_YOUR_TOKEN olan headers girişi əlavə edin. Konfiqurasiya faylının dəqiq yeri klientdən asılıdır; onun MCP sənədlərinə baxın.

Yalnız URL qəbul edən klientlər (bəzi ChatGPT və veb konnektorları): https://testerexchange.com/agents/ ünvanındakı sənədlərdə onlar üçün URL forması göstərilib. Token olmadan da ictimai alətlər (Tester Exchange nədir, qiymətlər, platforma statistikası) işləyir.

3. Başlamaq üçün tək alət: get_testers

Bütün alət siyahısını öyrənmək lazım deyil. Əsas alət get_testers(package_name, name?)-dir. Bir çağırış tətbiqinizi əlavə edir, testini açır, kreditlərinizi tətbiq edir və irəliləyişinizi, həmçinin yalnız insanın edə biləcəyi addımları (məsələn, Play Console-da Google Group-u əlavə etmək) qaytarır. İrəliləyişi yoxlamaq üçün istənilən vaxt yenidən çağırın.

Digər alətlər təfərrüatları əhatə edir: my_apps, campaign_report (testerlər, gündəlik aktivlik, rəylər və production giriş məlumatları), add_testers, set_campaign_status (dayandır, davam etdir və ya bağla; istifadə olunmamış kreditlər balansınıza qayıdır), share_kit və buy_credits_links (insanın ödəməsi üçün ödəniş linkləri qaytarır).

İşləyən promptlar

  • "com.example.app üçün 15 tester əldə et və Play Console-da nə etməli olduğumu de."
  • "com.example.app üçün Tester Exchange kampaniyamı yoxla. Bu həftə hər gün neçə tester aktiv olub?"
  • "Kampaniya hesabatını çək və production giriş cavablarımın qaralamasını yaz. Yalnız real rəqəmlərdən istifadə et."
  • "Production girişi təsdiqləndiyi üçün com.example.app kampaniyasını bağla."

12 yox, 15 tester istəyin ki, bir nəfərin çıxması sizi Google-un minimumundan aşağı salmasın.

Skriptlər və CI üçün HTTP API

Aləti MCP dəstəkləmirsə, HTTP endpointdən istifadə edin: POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call. Gövdə JSON-dur: p_token (tx_ tokeniniz), p_action (məsələn, help, my_apps və ya start_campaign) və p_args (məsələn, package_name və tester sayı). Sənədlərdə göstərilən ictimai apikey başlığını göndərin.

Əvvəlcə help əməliyyatını çağırın: o, bütün əməliyyatları və arqumentlərini qaytarır. Tam sxem https://testerexchange.com/openapi.json ünvanındadır və ChatGPT custom GPT actions və digər OpenAPI alətləri ilə işləyir.

A2A agent kartı

Agentdən agentə qurulmalar üçün Tester Exchange https://testerexchange.com/.well-known/agent-card.json ünvanında A2A agent kartı dərc edir. A2A protokolunu dəstəkləyən orkestratorlar agentin nə təklif etdiyini və ona necə müraciət etməyi kəşf edə bilər. Hesabınıza bağlı hər şey üçün eyni tx_ tokenindən istifadə edin.

Başdan sona tam proses

  1. Play Console-da qapalı trekə ilk .aab faylınızı yükləyirsiniz.
  2. Agentiniz paket adınız üçün get_testers çağırır və qapalı trekdə Google Groups altında testerexchange-testers@googlegroups.com əlavə etməyi deyir.
  3. Qrupu əlavə edib yadda saxlayırsınız və buraxılışın dərc olunduğuna əmin olursunuz.
  4. Kreditiniz yoxdursa, agent sizə ödəniş linki verir. Ödəyirsiniz (12 tester üçün $12.99, 15 üçün $14.99, 25 üçün $22.99) və ya https://testerexchange.com/earn ünvanında başqa tətbiqləri test edib pulsuz kredit qazanırsınız.
  5. Real testerlər tətbiqinizi 14 gün quraşdırıb istifadə edir. Agentiniz irəliləyişi hər gün yoxlayır və aktiv testerlər azalarsa, sizi xəbərdar edir.
  6. 15-ci gün agent kampaniya hesabatını çəkir və production giriş cavablarınızın qaralamasını yazır. Siz onlara baxıb Apply for production düyməsini basırsınız.

Təhlükəsizlik qeydləri

  • Tokenləri git-dən kənarda saxlayın. Onları klientinizin gizli məlumat anbarında və ya mühit dəyişənində saxlayın.
  • Tokenlər bizdə yalnız hash şəklində saxlanılır və hər hesab üçün 10 ilə məhdudlaşır. İstifadə etmədiyiniz tokeni ləğv edin.
  • Göndərməzdən əvvəl agentin production formunuza yazdığını oxuyun. Google testinizi düzgün təsvir etməyinizi tələb edir.

Tez-tez verilən suallar

AI agent 14 günlük testi mənim əvəzimə tamamlaya bilərmi?

Xeyr. 14 gün üçün tətbiqinizi öz telefonlarında istifadə edən real insanlar lazımdır. Agentlər quraşdırma, monitorinq və hesabatı idarə edir.

Agent testerlər üçün ödəniş edə bilərmi?

Xeyr. O, ödəniş linkləri qaytara bilər, amma ödəniş həmişə insanın brauzerində olur.

Hansı klientlər MCP serveri ilə işləyir?

Xüsusi başlıqla Streamable HTTP üzərindən remote MCP-ni dəstəkləyən hər klient, o cümlədən Claude Code, Claude Desktop, Cursor və VS Code. Digərləri HTTP API-dən istifadə edə bilər.

Tokeni haradan alım?

Daxil olduqdan sonra https://testerexchange.com/api ünvanında. Tokenlər tx_ ilə başlayır və istənilən vaxt ləğv edilə bilər.

Agent Play Console-umda nəyisə dəyişirmi?

Xeyr. Onun Play Console-unuza girişi yoxdur. Orada atmalı olduğunuz addımları o, sizə deyir.
