Android tətbiqinizi Cursor ilə yaratmısınız? 12 testerinizi 14 gün üçün əldə edin

Yenilənib: Noyabr 2026

Cursor Android tətbiqinizi yaza və yarada bilər, lakin Google Play-in tələb etdiyi 12 real testeri təmin edə bilməz. Şəxsi developer hesabınız 13 noyabr 2023-dən sonra yaradılıbsa, istehsalata müraciət etməzdən əvvəl ən azı 12 testerin 14 gün fasiləsiz qoşulduğu qapalı test keçirməlisiniz. Bu bələdçi bundle-ın yaradılmasını, qapalı testin başladılmasını, testerlərin tapılmasını (əvvəlcə pulsuz, sonra ödənişli) və agentin rəsmiyyət işlərini görə bilməsi üçün Tester Exchange-in Cursor-a qoşulmasını əhatə edir.

1. Release bundle-ı (.aab) yaradın

  1. Cursor agentindən modulunuzun build.gradle.kts faylında release imzalanmasını konfiqurasiya etməsini xahiş edin (storeFile, storePassword, keyAlias və keyPassword olan signingConfigs bloku, release build type-a tətbiq olunmaqla). Parolları git-dən kənarda saxlayın (Android build sənədləri: https://developer.android.com/build/building-cmdline).
  2. Terminalda ./gradlew bundleRelease əmrini icra edin. Gradle bundle-ı yaradır və imzalayır; .aab faylı adətən app/build/outputs/bundle/release/ qovluğunda görünür, lakin öz build nəticənizi yoxlayın.
  3. Keystore-unuz yoxdursa, keytool ilə yaradın və ehtiyat nüsxəsini saxlayın. Google Play App Signing ilk buraxılışı yüklədiyiniz zaman təklif olunur.

2. Play Console-da qapalı testi başladın

  1. Test and release > Testing > Closed testing bölməsini açın, sonra Create track (və ya Manage track) seçin.
  2. Create new release düyməsini basın, .aab faylını yükləyin, buraxılış adı və qeydlər əlavə edin, Save as draft, Next, sonra Start rollout seçin (addımlar https://support.google.com/googleplay/android-developer/answer/9859348 ünvanından).
  3. Əvvəlcə Dashboard-dakı tətbiq quraşdırma tapşırıqlarını tamamlayın, əks halda buraxılış düyməsi deaktiv qalır.

3. 12 testerinizi əldə edin: əvvəl pulsuz, sonra ödənişli

  • Pulsuz yol: telefonunuzda https://testerexchange.com/earn ünvanını açın və sizə verilən tətbiqləri test edin. Test etdiyiniz hər tətbiq sizinkinə bir tester gətirir.
  • Ödənişli yol: bir dəfə ödəyin, testerlər avtomatik təyin olunur. Cari qiymətlər https://testerexchange.com/llms.txt ünvanında göstərilib.
  • 12 əvəzinə 15 tester istəyin ki, bir nəfərin çıxması sizi Google-un minimumundan aşağı salmasın.

4. Tester Exchange-i Cursor-a qoşun (könüllü)

Əvvəlcə https://testerexchange.com/api ünvanında API açarı yaradın. Sonra bunu layihənizdəki .cursor/mcp.json faylına, ya da hər yerdə istifadə etmək üçün ~/.cursor/mcp.json faylına yazın (fayl yerləri Cursor-un MCP sənədlərindəndir, https://cursor.com/docs/context/mcp). Açarın commit olunmaması üçün əvvəlcə shell mühitində TESTER_EXCHANGE_KEY dəyişənini təyin edin:

{"mcpServers":{"tester-exchange":{"url":"https://vvrlxzbngxfxddywidoq.supabase.co/functions/v1/mcp","headers":{"Authorization":"Bearer ${env:TESTER_EXCHANGE_KEY}"}}}}

Cursor ${env:NAME} ifadəsini url və headers sahələrində həll edir. Server yüklənmirsə, Output panelini açın və MCP Logs seçin. Server OAuth olmadan Streamable HTTP üzərindən adi MCP-dir; açıq alətlər (about, pricing, platform_stats) açarsız işləyir.

5. Agentdən xahiş edin

  • "Tester Exchange ilə com.example.app üçün 15 tester əldə et və Play Console-da nə etməli olduğumu de."
  • "com.example.app üçün Tester Exchange kampaniyamı yoxla və dünən neçə testerin aktiv olduğunu de."
  • "Kampaniya hesabatını çək və istehsalata çıxış cavablarımın qaralamasını real rəqəmlərə əsasən hazırla."

Əsas alət get_testers-dir: o, tətbiqi əlavə edir, testini açır və yalnız insanın edə biləcəyi addımları qaytarır, məsələn, Play Console-da testerlərin Google Group-unu əlavə etmək. Agent sizin əvəzinizə ödəniş edə və ya Apply for production düyməsini basa bilməz.

MCP yoxdur? HTTP API-dən istifadə edin

POST https://vvrlxzbngxfxddywidoq.supabase.co/rest/v1/rpc/agent_call ünvanına, https://testerexchange.com/agents/ səhifəsində göstərilən açıq apikey başlığı ilə və {"p_token":"tx_YOUR_TOKEN","p_action":"get_testers","p_args":{"package_name":"com.example.app"}} gövdəsi ilə sorğu göndərin. Sxem https://testerexchange.com/openapi.json ünvanındadır. Digər alətlər: https://testerexchange.com/guide/ai-builders/.

Tez-tez verilən suallar

Cursor 14 günlük testi mənim üçün tamamlaya bilərmi?

Xeyr. 14 gün üçün real insanlar tətbiqinizdən öz Android telefonlarında istifadə etməlidir. Cursor tətbiqi yarada və qurulumu idarə edə bilər.

Tester Exchange rəsmi Cursor inteqrasiyasıdır?

Xeyr. Bu, HTTP üzərindən uzaq MCP-ni dəstəkləyən istənilən klientlə işləyən müstəqil xidmətdir; Cursor da belədir.

AAB hara yüklənir?

Onu Play Console-da qapalı test buraxılışına yükləyin, sonra həmin track-də testerlərinizin Google Group-unu və ya e-poçt siyahısını əlavə edin.

12 testeri əldə etməyin pulsuz yolu var?

Bəli. https://testerexchange.com/earn ünvanında digər developerlərin tətbiqlərini test edin; test etdiyiniz hər tətbiq sizinkinə bir tester gətirir.
